# 内部汇报PPT设计规范手册

> 基于公司内部汇报材料总结的专业PPT设计标准

---

## 一、色彩体系规范 🎨

### 1.1 主色调：蓝色系（企业主色）

#### 标准色值

- **主标题蓝**：`#0066FF` / `RGB(0, 102, 255)`
  - 用途：页面顶部标题栏背景
  - 特征：鲜艳、饱和度高、科技感强

- **内容蓝**：`#3399FF` / `RGB(51, 153, 255)`
  - 用途：一级标题背景、重要按钮
  - 特征：中等明度，易读性好

- **浅蓝**：`#66B3FF` ~ `#CCE5FF`
  - 用途：次级标题、卡片背景、虚线边框
  - 特征：柔和、不抢眼、层次丰富

#### 蓝色使用原则

1. **主标题区**：100%饱和度蓝色，形成强烈视觉锚点
2. **内容区**：渐变式使用，从深到浅建立层次
3. **边框线**：使用中等明度蓝色虚线（#4D94FF）
4. **文字强调**：深蓝色（#0052CC）用于重点文字

### 1.2 辅助色：黄色/金色

#### 标准色值

- **金黄色**：`#FFB800` / `RGB(255, 184, 0)`
  - 用途：装饰元素、次要信息模块、对比强调

- **浅黄色**：`#FFD54F` / `RGB(255, 213, 79)`
  - 用途：辅助说明框、标签背景

#### 黄色使用原则

1. **右上角装饰三角**：必备元素，蓝白黄三色组合
2. **对比板块**：当需要与蓝色板块区分时使用（如"工具及协同部门"板块）
3. **强调标签**：重要数字、关键词的背景色
4. **配比限制**：黄色面积不超过页面的20%

### 1.3 中性色：白色和灰色

- **纯白**：`#FFFFFF` - 主要背景色
- **浅灰**：`#F5F5F5` - 次要背景色、内容区域底色
- **中灰**：`#E0E0E0` - 分隔线、不重要边框
- **深灰**：`#333333` - 正文文字（非强调内容）

### 1.4 警示色：红色（谨慎使用）

- **警示红**：`#FF0000` / `RGB(255, 0, 0)`
  - 用途：极度重要的核心目标、关键数据
  - 使用频率：每页不超过1-2处
  - 示例："核心目标条幅"、重大风险提示

## 二、版式布局规范 📐

### 2.1 页面结构（标准16:9比例）

```
┌─────────────────────────────────────────────────┐
│ 标题区域（10-15%高度）                          │ 蓝色背景 + 右上角三角装饰
├─────────────────────────────────────────────────┤
│                                                 │
│          内容区域（80-85%高度）                 │ 白色/浅灰背景
│                                                 │
│   [留白]  [模块] [模块] [模块]  [留白]         │
│                                                 │
├─────────────────────────────────────────────────┤
│ 页码区域（5%高度）                              │ 右下角小字
└─────────────────────────────────────────────────┘
```

### 2.2 标题区域设计

#### 结构要素

1. **背景色**：渐变蓝色（从 #0066FF 到 #0052D9）
2. **标题文字**：
   - 颜色：纯白色 `#FFFFFF`
   - 字号：40-48pt
   - 字体：微软雅黑 Bold / 思源黑体 Bold
   - 对齐：左对齐，左边距约占宽度的3%
3. **装饰元素**：
   - 右上角三角形组合（蓝、白、黄三色）
   - 尺寸：约占标题区高度的100%
   - 样式：几何扁平风格

#### 标题文字规范

- **主标题**：产品名称/主题名称
  - 示例：`汉云AI产品研发`、`考核机制`
- **副标题**（可选）：补充说明
  - 字号：20-24pt
  - 位置：主标题下方或右侧
  - 颜色：白色，透明度90%

### 2.3 内容区域布局

#### 布局模式选择

##### 模式1：多栏架构图（用于产品架构、组织结构）

```
┌──────┬──────┬──────┬──────┬──────┐
│ 栏1  │ 栏2  │ 栏3  │ 栏4  │ 栏5  │
│      │      │      │      │      │
│ [模块] [模块] [模块] [模块] [模块] │
│ [模块] [模块] [模块] [模块] [模块] │
│ [模块] [模块] [模块] [模块] [模块] │
└──────┴──────┴──────┴──────┴──────┘
```

- **适用场景**：产品功能展示、技术栈展示
- **栏数**：3-5栏
- **间距**：栏间距约2-3%页面宽度
- **对齐**：顶部对齐

##### 模式2：左右对比型（用于原则说明、方案对比）

```
┌─────────────────┬─────────────────┐
│                 │                 │
│   左侧内容      │   右侧内容      │
│   （原则/痛点） │   （方案/对比） │
│                 │                 │
└─────────────────┴─────────────────┘
```

- **适用场景**：对比分析、原则与实践对照
- **比例**：通常 1:1 或 4:6
- **分隔**：使用细灰线或留白

##### 模式3：流程图型（用于流程介绍、智能体工作流）

```
┌────┐    ┌────┐    ┌────┐    ┌────┐
│步骤1│ ──→│步骤2│ ──→│步骤3│ ──→│步骤4│
└────┘    └────┘    └────┘    └────┘
   ↑                              │
   └──────────────────────────────┘
```

- **适用场景**：流程展示、系统架构
- **方向**：横向流程（主要）、纵向流程（次要）
- **连接**：蓝色箭头，线宽2-3pt

##### 模式4：卡片网格型（用于产品展示、功能列表）

```
┌──────┐  ┌──────┐  ┌──────┐
│ 卡片1│  │ 卡片2│  │ 卡片3│
└──────┘  └──────┘  └──────┘

┌──────┐  ┌──────┐  ┌──────┐
│ 卡片4│  │ 卡片5│  │ 卡片6│
└──────┘  └──────┘  └──────┘
```

- **适用场景**：功能点展示、产品特性
- **卡片尺寸**：统一或自适应
- **间距**：横向和纵向间距一致（2-3%页面宽度）

### 2.4 边距和留白规范

#### 页面边距

- **左右边距**：5-7% 页面宽度
- **上边距**（内容区）：3-5% 页面高度
- **下边距**：5% 页面高度（预留页码空间）

#### 元素间距

- **标题与内容间距**：20-30px
- **段落间距**：15-20px
- **卡片间距**：30-40px
- **栏间距**：40-60px

#### 留白原则

1. **呼吸感**：信息密集页面必须增加留白，避免拥挤
2. **视觉平衡**：左右、上下留白基本对称
3. **聚焦引导**：通过留白引导视线流动

## 三、字体规范 ✍️

### 3.1 字体选择

#### 首选字体

- **中文**：微软雅黑（Microsoft YaHei）
  - 备选：思源黑体（Source Han Sans）、阿里巴巴普惠体
- **英文**：Arial / Helvetica
  - 备选：Segoe UI、San Francisco

#### 禁用字体

❌ 宋体、楷体、艺术字体（除特殊设计需求）

### 3.2 字号层级体系

| 层级         | 字号    | 字重    | 颜色         | 用途               |
| ------------ | ------- | ------- | ------------ | ------------------ |
| **H1**       | 40-48pt | Bold    | 白色         | 页面主标题         |
| **H2**       | 28-32pt | Bold    | 蓝色/白色    | 一级板块标题       |
| **H3**       | 20-24pt | Bold    | 蓝色         | 二级标题、卡片标题 |
| **H4**       | 16-18pt | Medium  | 深灰/蓝色    | 三级标题、列表标题 |
| **正文**     | 14-16pt | Regular | 深灰 #333333 | 正文内容           |
| **辅助文字** | 12-14pt | Regular | 中灰 #666666 | 说明文字、注释     |
| **页码**     | 10-12pt | Regular | 浅灰 #999999 | 页码、版权信息     |

### 3.3 文字样式规范

#### 强调样式

1. **加粗**：重要词汇、关键数据
2. **颜色强调**：蓝色（#0066FF）用于产品名、技术术语
3. **背景色强调**：浅蓝色背景 + 深蓝文字（用于核心指标）

#### 段落样式

- **行距**：1.5倍（正文）、1.3倍（标题）
- **段落间距**：0.5-1倍行距
- **对齐方式**：
  - 标题：左对齐（主流）、居中（特殊页面）
  - 正文：左对齐、两端对齐（长文本）
  - 数据：居中或右对齐

#### 列表样式

- **项目符号**：
  - 菱形符号（◆）蓝色
  - 箭头符号（▶）蓝色
  - 数字编号（①②③）白底蓝字圆形
- **缩进**：2个字符
- **行距**：1.2-1.5倍

## 四、图形与图标规范 🎯

### 4.1 几何图形库

#### 矩形框（最常用）

- **标准圆角矩形**：
  - 圆角半径：5-8px（小卡片）、10-15px（大板块）
  - 边框：2pt蓝色虚线（#4D94FF）
  - 填充：白色/浅灰色/浅蓝色
  - 用途：内容分组、卡片背景

- **直角矩形**：
  - 边框：实线，1-2pt
  - 用途：表格、数据展示

#### 按钮样式

- **主按钮**：
  - 背景：蓝色渐变（#0066FF → #3399FF）
  - 文字：白色，16-18pt，Bold
  - 圆角：5px
  - 阴影：可选，Y轴偏移2px，模糊5px，#000 20%

- **次按钮**：
  - 背景：白色
  - 边框：2pt蓝色
  - 文字：蓝色，16-18pt，Medium

#### 装饰图形

1. **右上角三角组合**（标志性元素）：

   ```
   ┌───────────────┐
   │           ╱│  │ ← 白色三角
   │         ╱  │╲ │ ← 黄色三角
   │       ╱────│─╲│ ← 蓝色三角
   ```

   - 必备：每页都有
   - 位置：右上角，与标题区齐平
   - 尺寸：高度=标题区高度，宽度自适应

2. **分隔线**：
   - 实线：1pt，#E0E0E0，用于板块分隔
   - 虚线：2pt，#4D94FF，用于内容分组

### 4.2 图标设计规范

#### 风格统一

- **类型**：扁平化图标（Flat Design）
- **风格**：线性图标（Line Icon）或面性图标（Fill Icon）
- **颜色**：单色（蓝色系）或双色（蓝+白）
- **尺寸**：32x32px、48x48px、64x64px（根据场景选择）

#### 常用图标库

- 推荐使用：Iconfont（阿里巴巴矢量图标库）、Feather Icons
- 避免使用：过于复杂的插画、3D图标

#### 图标使用原则

1. **一致性**：同一页面图标风格必须统一
2. **语义性**：图标含义清晰，避免歧义
3. **辅助性**：图标配文字说明，不单独使用

### 4.3 流程图与架构图

#### 流程图节点

- **形状**：圆角矩形（推荐）、圆形（起止点）、菱形（判断点）
- **颜色**：
  - 主流程：蓝色渐变（#0066FF → #66B3FF）
  - 子流程：浅蓝色（#CCE5FF）
  - 结果节点：黄色（#FFB800）
- **大小**：宽 120-180px，高 50-80px
- **文字**：白色（深色背景）/ 深蓝色（浅色背景），14-16pt，居中

#### 连接线

- **箭头**：
  - 颜色：蓝色（#0066FF）
  - 线宽：2-3pt
  - 样式：直线（主要）、曲线（复杂关系）
- **流向**：从左至右、从上至下（符合阅读习惯）

#### 架构图设计

- **分层**：使用颜色和位置区分层级
  - 平台层：深蓝色
  - 功能层：中蓝色
  - 应用层：浅蓝色
- **分组**：虚线边框框选相关模块
- **标签**：每个模块必须有清晰标签

## 五、内容编排规范 📝

### 5.1 信息层次设计

#### 金字塔原则

```
         [核心结论/目标]
              ↓
    [3-5个支撑论点]
              ↓
  [详细数据/案例/说明]
```

#### 每页信息量控制

- **标题**：1个主标题（必须）
- **核心观点**：1-3个
- **支撑论据**：3-7个
- **文字总量**：不超过200字（理想）、不超过300字（上限）

### 5.2 内容模块化

#### 标准卡片设计

```
┌─────────────────────────────┐
│ [图标] 卡片标题            │ ← 蓝色背景，白色文字
├─────────────────────────────┤
│                             │
│  • 要点1                    │
│  • 要点2                    │
│  • 要点3                    │
│                             │
└─────────────────────────────┘
```

- **卡片标题**：简洁（4-8字）、有概括性
- **内容组织**：列表式（推荐）、段落式（少用）
- **视觉效果**：阴影、边框、背景色区分

#### 模块组合规则

1. **对称布局**：2/4/6个卡片
2. **不对称布局**：3/5个卡片（中间或两侧对齐）
3. **留白**：卡片间距统一

### 5.3 文案撰写规范

#### 标题文案

- **简洁有力**：4-12字
- **动宾结构**：优先使用（如"汉云AI产品研发"）
- **专业术语**：可使用，但需通俗易懂
- **避免**：过长标题、模糊表述

#### 正文文案

- **要点突出**：使用列表、加粗、颜色
- **数据支撑**：关键指标必须量化
  - 示例：`资源需求节约80%`、`CPU从95%降至30%`
- **逻辑清晰**：总分总结构、并列关系、递进关系
- **避免**：大段文字、复杂句式

#### 数据展示

- **数字格式**：
  - 大数字：使用千分位（1,234,567）
  - 百分比：保留1-2位小数（73.5%）
  - 金额：带单位（123万元）
- **数字强调**：
  - 字号放大（24-36pt）
  - 颜色：蓝色或红色
  - 背景：浅色圆角矩形

## 六、特殊页面类型规范 📄

### 6.1 封面页

#### 结构

```
┌─────────────────────────────────────┐
│                                     │
│         [公司Logo]                  │
│                                     │
│       【PPT主题标题】               │
│       （大号粗体）                  │
│                                     │
│         副标题/日期                 │
│                                     │
│                                     │
│    汇报人：XXX  |  日期：XXXX-XX-XX│
└─────────────────────────────────────┘
```

#### 设计要点

- **背景**：蓝色渐变或白色简洁背景
- **主题**：居中，60-72pt
- **装饰**：右上角三角（可选）、几何图形点缀

### 6.2 目录页

#### 布局

- **纵向列表**：

  ```
  目录

  01  章节名称1
  02  章节名称2
  03  章节名称3
  04  章节名称4
  ```

- **卡片式**：
  ```
  ┌──────┐  ┌──────┐
  │  01  │  │  02  │
  │ XX章 │  │ XX章 │
  └──────┘  └──────┘
  ```

#### 设计要点

- **数字标签**：蓝色圆形，白色数字
- **章节名称**：16-20pt，左对齐
- **页码**：可选，使用虚线连接

### 6.3 过渡页（章节分隔页）

#### 极简设计

```
┌─────────────────────────────────────┐
│                                     │
│                                     │
│            01                       │
│                                     │
│          章节标题                   │
│                                     │
│                                     │
└─────────────────────────────────────┘
```

- **背景**：纯蓝色或蓝色渐变
- **数字**：超大号（72-96pt），白色，半透明
- **标题**：48-60pt，白色

### 6.4 总结页

#### 结构

```
总结 / 下一步计划

✓ 核心成果1
✓ 核心成果2
✓ 核心成果3

→ 下一步行动1
→ 下一步行动2
```

#### 设计要点

- **符号**：对勾（✓）、箭头（→）、星号（★）
- **颜色**：成果用蓝色，行动用黄色
- **布局**：左对齐或居中

### 6.5 产品架构图页（重点）

#### 布局特征

- **横向分栏**：3-5个大栏
- **纵向分层**：每栏内有多个子模块
- **色彩编码**：不同类别使用不同蓝色深浅

#### 示例结构（参考"汉云AI产品研发"页面）

```
┌──────┬──────┬──────┬──────┬──────┐
│平台类│ 应用1│ 应用2│ 行业 │ 基础 │
├──────┼──────┼──────┼──────┼──────┤
│ 模块 │ 模块 │ 模块 │ 模块 │ 模块 │
│ 模块 │ 模块 │ 模块 │ 模块 │ 模块 │
│ 模块 │ 模块 │ 模块 │ 模块 │ 模块 │
├──────┼──────┴──────┼──────┴──────┤
│ 模块 │   模块组     │   模块组   │
└──────┴──────────────┴─────────────┘
```

#### 设计要点

1. **顶部说明**：用虚线边框框选，说明产品定位和能力
2. **栏标题**：蓝色背景，白色文字，占栏宽100%
3. **模块卡片**：
   - 统一使用圆角矩形
   - 蓝色边框或蓝色填充
   - 文字居中，12-14pt
4. **分组**：相关模块用虚线大框包裹

### 6.6 方案介绍页（重点）

#### 布局（左右结构）

```
┌──────────────┬─────────────────┐
│              │                 │
│  核心痛点    │   技术方案      │
│  (左侧)      │   (右侧)        │
│              │                 │
│  • 痛点1     │   智能体层      │
│  • 痛点2     │   算法层        │
│  • 痛点3     │   数据层        │
│  • 痛点4     │   算力层        │
│              │                 │
└──────────────┴─────────────────┘
```

#### 设计要点（参考"AI应用场景2"页面）

1. **左侧痛点区**：
   - 白色背景
   - 菱形符号（◆）+ 文字描述
   - 14-16pt，行距1.5

2. **右侧方案区**：
   - 分层架构图
   - 每层用蓝色矩形框表示
   - 层内有多个虚线框子模块

3. **顶部核心目标**：
   - 红色文字标注
   - 蓝色底纹强调
   - 字号18-20pt

## 七、动画与交互规范 🎬

### 7.1 动画原则

#### 使用场景

✅ **适合使用动画**：

- 汇报演示（路演、述职）
- 流程展示（逐步展开）
- 重点强调（数据跳动、颜色变化）

❌ **不适合使用动画**：

- 打印材料
- 快速翻阅场景
- 技术文档

#### 动画类型

1. **进入动画**：
   - 推荐：淡入（Fade In）、上浮（Float In）
   - 时长：0.3-0.5秒
   - 顺序：从上到下、从左到右

2. **强调动画**：
   - 推荐：放大/缩小（Pulse）、颜色变化
   - 时长：0.5-1秒
   - 触发：点击或自动

3. **退出动画**：
   - 少用：仅在页面切换时使用
   - 推荐：淡出（Fade Out）

### 7.2 交互设计

#### 超链接

- **颜色**：蓝色（#0066FF），下划线
- **悬停效果**：颜色加深（#0052CC）
- **用途**：跳转其他页面、外部链接

#### 可点击元素

- **视觉提示**：阴影、边框加粗
- **鼠标样式**：指针（Pointer）
- **反馈**：点击后颜色变化

## 八、高级技巧与最佳实践 🏆

### 8.1 对比与强调技巧

#### 颜色对比

- **蓝黄对比**：主次信息区分（如"考核机制"页面）
  - 人天投入：蓝色板块
  - 工具及协同部门：黄色板块

#### 大小对比

- **放大关键数据**：字号是正文的2-3倍
- **缩小辅助信息**：字号是正文的0.7-0.8倍

#### 位置对比

- **上方=重要**：核心信息置顶
- **中央=焦点**：最重要内容居中
- **下方=支撑**：详细数据置底

### 8.2 视觉引导技巧

#### 视线流动路径

- **Z型路径**：左上 → 右上 → 左下 → 右下（西方阅读习惯）
- **F型路径**：上中下逐行扫描（列表型页面）

#### 引导元素

1. **箭头**：明确指向，2-3pt线宽
2. **连接线**：表示关系，虚线/实线
3. **编号**：表示顺序，圆形标签
4. **颜色**：热点用蓝色，冷点用灰色

### 8.3 信息密度控制

#### 低密度页面（推荐）

- **文字量**：100-150字
- **元素数量**：3-5个
- **留白比例**：40-50%
- **适用**：战略汇报、高层汇报

#### 中密度页面（常用）

- **文字量**：150-250字
- **元素数量**：5-8个
- **留白比例**：30-40%
- **适用**：产品介绍、方案汇报

#### 高密度页面（慎用）

- **文字量**：250-350字
- **元素数量**：8-12个
- **留白比例**：20-30%
- **适用**：架构图、详细数据
- **注意**：必须加强视觉分组，避免混乱

### 8.4 多页面一致性

#### 必须统一的元素

1. **标题区高度**：所有内容页统一
2. **右上角装饰**：位置、大小、颜色统一
3. **字体字号**：同级标题必须一致
4. **色彩使用**：蓝色色值统一
5. **边距留白**：上下左右边距统一

#### 可变化的元素

1. **布局方式**：根据内容选择（多栏、对比、流程）
2. **卡片数量**：根据信息量调整
3. **图表类型**：根据数据类型选择

### 8.5 常见错误与避免

#### ❌ 错误示范

1. **信息过载**：一页超过10个要点
2. **颜色混乱**：使用5种以上主色调
3. **字号不一致**：同级标题字号不同
4. **对齐混乱**：元素左对齐、居中混用
5. **留白不足**：元素紧密堆砌

#### ✅ 正确做法

1. **精简信息**：一页一个核心观点
2. **色彩克制**：蓝+黄+白+灰，不超过4种
3. **建立字号体系**：H1/H2/H3/正文层级分明
4. **严格对齐**：使用参考线、网格
5. **增加留白**：元素间距≥30px
