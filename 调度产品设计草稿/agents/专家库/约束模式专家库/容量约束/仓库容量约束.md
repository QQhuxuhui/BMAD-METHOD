## 📖 约束概述

### 定义

**仓库容量约束**（Warehouse Capacity Constraint）规定仓库的最大存储能力，确保库存量不超过仓库容量限制。

**数学定义**：

```
对于仓库 w，定义:
  Q_w: 仓库 w 的总容量
  I_w(t): 时间 t 的库存量
  q_i: 物品 i 的体积/重量

容量约束:
  ∑ q_i × I_i(t) ≤ Q_w  ∀t

多维度约束:
  体积约束: ∑ v_i × I_i ≤ V_w
  重量约束: ∑ m_i × I_i ≤ M_w
  托盘约束: ∑ p_i × I_i ≤ P_w
```

### 约束类型

#### 1. **总量容量约束** (Total Capacity)

```
仓库总容量不能超过限制
I_total ≤ Q_max

例如:
  仓库最大容量: 10000 m³
  当前库存: 8500 m³
  可用容量: 1500 m³
```

#### 2. **分区容量约束** (Zone Capacity)

```
仓库按区域划分，每个区域有独立容量
I_zone_k ≤ Q_zone_k  ∀k

例如:
  冷藏区: 2000 m³
  常温区: 5000 m³
  危险品区: 500 m³
```

#### 3. **动态容量约束** (Dynamic Capacity)

```
考虑时间维度的库存变化
I(t) = I(t-1) + arrivals(t) - shipments(t)
I(t) ≤ Q_max  ∀t

要求:
  任何时刻库存都不能超出容量
```

#### 4. **多仓库网络约束** (Multi-Warehouse Network)

```
多个仓库协同，总容量分配优化
∑_w I_w ≤ ∑_w Q_w
min ∑_w c_w × I_w  (最小化仓储成本)
```

## 💡 核心理论

### ABC库存分类

**用途**：按价值和周转率对库存分类，优化存储策略。

**分类标准**：

```
A类: 20%的物品占80%的价值 - 严格控制
B类: 30%的物品占15%的价值 - 中等控制
C类: 50%的物品占5%的价值  - 宽松控制

存储策略:
  A类: 快速存取区，高频盘点
  B类: 次要区域，定期盘点
  C类: 远端区域，低频盘点
```

### 经济订货批量 (EOQ)

**用途**：确定最优订货量，平衡订货成本和持有成本。

```python
def calculate_eoq(annual_demand, ordering_cost, holding_cost_per_unit):
    """
    经济订货批量公式

    EOQ = √(2 × D × S / H)

    参数:
      D: 年需求量
      S: 单次订货成本
      H: 单位持有成本（年）

    返回:
      eoq: 最优订货量
    """
    import math
    eoq = math.sqrt((2 * annual_demand * ordering_cost) / holding_cost_per_unit)
    return eoq

# 相关计算
def calculate_total_cost(eoq, annual_demand, ordering_cost, holding_cost):
    """总成本 = 订货成本 + 持有成本"""
    ordering_cost_total = (annual_demand / eoq) * ordering_cost
    holding_cost_total = (eoq / 2) * holding_cost
    return ordering_cost_total + holding_cost_total

def calculate_reorder_point(daily_demand, lead_time, safety_stock=0):
    """再订货点 = 提前期需求 + 安全库存"""
    return (daily_demand * lead_time) + safety_stock
```

### 库存周转率

```python
def calculate_turnover_rate(cogs, average_inventory):
    """
    库存周转率 = 销货成本 / 平均库存价值

    高周转率: 库存管理效率高，占用资金少
    低周转率: 库存积压，资金占用多
    """
    return cogs / average_inventory if average_inventory > 0 else 0
```

## 🔧 代码实现

```python
from typing import Dict, List, Tuple, Optional
from dataclasses import dataclass
from datetime import datetime, timedelta
from enum import Enum
import math

class CapacityDimension(Enum):
    """容量维度"""
    VOLUME = "volume"       # 体积 (m³)
    WEIGHT = "weight"       # 重量 (kg)
    PALLETS = "pallets"     # 托盘数
    UNITS = "units"         # 件数

class ABCClass(Enum):
    """ABC分类"""
    A = "A"  # 高价值、高周转
    B = "B"  # 中等
    C = "C"  # 低价值、低周转

@dataclass
class Item:
    """物品定义"""
    id: str
    volume: float = 0       # m³
    weight: float = 0       # kg
    pallets: float = 0      # 托盘数
    value: float = 0        # 单价
    abc_class: ABCClass = ABCClass.C

@dataclass
class WarehouseZone:
    """仓库分区"""
    id: str
    capacity_volume: float
    capacity_weight: float
    capacity_pallets: int
    current_volume: float = 0
    current_weight: float = 0
    current_pallets: int = 0
    zone_type: str = "general"  # general, cold, hazardous

@dataclass
class Warehouse:
    """仓库定义"""
    id: str
    zones: Dict[str, WarehouseZone]
    total_capacity_volume: float
    total_capacity_weight: float
    total_capacity_pallets: int

    @property
    def current_volume(self):
        return sum(zone.current_volume for zone in self.zones.values())

    @property
    def current_weight(self):
        return sum(zone.current_weight for zone in self.zones.values())

    @property
    def current_pallets(self):
        return sum(zone.current_pallets for zone in self.zones.values())

    @property
    def utilization_volume(self):
        return (self.current_volume / self.total_capacity_volume * 100
                if self.total_capacity_volume > 0 else 0)

class WarehouseCapacityConstraintHandler:
    """仓库容量约束处理器"""

    def __init__(self, warehouses: Dict[str, Warehouse],
                 items: Dict[str, Item]):
        """
        参数:
          warehouses: {warehouse_id: Warehouse}
          items: {item_id: Item}
        """
        self.warehouses = warehouses
        self.items = items

    def validate(self, inventory: Dict[str, Dict[str, float]]) -> Tuple[bool, List[Dict]]:
        """
        验证库存是否满足容量约束

        参数:
          inventory: {warehouse_id: {item_id: quantity}}

        返回:
          (is_valid, violations)
        """
        violations = []

        for warehouse_id, items_qty in inventory.items():
            warehouse = self.warehouses.get(warehouse_id)
            if not warehouse:
                continue

            # 计算总需求
            total_volume = 0
            total_weight = 0
            total_pallets = 0

            for item_id, quantity in items_qty.items():
                item = self.items.get(item_id)
                if not item:
                    continue

                total_volume += item.volume * quantity
                total_weight += item.weight * quantity
                total_pallets += math.ceil(item.pallets * quantity)

            # 检查容量违反
            violations_found = []

            if total_volume > warehouse.total_capacity_volume:
                overflow = total_volume - warehouse.total_capacity_volume
                overflow_percent = (overflow / warehouse.total_capacity_volume) * 100

                violations_found.append({
                    'dimension': 'volume',
                    'overflow': overflow,
                    'overflow_percent': round(overflow_percent, 2),
                    'penalty': overflow_percent * 10
                })

            if total_weight > warehouse.total_capacity_weight:
                overflow = total_weight - warehouse.total_capacity_weight
                overflow_percent = (overflow / warehouse.total_capacity_weight) * 100

                violations_found.append({
                    'dimension': 'weight',
                    'overflow': overflow,
                    'overflow_percent': round(overflow_percent, 2),
                    'penalty': overflow_percent * 10
                })

            if total_pallets > warehouse.total_capacity_pallets:
                overflow = total_pallets - warehouse.total_capacity_pallets
                overflow_percent = (overflow / warehouse.total_capacity_pallets) * 100

                violations_found.append({
                    'dimension': 'pallets',
                    'overflow': overflow,
                    'overflow_percent': round(overflow_percent, 2),
                    'penalty': overflow_percent * 15
                })

            for v in violations_found:
                violations.append({
                    'type': 'warehouse_capacity_overflow',
                    'warehouse': warehouse_id,
                    **v
                })

        return len(violations) == 0, violations

    def validate_zone(self, warehouse_id: str,
                     zone_inventory: Dict[str, Dict[str, float]]) -> Tuple[bool, List[Dict]]:
        """
        验证分区容量约束

        参数:
          zone_inventory: {zone_id: {item_id: quantity}}
        """
        violations = []
        warehouse = self.warehouses.get(warehouse_id)

        if not warehouse:
            return True, []

        for zone_id, items_qty in zone_inventory.items():
            zone = warehouse.zones.get(zone_id)
            if not zone:
                continue

            # 计算分区需求
            zone_volume = sum(
                self.items[item_id].volume * qty
                for item_id, qty in items_qty.items()
                if item_id in self.items
            )

            zone_weight = sum(
                self.items[item_id].weight * qty
                for item_id, qty in items_qty.items()
                if item_id in self.items
            )

            # 检查分区容量
            if zone_volume > zone.capacity_volume:
                violations.append({
                    'type': 'zone_capacity_overflow',
                    'warehouse': warehouse_id,
                    'zone': zone_id,
                    'dimension': 'volume',
                    'overflow': zone_volume - zone.capacity_volume,
                    'penalty': (zone_volume - zone.capacity_volume) * 5
                })

        return len(violations) == 0, violations

    def calculate_eoq(self, item_id: str,
                     annual_demand: float,
                     ordering_cost: float,
                     holding_cost_rate: float) -> Dict:
        """
        计算经济订货批量

        参数:
          annual_demand: 年需求量
          ordering_cost: 单次订货成本
          holding_cost_rate: 年持有成本率 (占单价百分比)

        返回:
          eoq_info: {eoq, total_cost, reorder_point, ...}
        """
        item = self.items.get(item_id)
        if not item:
            return {}

        holding_cost_per_unit = item.value * holding_cost_rate

        # EOQ公式
        eoq = math.sqrt((2 * annual_demand * ordering_cost) / holding_cost_per_unit)

        # 总成本
        ordering_cost_total = (annual_demand / eoq) * ordering_cost
        holding_cost_total = (eoq / 2) * holding_cost_per_unit
        total_cost = ordering_cost_total + holding_cost_total

        # 订货频率
        orders_per_year = annual_demand / eoq

        return {
            'eoq': round(eoq, 2),
            'total_cost': round(total_cost, 2),
            'ordering_cost': round(ordering_cost_total, 2),
            'holding_cost': round(holding_cost_total, 2),
            'orders_per_year': round(orders_per_year, 2),
            'order_interval_days': round(365 / orders_per_year, 1)
        }

    def calculate_reorder_point(self, daily_demand: float,
                               lead_time_days: int,
                               service_level: float = 0.95) -> float:
        """
        计算再订货点

        参数:
          daily_demand: 日需求量
          lead_time_days: 供货提前期（天）
          service_level: 服务水平 (默认95%)

        返回:
          reorder_point: 再订货点
        """
        # 提前期需求
        lead_time_demand = daily_demand * lead_time_days

        # 安全库存（简化模型，假设需求标准差 = 日需求量 * 0.2）
        demand_std = daily_demand * 0.2
        lead_time_std = demand_std * math.sqrt(lead_time_days)

        # Z值查表（95% → 1.65，99% → 2.33）
        z_score = 1.65 if service_level == 0.95 else 2.33
        safety_stock = z_score * lead_time_std

        reorder_point = lead_time_demand + safety_stock

        return round(reorder_point, 2)

    def optimize_allocation(self, total_inventory: Dict[str, float],
                          priority: str = "cost") -> Dict[str, Dict[str, float]]:
        """
        多仓库库存优化分配

        参数:
          total_inventory: {item_id: total_quantity}
          priority: 优化目标 ("cost", "utilization", "distance")

        返回:
          allocation: {warehouse_id: {item_id: quantity}}
        """
        allocation = {wh_id: {} for wh_id in self.warehouses}

        for item_id, total_qty in total_inventory.items():
            item = self.items.get(item_id)
            if not item:
                continue

            # 按容量可用性排序仓库
            available_warehouses = []

            for wh_id, warehouse in self.warehouses.items():
                available_volume = warehouse.total_capacity_volume - warehouse.current_volume
                available_weight = warehouse.total_capacity_weight - warehouse.current_weight

                # 检查是否能容纳
                if (available_volume >= item.volume * total_qty and
                    available_weight >= item.weight * total_qty):

                    available_warehouses.append((wh_id, available_volume))

            # 按可用容量排序
            available_warehouses.sort(key=lambda x: x[1], reverse=True)

            # 分配到第一个可用仓库（简化策略）
            if available_warehouses:
                selected_wh = available_warehouses[0][0]
                allocation[selected_wh][item_id] = total_qty

        return allocation

    def calculate_utilization(self, warehouse_id: str) -> Dict:
        """
        计算仓库利用率

        返回:
          utilization: {volume_util, weight_util, pallet_util, overall_util}
        """
        warehouse = self.warehouses.get(warehouse_id)
        if not warehouse:
            return {}

        volume_util = (warehouse.current_volume / warehouse.total_capacity_volume * 100
                      if warehouse.total_capacity_volume > 0 else 0)

        weight_util = (warehouse.current_weight / warehouse.total_capacity_weight * 100
                      if warehouse.total_capacity_weight > 0 else 0)

        pallet_util = (warehouse.current_pallets / warehouse.total_capacity_pallets * 100
                      if warehouse.total_capacity_pallets > 0 else 0)

        overall_util = (volume_util + weight_util + pallet_util) / 3

        return {
            'volume_utilization': round(volume_util, 2),
            'weight_utilization': round(weight_util, 2),
            'pallet_utilization': round(pallet_util, 2),
            'overall_utilization': round(overall_util, 2)
        }

```

## 📊 应用场景

### 场景1: 电商仓库容量管理

```python
# 定义物品
items = {
    'laptop': Item(id='laptop', volume=0.05, weight=2.5, pallets=0.01, value=1000, abc_class=ABCClass.A),
    'phone': Item(id='phone', volume=0.001, weight=0.2, pallets=0.001, value=500, abc_class=ABCClass.A),
    'book': Item(id='book', volume=0.002, weight=0.5, pallets=0.002, value=20, abc_class=ABCClass.C),
}

# 定义仓库分区
zones = {
    'high_value': WarehouseZone(
        id='high_value',
        capacity_volume=500,
        capacity_weight=10000,
        capacity_pallets=100,
        zone_type='secure'
    ),
    'general': WarehouseZone(
        id='general',
        capacity_volume=2000,
        capacity_weight=50000,
        capacity_pallets=500
    )
}

warehouse = Warehouse(
    id='main_warehouse',
    zones=zones,
    total_capacity_volume=2500,
    total_capacity_weight=60000,
    total_capacity_pallets=600
)

handler = WarehouseCapacityConstraintHandler({'main_warehouse': warehouse}, items)

# 验证库存
inventory = {
    'main_warehouse': {
        'laptop': 5000,  # 250 m³
        'phone': 10000,  # 10 m³
        'book': 50000    # 100 m³
    }
}

is_valid, violations = handler.validate(inventory)

# 计算EOQ
eoq_info = handler.calculate_eoq(
    item_id='laptop',
    annual_demand=10000,
    ordering_cost=500,
    holding_cost_rate=0.15
)
print(f"经济订货批量: {eoq_info['eoq']} 台")
print(f"年订货次数: {eoq_info['orders_per_year']} 次")
```

### 容量预测

```python
def forecast_capacity_needs(historical_demand: List[float],
                           forecast_periods: int = 12) -> List[float]:
    """
    预测未来容量需求 - 简单移动平均

    参数:
      historical_demand: 历史需求数据
      forecast_periods: 预测周期数

    返回:
      forecasted_demand: 预测需求
    """
    avg_demand = sum(historical_demand) / len(historical_demand)
    return [avg_demand] * forecast_periods
```

### 动态容量调整

```python
class DynamicCapacityHandler(WarehouseCapacityConstraintHandler):
    """支持动态容量调整的处理器"""

    def adjust_capacity(self, warehouse_id: str,
                       dimension: CapacityDimension,
                       adjustment: float):
        """动态调整仓库容量"""
        warehouse = self.warehouses.get(warehouse_id)
        if not warehouse:
            return

        if dimension == CapacityDimension.VOLUME:
            warehouse.total_capacity_volume += adjustment
        elif dimension == CapacityDimension.WEIGHT:
            warehouse.total_capacity_weight += adjustment
```
