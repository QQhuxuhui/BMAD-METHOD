## 💡 关键设计决策

| 决策                                                             | 理由                                                                                                 |
| ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| 三层架构图（总指挥→4 专家→专家库）                               | 认知结构清晰：业务评委看到"团队层级"秒懂；技术评委看到"智能体-专家库对应关系"秒懂                    |
| 保留中文角色名（赵领域、李严谨、张效率、王目标、孙质量、钱扩展） | 创新案例答辩需要**记忆点**——这些名字是我们产品的"温度"，让 AI 团队像真的团队；名字后都带专业职称兜底 |
| 钱扩展放支撑层 + 箭头 "→ 飞轮"                                   | 为 **P7 专家经验飞轮** 页埋伏笔——钱扩展正是飞轮的"引擎"                                              |
| 孙质量放支撑层 + "92% 可用率保障"                                | 回应 **P3 / P4 的"工程可靠性"承诺**——谁在保障？有这个专家                                            |
| 底部汇总带 "7 专家 · 100+ 模板 · ↓75-87%"                        | 三个数字连起来 = 整套架构的一句话总结                                                                |

## 🎨 样式说明

**整体风格**：白色系商务正式 · 低密度高留白 · 强理性弱装饰

**配色规范**

| 用途     | 色值      | 用法                     |
| -------- | --------- | ------------------------ |
| 背景     | `#FFFFFF` | 纯白 · 全场统一          |
| 主文字   | `#1A202C` | 深墨灰 · 标题 / 正文     |
| 副文字   | `#4A5568` | 中灰 · 副标题 / 注释     |
| 强调色   | `#1A365D` | 深蓝 · 关键词 / 数字亮点 |
| 分割线   | `#E2E8F0` | 浅灰 · 1px 细线          |
| 警示色   | `#C53030` | 砖红 · 传统方案的负面点  |
| 收益色   | `#2F855A` | 墨绿 · 正面成效          |
| 点缀金色 | `#D69E2E` | 仅用于 🏆 国赛图标       |

**字体规范**

- 中文：思源黑体 / 微软雅黑（兜底）
- 英文 & 数字：Inter / Helvetica Neue（兜底）
- 主标题：大字号 · 加粗 · 深墨灰
- 副标题：次级字号 · 细体 · 中灰
- 数字亮点：超大字号 · 加粗 · 深蓝

**版式规范**

- 每页四角留白 ≥ 5%
- **克制使用 emoji**：保留功能性标识，删除装饰性表情；优先线框 icon（Feather / Tabler Icons 风格）
- 分隔元素：1px 浅灰细线，避免厚重底纹
- 对齐：统一居中或左对齐，避免混用

**文案语言规范**

- **除专业术语外，全文必须使用中文**（含标题、正文、讲词、图示注释、注脚）
- **可保留原文的专业术语**：如 `Agent as Doc` · `Sidecar` · `Token` · `Guardrails` · `Prompt` · `Markdown` · `Phase 0-4` · `Todo` · `QA` · `Git` · `Orchestrator` 等
- **数字与单位**：业务量用中文单位（"500 台"、"100+ 模板"），技术度量保留原单位（"50K tokens"、"15px"）
- **字体 / 产品 / 软件包名**保留原写法（思源黑体、Inter、Tabler Icons、Feather Icons、BMAD）

**本页视觉重点（P5 七专家架构图）**

- **三层结构分明**，用颜色和边框区分身份等级
  - **顶层（总指挥）**：深蓝填充 `#1A365D` + 白字 · 圆角矩形 · 强调"统筹"地位
  - **中层（4 位核心专家）**：白底 + 深蓝细边框（2px）· 圆角 · 等宽
  - **底层（专家库）**：浅灰底 `#F7FAFC` + 深灰字 · 略小字号（体现"知识容器"身份）
- **支撑层（孙质量 / 钱扩展）**：**虚线框**（1px 浅蓝虚线）与主结构区分
- **连接线**：浅灰实线（指挥→专家）· 细箭头（1px）· 无粗装饰
- **专家 emoji**（🏢🔒🎯⚙️🛡️🔧）：作为角色身份标识**保留**（这是整页少数有温度的元素），但建议替换为**同风格扁平 icon**（如 Tabler Icons 配套）
- **底部汇总带**：深蓝底 + 白字 "7 专家 · 100+ 模板 · ↓75-87%"，字号醒目
- **中文角色名**：保留（赵领域 / 李严谨 等）· 比职称字号稍大 · 加粗
