## 📖 约束概述

### 定义

**依赖约束**（Dependency Constraint）规定任务、模块、组件之间的先后关系，确保前置条件满足后才能执行后续操作。

**数学定义**：

```
对于任务集合 T，定义依赖关系 D ⊆ T × T

依赖约束:
  (i, j) ∈ D 表示 j 依赖于 i
  即: i 必须在 j 之前完成

传递性:
  if (i, j) ∈ D and (j, k) ∈ D
  then (i, k) ∈ D（传递闭包）
```

### 依赖类型

#### 1. **直接依赖** (Direct Dependency)

```
任务B直接依赖任务A

A → B

例如:
  "编译" → "链接"
  "需求分析" → "系统设计"
```

#### 2. **传递依赖** (Transitive Dependency)

```
A → B → C
则 A → C（传递依赖）

例如:
  "需求" → "设计" → "开发"
  隐含: "需求" → "开发"
```

#### 3. **循环依赖** (Circular Dependency)

```
不允许的依赖模式

A → B → C → A（形成环）

检测: 拓扑排序失败
```

#### 4. **条件依赖** (Conditional Dependency)

```
依赖关系取决于条件

if condition:
    B depends on A
else:
    B depends on C

例如:
  if 使用缓存:
      部署 → 清理缓存
  else:
      部署 → 重启服务
```

## 💡 核心理论

### 有向无环图 (DAG)

**定义**：

```
DAG (Directed Acyclic Graph)
- 有向图
- 无环（不存在从节点到自身的路径）

依赖图必须是DAG才能有合法的执行顺序
```

**检测环**：

```python
def has_cycle(graph):
    """
    DFS检测有向图是否存在环

    使用三色标记法:
      - 白色(0): 未访问
      - 灰色(1): 访问中（在当前DFS路径上）
      - 黑色(2): 已完成

    发现灰色节点 → 存在环
    """
    color = {node: 0 for node in graph}

    def dfs(node):
        if color[node] == 1:  # 灰色节点，发现环
            return True
        if color[node] == 2:  # 黑色节点，已检查
            return False

        color[node] = 1  # 标记为灰色

        for neighbor in graph.get(node, []):
            if dfs(neighbor):
                return True

        color[node] = 2  # 标记为黑色
        return False

    for node in graph:
        if color[node] == 0:
            if dfs(node):
                return True

    return False
```

### 拓扑排序 (Topological Sort)

**Kahn算法**（已在时序依赖约束中实现）：

```python
def topological_sort_kahn(graph):
    """
    Kahn算法拓扑排序

    复杂度: O(V + E)

    步骤:
      1. 计算所有节点的入度
      2. 将入度为0的节点加入队列
      3. 依次从队列取出节点，减少邻居入度
      4. 重复直到队列为空
    """
    in_degree = {node: 0 for node in graph}

    for node in graph:
        for neighbor in graph[node]:
            in_degree[neighbor] += 1

    queue = [node for node in graph if in_degree[node] == 0]
    result = []

    while queue:
        node = queue.pop(0)
        result.append(node)

        for neighbor in graph.get(node, []):
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)

    if len(result) != len(graph):
        return None  # 存在环
    return result
```

**DFS算法**：

```python
def topological_sort_dfs(graph):
    """
    DFS拓扑排序

    复杂度: O(V + E)

    特点: 逆后序遍历 = 拓扑序
    """
    visited = set()
    stack = []

    def dfs(node):
        visited.add(node)

        for neighbor in graph.get(node, []):
            if neighbor not in visited:
                dfs(neighbor)

        stack.append(node)  # 后序位置

    for node in graph:
        if node not in visited:
            dfs(node)

    return stack[::-1]  # 逆序
```

### 依赖层级计算

```python
def calculate_dependency_levels(graph):
    """
    计算依赖层级（并行度分析）

    Level 0: 无依赖任务
    Level 1: 只依赖Level 0任务
    Level k: 依赖Level < k任务

    用途:
      - 识别可并行执行的任务
      - 关键路径分析
    """
    in_degree = {node: 0 for node in graph}

    for node in graph:
        for neighbor in graph[node]:
            in_degree[neighbor] += 1

    levels = {}
    current_level = 0
    queue = [node for node in graph if in_degree[node] == 0]

    while queue:
        next_queue = []

        for node in queue:
            levels[node] = current_level

            for neighbor in graph.get(node, []):
                in_degree[neighbor] -= 1
                if in_degree[neighbor] == 0:
                    next_queue.append(neighbor)

        queue = next_queue
        current_level += 1

    return levels
```

## 🔧 代码实现

```python
from typing import Dict, List, Tuple, Set, Optional
from dataclasses import dataclass, field
from collections import defaultdict

@dataclass
class Dependency:
    """依赖关系"""
    predecessor: str  # 前置任务
    successor: str    # 后续任务
    type: str = "finish-to-start"  # 依赖类型
    condition: Optional[str] = None  # 条件依赖

@dataclass
class Task:
    """任务定义"""
    id: str
    dependencies: List[str] = field(default_factory=list)

class DependencyConstraintHandler:
    """依赖约束处理器"""

    def __init__(self, tasks: Dict[str, Task],
                 dependencies: List[Dependency] = None):
        """
        参数:
          tasks: {task_id: Task}
          dependencies: 依赖关系列表
        """
        self.tasks = tasks
        self.dependencies = dependencies or []
        self.dependency_graph = self._build_graph()

    def _build_graph(self) -> Dict[str, List[str]]:
        """构建依赖图"""
        graph = {task_id: [] for task_id in self.tasks}

        # 从Task对象构建
        for task_id, task in self.tasks.items():
            for dep in task.dependencies:
                if dep not in graph:
                    graph[dep] = []
                graph[dep].append(task_id)

        # 从Dependency列表构建
        for dep in self.dependencies:
            if dep.predecessor in graph:
                if dep.successor not in graph[dep.predecessor]:
                    graph[dep.predecessor].append(dep.successor)

        return graph

    def validate(self, execution_order: List[str]) -> Tuple[bool, List[Dict]]:
        """
        验证执行顺序是否满足依赖约束

        参数:
          execution_order: 任务执行顺序

        返回:
          (is_valid, violations)
        """
        violations = []

        # 记录已执行任务的位置
        position = {task_id: idx for idx, task_id in enumerate(execution_order)}

        # 检查每个依赖关系
        for task_id in execution_order:
            task = self.tasks.get(task_id)
            if not task:
                continue

            # 检查所有前置任务是否已执行
            for dep in task.dependencies:
                if dep not in position:
                    violations.append({
                        'type': 'missing_predecessor',
                        'task': task_id,
                        'missing_dependency': dep,
                        'penalty': 100
                    })
                elif position[dep] > position[task_id]:
                    violations.append({
                        'type': 'dependency_order_violation',
                        'task': task_id,
                        'predecessor': dep,
                        'task_position': position[task_id],
                        'predecessor_position': position[dep],
                        'penalty': 50
                    })

        return len(violations) == 0, violations

    def has_cycle(self) -> Tuple[bool, Optional[List[str]]]:
        """
        检测依赖图是否存在环

        返回:
          (has_cycle, cycle_path)
        """
        color = {node: 0 for node in self.dependency_graph}  # 0:白 1:灰 2:黑
        parent = {}
        cycle = None

        def dfs(node, path):
            nonlocal cycle

            if cycle:  # 已找到环
                return True

            if color[node] == 1:  # 发现环
                cycle_start = path.index(node)
                cycle = path[cycle_start:] + [node]
                return True

            if color[node] == 2:
                return False

            color[node] = 1
            path.append(node)

            for neighbor in self.dependency_graph.get(node, []):
                if dfs(neighbor, path):
                    return True

            path.pop()
            color[node] = 2
            return False

        for node in self.dependency_graph:
            if color[node] == 0:
                if dfs(node, []):
                    return True, cycle

        return False, None

    def topological_sort(self) -> Optional[List[str]]:
        """
        拓扑排序 - Kahn算法

        返回:
          sorted_tasks: 拓扑有序的任务列表
          或 None（存在环）
        """
        in_degree = {node: 0 for node in self.dependency_graph}

        for node in self.dependency_graph:
            for neighbor in self.dependency_graph[node]:
                in_degree[neighbor] += 1

        queue = [node for node in self.dependency_graph if in_degree[node] == 0]
        result = []

        while queue:
            node = queue.pop(0)
            result.append(node)

            for neighbor in self.dependency_graph.get(node, []):
                in_degree[neighbor] -= 1
                if in_degree[neighbor] == 0:
                    queue.append(neighbor)

        if len(result) != len(self.dependency_graph):
            return None  # 存在环

        return result

    def calculate_levels(self) -> Dict[str, int]:
        """
        计算依赖层级

        返回:
          {task_id: level}
          Level 0: 无依赖
          Level k: 最大前置任务Level + 1
        """
        in_degree = {node: 0 for node in self.dependency_graph}

        for node in self.dependency_graph:
            for neighbor in self.dependency_graph[node]:
                in_degree[neighbor] += 1

        levels = {}
        current_level = 0
        queue = [node for node in self.dependency_graph if in_degree[node] == 0]

        while queue:
            next_queue = []

            for node in queue:
                levels[node] = current_level

                for neighbor in self.dependency_graph.get(node, []):
                    in_degree[neighbor] -= 1
                    if in_degree[neighbor] == 0:
                        next_queue.append(neighbor)

            queue = next_queue
            current_level += 1

        return levels

    def find_parallel_tasks(self) -> List[List[str]]:
        """
        找到可并行执行的任务组

        返回:
          [[level0_tasks], [level1_tasks], ...]
        """
        levels = self.calculate_levels()

        # 按层级分组
        level_groups = defaultdict(list)
        for task_id, level in levels.items():
            level_groups[level].append(task_id)

        # 转换为列表
        max_level = max(levels.values()) if levels else -1
        result = [level_groups[i] for i in range(max_level + 1)]

        return result

    def get_transitive_closure(self) -> Dict[str, Set[str]]:
        """
        计算传递闭包（所有间接依赖）

        返回:
          {task_id: set_of_all_dependencies}
        """
        closure = {node: set() for node in self.dependency_graph}

        # Floyd-Warshall算法计算传递闭包
        for k in self.dependency_graph:
            for i in self.dependency_graph:
                for j in self.dependency_graph:
                    # 如果存在i→k和k→j，则添加i→j
                    if (k in self.dependency_graph.get(i, []) and
                        j in self.dependency_graph.get(k, [])):
                        if i not in self.dependency_graph:
                            self.dependency_graph[i] = []
                        if j not in self.dependency_graph[i]:
                            self.dependency_graph[i].append(j)

        # 构建闭包集合
        for task_id in self.dependency_graph:
            visited = set()

            def dfs(node):
                visited.add(node)
                for neighbor in self.dependency_graph.get(node, []):
                    if neighbor not in visited:
                        dfs(neighbor)

            # 收集所有可达节点
            for dep in self.dependency_graph.get(task_id, []):
                dfs(dep)

            closure[task_id] = visited

        return closure

```

## 📊 应用场景

### 场景1: 软件编译依赖

```python
# 定义编译任务
tasks = {
    'compile_A': Task('compile_A', dependencies=[]),
    'compile_B': Task('compile_B', dependencies=['compile_A']),
    'compile_C': Task('compile_C', dependencies=['compile_A']),
    'link': Task('link', dependencies=['compile_B', 'compile_C']),
    'package': Task('package', dependencies=['link']),
}

handler = DependencyConstraintHandler(tasks)

# 检测环
has_cycle, cycle = handler.has_cycle()
if has_cycle:
    print(f"发现循环依赖: {' → '.join(cycle)}")

# 拓扑排序
build_order = handler.topological_sort()
print(f"编译顺序: {' → '.join(build_order)}")

# 并行编译
parallel_groups = handler.find_parallel_tasks()
for i, group in enumerate(parallel_groups):
    print(f"阶段 {i}: {', '.join(group)} (可并行)")
```

### 场景2: 项目任务依赖

```python
# 定义项目任务
dependencies = [
    Dependency('requirements', 'design'),
    Dependency('design', 'development'),
    Dependency('development', 'testing'),
    Dependency('testing', 'deployment'),
]

tasks = {
    'requirements': Task('requirements'),
    'design': Task('design'),
    'development': Task('development'),
    'testing': Task('testing'),
    'deployment': Task('deployment'),
}

handler = DependencyConstraintHandler(tasks, dependencies)

# 验证执行顺序
execution_order = ['requirements', 'development', 'design', 'testing', 'deployment']
is_valid, violations = handler.validate(execution_order)

if not is_valid:
    for v in violations:
        print(f"违反: {v['type']} - 任务 {v['task']} 前置任务 {v.get('predecessor')} 未完成")
```

closure = handler.get_transitive_closure()

## 🎯 性能优化

### 增量拓扑排序

```python
class IncrementalTopoSort:
    """支持动态添加依赖的增量拓扑排序"""

    def __init__(self, graph: Dict[str, List[str]]):
        self.graph = graph
        self.sorted_list = self._initial_sort()
        self.position = {task: idx for idx, task in enumerate(self.sorted_list)}

    def _initial_sort(self):
        """初始拓扑排序"""
        handler = DependencyConstraintHandler({}, [])
        handler.dependency_graph = self.graph
        return handler.topological_sort() or []

    def add_edge(self, from_task: str, to_task: str):
        """增量添加边"""
        if from_task not in self.graph:
            self.graph[from_task] = []

        self.graph[from_task].append(to_task)

        # 检查是否引入环
        # 如果to_task在from_task之前，需要重新排序
        if self.position.get(to_task, float('inf')) < self.position.get(from_task, float('inf')):
            # 重新拓扑排序（简化处理）
            self.sorted_list = self._initial_sort()
            self.position = {task: idx for idx, task in enumerate(self.sorted_list)}
```
