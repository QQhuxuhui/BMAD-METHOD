## 核心原理

### 理论基础

遗传算法（Genetic Algorithm, GA）由John Holland于1975年提出，受达尔文进化论启发，通过模拟自然选择和遗传机制求解优化问题。

**核心思想**：

- **种群进化**: 维护一组候选解（种群），通过代际演化逐步改进
- **适者生存**: 高适应度个体有更大概率遗传到下一代
- **遗传变异**: 通过交叉和变异产生新个体，保持种群多样性

**关键概念**：

- **个体（Individual）**: 问题的一个候选解
- **种群（Population）**: 多个个体的集合
- **适应度（Fitness）**: 个体解的质量评价值
- **基因（Gene）**: 个体编码的基本单元
- **染色体（Chromosome）**: 个体的完整编码

### 核心机制

**工作流程**：

1. **初始化**: 随机生成初始种群
2. **选择（Selection）**: 根据适应度选择优秀个体作为父代
3. **交叉（Crossover）**: 父代个体交换基因产生子代
4. **变异（Mutation）**: 以小概率随机改变个体基因
5. **环境选择**: 从父代和子代中选择下一代种群
6. **迭代**: 重复2-5步直到满足终止条件

**三大遗传算子**：

1. **选择算子**：
   - 轮盘赌选择（Roulette Wheel Selection）
   - 锦标赛选择（Tournament Selection）
   - 排序选择（Rank Selection）

2. **交叉算子**：
   - 单点交叉（Single-Point Crossover）
   - 多点交叉（Multi-Point Crossover）
   - 均匀交叉（Uniform Crossover）
   - 顺序交叉（Order Crossover, OX）

3. **变异算子**：
   - 位翻转变异（Bit Flip Mutation）
   - 插入变异（Insertion Mutation）
   - 交换变异（Swap Mutation）
   - 倒位变异（Inversion Mutation）

## 实现框架

### 算法伪代码

```python
def genetic_algorithm(problem, config):
    """
    遗传算法主函数

    参数:
        problem: 调度问题定义（目标函数、约束条件、决策变量）
        config: 算法配置（种群大小、代数、交叉率、变异率）

    返回:
        best_solution: 最优解
        evolution_history: 进化历史（收敛曲线）
    """
    # 1. 初始化种群
    population = initialize_population(config.population_size, problem)

    # 2. 评估初始种群
    fitness = evaluate_population(population, problem)

    # 3. 记录最优解
    best_solution = population[argmax(fitness)]
    evolution_history = []

    # 4. 主循环
    for generation in range(config.max_generations):

        # 5. 选择父代
        parents = selection(population, fitness, config.selection_method)

        # 6. 交叉产生子代
        offspring = []
        for i in range(0, len(parents), 2):
            if random() < config.crossover_rate:
                child1, child2 = crossover(parents[i], parents[i+1], config.crossover_method)
            else:
                child1, child2 = parents[i], parents[i+1]
            offspring.extend([child1, child2])

        # 7. 变异
        for i in range(len(offspring)):
            if random() < config.mutation_rate:
                offspring[i] = mutation(offspring[i], config.mutation_method)

        # 8. 修复不可行解（约束处理）
        offspring = repair_infeasible(offspring, problem)

        # 9. 评估子代
        offspring_fitness = evaluate_population(offspring, problem)

        # 10. 环境选择（生成下一代种群）
        population, fitness = environmental_selection(
            population, fitness,
            offspring, offspring_fitness,
            config.selection_strategy
        )

        # 11. 更新最优解
        current_best = population[argmax(fitness)]
        if fitness[argmax(fitness)] > fitness_of(best_solution):
            best_solution = current_best

        # 12. 记录历史
        evolution_history.append({
            'generation': generation,
            'best_fitness': fitness_of(best_solution),
            'avg_fitness': mean(fitness),
            'diversity': calculate_diversity(population)
        })

        # 13. 检查终止条件
        if termination_condition(evolution_history, config):
            break

    return best_solution, evolution_history
```

### 参数配置指南

| 参数名称        | 推荐范围 | 默认值 | 影响说明                         |
| --------------- | -------- | ------ | -------------------------------- |
| population_size | 50-200   | 100    | 过小易早熟收敛，过大增加计算成本 |
| max_generations | 100-1000 | 500    | 根据问题规模和时间预算调整       |
| crossover_rate  | 0.6-0.9  | 0.8    | 高交叉率加快收敛，但可能破坏好解 |
| mutation_rate   | 0.01-0.1 | 0.05   | 过低缺乏探索，过高破坏性强       |
| elite_size      | 1-5      | 2      | 精英保留数量，确保最优解不丢失   |
| tournament_size | 2-7      | 3      | 锦标赛选择的竞争强度             |

**参数调优建议**：

- **种群大小**:
  - 小规模问题(<100变量): 50-80
  - 中规模问题(100-500变量): 100-150
  - 大规模问题(>500变量): 150-200

- **交叉率与变异率平衡**:
  - 初期: 高交叉率(0.9) + 低变异率(0.01) - 快速收敛
  - 中期: 中交叉率(0.7) + 中变异率(0.05) - 平衡探索
  - 后期: 低交叉率(0.6) + 高变异率(0.1) - 跳出局部最优

- **自适应参数策略**:

  ```python
  # 自适应变异率
  mutation_rate = initial_rate * (1 - generation / max_generations) + min_rate

  # 自适应交叉率
  crossover_rate = max_rate - (max_rate - min_rate) * (generation / max_generations)
  ```

### 实现注意事项

1. **编码方式选择**:
   - 二进制编码: 适合连续优化问题离散化
   - 整数编码: 适合调度、分配问题
   - 排列编码: 适合TSP、调度序列问题
   - 实数编码: 适合连续优化问题

2. **性能优化点**:
   - 适应度缓存: 避免重复评估相同个体
   - 并行评估: 种群评估可并行化
   - 增量评估: 仅评估变异部分（特定问题）
   - 早停机制: 检测收敛停滞

3. **常见错误**:
   - 忘记修复不可行解导致大量约束违反
   - 精英保留未实现导致最优解丢失
   - 种群多样性丧失导致早熟收敛
   - 交叉变异算子与编码方式不匹配

## 应用案例

### 案例1：车辆路径规划（CVRPTW）

**场景描述**：
50个客户配送问题，考虑车辆容量约束和时间窗约束，目标最小化总行驶距离。

**问题建模**：

```yaml
决策变量: 车辆路径序列 [route1, route2, ..., routeK]
约束条件:
  - 容量约束: 每条路径的需求总量 ≤ 车辆容量
  - 时间窗约束: 到达每个客户的时间在其时间窗内
  - 访问约束: 每个客户恰好被访问一次
目标函数: minimize Σ(路径距离)
```

**实施方案**：

```python
# 编码方式: 排列编码
# 染色体 = [c5, c12, 0, c3, c8, 0, c1, ...]
# 其中 0 表示路径分隔符

# 参数设置
config = {
    'population_size': 100,
    'max_generations': 500,
    'crossover_rate': 0.85,
    'mutation_rate': 0.03,
    'crossover_method': 'order_crossover',  # OX交叉
    'mutation_method': 'swap_mutation',     # 交换变异
    'selection_method': 'tournament',
    'tournament_size': 5,
    'elite_size': 2
}

# 约束处理: 修复策略
def repair_capacity(route):
    """容量约束修复"""
    if total_demand(route) > vehicle_capacity:
        # 拆分超载路径
        return split_route_by_capacity(route)
    return route

def repair_time_window(route):
    """时间窗约束修复"""
    # 调整访问顺序以满足时间窗
    return reorder_by_time_window(route)

# 适应度函数
def fitness(individual):
    routes = decode_individual(individual)
    # 修复不可行解
    routes = [repair_capacity(r) for r in routes]
    routes = [repair_time_window(r) for r in routes]
    # 计算总距离（带惩罚）
    distance = sum(calculate_route_distance(r) for r in routes)
    penalty = calculate_constraint_violation(routes)
    return 1 / (distance + 1000 * penalty)
```

**实施结果**：

- **优化效果**: 比初始随机解降低 18% 总距离
- **计算时间**: 23秒（100种群 × 500代）
- **收敛特性**: 第150代达到较优解，第400代基本收敛
- **最终解质量**: 与已知最优解Gap为 3.2%

**问题建模**：

决策变量: 工序调度序列

## 优势与局限

### 优势

- ✅ **全局搜索能力强**: 基于种群的搜索方式，不易陷入局部最优
- ✅ **问题通用性高**: 不依赖问题特定知识，适用于多种调度问题
- ✅ **易于并行化**: 种群评估和多种群并行进化可显著加速
- ✅ **自适应能力**: 可通过参数自适应策略提升性能
- ✅ **多目标优化**: 扩展为NSGA-II可有效处理多目标问题

### 局限

- ⚠️ **参数敏感**: 参数配置对性能影响大，需要调优
  - **应对**: 使用自适应参数策略或参数调优工具（如贝叶斯优化）

- ⚠️ **早熟收敛风险**: 种群多样性丧失导致过早收敛
  - **应对**: 增加变异率、引入多样性保持机制、重启策略

- ⚠️ **计算成本高**: 大规模问题需要大量适应度评估
  - **应对**: 近似评估、代理模型、增量评估

- ⚠️ **局部搜索能力弱**: 纯GA精细搜索能力不足
  - **应对**: 混合局部搜索算法（Memetic Algorithm）

### 适用性判断

**适合使用的情况**：

- 问题规模>100变量，精确算法不可行
- 约束条件复杂，数学规划难以建模
- 多目标优化问题
- 需要多个高质量解（种群）

**不适合使用的情况**：

- 问题规模<50变量（精确算法更优）
- 实时性要求极高（<1秒）
- 解空间连续且光滑（梯度方法更优）
- 问题有特殊结构可利用（构造式启发式更优）

## 扩展变种

### 变种1：自适应遗传算法 (Adaptive GA)

**核心改进**：根据种群状态动态调整交叉率和变异率

```python
def adaptive_parameters(population, fitness):
    """自适应参数调整"""
    f_max = max(fitness)
    f_avg = mean(fitness)

    for i, individual in enumerate(population):
        f = fitness[i]

        # 优秀个体：低交叉率、低变异率（保护）
        if f > f_avg:
            pc = 0.6 * (f_max - f) / (f_max - f_avg)
            pm = 0.01
        # 较差个体：高交叉率、高变异率（探索）
        else:
            pc = 0.9
            pm = 0.1

        individual.crossover_rate = pc
        individual.mutation_rate = pm
```

**适用场景**：需要平衡探索与利用的复杂调度问题
**性能提升**：相比标准GA，解质量提升5-8%，收敛速度提升15-20%

### 变种2：多种群协同进化 (Multi-Population Coevolution)

**核心改进**：多个子种群并行进化，定期交换优秀个体

```python
def multi_population_ga(problem, num_populations=4):
    """多种群协同进化"""
    # 初始化多个子种群
    populations = [initialize_population(...) for _ in range(num_populations)]

    for generation in range(max_generations):
        # 各子种群独立进化
        for pop in populations:
            pop = evolve_one_generation(pop, problem)

        # 周期性迁移（每10代）
        if generation % 10 == 0:
            # 每个种群贡献最优个体
            migrants = [get_best_individual(pop) for pop in populations]
            # 随机替换各种群中的较差个体
            for pop in populations:
                replace_worst_with_migrant(pop, random.choice(migrants))

    # 返回所有种群中的最优解
    return get_global_best(populations)
```

**适用场景**：大规模、多模态优化问题
**性能提升**：避免早熟收敛，解质量提升10-15%

### 变种3：Memetic算法（混合局部搜索）

**核心改进**：GA + 局部搜索算法

```python
def memetic_algorithm(problem, config):
    """Memetic算法：GA + 局部搜索"""
    population = initialize_population(config.population_size, problem)

    for generation in range(config.max_generations):
        # 标准GA操作
        population = ga_evolution(population, problem, config)

        # 对部分优秀个体执行局部搜索
        elite_indices = select_elite(population, elite_ratio=0.2)
        for idx in elite_indices:
            population[idx] = local_search(population[idx], problem, max_iter=50)

    return get_best_individual(population)
```

**适用场景**：需要高精度解的调度问题
**性能提升**：解质量提升15-25%，但计算时间增加30-50%
