## 🎨 视觉意境描述（投喂 flow 平台 · 敞开想象）

> **整体氛围**
>
> 全场对业务评委最有穿透力的一页。"飞轮"这个词本身就是循环概念——**视觉即概念**。
>
> 画面中央是一个**正在转动的圆环**，4 个节点等距分布在圆周上，节点之间用顺时针箭头流转——观者一眼就能感受到"动势"。这不是静态的"知识库藏图"，是**正在加速转动的飞轮**。整页气质是**温暖的力量感**——不像 P3 那么对抗，不像 P8 那么硬核，而是一种"东西在生长"的有机感。
>
> **页眉**
>
> 主标题「**专家经验飞轮 · 越用越强的知识资产**」深墨灰加粗大字、居中。副标题「**打破"专家离职=经验归零"的魔咒**」中灰偏小字号——一句话点出业务痛点，让评委秒懂为什么这页重要。
>
> **画面主体 · 飞轮圆环（占据画面 2/3 高度 · 视觉绝对焦点）**
>
> ---
>
> **中心核**：一个**深蓝 `#1A365D` 实心圆**（直径占整个圆环约 1/3），白字三行居中：
>
> > **100+ 模板**
> > **持续增长**
> > **飞轮中心**
>
> 中心圆是整个飞轮的"引擎"——视觉上**最重最沉**，让评委一眼锁定"这个东西已经在转，而且越转越多"。
>
> ---
>
> **4 节点等距分布在圆周上**（**顺时针 12-3-6-9 点位**），每个节点是一枚**白底 + 浅蓝 2px 边框圆章** + 深蓝编号 ①②③④ + **节点名加粗**：
>
> - **① 沉淀**（顶端 12 点位置）—— 专家经验 → 专家库（资深专家写入模板）
> - **② 实战**（3 点位置）—— 真实业务激活（调用 + 运行）
> - **③ 优化**（6 点位置）—— 代码可用率↑ · 参数持续调优（反馈迭代）
> - **④ 复用**（9 点位置）—— 跨场景标准化（新版本发布）
>
> 节点名下方一行小字（中灰）解释该环节的具体动作——**字号要明显小于节点名**，让节点名本身成为记忆点。
>
> ---
>
> **流转箭头**：4 个节点之间用**浅蓝 1.5px 细实线 + 单向箭头**沿圆周**顺时针**连接，箭头大小适中、不喧宾夺主，但要让"转动方向"一目了然。可以让箭头略带渐变（从浅到深），暗示"越转越快"的加速感——**这是全页唯一允许的渐变**。
>
> ---
>
> **底部三句话**（高亮色带 · 过去/现在/未来 三段对仗 · 全页第二记忆点）
>
> 画面下方一条**浅灰底色带**横贯通栏，三段并列居中（每段之间用 1px 浅灰竖线分隔）：
>
> | 时间维度 | 符号                    | 文本                                  | 视觉                        |
> | -------- | ----------------------- | ------------------------------------- | --------------------------- |
> | **过去** | `✘` 砖红 `#C53030`      | 专家离职 = 经验归零                   | 中灰文字 · 带"被划掉"感     |
> | **现在** | `✓` 墨绿 `#2F855A`      | 专家经验 = 可 Git 管理的数字资产      | 深墨灰加粗 · 带"踏实落地"感 |

>
> ✘ → ✓ → → 三符号建立**"从问题到解药到想象"**的视觉递进。

>
> ---
>
> **金句收尾**（全场记忆点之一）
>
> 三句话色带下方留白，中央放置金句（**大字号 32pt+ · 居中 · 深蓝加粗**）：
>
> > 「**智能体不是替代专家，而是让专家的经验成为组织的永久资产**」
>
> "**永久资产**"是业务评委的母语——把技术创新翻译成组织管理语言。金句字号略小于飞轮中心核，但视觉重量相当——构成**"中心核 + 底部金句"**的视觉双锚点。
>
> **配色协奏**
>
> - 纯白 `#FFFFFF` 主导背景
> - 深墨灰 `#1A202C` 用于主标题、节点名加粗、"现在"段落文字
> - 中灰 `#4A5568` 用于副标题、节点名下小字、"过去"段落文字
> - **深蓝 `#1A365D`** 用于飞轮中心核（满铺 + 白字）、节点编号、流转箭头颜色基调、"未来"段落、金句
> - **浅蓝**（深蓝 50% 透明）用于节点圆章边框、流转箭头主体
> - **砖红 `#C53030`** 仅用于"过去"的 ✘ 符号
> - **墨绿 `#2F855A`** 仅用于"现在"的 ✓ 符号
> - 浅灰 `#E2E8F0` / `#F7FAFC` 用于底部三句话色带、节点之间细分隔线
>
> **严禁**
>
> 渐变背景 / 装饰花纹 / 立体阴影 / 拟物化齿轮 / 卡通飞轮插画 / 3D 圆环效果。飞轮必须是**抽象几何**（圆环 + 节点圆章 + 细线箭头），保持商务气质。**唯一允许的渐变**：流转箭头从浅到深暗示加速感。
>
> **🚨 语言硬性约束**
>
> 画面所有可见文案 **必须使用中文**。**唯一豁免**：专业术语（如 `Git` · `Agent` · `AI`）以及技术度量（如 `100+`、`70-85%`）保留原写法。**禁止**任何可用中文等价表达的英文（如不要写 "Past / Present / Future"，必须用「过去 / 现在 / 未来」；不要写 "Sediment / Practice / Optimize / Reuse"，必须用「沉淀 / 实战 / 优化 / 复用」；不要写 "Flywheel Center"，必须用「飞轮中心」）。

## 💡 关键设计决策

| 决策                                  | 理由                                                                           |
| ------------------------------------- | ------------------------------------------------------------------------------ |
| 圆环飞轮（而非竖向链表）              | "飞轮"这个词本身就是循环概念——圆环图 = 视觉即概念                              |
| 飞轮中心放 "100+ 模板 / 持续增长"     | 不是空中楼阁——这是**已经在转的飞轮**；用"持续增长"而不是静态库数，强调飞轮动势 |
| 四节点命名：沉淀 → 实战 → 优化 → 复用 | 4 个词每个 2 字，极度精简，节奏感强，口语化易记                                |
| 三句话 "过去 / 现在 / 未来" 对仗      | 答辩最强叙事结构——损失感（过去）+ 解药感（现在）+ 想象力（未来）一次打满       |
| ✘ ✓ 🚀 三符号                         | 视觉上建立 "从问题到解药到想象" 的递进                                         |
| 底部金句 "组织的永久资产"             | "永久资产"是业务评委的母语——把技术创新翻译成组织管理语言                       |
