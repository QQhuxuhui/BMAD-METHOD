### 4. 自动化工具

#### 4.1 索引生成器

**文件路径**: `tools/index_generator.py`

**核心功能**:

- 自动扫描专家库目录
- 提取模块元数据（版本、状态）
- 按类别分组生成索引
- 自动更新主文件索引章节

**使用方式**:

```bash
# 预览单个专家库索引
python3 tools/index_generator.py --lib-name "调度算法专家库" --preview

# 更新主文件索引
python3 tools/index_generator.py \
  --lib-name "调度算法专家库" \
  --agent-file "docs/agents/智能体团队/调度算法专家智能体.md"

# 生成所有专家库索引
python3 tools/index_generator.py --all
```

**测试状态**: ✅ 已测试通过

- 成功扫描3个模块文件
- 正确提取元数据（版本号）
- 按字母顺序排列输出

**核心价值**:

- 自动化索引维护，零手工工作

## 🎓 经验总结

### 成功经验

1. **标准化模板设计**
   - 统一的章节结构保证一致性
   - YAML元数据支持自动化处理
   - 模板本身就是最好的文档

2. **渐进式迁移策略**
   - 先试点再推广，降低风险
   - V4.0和V4.1并存，平滑过渡
   - 每个阶段都有验收标准

3. **自动化工具优先**
   - 索引生成器避免手工维护
   - 提高效率，减少错误
   - 支持CI/CD集成

4. **完整的文档体系**
   - 设计文档：为什么这样做
   - 迁移指南：怎么做
   - 模板：做什么
   - 示例：具体怎么做

### 遇到的挑战

1. **YAML元数据中的@符号**
   - 问题: @符号在YAML中需要转义
   - 解决: 所有@引用加双引号

2. **索引章节标题识别**
   - 问题: 带emoji的标题正则匹配失败
   - 解决: 调整正则表达式或统一标题格式

3. **知识内容迁移**
   - 挑战: 从V4.0主文件提取算法内容
   - 方案: 手工创建示例，未来开发自动化工具
