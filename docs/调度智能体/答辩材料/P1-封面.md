## 💡 关键设计决策

| 决策                                       | 理由                                                                                                                                               |
| ------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 金句锁定 **「文档即智能体 · 经验即资产」** | 8 字金句、强记忆点；前 4 字（文档即智能体）技术侧秒懂 Agent as Doc；后 4 字（经验即资产）业务侧秒懂专家经验资产化——**技术 + 业务双主题一次性打出** |
| 主标题最大字号 + 金句次级字号              | 视觉层级清晰；主标题负责"是什么"，金句负责"定乾坤"                                                                                                 |
| 获奖信息 + 主讲人 + 日期 放在下半部分      | 保持封面整洁；身份信息兜底不抢戏                                                                                                                   |

## 🎨 样式说明

**整体风格**：白色系商务正式 · 低密度高留白 · 强理性弱装饰

**配色规范**

| 用途     | 色值      | 用法                     |
| -------- | --------- | ------------------------ |
| 背景     | `#FFFFFF` | 纯白 · 全场统一          |
| 主文字   | `#1A202C` | 深墨灰 · 标题 / 正文     |
| 副文字   | `#4A5568` | 中灰 · 副标题 / 注释     |
| 强调色   | `#1A365D` | 深蓝 · 关键词 / 数字亮点 |
| 分割线   | `#E2E8F0` | 浅灰 · 1px 细线          |
| 警示色   | `#C53030` | 砖红 · 传统方案的负面点  |
| 收益色   | `#2F855A` | 墨绿 · 正面成效          |
| 点缀金色 | `#D69E2E` | 仅用于 🏆 国赛图标       |

**字体规范**

- 中文：思源黑体 / 微软雅黑（兜底）
- 英文 & 数字：Inter / Helvetica Neue（兜底）
- 主标题：大字号 · 加粗 · 深墨灰
- 副标题：次级字号 · 细体 · 中灰
- 数字亮点：超大字号 · 加粗 · 深蓝

**版式规范**

- 每页四角留白 ≥ 5%
- **克制使用 emoji**：保留功能性标识，删除装饰性表情；优先线框 icon（Feather / Tabler Icons 风格）
- 分隔元素：1px 浅灰细线，避免厚重底纹
- 对齐：统一居中或左对齐，避免混用

**本页视觉重点（P1 封面）**

- **主标题**居中 · 超大字号（≥ 60pt）· 深墨灰加粗
- **金句副标题** `「文档即智能体 · 经验即资产」`：字号 36-40pt · 深蓝 · 书名号包裹
- **顶/底装饰**：一条深蓝 1px 细线点缀，不喧宾夺主
- **奖项 / 主讲人 / 日期**：底部居中或左对齐 · 中灰 · 小字号（18-20pt）
- **整体**：大面积留白，主标题 + 金句构成唯一视觉焦点
