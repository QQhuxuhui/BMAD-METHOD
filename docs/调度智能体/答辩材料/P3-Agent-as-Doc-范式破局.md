## 💡 关键设计决策

| 决策                                 | 理由                                                                                                                              |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| **"业界首创·已申请专利"** 6 字小标签 | 答辩是"创新案例"——**专利**是最硬的创新证据，必须在王牌页打出                                                                      |
| 左"盒子" vs 右"卫星图" 视觉语言      | 传统是"笨重单体"，我们是"轻量中心 + 分布式知识"——**视觉本身就在讲创新**                                                           |
| 三条对比特性精准回应 P2 三道墙       | **墙② Token 浪费** → 左红/右绿首条<br/>**墙③ 专家经验留不住** → 第二条（知识更新方式）<br/>**墙① AI 幻觉难控** → 第三条（可追溯） |
| 红绿色对比 🔴🟢                      | 业务评委不需要看懂技术细节，看颜色就知道"左边是问题，右边是解药"                                                                  |
| 硬数字横幅独占一带                   | 三个数字是全答辩最硬的"ROI 证据"——独占一带让评委无法忽略                                                                          |
| 金句"根本的翻转"                     | "翻转"这个词比"突破""创新"更有画面感——让概念有形状                                                                                |

## 🎨 样式说明

**整体风格**：白色系商务正式 · 低密度高留白 · 强理性弱装饰

**配色规范**

| 用途     | 色值      | 用法                     |
| -------- | --------- | ------------------------ |
| 背景     | `#FFFFFF` | 纯白 · 全场统一          |
| 主文字   | `#1A202C` | 深墨灰 · 标题 / 正文     |
| 副文字   | `#4A5568` | 中灰 · 副标题 / 注释     |
| 强调色   | `#1A365D` | 深蓝 · 关键词 / 数字亮点 |
| 分割线   | `#E2E8F0` | 浅灰 · 1px 细线          |
| 警示色   | `#C53030` | 砖红 · 传统方案的负面点  |
| 收益色   | `#2F855A` | 墨绿 · 正面成效          |
| 点缀金色 | `#D69E2E` | 仅用于 🏆 国赛图标       |

**字体规范**

- 中文：思源黑体 / 微软雅黑（兜底）
- 英文 & 数字：Inter / Helvetica Neue（兜底）
- 主标题：大字号 · 加粗 · 深墨灰
- 副标题：次级字号 · 细体 · 中灰
- 数字亮点：超大字号 · 加粗 · 深蓝

**版式规范**

- 每页四角留白 ≥ 5%
- **克制使用 emoji**：保留功能性标识，删除装饰性表情；优先线框 icon（Feather / Tabler Icons 风格）
- 分隔元素：1px 浅灰细线，避免厚重底纹
- 对齐：统一居中或左对齐，避免混用

**本页视觉重点（P3 王牌页 · 全场 Money Slide）**

- **左右对比视觉最关键**
  - 左侧（传统）：**浅灰底** `#F7FAFC`，暗示"笨重 / 单体 / 陈旧"
  - 右侧（我们）：**纯白底 + 细边框卫星图**，暗示"轻量 / 分布式 / 现代"
- **红绿色圆点**：用纯色小圆 `●` 砖红 / 墨绿，**代替 🔴🟢 emoji**，更商务更精致
- **硬数字横幅**：深蓝底 `#1A365D` + 白字，字号突出，占据整行
- **"已申请专利"小标签**：深蓝描边 + 白底深蓝字的胶囊标签
- **金句收尾**：大字号 · 斜体 · 居中 · 深墨灰 · 两行对称排版
- **整体留白**：左右两块之间保留充足间距（≥ 60px），不挤压

## 🎤 口头讲词（~90 秒）

> "这一页是我们整个项目最想让大家记住的一个词——**Agent as Doc**。
>
> 业界绝大多数 AI Agent 走的是 **Agent as Prompt** 路线：智能体就是一个塞满知识的大 Prompt。问题是——这个 Prompt 一旦到 50K tokens，利用率只有 10-20%，剩下 80% 都是'以防万一'的浪费；而且知识和智能体绑死，更新一次相当于重新训练。
>
> 我们走的是另一条路：**智能体不应该包含知识，智能体应该承载知识**。
>
> 智能体本体只有 500 tokens——就是一个角色定位；所有专业知识，放在外面的文档库里，按需加载。需要算法，拿算法文档；需要约束，拿约束文档。
>
> 结果是三件事同时发生：**Token 省了 75-87%**（底部第一个数）、**知识更新变成改 Markdown**（业务专家都能做，效率提升 100 倍）、**每一条决策都可以追溯到具体文档**（AI 幻觉根本没空间发生）。
>
> 这是一次'智能体'这件事的**根本翻转**。"
