## 📖 领域概述

**生产调度** 涉及制造资源的优化配置，包括机器、人员、物料的协调。

**问题类型**:

- **Job Shop**: 作业车间调度
- **Flow Shop**: 流水车间调度
- **Flexible Job Shop**: 柔性作业车间

## 🔧 代码实现

```python
from dataclasses import dataclass
from typing import List, Dict

@dataclass
class Job:
    """生产任务"""
    id: str
    operations: List[Dict]  # 工序列表
    due_date: float
    priority: int = 1

@dataclass
class Machine:
    """生产设备"""
    id: str
    capabilities: List[str]  # 可加工工序类型
    available_time: float = 0

class ProductionSchedulingAdapter:
    """生产调度领域适配器"""

    def __init__(self):
        self.domain_type = "production_scheduling"

    def extract_business_rules(self, context: Dict) -> List[Dict]:
        """提取生产业务规则"""
        rules = []

        # 工序顺序约束
        rules.append({
            'type': 'precedence_constraint',
            'description': '工序必须按顺序执行'
        })

        # 设备能力约束
        rules.append({
            'type': 'machine_capability',
            'description': '设备只能加工其能力范围内的工序'
        })

        return rules
```
