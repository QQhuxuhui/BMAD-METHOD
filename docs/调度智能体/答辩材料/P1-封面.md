# P1 · 封面

> 创新案例答辩PPT · 第 1 / 9 页 · 预计讲述时长 15 秒

## 🎯 页面定位

整场答辩的**第一张名片**。15 秒内让评委看到金句、项目名、获奖信息、讲者归属——**确立整场叙事的第一个记忆点**。

## 🎨 视觉意境描述（投喂 flow 平台 · 敞开想象）

> **整体氛围**
>
> 一张极简、克制、自信的现代商务 PPT 封面。纯白底色铺满整页，像一张未印刷的高级哑光纸面。整个画面的核心力量来自"留白"，而非装饰——这是一份"顶级咨询报告"该有的封皮气质。
>
> **画面焦点（中央偏上）**
>
> 主标题"【项目/产品正式名称】"以**全场最大字号**横亘画面中央——深墨灰思源黑体加粗，气质沉稳、专业。这一行字是画面的视觉锚点，承担"我是谁"的庄重宣告。
>
> **金句呼应（紧贴主标题之下）**
>
> 一行深蓝色「书名号」包裹的 8 字金句：「**文档即智能体 · 经验即资产**」。字号约为主标题的 60%，深蓝调让它既不抢主标题的戏，又是画面第二亮眼的存在。书名号两端形成视觉"引述感"，像一句被庄重引用的格言。
>
> **顶/底装饰带（呼吸的括号）**
>
> 画面顶端、底端各有一条仅 **1px 粗细的深蓝细线**，横贯通栏。它们像一对温和的括号，把整张封面温柔框定——既不喧宾夺主，又给画面定下"严谨理性"的基调。
>
> **底部署名信息（低调完整）**
>
> 画面下方约 1/4 处：**奖项全称**（其中 🏆 是整页**唯一的暖金色亮点**）、**主讲人**、**团队**、**日期**——四行小字号中灰色信息，居中或左对齐排列，行间有充足留白。这一组信息存在感低调但完整，是身份的"署名页"。
>
> **大面积留白（封面的呼吸）**
>
> 画面中部，从金句下方到底部信息之上，**整片留白**。这不是空——它就是这页的内容本身。让评委的视线在主标题与金句之间停留，再缓慢沉降到底部署名。
>
> **配色协奏**
>
> - 纯白 `#FFFFFF` 主导画面 80% 以上面积
> - 深墨灰 `#1A202C` 用于主标题
> - 深蓝 `#1A365D` 仅出现在金句、顶/底细线
> - 中灰 `#4A5568` 用于底部署名
> - 暖金色 `#D69E2E` **仅落在 🏆 一处**——全场唯一的金色，让它本身就是奖项的视觉证据
>
> **严禁出现**
>
> 渐变背景 / 装饰花纹 / 卡通元素 / 立体阴影 / 背景图片 / 任何装饰性 emoji（🏆 除外）
>
> **🚨 语言硬性约束**
>
> 画面所有可见文案 **必须使用中文**——含主标题、金句、奖项、主讲人、团队、日期。
> **唯一豁免**：专业术语（如 `Agent as Doc` · `Sidecar` · `Token` · `Guardrails` · `Prompt` · `Markdown` · `Phase 0-4` · `Todo` · `QA` · `Git` · `Orchestrator` 等）以及字体 / 产品 / 软件包名（思源黑体、Inter、BMAD 等）保留原写法。
> **禁止**：任何可用中文等价表达的英文（如 "Already Done / On Going / Next" 必须译为"已完成 / 进行中 / 下一步"）。

## 💡 关键设计决策

| 决策                                       | 理由                                                                                                                                               |
| ------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 金句锁定 **「文档即智能体 · 经验即资产」** | 8 字金句、强记忆点；前 4 字（文档即智能体）技术侧秒懂 Agent as Doc；后 4 字（经验即资产）业务侧秒懂专家经验资产化——**技术 + 业务双主题一次性打出** |
| 主标题最大字号 + 金句次级字号              | 视觉层级清晰；主标题负责"是什么"，金句负责"定乾坤"                                                                                                 |
| 获奖信息 + 主讲人 + 日期 放在下半部分      | 保持封面整洁；身份信息兜底不抢戏                                                                                                                   |

## 🎨 样式说明

**整体风格**：白色系商务正式 · 低密度高留白 · 强理性弱装饰

**配色规范**

| 用途     | 色值      | 用法                     |
| -------- | --------- | ------------------------ |
| 背景     | `#FFFFFF` | 纯白 · 全场统一          |
| 主文字   | `#1A202C` | 深墨灰 · 标题 / 正文     |
| 副文字   | `#4A5568` | 中灰 · 副标题 / 注释     |
| 强调色   | `#1A365D` | 深蓝 · 关键词 / 数字亮点 |
| 分割线   | `#E2E8F0` | 浅灰 · 1px 细线          |
| 警示色   | `#C53030` | 砖红 · 传统方案的负面点  |
| 收益色   | `#2F855A` | 墨绿 · 正面成效          |
| 点缀金色 | `#D69E2E` | 仅用于 🏆 国赛图标       |

**字体规范**

- 中文：思源黑体 / 微软雅黑（兜底）
- 英文 & 数字：Inter / Helvetica Neue（兜底）
- 主标题：大字号 · 加粗 · 深墨灰
- 副标题：次级字号 · 细体 · 中灰
- 数字亮点：超大字号 · 加粗 · 深蓝

**版式规范**

- 每页四角留白 ≥ 5%
- **克制使用 emoji**：保留功能性标识，删除装饰性表情；优先线框 icon（Feather / Tabler Icons 风格）
- 分隔元素：1px 浅灰细线，避免厚重底纹
- 对齐：统一居中或左对齐，避免混用

**文案语言规范**

- **除专业术语外，全文必须使用中文**（含标题、正文、讲词、图示注释、注脚）
- **可保留原文的专业术语**：如 `Agent as Doc` · `Sidecar` · `Token` · `Guardrails` · `Prompt` · `Markdown` · `Phase 0-4` · `Todo` · `QA` · `Git` · `Orchestrator` 等
- **数字与单位**：业务量用中文单位（"500 台"、"100+ 模板"），技术度量保留原单位（"50K tokens"、"15px"）
- **字体 / 产品 / 软件包名**保留原写法（思源黑体、Inter、Tabler Icons、Feather Icons、BMAD）

**本页视觉重点（P1 封面）**

- **主标题**居中 · 超大字号（≥ 60pt）· 深墨灰加粗
- **金句副标题** `「文档即智能体 · 经验即资产」`：字号 36-40pt · 深蓝 · 书名号包裹
- **顶/底装饰**：一条深蓝 1px 细线点缀，不喧宾夺主
- **奖项 / 主讲人 / 日期**：底部居中或左对齐 · 中灰 · 小字号（18-20pt）
- **整体**：大面积留白，主标题 + 金句构成唯一视觉焦点
