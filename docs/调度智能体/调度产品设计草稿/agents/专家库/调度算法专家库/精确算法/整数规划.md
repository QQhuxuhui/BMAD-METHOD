## 核心原理

### 理论基础

整数规划（Integer Programming, IP）是数学规划的重要分支，要求部分或全部决策变量取整数值。由George Dantzig等人在1950年代开创，是运筹学中求解离散优化问题的核心方法。

**核心思想**：

- **数学建模**: 将实际问题抽象为数学模型（目标函数 + 约束条件 + 整数变量）
- **求解器求解**: 使用专业求解器（CPLEX、Gurobi、OR-Tools）获得最优解
- **线性松弛**: 通过去除整数约束获得下界（最小化）或上界（最大化）
- **分支定界**: 系统地搜索整数解空间，保证找到全局最优解

**关键概念**：

- **决策变量（Decision Variables）**: 需要优化的未知量，可为整数、0-1变量或混合
- **目标函数（Objective Function）**: 需要最大化或最小化的线性函数
- **约束条件（Constraints）**: 决策变量必须满足的线性不等式或等式
- **可行域（Feasible Region）**: 满足所有约束的整数点集合
- **线性松弛（LP Relaxation）**: 去除整数约束后的线性规划问题
- **整数间隙（Integrality Gap）**: LP松弛最优值与IP最优值之间的差距

**问题分类**：

- **纯整数规划（Pure IP）**: 所有变量都是整数
- **混合整数规划（MIP）**: 部分变量是整数，部分是连续变量
- **0-1整数规划（Binary IP）**: 所有变量只能取0或1
- **整数线性规划（ILP）**: 目标函数和约束都是线性的（最常见）
- **整数非线性规划（INLP）**: 包含非线性项（更复杂）

### 数学模型

**标准形式（最小化问题）**：

```
minimize   c^T x
subject to Ax ≥ b        (不等式约束)
           A_eq x = b_eq (等式约束)
           x ≥ 0
           x_i ∈ Z, ∀i ∈ I  (整数约束)
           x_j ∈ {0,1}, ∀j ∈ B  (0-1约束)
```

其中：

- `x`: n维决策变量向量
- `c`: n维成本系数向量
- `A`: m×n约束系数矩阵
- `b`: m维约束右端向量
- `I`: 整数变量索引集合
- `B`: 0-1变量索引集合

**调度问题典型模型**：

工件-机器分配问题：

```
决策变量:
  x_ij ∈ {0,1}  # 工件i是否分配给机器j

目标函数:
  minimize Σ_i Σ_j c_ij * x_ij  # 最小化总成本

约束条件:
  Σ_j x_ij = 1, ∀i           # 每个工件分配给恰好一台机器
  Σ_i p_i * x_ij ≤ C_j, ∀j   # 每台机器容量限制
  x_ij ∈ {0,1}                # 0-1变量
```

### 核心机制

**求解方法**：

1. **分支定界（Branch and Bound）**：
   - 求解LP松弛获得下界
   - 选择分数值变量进行分支（x ≤ ⌊x*⌋ 或 x ≥ ⌈x*⌉）
   - 递归求解子问题
   - 剪枝：若子问题下界超过当前最优值则剪枝
   - 时间复杂度：指数级 O(2^n)，但剪枝可显著降低

2. **割平面法（Cutting Plane）**：
   - 求解LP松弛
   - 若解不是整数，添加割平面约束（排除当前分数解但保留所有整数解）
   - 重复直到获得整数解
   - 常用割：Gomory割、Cover不等式、Clique不等式

3. **分支切割法（Branch and Cut）**：
   - 结合分支定界和割平面
   - 在分支定界的每个节点添加割平面
   - 现代求解器（CPLEX、Gurobi）的主流方法
   - 大幅减少分支节点数

**预处理技术**：

- **变量固定**: 根据约束推导变量的固定值
- **约束传播**: 收紧变量上下界
- **冗余约束消除**: 删除不起作用的约束
- **系数缩放**: 改善数值稳定性

**启发式方法**：

- **潜水启发式（Diving Heuristic）**: 快速生成可行解作为上界
- **RINS（Relaxation Induced Neighborhood Search）**: 基于LP松弛解的局部搜索
- **可行性泵（Feasibility Pump）**: 快速生成可行解

### 算法伪代码

**基于PuLP的标准实现**：

```python
from pulp import LpProblem, LpMinimize, LpVariable, LpStatus, value, lpSum

def integer_programming_solver(jobs, machines, processing_times, costs, capacities, config):
    """
    整数规划求解器（工件-机器分配问题）

    参数:
        jobs: 工件列表 [J1, J2, ..., Jn]
        machines: 机器列表 [M1, M2, ..., Mm]
        processing_times: 加工时间矩阵 {(i,j): p_ij}
        costs: 成本矩阵 {(i,j): c_ij}
        capacities: 机器容量 {j: C_j}
        config: 求解器配置
            - solver: 求解器类型 ('PULP_CBC_CMD', 'GUROBI', 'CPLEX')
            - time_limit: 时间限制（秒）
            - mip_gap: MIP间隙容忍度（相对误差）
            - threads: 线程数
            - presolve: 是否启用预处理

    返回:
        solution: {
            'assignments': {(i,j): x_ij},  # 分配方案
            'objective': 目标函数值,
            'status': 求解状态,
            'solve_time': 求解时间,
            'gap': MIP间隙
        }
    """

    # 1. 创建问题实例
    prob = LpProblem("Job_Machine_Assignment", LpMinimize)

    # 2. 定义决策变量
    # x[i][j] = 1 表示工件i分配给机器j
    x = {}
    for i in jobs:
        for j in machines:
            x[i, j] = LpVariable(f"x_{i}_{j}", cat='Binary')

    # 3. 定义目标函数
    # minimize Σ_i Σ_j c_ij * x_ij
    prob += lpSum(costs[i, j] * x[i, j] for i in jobs for j in machines), "Total_Cost"

    # 4. 添加约束条件

    # 约束1: 每个工件必须且只能分配给一台机器
    for i in jobs:
        prob += lpSum(x[i, j] for j in machines) == 1, f"Job_{i}_Assignment"

    # 约束2: 每台机器的总加工时间不超过容量
    for j in machines:
        prob += (
            lpSum(processing_times[i, j] * x[i, j] for i in jobs) <= capacities[j],
            f"Machine_{j}_Capacity"
        )

    # 5. 配置求解器
    solver_name = config.get('solver', 'PULP_CBC_CMD')
    solver_options = []

    if config.get('time_limit'):
        solver_options.append(('seconds', config['time_limit']))
    if config.get('mip_gap'):
        solver_options.append(('ratio_gap', config['mip_gap']))
    if config.get('threads'):
        solver_options.append(('threads', config['threads']))

    # 6. 求解
    import time
    start_time = time.time()

    if solver_name == 'PULP_CBC_CMD':
        from pulp import PULP_CBC_CMD
        solver = PULP_CBC_CMD(msg=1, options=solver_options)
    elif solver_name == 'GUROBI':
        from pulp import GUROBI
        solver = GUROBI(msg=1, options=solver_options)
    elif solver_name == 'CPLEX':
        from pulp import CPLEX
        solver = CPLEX(msg=1, options=solver_options)
    else:
        solver = None  # 使用默认求解器

    status = prob.solve(solver)
    solve_time = time.time() - start_time

    # 7. 提取解
    solution = {
        'assignments': {(i, j): value(x[i, j]) for i in jobs for j in machines if value(x[i, j]) > 0.5},
        'objective': value(prob.objective),
        'status': LpStatus[status],
        'solve_time': solve_time,
        'gap': prob.solver.actualGap if hasattr(prob.solver, 'actualGap') else 0.0
    }

    return solution


def build_ip_model_general(variables, objective, constraints, var_types, config):
    """
    通用整数规划建模框架

    参数:
        variables: 变量定义 {name: (lower_bound, upper_bound)}
        objective: 目标函数 {'coeffs': {var: coeff}, 'sense': 'min'/'max'}
        constraints: 约束列表 [{'lhs': {var: coeff}, 'sense': '<=', 'rhs': value}]
        var_types: 变量类型 {var: 'Integer'/'Binary'/'Continuous'}
        config: 求解器配置

    返回:
        problem: PuLP问题对象
        vars_dict: 变量字典
    """

    # 创建问题
    sense = LpMinimize if objective['sense'] == 'min' else LpMaximize
    prob = LpProblem("General_IP", sense)

    # 创建变量
    vars_dict = {}
    for var_name, (lb, ub) in variables.items():
        cat = var_types.get(var_name, 'Continuous')
        vars_dict[var_name] = LpVariable(var_name, lowBound=lb, upBound=ub, cat=cat)

    # 添加目标函数
    prob += lpSum(coeff * vars_dict[var] for var, coeff in objective['coeffs'].items())

    # 添加约束
    for idx, constraint in enumerate(constraints):
        lhs = lpSum(coeff * vars_dict[var] for var, coeff in constraint['lhs'].items())

        if constraint['sense'] == '<=':
            prob += lhs <= constraint['rhs'], f"Constraint_{idx}"
        elif constraint['sense'] == '>=':
            prob += lhs >= constraint['rhs'], f"Constraint_{idx}"
        elif constraint['sense'] == '==':
            prob += lhs == constraint['rhs'], f"Constraint_{idx}"

    return prob, vars_dict
```

**使用OR-Tools的实现**：

```python
from ortools.linear_solver import pywraplp

def solve_with_ortools(jobs, machines, costs, capacities, processing_times, config):
    """
    使用OR-Tools CP-SAT求解器求解整数规划

    适用于大规模0-1规划问题，性能优于PuLP
    """

    # 创建求解器
    solver = pywraplp.Solver.CreateSolver('SCIP')  # 或 'CBC', 'GLOP', 'GUROBI'

    if not solver:
        raise Exception("求解器创建失败")

    # 定义变量
    x = {}
    for i in jobs:
        for j in machines:
            x[i, j] = solver.IntVar(0, 1, f'x_{i}_{j}')

    # 目标函数
    objective = solver.Objective()
    for i in jobs:
        for j in machines:
            objective.SetCoefficient(x[i, j], costs[i, j])
    objective.SetMinimization()

    # 约束1: 工件分配
    for i in jobs:
        constraint = solver.Constraint(1, 1)
        for j in machines:
            constraint.SetCoefficient(x[i, j], 1)

    # 约束2: 容量限制
    for j in machines:
        constraint = solver.Constraint(0, capacities[j])
        for i in jobs:
            constraint.SetCoefficient(x[i, j], processing_times[i, j])

    # 设置求解器参数
    if config.get('time_limit'):
        solver.SetTimeLimit(config['time_limit'] * 1000)  # 毫秒

    # 求解
    status = solver.Solve()

    # 提取结果
    if status == pywraplp.Solver.OPTIMAL or status == pywraplp.Solver.FEASIBLE:
        solution = {
            'assignments': {(i, j): x[i, j].solution_value()
                          for i in jobs for j in machines if x[i, j].solution_value() > 0.5},
            'objective': solver.Objective().Value(),
            'status': 'Optimal' if status == pywraplp.Solver.OPTIMAL else 'Feasible',
            'solve_time': solver.wall_time() / 1000.0
        }
        return solution
    else:
        return {'status': 'Infeasible', 'objective': None}
```

### 实现注意事项

**关键实现细节**：

1. **变量定义规范**：

   ```python

   # ❌ 错误：未指定边界导致求解效率低

   ```

2. **大M方法（建模逻辑约束）**：

   ```python
   # 逻辑约束：如果 y=1，则 x <= 5；如果 y=0，则 x 无限制
   M = 1000  # 足够大的常数
   prob += x <= 5 + M * (1 - y)

   # ⚠️ M不能太大（数值不稳定）也不能太小（约束失效）
   # 推荐：M = max(x的合理上界) * 1.5
   ```

3. **数值稳定性**：

   ```python
   # ❌ 避免系数差异过大
   # 目标: 0.0001*x + 10000*y  (系数相差10^8)

   # ✅ 变量缩放后
   # 目标: x_scaled + y_scaled, where x_scaled = 0.0001*x, y_scaled = 10000*y
   ```

4. **对称性破缺**：
   ```python
   # 对于对称问题（如n个相同机器），添加对称破缺约束

   ```

**常见错误**：

1. **约束遗漏**：

   ```python
   # ❌ 忘记添加非负约束

   # ✅ 显式添加
   x = LpVariable("x", lowBound=0, cat='Integer')
   ```

2. **线性化错误**：

   ```python
   # ❌ 非线性约束无法直接求解
   prob += x * y <= 10  # 两个变量相乘

   # ✅ 需要线性化技巧（如果y是0-1变量）
   # 引入辅助变量 z = x * y
   z = LpVariable("z", lowBound=0, cat='Integer')
   prob += z <= M * y
   prob += z <= x
   prob += z >= x - M * (1 - y)
   ```

## 应用案例

### 案例1：生产调度 - 工件-机器分配

**场景描述**：

某制造企业有15个工件需要在5台不同类型的机器上加工，每个工件只能在一台机器上完成加工，不同机器加工同一工件的成本和时间不同。每台机器每天工作8小时，需要找到最小化总成本的分配方案。

**问题数据**：

- 工件：J1-J15（15个）
- 机器：M1-M5（5台）
- 加工时间：p_ij ∈ [30, 180]分钟
- 加工成本：c_ij ∈ [100, 500]元
- 机器容量：每台480分钟/天

**问题建模**：

```yaml
决策变量:
  x_ij ∈ {0,1}: # 工件i是否分配给机器j
    含义: 'x_ij = 1 表示工件i在机器j上加工，0表示不在'
    规模: 15 × 5 = 75个二值变量

目标函数:
  minimize: Σ_i Σ_j c_ij * x_ij
  含义: 最小化总加工成本

约束条件:
  工件分配约束:
    - Σ_j x_ij = 1, ∀i ∈ {1,...,15} # 每个工件必须且只能分配给一台机器
    - 共15个等式约束

  机器容量约束:
    - Σ_i p_ij * x_ij ≤ 480, ∀j ∈ {1,...,5} # 每台机器总加工时间不超过8小时
    - 共5个不等式约束

  变量类型约束:
    - x_ij ∈ {0,1}, ∀i,j
```

**实施方案**：

```python
from pulp import LpProblem, LpMinimize, LpVariable, lpSum, value

# 问题数据
jobs = list(range(1, 16))  # J1-J15
machines = list(range(1, 6))  # M1-M5

# 加工时间（分钟）
processing_times = {
```

### 案例2：设施选址 - 仓库布局优化

**场景描述**：

**问题数据**：

- 候选仓库位置：L1-L8（8个）
- 客户区域：C1-C12（12个）
- 仓库固定成本：150,000-300,000元/年

**问题建模**：


## 优势与局限

### 优势

- ✅ **最优性保证**：
  - 分支定界算法保证找到全局最优解（在有限时间内或达到收敛条件）
  - LP松弛提供最优性下界，可验证解的质量
  - 与启发式算法不同，不会陷入局部最优

- ✅ **成熟的求解器生态**：
  - 商业求解器（CPLEX、Gurobi）性能极强，可处理百万级变量
  - 开源求解器（CBC、SCIP、GLPK）免费可用，适合中小规模问题
  - 求解器持续优化，性能逐年提升（摩尔定律外的进步）

- ✅ **建模灵活性**：
  - 可表达复杂的逻辑约束（if-then、大M方法、指示变量）
  - 支持多目标优化（加权求和、分层优化）
  - 易于扩展和修改模型（添加约束、改变目标）

- ✅ **理论基础扎实**：
  - 数学原理清晰，可解释性强
  - 丰富的理论工具（对偶理论、灵敏度分析）
  - 学术界和工业界广泛认可

- ✅ **广泛的适用性**：
  - 适用于离散决策问题（0-1选择、整数分配）
  - 可处理线性和部分非线性问题
  - 支持混合整数规划（整数+连续变量）

- ✅ **丰富的工具支持**：
  - Python接口：PuLP、OR-Tools、Pyomo、CVXPY
  - 建模语言：AMPL、GAMS
  - 可视化和分析工具完善

### 局限

- ⚠️ **计算复杂度高**：
  - 整数规划是NP-hard问题，最坏情况指数级时间
  - 大规模问题（>10,000变量）求解时间可能过长
  - 难以预测求解时间，某些实例特别困难

- ⚠️ **规模限制**：
  - 开源求解器（CBC）：适用于<1万变量
  - 商业求解器（Gurobi）：可处理10万-100万变量，但需要授权
  - 超大规模问题（>百万变量）仍然困难

- ⚠️ **建模难度**：
  - 需要将实际问题转化为数学模型（需要专业知识）
  - 非线性约束需要线性化技巧（大M方法、分段线性化）
  - 建模不当可能导致求解效率低下或不可行

- ⚠️ **数值稳定性问题**：
  - 系数差异过大导致数值误差
  - 大M方法中M值选择困难（太大不稳定，太小约束失效）
  - 需要仔细调整容忍度参数

- ⚠️ **求解器依赖**：
  - 商业求解器价格昂贵（Gurobi学术版免费，商业版数万美元/年）
  - 开源求解器性能有限，难以处理大规模问题
  - 不同求解器性能差异大，需要测试选择

- ⚠️ **动态问题处理困难**：
  - 适合静态优化，难以处理动态到达、实时调整
  - 问题数据变化需要重新求解
  - 在线优化场景下延迟可能过高

### 适用性判断

**适合使用的情况**：

1. **问题特征**：
   - 决策变量为整数或0-1变量
   - 目标函数和约束可线性化
   - 问题规模适中（变量数<10,000）
   - 需要最优解或高质量解

2. **应用场景**：
   - 生产调度（工件分配、批量计划）
   - 设施选址（仓库、工厂、基站布局）
   - 资源分配（人员排班、车辆调度）
   - 组合优化（装箱、切割、路径规划）

3. **业务需求**：
   - 对解质量要求高（成本节约、效率提升）
   - 离线优化，允许分钟级计算时间
   - 需要解的可解释性和可验证性
   - 可承担商业求解器成本或规模适合开源求解器

4. **数据条件**：
   - 问题参数已知且相对稳定
   - 数据质量高，约束明确
   - 历史数据可用于模型验证

**不适合使用的情况**：

1. **问题特征**：
   - 问题规模过大（>100,000变量）
   - 高度非线性且难以线性化
   - 约束难以用线性形式表达
   - NP-hard问题中特别困难的实例

2. **应用场景**：
   - 实时在线优化（要求毫秒级响应）
   - 高度动态环境（频繁数据变化）
   - 探索性优化（目标和约束不明确）
   - 连续变量为主的问题（使用线性规划更合适）

3. **业务约束**：
   - 无法承担商业求解器成本且规模超出开源求解器能力
   - 需要秒级甚至毫秒级响应时间
   - 问题定义频繁变化，建模成本高
   - 近似解已满足需求，无需最优解

4. **替代方案更优**：
   - 启发式算法可快速获得满意解
   - 约束规划（CP）更适合调度问题
   - 元启发式算法可处理更大规模
   - 机器学习方法可利用历史数据

## 扩展变种

### 1. 列生成（Column Generation）

**核心思想**：

对于变量数量巨大的整数规划问题，不显式枚举所有变量，而是动态生成有价值的变量（列）。

**适用场景**：

- 切割下料问题（Cutting Stock Problem）
- 车辆路径问题（VRP）
- 班次排程问题（Crew Scheduling）

**算法框架**：

```python
def column_generation(master_problem, subproblem_solver, config):
    """
    列生成算法

    参数:
        master_problem: 主问题（限制主问题，Restricted Master Problem）
        subproblem_solver: 子问题求解器（定价问题，Pricing Problem）
        config: 算法配置
    """

    # 1. 初始化：使用少量初始列
    columns = initialize_columns()
    master_problem.set_columns(columns)

    iteration = 0
    while iteration < config['max_iterations']:
        # 2. 求解限制主问题（LP松弛）
        master_solution = master_problem.solve_lp()
        dual_values = master_solution.get_dual_values()

        # 3. 求解定价子问题（寻找负reduced cost的列）
        new_columns = subproblem_solver.solve(dual_values)

        # 4. 检查停止条件
        if not new_columns or all(col.reduced_cost >= -1e-6 for col in new_columns):
            break  # 无负reduced cost的列，达到最优

        # 5. 添加新列到主问题
        columns.extend(new_columns)
        master_problem.add_columns(new_columns)

        iteration += 1

    # 6. 求解整数问题（对最终列进行分支定界）
    final_solution = master_problem.solve_integer()

    return final_solution
```

**切割下料问题示例**：

```python
# 问题：将标准长度原材料切割成不同长度的成品，最小化原材料使用量

# 主问题：
# minimize Σ_p λ_p  (每个切割模式p的使用次数)
# s.t. Σ_p a_ip * λ_p >= d_i, ∀i  (满足成品i的需求量)
#      λ_p >= 0, integer

# 子问题（定价问题）：
# maximize Σ_i π_i * y_i - 1  (π_i是对偶变量)
# s.t. Σ_i l_i * y_i <= L  (不超过原材料长度)
#      y_i >= 0, integer  (成品i的切割数量)

# 实现
from pulp import LpProblem, LpMinimize, LpVariable, lpSum

def solve_cutting_stock_cg(demands, item_lengths, stock_length):
    """使用列生成求解切割下料问题"""

    # 初始模式：每种成品单独切割
    patterns = []
    for i, length in enumerate(item_lengths):
        pattern = [0] * len(item_lengths)
        pattern[i] = stock_length // length
        patterns.append(pattern)

    max_iterations = 100
    for iteration in range(max_iterations):
        # 主问题
        prob = LpProblem("Master", LpMinimize)
        lambdas = [LpVariable(f"lambda_{p}", lowBound=0) for p in range(len(patterns))]

        prob += lpSum(lambdas), "Minimize_Rolls"

        for i in range(len(item_lengths)):
            prob += (
                lpSum(patterns[p][i] * lambdas[p] for p in range(len(patterns))) >= demands[i],
                f"Demand_{i}"
            )

        prob.solve()

        # 获取对偶值
        dual_values = [prob.constraints[f"Demand_{i}"].pi for i in range(len(item_lengths))]

        # 子问题：背包问题
        subprob = LpProblem("Subproblem", LpMaximize)
        y = [LpVariable(f"y_{i}", lowBound=0, cat='Integer') for i in range(len(item_lengths))]

        subprob += lpSum(dual_values[i] * y[i] for i in range(len(item_lengths))) - 1
        subprob += lpSum(item_lengths[i] * y[i] for i in range(len(item_lengths))) <= stock_length

        subprob.solve()

        # 检查停止条件
        if subprob.objective.value() <= 1e-6:
            break  # 无改进的新模式

        # 添加新模式
        new_pattern = [int(y[i].varValue) for i in range(len(item_lengths))]
        patterns.append(new_pattern)

    # 求解整数主问题
    final_prob = LpProblem("Final_Master", LpMinimize)
    lambdas = [LpVariable(f"lambda_{p}", lowBound=0, cat='Integer') for p in range(len(patterns))]
    # ... (同上约束)
    final_prob.solve()

    return final_prob
```

### 2. Benders分解（Benders Decomposition）

**核心思想**：

将混合整数规划问题分解为主问题（整数变量）和子问题（连续变量），通过迭代添加割平面来求解。

**适用场景**：

- 设施选址与网络流问题
- 两阶段随机规划
- 大规模MIP问题

**算法框架**：

```python
def benders_decomposition(integer_vars, continuous_vars, constraints, objective, config):
    """
    Benders分解算法

    参数:
        integer_vars: 整数变量（第一阶段决策）
        continuous_vars: 连续变量（第二阶段决策）
        constraints: 约束条件
        objective: 目标函数
    """

    # 1. 主问题：仅包含整数变量和辅助变量η
    master = LpProblem("Benders_Master", LpMinimize)
    x = {name: LpVariable(name, cat='Binary') for name in integer_vars}
    eta = LpVariable("eta", lowBound=-float('inf'))  # 子问题目标值的下界

    master += lpSum(c_i * x[i] for i in integer_vars) + eta, "Objective"

    iteration = 0
    LB = -float('inf')  # 下界
    UB = float('inf')   # 上界

    while iteration < config['max_iterations'] and UB - LB > config['gap']:
        # 2. 求解主问题
        master.solve()
        x_solution = {i: x[i].varValue for i in integer_vars}
        LB = master.objective.value()

        # 3. 固定整数变量，求解子问题
        subproblem = build_subproblem(x_solution, continuous_vars, constraints)
        subproblem.solve()

        # 4. 检查子问题可行性
        if subproblem.status == 'Optimal':
            # 可行：添加最优性割（Optimality Cut）
            UB = min(UB, sum(c_i * x_solution[i] for i in integer_vars) + subproblem.objective.value())

            # 获取对偶值，构造割平面
            dual_values = subproblem.get_dual_values()
            cut = build_optimality_cut(dual_values, x, eta)
            master += cut, f"Optimality_Cut_{iteration}"

        else:
            # 不可行：添加可行性割（Feasibility Cut）
            extreme_ray = subproblem.get_extreme_ray()
            cut = build_feasibility_cut(extreme_ray, x)
            master += cut, f"Feasibility_Cut_{iteration}"

        iteration += 1

    return x_solution, subproblem
```

### 3. 整数二次规划（Integer Quadratic Programming, IQP）

**核心思想**：

目标函数或约束包含二次项的整数规划问题。

**标准形式**：

```
minimize   (1/2) x^T Q x + c^T x
subject to Ax >= b
           x_i ∈ Z, ∀i ∈ I
           x_j ∈ {0,1}, ∀j ∈ B
```

**适用场景**：

- 投资组合优化（风险最小化）
- 聚类问题（最小化类内距离平方和）
- 设施选址（考虑距离平方）

**示例：0-1二次规划**：

```python
from pulp import LpProblem, LpMinimize, LpVariable, lpSum
import numpy as np

def solve_binary_quadratic_programming(Q, c, A, b):
    """
    求解0-1二次规划（通过线性化）

    Q: n×n 二次项系数矩阵
    c: n维 线性项系数向量
    """

    n = len(c)

    # 线性化技巧：引入辅助变量 w_ij = x_i * x_j
    prob = LpProblem("Binary_QP", LpMinimize)

    x = [LpVariable(f"x_{i}", cat='Binary') for i in range(n)]
    w = {}
    for i in range(n):
        for j in range(i, n):
            w[i, j] = LpVariable(f"w_{i}_{j}", lowBound=0, upBound=1)

    # 目标函数：(1/2) Σ_i Σ_j Q_ij * w_ij + Σ_i c_i * x_i
    objective = 0.5 * lpSum(Q[i][j] * w[i, j] for i in range(n) for j in range(i, n))
    objective += lpSum(c[i] * x[i] for i in range(n))
    prob += objective

    # 线性化约束：w_ij = x_i * x_j（对于0-1变量）
    for i in range(n):
        for j in range(i, n):
            if i == j:
                prob += w[i, j] == x[i], f"Linearization_{i}_{j}_1"
            else:
                prob += w[i, j] <= x[i], f"Linearization_{i}_{j}_1"
                prob += w[i, j] <= x[j], f"Linearization_{i}_{j}_2"
                prob += w[i, j] >= x[i] + x[j] - 1, f"Linearization_{i}_{j}_3"

    # 原始约束
    for k in range(len(A)):
        prob += lpSum(A[k][i] * x[i] for i in range(n)) >= b[k], f"Constraint_{k}"

    prob.solve()

    return [x[i].varValue for i in range(n)]
```

### 4. 鲁棒优化（Robust Optimization）

**核心思想**：

考虑参数不确定性，优化最坏情况下的性能。

**不确定性集合**：

- 盒式不确定性：`c_i ∈ [c_i - Δ_i, c_i + Δ_i]`
- 椭球不确定性：`||c - c_0||_2 <= Ω`
- 多面体不确定性：`c ∈ {c | Fc <= g}`

**鲁棒对应（Robust Counterpart）**：

```python
# 原问题（确定性）:
# minimize c^T x
# s.t. Ax >= b, x ∈ {0,1}^n

# 鲁棒问题（盒式不确定性）:
# minimize max_{c ∈ [c_min, c_max]} c^T x
# 等价于：minimize c_max^T x (因为要最大化，选择最大系数)

# 鲁棒约束（不确定性在右端）:
# Ax >= b - Δ (最坏情况下右端最小)
```

### 5. 多目标整数规划（Multi-Objective IP）

**方法**：

1. **加权求和法**：

   ```python
   minimize w1*f1(x) + w2*f2(x) + w3*f3(x)
   ```

2. **ε-约束法**：

   ```python
   minimize f1(x)
   s.t. f2(x) <= ε2
        f3(x) <= ε3
   ```

3. **分层优化法**：
   ```python
   # 第一层：优化首要目标
   minimize f1(x)
   # 第二层：在保持f1最优的前提下优化f2
   minimize f2(x)
   s.t. f1(x) <= f1* + δ
   ```

## V4.0 代码生成提示

### 核心类结构

以下是完整的整数规划实现类，包含问题建模、求解、结果提取和验证功能。

```python
"""
整数规划求解器 - V4.0完整实现
支持PuLP、OR-Tools、Gurobi等多种求解器
"""

from pulp import (LpProblem, LpMinimize, LpMaximize, LpVariable,
                  LpStatus, value, lpSum, PULP_CBC_CMD)
from typing import Dict, List, Tuple, Any, Optional
import time
import numpy as np


class IntegerProgramming:
    """
    整数规划求解器核心类

    支持功能：
    - 多种求解器（PuLP-CBC、Gurobi、CPLEX、OR-Tools）
    - 灵活的建模接口
    - 热启动（Warm Start）
    - 求解过程监控
    - 结果验证和敏感性分析
    """

    def __init__(self, config: Dict[str, Any]):
        """
        初始化求解器

        参数:
            config: 求解器配置字典
                - solver: 求解器类型 ('PULP_CBC_CMD', 'GUROBI', 'CPLEX', 'ORTOOLS')
                - time_limit: 时间限制（秒）
                - mip_gap: MIP间隙容忍度
                - threads: 线程数
                - presolve: 是否启用预处理
                - cuts: 割平面策略
                - heuristics: 是否启用启发式
                - log_level: 日志级别 (0-2)
        """
        self.config = config
        self.solver_name = config.get('solver', 'PULP_CBC_CMD')
        self.problem = None
        self.variables = {}
        self.solution = {}
        self.solve_info = {}

    def build_problem(self,
                     variables: Dict[str, Dict],
                     objective: Dict[str, Any],
                     constraints: List[Dict],
                     var_types: Dict[str, str]) -> None:
        """
        构建整数规划模型

        参数:
            variables: 变量定义 {name: {'lb': lower_bound, 'ub': upper_bound}}
            objective: 目标函数 {'sense': 'min'/'max', 'coeffs': {var: coeff}}
            constraints: 约束列表 [{'lhs': {var: coeff}, 'sense': '<=', 'rhs': value, 'name': '...'}]
            var_types: 变量类型 {var: 'Binary'/'Integer'/'Continuous'}
        """

        # 创建问题实例
        sense = LpMinimize if objective['sense'] == 'min' else LpMaximize
        self.problem = LpProblem("IP_Problem", sense)

        # 创建变量
        for var_name, bounds in variables.items():
            lb = bounds.get('lb', 0)
            ub = bounds.get('ub', None)
            cat = var_types.get(var_name, 'Continuous')
            self.variables[var_name] = LpVariable(var_name, lowBound=lb, upBound=ub, cat=cat)

        # 添加目标函数
        obj_expr = lpSum(coeff * self.variables[var]
                        for var, coeff in objective['coeffs'].items()
                        if var in self.variables)
        self.problem += obj_expr, "Objective"

        # 添加约束
        for idx, constraint in enumerate(constraints):
            lhs = lpSum(coeff * self.variables[var]
                       for var, coeff in constraint['lhs'].items()
                       if var in self.variables)

            name = constraint.get('name', f"Constraint_{idx}")

            if constraint['sense'] == '<=':
                self.problem += lhs <= constraint['rhs'], name
            elif constraint['sense'] == '>=':
                self.problem += lhs >= constraint['rhs'], name
            elif constraint['sense'] == '==':
                self.problem += lhs == constraint['rhs'], name

    def set_warm_start(self, initial_solution: Dict[str, float]) -> None:
        """
        设置热启动（初始解）

        参数:
            initial_solution: 初始解 {var_name: value}
        """
        for var_name, value in initial_solution.items():
            if var_name in self.variables:
                self.variables[var_name].setInitialValue(value)

    def solve(self) -> Dict[str, Any]:
        """
        求解整数规划问题

        返回:
            solution: 求解结果字典
                - status: 求解状态
                - objective: 目标函数值
                - variables: 变量取值
                - solve_time: 求解时间
                - mip_gap: MIP间隙
                - iterations: 分支节点数
        """

        if self.problem is None:
            raise ValueError("问题未建立，请先调用build_problem()")

        # 配置求解器
        solver = self._create_solver()

        # 求解
        start_time = time.time()
        status = self.problem.solve(solver)
        solve_time = time.time() - start_time

        # 提取结果
        self.solution = {
            'status': LpStatus[status],
            'objective': value(self.problem.objective) if status == 1 else None,
            'variables': {name: value(var) for name, var in self.variables.items()},
            'solve_time': solve_time,
            'mip_gap': self._get_mip_gap(),
            'iterations': self._get_iterations()
        }

        self.solve_info = {
            'solver': self.solver_name,
            'problem_size': {
                'variables': len(self.variables),
                'constraints': len(self.problem.constraints)
            }
        }

        return self.solution

    def _create_solver(self):
        """创建求解器实例"""

        solver_options = []

        if self.config.get('time_limit'):
            solver_options.append(('seconds', self.config['time_limit']))
        if self.config.get('mip_gap'):
            solver_options.append(('ratio_gap', self.config['mip_gap']))
        if self.config.get('threads'):
            solver_options.append(('threads', self.config['threads']))

        msg = self.config.get('log_level', 1)

        if self.solver_name == 'PULP_CBC_CMD':
            return PULP_CBC_CMD(msg=msg, options=solver_options)
        elif self.solver_name == 'GUROBI':
            from pulp import GUROBI
            return GUROBI(msg=msg, options=solver_options)
        elif self.solver_name == 'CPLEX':
            from pulp import CPLEX
            return CPLEX(msg=msg, options=solver_options)
        else:
            return None  # 使用默认求解器

    def _get_mip_gap(self) -> float:
        """获取MIP间隙"""
        if hasattr(self.problem, 'solver') and hasattr(self.problem.solver, 'actualGap'):
            return self.problem.solver.actualGap
        return 0.0

    def _get_iterations(self) -> int:
        """获取迭代次数（分支节点数）"""
        if hasattr(self.problem, 'solver') and hasattr(self.problem.solver, 'iterations'):
            return self.problem.solver.iterations
        return 0

    def validate_solution(self) -> Dict[str, Any]:
        """
        验证解的可行性

        返回:
            validation: 验证结果
                - feasible: 是否可行
                - violated_constraints: 违反的约束列表
                - constraint_satisfaction: 约束满足度
        """

        if not self.solution or self.solution['status'] != 'Optimal':
            return {'feasible': False, 'reason': '无最优解'}

        violated = []
        total_constraints = len(self.problem.constraints)

        for name, constraint in self.problem.constraints.items():
            lhs_value = value(constraint)
            sense = str(constraint).split()[1]  # '<=', '>=', '=='
            rhs_value = constraint.constant

            violated_flag = False
            if sense == '<=':
                if lhs_value > rhs_value + 1e-6:
                    violated_flag = True
            elif sense == '>=':
                if lhs_value < rhs_value - 1e-6:
                    violated_flag = True
            elif sense == '==':
                if abs(lhs_value - rhs_value) > 1e-6:
                    violated_flag = True

            if violated_flag:
                violated.append({
                    'name': name,
                    'lhs': lhs_value,
                    'sense': sense,
                    'rhs': rhs_value
                })

        return {
            'feasible': len(violated) == 0,
            'violated_constraints': violated,
            'constraint_satisfaction': (total_constraints - len(violated)) / total_constraints * 100
        }

    def get_dual_values(self) -> Dict[str, float]:
        """
        获取对偶值（用于灵敏度分析）

        返回:
            dual_values: 约束对偶值 {constraint_name: dual_value}
        """

        dual_values = {}
        for name, constraint in self.problem.constraints.items():
            if hasattr(constraint, 'pi'):
                dual_values[name] = constraint.pi

        return dual_values

    def export_model(self, filename: str) -> None:
        """
        导出模型为LP或MPS文件

        参数:
            filename: 文件名（.lp或.mps）
        """
        if self.problem:
            self.problem.writeLP(filename)
            print(f"模型已导出到: {filename}")

def test_job_machine_assignment():
    """
    测试用例1：工件-机器分配问题
    """

    # 问题数据
    jobs = [1, 2, 3, 4, 5]
    machines = [1, 2, 3]

    # 成本矩阵
    costs = {
        (1, 1): 10, (1, 2): 15, (1, 3): 12,
        (2, 1): 8, (2, 2): 11, (2, 3): 14,
        (3, 1): 13, (3, 2): 9, (3, 3): 10,
        (4, 1): 12, (4, 2): 13, (4, 3): 8,
        (5, 1): 11, (5, 2): 10, (5, 3): 9
    }

    # 加工时间
    processing_times = {
        (1, 1): 5, (1, 2): 4, (1, 3): 6,
        (2, 1): 3, (2, 2): 5, (2, 3): 4,
        (3, 1): 6, (3, 2): 3, (3, 3): 5,
        (4, 1): 4, (4, 2): 6, (4, 3): 3,
        (5, 1): 5, (5, 2): 4, (5, 3): 5
    }

    # 机器容量
    capacities = {1: 15, 2: 15, 3: 15}

    # 1. 创建求解器
    config = {
        'solver': 'PULP_CBC_CMD',
        'time_limit': 60,
        'mip_gap': 0.01,
        'threads': 4,
        'log_level': 1
    }
    ip_solver = IntegerProgramming(config)

    # 2. 定义变量
    variables = {f"x_{i}_{j}": {'lb': 0, 'ub': 1}
                for i in jobs for j in machines}

    var_types = {f"x_{i}_{j}": 'Binary'
                for i in jobs for j in machines}

    # 3. 定义目标函数
    objective = {
        'sense': 'min',
        'coeffs': {f"x_{i}_{j}": costs[i, j]
                  for i in jobs for j in machines}
    }

    # 4. 定义约束
    constraints = []

    # 工件分配约束
    for i in jobs:
        constraints.append({
            'lhs': {f"x_{i}_{j}": 1 for j in machines},
            'sense': '==',
            'rhs': 1,
            'name': f"Job_{i}_Assignment"
        })

    # 机器容量约束
    for j in machines:
        constraints.append({
            'lhs': {f"x_{i}_{j}": processing_times[i, j] for i in jobs},
            'sense': '<=',
            'rhs': capacities[j],
            'name': f"Machine_{j}_Capacity"
        })

    # 5. 建立模型并求解
    ip_solver.build_problem(variables, objective, constraints, var_types)
    solution = ip_solver.solve()

    # 6. 输出结果
    print(f"求解状态: {solution['status']}")
    print(f"最优成本: {solution['objective']:.2f}")
    print(f"求解时间: {solution['solve_time']:.2f}秒")

    print("\n分配方案:")
    for i in jobs:
        for j in machines:
            if solution['variables'][f"x_{i}_{j}"] > 0.5:
                print(f"  工件{i} → 机器{j}, 成本={costs[i,j]}, 时间={processing_times[i,j]}")

    # 7. 验证解
    validation = ip_solver.validate_solution()
    print(f"\n解验证: {'可行' if validation['feasible'] else '不可行'}")
    print(f"约束满足度: {validation['constraint_satisfaction']:.1f}%")


if __name__ == "__main__":
```
