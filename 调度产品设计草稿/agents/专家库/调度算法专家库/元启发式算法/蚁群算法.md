## 核心原理

### 理论基础

蚁群算法（Ant Colony Optimization, ACO）由意大利学者Marco Dorigo于1992年在其博士论文中首次提出，灵感来源于真实蚂蚁觅食过程中的群体行为。算法通过模拟蚂蚁在寻找食物源时通过信息素（Pheromone）进行间接通信的机制，实现对组合优化问题的高效求解。

**生物学基础**：

真实蚂蚁的觅食行为具有以下特点：

1. **盲目搜索**：单只蚂蚁的感知能力有限，随机探索环境
2. **信息素标记**：蚂蚁在移动路径上释放化学信息素
3. **正反馈机制**：后续蚂蚁倾向于选择信息素浓度高的路径
4. **信息素挥发**：时间流逝导致信息素浓度自然降低
5. **集体智能涌现**：群体协作最终找到从巢穴到食物源的最短路径

**算法核心思想**：

- **分布式计算**：多只人工蚂蚁并行搜索，无需中央控制
- **正反馈强化**：优质路径上的信息素不断积累，吸引更多蚂蚁
- **信息素挥发**：避免早熟收敛，保持搜索多样性
- **启发式引导**：结合问题特定的启发式信息（如距离、成本）
- **间接通信**：蚂蚁通过信息素矩阵共享信息，无需直接交互

**关键概念**：

- **人工蚂蚁（Artificial Ant）**：算法中的基本搜索单元，通过概率规则构建解
- **信息素（Pheromone）**：τij表示从节点i到节点j的信息素浓度，代表历史搜索经验
- **启发式信息（Heuristic Information）**：ηij表示从节点i到节点j的启发式价值（如1/距离）
- **信息素更新**：全局更新和局部更新机制
- **概率转移规则**：蚂蚁选择下一节点的概率函数
- **信息素挥发系数**：ρ ∈ [0,1]，控制信息素的持久性

**与其他算法对比**：

| 算法           | 核心机制        | 适用问题         | 优势                     | 劣势             |
| -------------- | --------------- | ---------------- | ------------------------ | ---------------- |
| **蚁群算法**   | 信息素+概率决策 | 路径、调度、分配 | 正反馈快速收敛，易并行化 | 参数敏感，易早熟 |
| **遗传算法**   | 交叉变异        | 连续、组合优化   | 全局搜索能力强           | 收敛速度慢       |
| **粒子群算法** | 速度位置更新    | 连续优化         | 简单高效                 | 离散问题困难     |
| **禁忌搜索**   | 禁忌表+记忆     | 组合优化         | 局部搜索强               | 需要好的初始解   |

### 核心机制

**算法核心公式**：

1. **状态转移概率**（Ant System基本版本）：

   蚂蚁k在节点i选择下一节点j的概率：

   ```
   p_ij^k(t) = [τ_ij(t)]^α · [η_ij]^β / Σ_l∈allowed_k [τ_il(t)]^α · [η_il]^β
   ```

   其中：
   - τ_ij(t)：t时刻边(i,j)上的信息素浓度
   - η_ij：启发式信息（通常为1/d_ij，d_ij为距离）
   - α：信息素重要程度因子（通常α=1）
   - β：启发式信息重要程度因子（通常β=2-5）
   - allowed_k：蚂蚁k允许访问的节点集合（未访问的节点）

2. **信息素更新规则**：

   **全局更新**（每轮迭代结束后）：

   ```
   τ_ij(t+1) = (1 - ρ) · τ_ij(t) + Δτ_ij(t)
   ```

   其中：
   - ρ ∈ [0,1]：信息素挥发系数
   - Δτ_ij(t) = Σ_k Δτ_ij^k(t)：所有蚂蚁在边(i,j)上释放的信息素之和

   **信息素增量**（Ant System）：

   ```
   Δτ_ij^k(t) = Q / L_k, 如果蚂蚁k经过边(i,j)
   Δτ_ij^k(t) = 0,      否则
   ```

   其中：
   - Q：信息素强度常数
   - L_k：蚂蚁k构建路径的总长度

**算法工作流程**：

```
阶段1: 初始化
├─ 设置参数：α, β, ρ, Q, 蚂蚁数量m, 最大迭代次数
├─ 初始化信息素矩阵：τ_ij(0) = τ_0（小正常数）
└─ 初始化启发式信息矩阵：η_ij = 1/d_ij

阶段2: 构建解（每只蚂蚁）
├─ 随机选择起始节点
├─ while 未访问完所有节点:
│  ├─ 根据状态转移概率选择下一节点j
│  ├─ 移动到节点j，标记为已访问
│  └─ 更新allowed集合
└─ 返回起点，完成路径构建

阶段3: 信息素更新
├─ 计算所有蚂蚁的路径长度L_k
├─ 执行信息素挥发：τ_ij ← (1-ρ)·τ_ij
├─ 累加信息素增量：τ_ij ← τ_ij + Δτ_ij
└─ 可选：信息素边界限制 [τ_min, τ_max]

阶段4: 记录最优解
├─ 更新全局最优解（如果发现更优）
└─ 记录收敛历史

阶段5: 终止判断
├─ 达到最大迭代次数？
├─ 收敛到稳定状态？
└─ 是 → 输出最优解，否 → 返回阶段2
```

**三大改进机制**：

1. **精英蚂蚁策略（Elitist Ant System）**：
   - 对历史最优解额外增加信息素
   - 加速收敛到优质区域

   ```
   τ_ij ← τ_ij + e·(Q/L_best), 如果边(i,j)在最优路径上
   ```

   e为精英蚂蚁权重（通常e=5-10）

2. **信息素边界控制（MMAS - Max-Min Ant System）**：
   - 限制信息素在[τ_min, τ_max]范围内
   - 避免早熟收敛，保持探索能力

   ```
   τ_max = 1 / (ρ · L_best)
   τ_min = τ_max / (2·n)
   ```

3. **局部信息素更新（ACS - Ant Colony System）**：
   - 蚂蚁每访问一条边立即减少信息素
   - 鼓励后续蚂蚁探索不同路径
   ```
   τ_ij ← (1-φ)·τ_ij + φ·τ_0, 蚂蚁访问边(i,j)后
   ```
   φ为局部挥发系数（通常φ=0.1）

## 实现框架

### 算法伪代码

```python
import numpy as np
from typing import List, Tuple, Dict, Callable
import random


class AntColonyOptimization:
    """
    蚁群算法实现类

    支持TSP、VRP等路径优化问题的求解
    实现了AS、ACS、MMAS等多种变种
    """

    def __init__(self,
                 distance_matrix: np.ndarray,
                 num_ants: int = 20,
                 num_iterations: int = 100,
                 alpha: float = 1.0,
                 beta: float = 2.0,
                 rho: float = 0.1,
                 Q: float = 100,
                 variant: str = 'AS',
                 elite_weight: int = 5,
                 local_decay: float = 0.1):
        """
        初始化蚁群算法

        参数:
            distance_matrix: n×n距离矩阵
            num_ants: 蚂蚁数量
            num_iterations: 最大迭代次数
            alpha: 信息素重要程度因子
            beta: 启发式信息重要程度因子
            rho: 信息素挥发系数
            Q: 信息素强度常数
            variant: 算法变种 ('AS', 'ACS', 'MMAS', 'EAS')
            elite_weight: 精英蚂蚁权重
            local_decay: 局部信息素衰减系数
        """
        self.distance_matrix = distance_matrix
        self.num_nodes = len(distance_matrix)
        self.num_ants = num_ants
        self.num_iterations = num_iterations
        self.alpha = alpha
        self.beta = beta
        self.rho = rho
        self.Q = Q
        self.variant = variant
        self.elite_weight = elite_weight
        self.local_decay = local_decay

        # 初始化信息素矩阵
        self.pheromone = np.ones((self.num_nodes, self.num_nodes)) * 0.1

        # 计算启发式信息矩阵 η = 1/distance
        self.heuristic = np.zeros((self.num_nodes, self.num_nodes))
        for i in range(self.num_nodes):
            for j in range(self.num_nodes):
                if i != j and distance_matrix[i][j] > 0:
                    self.heuristic[i][j] = 1.0 / distance_matrix[i][j]

        # MMAS参数
        if variant == 'MMAS':
            self.tau_max = 1.0
            self.tau_min = 0.01

        # 记录
        self.best_path = None
        self.best_distance = float('inf')
        self.convergence_history = []


    def run(self) -> Tuple[List[int], float, List[float]]:
        """
        执行蚁群算法

        返回:
            best_path: 最优路径
            best_distance: 最优路径长度
            convergence_history: 每轮迭代的最优值
        """
        for iteration in range(self.num_iterations):
            # 所有蚂蚁构建解
            paths = []
            distances = []

            for ant in range(self.num_ants):
                path = self._construct_solution()
                distance = self._calculate_path_distance(path)
                paths.append(path)
                distances.append(distance)

                # ACS局部信息素更新
                if self.variant == 'ACS':
                    self._local_pheromone_update(path)

            # 找到本轮最优解
            iter_best_idx = np.argmin(distances)
            iter_best_path = paths[iter_best_idx]
            iter_best_distance = distances[iter_best_idx]

            # 更新全局最优解
            if iter_best_distance < self.best_distance:
                self.best_path = iter_best_path
                self.best_distance = iter_best_distance

            # 全局信息素更新
            self._global_pheromone_update(paths, distances)

            # 记录收敛历史
            self.convergence_history.append(self.best_distance)

            # 动态调整参数（可选）
            if iteration % 20 == 0 and iteration > 0:
                self._adaptive_parameter_adjustment()

            # 输出进度
            if iteration % 10 == 0:
                print(f"Iteration {iteration}: Best = {self.best_distance:.2f}")

        return self.best_path, self.best_distance, self.convergence_history


    def _construct_solution(self) -> List[int]:
        """
        单只蚂蚁构建完整路径

        返回:
            path: 节点访问顺序列表
        """
        # 随机选择起始节点
        current_node = random.randint(0, self.num_nodes - 1)
        path = [current_node]
        visited = {current_node}

        # 构建完整路径
        while len(visited) < self.num_nodes:
            next_node = self._select_next_node(current_node, visited)
            path.append(next_node)
            visited.add(next_node)
            current_node = next_node

        # 返回起点（TSP闭环）
        path.append(path[0])

        return path


    def _select_next_node(self, current: int, visited: set) -> int:
        """
        根据状态转移概率选择下一节点

        参数:
            current: 当前节点
            visited: 已访问节点集合

        返回:
            next_node: 下一个访问的节点
        """
        # 候选节点
        candidates = [j for j in range(self.num_nodes) if j not in visited]

        if not candidates:
            return current

        # ACS伪随机比例规则
        if self.variant == 'ACS':
            q0 = 0.9  # 开发vs探索平衡参数
            q = random.random()

            if q <= q0:
                # 开发：选择最优节点
                scores = []
                for j in candidates:
                    score = (self.pheromone[current][j] ** self.alpha) * \
                           (self.heuristic[current][j] ** self.beta)
                    scores.append(score)
                return candidates[np.argmax(scores)]
            # 否则按概率选择（探索）

        # 标准AS/MMAS概率选择
        probabilities = []
        prob_sum = 0

        for j in candidates:
            tau = self.pheromone[current][j] ** self.alpha
            eta = self.heuristic[current][j] ** self.beta
            prob = tau * eta
            probabilities.append(prob)
            prob_sum += prob

        # 归一化概率
        if prob_sum > 0:
            probabilities = [p / prob_sum for p in probabilities]
        else:
            # 均匀分布
            probabilities = [1.0 / len(candidates)] * len(candidates)

        # 轮盘赌选择
        r = random.random()
        cumulative = 0
        for i, prob in enumerate(probabilities):
            cumulative += prob
            if r <= cumulative:
                return candidates[i]

        return candidates[-1]


    def _calculate_path_distance(self, path: List[int]) -> float:
        """计算路径总长度"""
        distance = 0
        for i in range(len(path) - 1):
            distance += self.distance_matrix[path[i]][path[i+1]]
        return distance


    def _global_pheromone_update(self, paths: List[List[int]],
                                 distances: List[float]):
        """
        全局信息素更新

        参数:
            paths: 所有蚂蚁的路径
            distances: 对应的路径长度
        """
        # 信息素挥发
        self.pheromone *= (1 - self.rho)

        # 根据变种选择更新策略
        if self.variant == 'AS':
            # Ant System: 所有蚂蚁贡献信息素
            for path, distance in zip(paths, distances):
                delta = self.Q / distance
                for i in range(len(path) - 1):
                    self.pheromone[path[i]][path[i+1]] += delta
                    self.pheromone[path[i+1]][path[i]] += delta  # 对称

        elif self.variant == 'EAS':
            # Elitist AS: 普通蚂蚁 + 精英蚂蚁
            # 普通蚂蚁
            for path, distance in zip(paths, distances):
                delta = self.Q / distance
                for i in range(len(path) - 1):
                    self.pheromone[path[i]][path[i+1]] += delta
                    self.pheromone[path[i+1]][path[i]] += delta

            # 精英蚂蚁（最优解额外奖励）
            delta_elite = self.elite_weight * self.Q / self.best_distance
            for i in range(len(self.best_path) - 1):
                self.pheromone[self.best_path[i]][self.best_path[i+1]] += delta_elite
                self.pheromone[self.best_path[i+1]][self.best_path[i]] += delta_elite

        elif self.variant == 'MMAS' or self.variant == 'ACS':
            # MMAS/ACS: 只有最优解更新信息素
            delta = self.Q / self.best_distance
            for i in range(len(self.best_path) - 1):
                self.pheromone[self.best_path[i]][self.best_path[i+1]] += delta
                self.pheromone[self.best_path[i+1]][self.best_path[i]] += delta

        # MMAS: 信息素边界限制
        if self.variant == 'MMAS':
            self.tau_max = 1.0 / (self.rho * self.best_distance)
            self.tau_min = self.tau_max / (2 * self.num_nodes)
            self.pheromone = np.clip(self.pheromone, self.tau_min, self.tau_max)


    def _local_pheromone_update(self, path: List[int]):
        """
        ACS局部信息素更新

        参数:
            path: 蚂蚁访问的路径
        """
        tau0 = 0.1  # 初始信息素值
        for i in range(len(path) - 1):
            # 局部挥发
            self.pheromone[path[i]][path[i+1]] = \
                (1 - self.local_decay) * self.pheromone[path[i]][path[i+1]] + \
                self.local_decay * tau0
            self.pheromone[path[i+1]][path[i]] = self.pheromone[path[i]][path[i+1]]


    def _adaptive_parameter_adjustment(self):
        """动态调整参数（增强算法鲁棒性）"""
        # 检测收敛停滞
        if len(self.convergence_history) >= 20:
            recent = self.convergence_history[-20:]
            if max(recent) - min(recent) < 0.01 * min(recent):
                # 停滞，增加探索
                self.rho = min(0.3, self.rho * 1.1)
                print("  [自适应] 检测到收敛停滞，增加信息素挥发系数")


    def get_statistics(self) -> Dict:
        """获取算法执行统计信息"""
        return {
            'best_distance': self.best_distance,
            'best_path': self.best_path,
            'convergence_speed': self._calculate_convergence_speed(),
            'final_pheromone_variance': np.var(self.pheromone),
            'iterations_to_best': self.convergence_history.index(self.best_distance)
        }


    def _calculate_convergence_speed(self) -> float:
        """计算收敛速度（前50%迭代的改进幅度）"""
        if len(self.convergence_history) < 10:
            return 0.0
        half = len(self.convergence_history) // 2
        improvement = (self.convergence_history[0] -
                      self.convergence_history[half]) / self.convergence_history[0]
        return improvement


# ============= 辅助函数 =============

def generate_random_tsp(num_cities: int, area_size: int = 100) -> np.ndarray:
    """
    生成随机TSP问题实例

    参数:
        num_cities: 城市数量
        area_size: 平面区域大小

    返回:
        distance_matrix: 欧几里得距离矩阵
    """
    # 随机生成城市坐标
    cities = np.random.rand(num_cities, 2) * area_size

    # 计算距离矩阵
    distance_matrix = np.zeros((num_cities, num_cities))
    for i in range(num_cities):
        for j in range(num_cities):
            if i != j:
                distance_matrix[i][j] = np.linalg.norm(cities[i] - cities[j])

    return distance_matrix, cities


def visualize_solution(cities: np.ndarray, path: List[int],
                       title: str = "ACO Solution"):
    """
    可视化TSP解

    参数:
        cities: 城市坐标数组
        path: 访问路径
        title: 图表标题
    """
    try:
        import matplotlib.pyplot as plt

        plt.figure(figsize=(10, 8))

        # 绘制城市
        plt.scatter(cities[:, 0], cities[:, 1], c='red', s=100, zorder=5)

        # 绘制路径
        for i in range(len(path) - 1):
            city1 = cities[path[i]]
            city2 = cities[path[i+1]]
            plt.plot([city1[0], city2[0]], [city1[1], city2[1]],
                    'b-', linewidth=1.5, alpha=0.7)

        # 标注城市编号
        for i, city in enumerate(cities):
            plt.annotate(str(i), (city[0], city[1]),
                        xytext=(5, 5), textcoords='offset points')

        plt.title(title)
        plt.xlabel('X')
        plt.ylabel('Y')
        plt.grid(True, alpha=0.3)
        plt.tight_layout()
        plt.show()
    except ImportError:
        print("需要matplotlib库进行可视化")
```

| num_ants       | 10-50           | 20     | 蚂蚁数量，增加可提高解质量但降低速度 |
| num_iterations | 50-500          | 100    | 迭代次数，根据问题规模调整           |
| alpha (α)      | 0.5-2.0         | 1.0    | 信息素重要程度，α=0退化为贪心算法    |
| beta (β)       | 2.0-5.0         | 2.0    | 启发式信息重要程度，β越大越贪心      |
| rho (ρ)        | 0.01-0.3        | 0.1    | 信息素挥发系数，ρ越大探索性越强      |
| Q              | 1-1000          | 100    | 信息素强度，与问题规模相关           |
| variant        | AS/ACS/MMAS/EAS | AS     | 算法变种选择                         |

**参数调优建议**：

1. **蚂蚁数量vs问题规模**：
   - 小规模问题(n<50): 10-20只蚂蚁
   - 中规模问题(n=50-200): 20-30只蚂蚁
   - 大规模问题(n>200): 30-50只蚂蚁
   - **经验法则**: num_ants ≈ √n 或 0.2n

2. **α和β的平衡**：
   - **α>β**: 更依赖历史经验（信息素），快速收敛但易早熟
   - **α<β**: 更依赖启发式信息（距离），贪心性强
   - **推荐**: α=1, β=2-5（路径问题）或β=1-2（调度问题）

3. **信息素挥发系数ρ**：
   - **小ρ(0.01-0.1)**: 信息素持久，快速收敛，适合解空间平滑
   - **大ρ(0.2-0.5)**: 探索性强，避免早熟，适合多峰问题
   - **自适应策略**: 初期ρ小，后期检测停滞时增大ρ

4. **不同变种的适用场景**：
   - **AS（Ant System）**: 基础版本，适合教学和小规模问题
   - **EAS（Elitist AS）**: 加速收敛，适合质量优先场景
   - **ACS（Ant Colony System）**: 平衡探索与开发，通用性强
   - **MMAS（Max-Min AS）**: 鲁棒性最好，适合大规模复杂问题

### 实现注意事项

**关键实现细节**：

1. **信息素初始化**：

   ```python
   # 方法1: 小正常数（常用）
   tau0 = 0.1

   # 方法2: 基于贪心解（更优）
   greedy_tour_length = construct_greedy_solution()
   tau0 = num_ants / greedy_tour_length
   ```

2. **启发式信息处理**：

   ```python
   # TSP: 距离倒数
   eta[i][j] = 1.0 / distance[i][j]

   # VRP: 考虑时间窗和容量
   eta[i][j] = (1.0 / distance[i][j]) * urgency[j] * feasibility[j]

   # 调度: 考虑处理时间和截止期
   eta[i][j] = 1.0 / (processing_time[j] + due_date[j])
   ```

3. **数值稳定性**：
   ```python
   # 避免概率计算下溢
   log_prob = alpha * np.log(tau + 1e-10) + beta * np.log(eta + 1e-10)
   prob = np.exp(log_prob - np.max(log_prob))  # 减去最大值防止溢出
   prob /= np.sum(prob)
   ```

**性能优化点**：

1. **候选列表策略**：
   - 不评估所有邻居，只考虑最近的k个（k=15-20）
   - 加速节点选择，减少计算量

   ```python
   # 预计算每个节点的候选列表
   candidate_lists = {}
   for i in range(num_nodes):
       distances = [(j, distance[i][j]) for j in range(num_nodes) if i != j]
       distances.sort(key=lambda x: x[1])
       candidate_lists[i] = [j for j, _ in distances[:20]]
   ```

2. **并行化**：
   - 多只蚂蚁的解构建可以并行

   ```python
   from multiprocessing import Pool

   with Pool(processes=4) as pool:
       paths = pool.map(self._construct_solution, range(num_ants))
   ```

3. **缓存机制**：
   - 缓存概率计算结果
   - 缓存距离/启发式信息

**常见错误**：

1. **信息素过度累积**：
   - 症状：算法很快收敛到次优解
   - 原因：ρ过小或信息素更新量过大
   - 解决：增大ρ或使用MMAS边界限制

2. **早熟收敛**：
   - 症状：所有蚂蚁走相同路径，失去多样性
   - 原因：β过大或α/ρ设置不当
   - 解决：降低β，增大ρ，或周期性重新初始化信息素

3. **收敛慢**：
   - 症状：迭代很多次仍无明显改进
   - 原因：α过小或蚂蚁数量不足
   - 解决：增大α，增加蚂蚁数量，或使用精英策略

4. **内存溢出**：
   - 症状：大规模问题（n>5000）运行崩溃
   - 原因：信息素矩阵过大（n×n）
   - 解决：稀疏矩阵存储或分块处理

### 案例2：车辆路径规划（VRP）

**场景描述**：

物流公司需要用5辆容量为100单位的货车，从配送中心向30个客户配送货物。每个客户有特定需求量和时间窗约束，求最小化总行驶距离的车辆路径方案。

**问题建模**：

```yaml
决策变量:
  - 路径集合: R = {r1, r2, r3, r4, r5}
  - 每条路径: rk = (depot, c1, c2, ..., depot)

约束条件:
  - 容量约束: Σ(c∈rk) demand[c] ≤ 100, ∀k
  - 时间窗约束: service_time[c] ∈ [earliest[c], latest[c]]
  - 每个客户恰好被一辆车访问一次

目标函数:
  - minimize: Σ(k=1 to 5) distance(rk)

问题数据:
  - 车辆数: 5
  - 客户数: 30
  - 车辆容量: 100
  - 客户需求: 5-25单位（随机）
  - 时间窗: [8:00-18:00]
```

**实施方案**：

```python
class ACO_VRP(AntColonyOptimization):
    """
    VRP问题的ACO扩展实现
    """

    def __init__(self, distance_matrix, demands, capacity,
                 time_windows=None, **kwargs):
        super().__init__(distance_matrix, **kwargs)
        self.demands = demands
        self.capacity = capacity
        self.time_windows = time_windows
        self.depot = 0  # 配送中心为节点0


    def _construct_solution(self) -> List[List[int]]:
        """构建VRP解（多条路径）"""
        unvisited = set(range(1, self.num_nodes))  # 排除depot
        routes = []

        while unvisited:
            # 每辆车从depot出发
            route = [self.depot]
            current_load = 0
            current_node = self.depot
            current_time = 0

            while unvisited:
                # 筛选可行的下一节点（容量+时间窗）
                feasible = []
                for node in unvisited:
                    # 检查容量约束
                    if current_load + self.demands[node] <= self.capacity:
                        # 检查时间窗约束（如果有）
                        if self.time_windows is None or \
                           self._check_time_window(current_node, node, current_time):
                            feasible.append(node)

                if not feasible:
                    # 无可行节点，返回depot
                    break

                # 从可行节点中按概率选择
                next_node = self._select_next_node_vrp(
                    current_node, feasible, current_load
                )

                route.append(next_node)
                unvisited.remove(next_node)
                current_load += self.demands[next_node]
                current_time += self.distance_matrix[current_node][next_node]
                current_node = next_node

            # 返回depot
            route.append(self.depot)
            routes.append(route)

        return routes


    def _select_next_node_vrp(self, current, feasible, current_load):
        """VRP专用节点选择（考虑需求和容量）"""
        probabilities = []

        for node in feasible:
            # 信息素
            tau = self.pheromone[current][node] ** self.alpha

            # 启发式：距离倒数 + 需求量惩罚
            distance_heuristic = 1.0 / self.distance_matrix[current][node]
            demand_penalty = 1.0 / (1 + self.demands[node] / self.capacity)
            eta = (distance_heuristic * demand_penalty) ** self.beta

            probabilities.append(tau * eta)

        # 归一化并选择
        prob_sum = sum(probabilities)
        if prob_sum > 0:
            probabilities = [p / prob_sum for p in probabilities]
        else:
            probabilities = [1.0/len(feasible)] * len(feasible)

        # 轮盘赌
        r = random.random()
        cumulative = 0
        for i, prob in enumerate(probabilities):
            cumulative += prob
            if r <= cumulative:
                return feasible[i]
        return feasible[-1]


    def _calculate_routes_distance(self, routes):
        """计算所有路径的总距离"""
        total_distance = 0
        for route in routes:
            for i in range(len(route) - 1):
                total_distance += self.distance_matrix[route[i]][route[i+1]]
        return total_distance


# 使用示例
```

### 案例3：作业车间调度（Job Shop Scheduling）

**场景描述**：

工厂有5台机器需要加工10个作业，每个作业有特定的工序顺序和加工时间。目标是最小化完工时间（Makespan）。

**问题建模**：

```yaml
决策变量:
  - 作业调度序列: S = {s1, s2, ..., s50}
  - si表示第i个工序的开始时间

约束条件:
  - 工序顺序约束: 同一作业的工序必须按顺序执行
  - 机器约束: 同一时刻每台机器最多执行一个工序
  - 非抢占约束: 工序一旦开始不能中断

目标函数:
  - minimize: max(完工时间[j]), ∀作业j

问题数据:
  - 作业数: 10
  - 机器数: 5
  - 总工序数: 50 (每个作业5道工序)
```

**实施方案**：

```python
class ACO_JSP:
    """作业车间调度问题的ACO实现"""

    def __init__(self, jobs_data, num_ants=20, num_iterations=100):
        """
        参数:
            jobs_data: [(job_id, [(machine, time), ...]), ...]
        """
        self.jobs_data = jobs_data
        self.num_jobs = len(jobs_data)
        self.num_operations = sum(len(ops) for _, ops in jobs_data)
        self.num_ants = num_ants
        self.num_iterations = num_iterations

        # 初始化信息素矩阵（工序层面）
        self.pheromone = np.ones((self.num_operations, self.num_operations)) * 0.1

        self.best_schedule = None
        self.best_makespan = float('inf')


    def run(self):
        """执行ACO求解JSP"""
        for iteration in range(self.num_iterations):
            schedules = []
            makespans = []

            # 所有蚂蚁构建调度方案
            for ant in range(self.num_ants):
                schedule, makespan = self._construct_schedule()
                schedules.append(schedule)
                makespans.append(makespan)

            # 更新最优解
            iter_best_idx = np.argmin(makespans)
            if makespans[iter_best_idx] < self.best_makespan:
                self.best_schedule = schedules[iter_best_idx]
                self.best_makespan = makespans[iter_best_idx]

            # 更新信息素
            self._update_pheromone(schedules, makespans)

            if iteration % 10 == 0:
                print(f"Iteration {iteration}: Best Makespan = {self.best_makespan}")

        return self.best_schedule, self.best_makespan


    def _construct_schedule(self):
        """构建一个调度方案"""
        # 跟踪每个作业的下一道工序
        job_next_op = {job_id: 0 for job_id, _ in self.jobs_data}

        # 机器时间表
        machine_schedule = {i: [] for i in range(5)}

        # 作业完工时间
        job_completion = {job_id: 0 for job_id, _ in self.jobs_data}

        schedule = []

        # 调度所有工序
        for _ in range(self.num_operations):
            # 找到所有可调度的工序
            available_ops = []
            for job_id, operations in self.jobs_data:
                next_op_idx = job_next_op[job_id]
                if next_op_idx < len(operations):
                    available_ops.append((job_id, next_op_idx))

            if not available_ops:
                break

            # 按信息素+启发式选择工序
            selected_job, selected_op_idx = self._select_operation(
                available_ops, job_completion
            )

            # 获取工序信息
            machine, proc_time = self.jobs_data[selected_job][1][selected_op_idx]

            # 计算开始时间（max(作业就绪时间, 机器可用时间)）
            job_ready_time = job_completion[selected_job]
            machine_ready_time = max([end for _, end in machine_schedule[machine]],
                                    default=0)
            start_time = max(job_ready_time, machine_ready_time)
            end_time = start_time + proc_time

            # 更新
            schedule.append((selected_job, selected_op_idx, machine,
                           start_time, end_time))
            machine_schedule[machine].append((start_time, end_time))
            job_completion[selected_job] = end_time
            job_next_op[selected_job] += 1

        # 计算makespan
        makespan = max(job_completion.values())

        return schedule, makespan


    def _select_operation(self, available_ops, job_completion):
        """选择下一个调度的工序"""
        # 简化：基于启发式（最短加工时间优先+信息素）
        probabilities = []

        for job_id, op_idx in available_ops:
            machine, proc_time = self.jobs_data[job_id][1][op_idx]

            # 启发式：倾向选择加工时间短的
            eta = 1.0 / proc_time

            # 信息素（简化版本）
            tau = self.pheromone[job_id][op_idx]

            probabilities.append(tau * eta ** 2)

        # 归一化并选择
        prob_sum = sum(probabilities)
        probabilities = [p / prob_sum for p in probabilities]

        r = random.random()
        cumulative = 0
        for i, prob in enumerate(probabilities):
            cumulative += prob
            if r <= cumulative:
                return available_ops[i]

        return available_ops[-1]


    def _update_pheromone(self, schedules, makespans):
        """更新信息素"""
        rho = 0.1
        self.pheromone *= (1 - rho)

        # 只有最优解更新信息素
        best_idx = np.argmin(makespans)
        best_schedule = schedules[best_idx]
        delta = 100.0 / makespans[best_idx]

        for job_id, op_idx, _, _, _ in best_schedule:
            self.pheromone[job_id][op_idx] += delta


# 使用示例

    (1, [(1, 2), (0, 4), (3, 3), (4, 2), (2, 3)]),  # Job 1
    # ... 更多作业
]
```

## 优势与局限

### 优势

- ✅ **正反馈机制强大**：优质路径上的信息素累积形成自强化，快速收敛到高质量解
- ✅ **天然并行性**：多只蚂蚁独立构建解，易于并行化实现，加速计算
- ✅ **鲁棒性好**：通过信息素挥发和随机选择，不易陷入局部最优
- ✅ **适应性强**：可灵活应用于TSP、VRP、JSP等多种组合优化问题
- ✅ **分布式特性**：无需中央控制，蚂蚁通过信息素间接通信，适合分布式系统
- ✅ **可解释性强**：算法机制直观，基于生物学原理，易于理解和调试
- ✅ **易于混合**：可与局部搜索（2-opt、3-opt）结合，进一步提升解质量

### 局限

- ⚠️ **参数敏感**：α、β、ρ等参数对性能影响大，需要针对问题调优
- ⚠️ **收敛速度不稳定**：参数设置不当可能导致早熟收敛或收敛过慢
- ⚠️ **理论分析困难**：缺乏严格的收敛性证明和时间复杂度分析
- ⚠️ **连续优化能力弱**：主要适用于离散/组合优化，处理连续变量需要特殊设计
- ⚠️ **大规模问题挑战**：n>5000时，信息素矩阵(n×n)占用内存大，计算开销高
- ⚠️ **停滞现象**：长时间无改进时，所有蚂蚁可能走相同路径，失去多样性

### 适用性判断

**适合使用的情况**：

1. **组合优化问题**：
   - 路径类：TSP、VRP、网络路由、物流配送
   - 调度类：作业调度、任务分配、生产排程
   - 分配类：二次分配、图着色、集合覆盖

2. **问题特征**：
   - 解空间离散且规模适中（n<5000）
   - 存在可利用的启发式信息（如距离、成本）
   - 子解的质量可叠加（路径可分段评估）
   - 需要多个高质量解（而非唯一最优解）

3. **应用场景**：
   - 实时性要求不极端（可接受秒级-分钟级）
   - 需要鲁棒性（解质量稳定性重要）
   - 可并行计算环境
   - 问题实例频繁变化（算法易于调整）

**不适合使用的情况**：

1. **连续优化问题**：
   - 高维连续函数优化（用DE、PSO更好）
   - 梯度信息可用的问题（用梯度下降）

2. **问题特征**：
   - 超大规模（n>10000，内存和计算瓶颈）
   - 极端实时性要求（<100ms，用贪心或规则）
   - 单峰凸优化（简单算法更高效）
   - 需要精确最优解且有精确算法可用

3. **应用场景**：
   - 在线实时决策（毫秒级响应）
   - 理论最优性证明需求
   - 资源极度受限（嵌入式系统）

**决策流程图**：

```
问题是组合优化？
├─ 是 → 规模<5000节点？
│       ├─ 是 → 有启发式信息？
│       │       ├─ 是 → 可接受秒级计算？
│       │       │       ├─ 是 → ✅ 推荐使用ACO
│       │       │       └─ 否 → 考虑贪心启发式
│       │       └─ 否 → 考虑遗传算法
│       └─ 否 → 考虑分解或近似算法
└─ 否 → 连续优化？
        ├─ 是 → 使用DE/PSO/梯度方法
        └─ 否 → 考虑约束规划或混合整数规划
```

## 扩展变种

蚁群算法自1992年提出以来，发展出众多改进变种。以下介绍最重要和常用的几种：

### 1. Ant System (AS) - 基础版本

**提出者**: Marco Dorigo (1992)

**核心特点**：

- 所有蚂蚁在路径上留下信息素
- 信息素更新发生在所有蚂蚁完成后
- 最原始和最基础的版本

**更新规则**：

```
τ_ij(t+1) = (1-ρ)·τ_ij(t) + Σ_k Δτ_ij^k
Δτ_ij^k = Q/L_k, 如果蚂蚁k使用了边(i,j)
```

**适用场景**: 小规模问题、教学演示、算法原理研究

### 2. Elitist Ant System (EAS) - 精英策略

**核心改进**：

- 对历史最优解给予额外信息素奖励
- 加速向优质区域收敛

**更新规则**：

```
τ_ij(t+1) = (1-ρ)·τ_ij(t) + Σ_k Δτ_ij^k + e·Δτ_ij^best
其中 e 为精英权重（通常5-10）
Δτ_ij^best = Q/L_best, 如果边(i,j)在最优路径上
```

**实现要点**：

```python
# 精英蚂蚁信息素更新
def elitist_update(pheromone, best_path, best_distance, elite_weight, Q):
    delta_elite = elite_weight * Q / best_distance
    for i in range(len(best_path) - 1):
        pheromone[best_path[i]][best_path[i+1]] += delta_elite
    return pheromone
```

**参数建议**：

- 精英权重 e: 5-10（小问题用5，大问题用10）
- 其他参数与AS相同

### 3. Ant Colony System (ACS) - 系统化改进

**提出者**: Dorigo & Gambardella (1997)

**三大核心改进**：

1. **伪随机比例规则** (Pseudo-random Proportional Rule)：

   ```
   若 q ≤ q0: 选择 argmax[τ_ij^α · η_ij^β] (开发)
   否则: 按概率选择 (探索)

   其中 q ∈ [0,1]随机数, q0=0.9
   ```

2. **局部信息素更新**：

   ```
   蚂蚁每访问边(i,j)后立即执行:
   τ_ij ← (1-φ)·τ_ij + φ·τ_0

   φ=0.1 (局部衰减系数)
   ```

3. **全局更新仅用最优解**：
   ```
   τ_ij ← (1-ρ)·τ_ij + ρ·Δτ_ij^best
   ```

**实现示例**：

```python
def acs_select_next_node(current, candidates, pheromone, heuristic,
                         alpha, beta, q0=0.9):
    """ACS伪随机比例规则"""
    q = random.random()

    if q <= q0:
        # 开发：选择最优
        scores = [(pheromone[current][j] ** alpha) *
                 (heuristic[current][j] ** beta)
                 for j in candidates]
        return candidates[np.argmax(scores)]
    else:
        # 探索：按概率选择
        return probabilistic_selection(current, candidates,
                                       pheromone, heuristic, alpha, beta)

def acs_local_update(pheromone, edge, phi=0.1, tau0=0.1):
    """ACS局部信息素更新"""
    i, j = edge
    pheromone[i][j] = (1 - phi) * pheromone[i][j] + phi * tau0
    pheromone[j][i] = pheromone[i][j]
```

**适用场景**: 通用性最强，适合各类组合优化问题

### 4. Max-Min Ant System (MMAS) - 边界限制

**提出者**: Stützle & Hoos (2000)

**核心改进**：

1. **信息素边界**：

   ```
   τ_min ≤ τ_ij ≤ τ_max

   τ_max = 1 / (ρ · L_best)
   τ_min = τ_max / (2·n)  或  τ_max / a  (a=参数)
   ```

2. **只有最优蚂蚁更新信息素**：
   - 可以是迭代最优或全局最优
   - 通常两者交替使用

3. **信息素重新初始化**：
   - 检测到停滞时重置为τ_max
   - 保持搜索多样性

**实现示例**：

```python
class MMAS(AntColonyOptimization):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self.tau_max = 1.0
        self.tau_min = 0.01
        self.stagnation_count = 0

    def global_pheromone_update(self, best_path, best_distance):
        # 挥发
        self.pheromone *= (1 - self.rho)

        # 只有最优解更新
        delta = self.Q / best_distance
        for i in range(len(best_path) - 1):
            self.pheromone[best_path[i]][best_path[i+1]] += delta

        # 边界限制
        self.tau_max = 1.0 / (self.rho * best_distance)
        self.tau_min = self.tau_max / (2 * self.num_nodes)
        self.pheromone = np.clip(self.pheromone, self.tau_min, self.tau_max)

        # 停滞检测和重新初始化
        if self._detect_stagnation():
            self.pheromone.fill(self.tau_max)
            self.stagnation_count = 0

    def _detect_stagnation(self):
        """检测是否停滞（多样性过低）"""
        variance = np.var(self.pheromone)
        if variance < 0.001:
            self.stagnation_count += 1
        else:
            self.stagnation_count = 0

        return self.stagnation_count > 20
```

**参数建议**：

- τ_max: 动态计算（基于最优解）
- τ_min: τ_max / (2n) 或 τ_max / 10
- 停滞检测阈值: 20-50次迭代无改进

**适用场景**: 大规模复杂问题，鲁棒性要求高

### 5. Rank-Based Ant System (AS-rank)

**核心思想**：

- 根据蚂蚁解的质量排名
- 排名靠前的蚂蚁贡献更多信息素

**更新规则**：

```
τ_ij(t+1) = (1-ρ)·τ_ij(t) + Σ(r=1 to w) (w-r+1)·Δτ_ij^r + w·Δτ_ij^best

其中:
- w: 权重蚂蚁数量（如取前6只）
- r: 蚂蚁排名（1=最优）
- (w-r+1): 排名权重（线性递减）
```

**实现示例**：

```python
def rank_based_update(pheromone, paths, distances, best_path,
                      best_distance, w=6, rho=0.1, Q=100):
    # 挥发
    pheromone *= (1 - rho)

    # 按距离排名
    ranked = sorted(zip(paths, distances), key=lambda x: x[1])

    # 前w只蚂蚁贡献信息素
    for rank, (path, distance) in enumerate(ranked[:w], 1):
        weight = w - rank + 1
        delta = weight * Q / distance
        for i in range(len(path) - 1):
            pheromone[path[i]][path[i+1]] += delta

    # 最优解额外奖励
    delta_best = w * Q / best_distance
    for i in range(len(best_path) - 1):
        pheromone[best_path[i]][best_path[i+1]] += delta_best

    return pheromone
```

### 6. 混合策略：ACO + 局部搜索

将ACO与局部搜索算法结合，显著提升解质量：

**常用局部搜索算子**：

1. **2-opt** (TSP路径优化)：

```python
def two_opt(path, distance_matrix):
    """2-opt局部搜索"""
    improved = True
    best_path = path[:]

    while improved:
        improved = False
        for i in range(1, len(path) - 2):
            for j in range(i + 1, len(path) - 1):
                # 尝试反转path[i:j+1]
                new_path = path[:i] + path[i:j+1][::-1] + path[j+1:]

                if calculate_distance(new_path, distance_matrix) < \
                   calculate_distance(best_path, distance_matrix):
                    best_path = new_path
                    improved = True
        path = best_path

    return best_path
```

2. **3-opt** (更强的TSP局部搜索)

3. **Or-opt** (移动子序列)

**混合框架**：

```python
class HybridACO(AntColonyOptimization):
    def construct_and_improve(self):
        """构建解 + 局部搜索"""
        # 构建初始解
        path = self._construct_solution()

        # 局部搜索改进
        improved_path = self.local_search(path)

        return improved_path
```

**协作模式3: 多目标优化（MOACO）**

```python
class MultiObjectiveACO:
    """多目标蚁群算法（Pareto最优解集）"""

    def __init__(self, distance_matrix, cost_matrix, num_ants=20):
        self.distance_matrix = distance_matrix
        self.cost_matrix = cost_matrix
        # 为每个目标维护独立信息素
        self.pheromone_distance = np.ones_like(distance_matrix) * 0.1
        self.pheromone_cost = np.ones_like(cost_matrix) * 0.1
        self.pareto_front = []

    def select_next_node(self, current, candidates):
        """基于多目标的节点选择"""
        probs = []
        for j in candidates:
            # 聚合两个目标的信息素
            tau_dist = self.pheromone_distance[current][j]
            tau_cost = self.pheromone_cost[current][j]
            tau_combined = tau_dist * tau_cost  # 或加权组合

            eta_dist = 1.0 / self.distance_matrix[current][j]
            eta_cost = 1.0 / self.cost_matrix[current][j]
            eta_combined = eta_dist * eta_cost

            probs.append(tau_combined * eta_combined ** 2)

        return probabilistic_selection(probs, candidates)

    def update_pareto_front(self, new_solution, distance, cost):
        """更新Pareto最优解集"""
        # 检查是否被支配
        dominated = False
        to_remove = []

        for sol, d, c in self.pareto_front:
            if d <= distance and c <= cost and (d < distance or c < cost):
                # 新解被支配
                dominated = True
                break
            elif distance <= d and cost <= c and (distance < d or cost < c):
                # 新解支配旧解
                to_remove.append((sol, d, c))

        if not dominated:
            # 移除被支配的解
            for item in to_remove:
                self.pareto_front.remove(item)
            # 添加新解
            self.pareto_front.append((new_solution, distance, cost))

# 使用
moaco = MultiObjectiveACO(distance_matrix, cost_matrix)
pareto_solutions = moaco.run()
print(f"找到{len(pareto_solutions)}个Pareto最优解")
```

```python
                 distance_matrix: np.ndarray,
                 config: Optional[ACOConfig] = None):
        """初始化ACO求解器"""
        self.distance_matrix = distance_matrix
        self.num_nodes = len(distance_matrix)
        self.config = config or ACOConfig()

        if self.config.seed is not None:
            random.seed(self.config.seed)
            np.random.seed(self.config.seed)

        # 初始化
        self._initialize_pheromone()
        self._initialize_heuristic()

        # 状态
        self.best_solution = None
        self.best_objective = float('inf')
        self.convergence_history = []
        self.iteration_count = 0


    def _initialize_pheromone(self):
        """初始化信息素矩阵"""
        # 基于贪心解初始化（可选）
        if hasattr(self.config, 'init_with_greedy') and self.config.init_with_greedy:
            greedy_length = self._greedy_solution_length()
            tau0 = self.config.num_ants / greedy_length
        else:
            tau0 = 0.1

        self.pheromone = np.ones((self.num_nodes, self.num_nodes)) * tau0

        if self.config.variant == ACOVariant.MMAS:
            self.tau_max = 1.0
            self.tau_min = 0.01


    def _initialize_heuristic(self):
        """初始化启发式信息矩阵"""
        self.heuristic = np.zeros((self.num_nodes, self.num_nodes))
        for i in range(self.num_nodes):
            for j in range(self.num_nodes):
                if i != j and self.distance_matrix[i][j] > 0:
                    self.heuristic[i][j] = 1.0 / self.distance_matrix[i][j]


    def run(self) -> ACOResult:
        """执行ACO算法"""
        import time
        start_time = time.time()

        for iteration in range(self.config.num_iterations):
            self.iteration_count = iteration

            # 构建解
            solutions, objectives = self._construct_solutions()

            # 更新最优解
            iter_best_idx = np.argmin(objectives)
            if objectives[iter_best_idx] < self.best_objective:
                self.best_solution = solutions[iter_best_idx]
                self.best_objective = objectives[iter_best_idx]
                self.best_iteration = iteration

            # 更新信息素
            self._update_pheromone(solutions, objectives)

            # 记录
            self.convergence_history.append(self.best_objective)

            # 自适应调整
            if iteration % 20 == 0:
                self._adaptive_adjustment()

            # 日志
            if iteration % 10 == 0:
                print(f"Iter {iteration}: Best = {self.best_objective:.2f}")

        computation_time = time.time() - start_time

        return ACOResult(
            best_solution=self.best_solution,
            best_objective=self.best_objective,
            convergence_history=self.convergence_history,
            iterations_used=self.iteration_count + 1,
            computation_time=computation_time,
            best_iteration=self.best_iteration,
            final_pheromone=self.pheromone.copy(),
            statistics=self._gather_statistics()
        )


    def _construct_solutions(self) -> Tuple[List[List[int]], List[float]]:
        """所有蚂蚁构建解"""
        solutions = []
        objectives = []

        for _ in range(self.config.num_ants):
            solution = self._construct_single_solution()
            objective = self._evaluate(solution)

            # 可选局部搜索

                solution = self._local_search(solution)
                objective = self._evaluate(solution)
```
