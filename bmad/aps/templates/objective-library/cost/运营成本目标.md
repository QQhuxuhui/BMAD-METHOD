## 📖 定义

**运营成本** = 设备运行成本 + 人力成本 + 能耗成本 + 维护成本

## 🔧 代码实现

```python
from typing import Dict, List

class OperationalCostObjective:
    """运营成本目标函数"""

    def __init__(self, weight: float = 1.0):
        self.name = "operational_cost"
        self.optimization_type = "minimize"
        self.weight = weight

    def evaluate(self, solution: Dict, config: Dict) -> float:
        """
        评估运营成本

        config包含:
          - equipment_cost: 设备成本率
          - labor_cost: 人力成本
          - energy_cost: 能耗成本率
          - maintenance_cost: 维护成本
        """
        equipment_cost = config.get('equipment_cost', 0.0)
        labor_cost = config.get('labor_cost', 0.0)
        energy_cost_rate = config.get('energy_cost', 0.0)
        maintenance_cost = config.get('maintenance_cost', 0.0)

        total_operating_time = sum(
            sum(task.get('duration', 0) for task in tasks)
            for tasks in solution.values()
        )

        operational_cost = (
            equipment_cost * total_operating_time +
            labor_cost +
            energy_cost_rate * total_operating_time +
            maintenance_cost
        )

        return operational_cost
```
