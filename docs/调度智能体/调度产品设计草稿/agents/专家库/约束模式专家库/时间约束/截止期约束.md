## 📖 约束概述

### 定义

**截止期约束**（Deadline Constraint）规定任务必须在指定的截止时间之前完成，超过截止期将产生惩罚或导致方案不可行。

**数学定义**：

```
对于任务 i，定义截止期 D_i
完工时间 C_i

硬截止期约束：C_i ≤ D_i
软截止期约束：C_i > D_i 时产生惩罚 P(C_i - D_i)
```

### 约束类型

1. **硬截止期** (Hard Deadline)
   - 绝对不能违反
   - C_i > D_i 则方案不可行

2. **软截止期** (Soft Deadline)
   - 可以违反但有惩罚
   - 延迟惩罚函数: P = α × (C_i - D_i)

3. **优先级截止期** (Priority Deadline)
   - 不同任务截止期重要性不同
   - 高优先级任务延迟惩罚更高

## 💡 核心理论

### 完工时间计算

```python
def calculate_completion_time(start_time, processing_time, task_dependencies):
    """
    计算任务完工时间

    C_i = max(r_i, max(C_j + t_ji)) + p_i

    其中:
      r_i: 释放时间/最早开始时间
      C_j: 前序任务j的完工时间
      t_ji: 从j到i的转换时间
      p_i: 处理时间
    """
    earliest_start = start_time

    for dep_task in task_dependencies:
        dep_completion = dep_task.completion_time
        transition_time = get_transition_time(dep_task, current_task)
        earliest_start = max(earliest_start, dep_completion + transition_time)

    completion_time = earliest_start + processing_time
    return completion_time
```

### 延迟惩罚函数

**线性惩罚**：

```
P(t) = α × max(0, C_i - D_i)
```

**二次惩罚**（延迟越久惩罚越重）：

```
P(t) = α × max(0, C_i - D_i)²
```

**分段惩罚**：

```
P(t) = {
  0,              if C_i ≤ D_i
  α₁(C_i - D_i),  if D_i < C_i ≤ D_i + Δ
  α₂(C_i - D_i),  if C_i > D_i + Δ
}
其中 α₂ >> α₁ (严重延迟惩罚更重)
```

## 🔧 代码实现

```python
from typing import Dict, List, Tuple
from dataclasses import dataclass
from datetime import datetime, timedelta
from enum import Enum

class DeadlineType(Enum):
    """截止期类型"""
    HARD = "hard"
    SOFT = "soft"
    PRIORITY = "priority"

@dataclass
class Task:
    """任务定义"""
    id: str
    processing_time: timedelta
    deadline: datetime
    deadline_type: DeadlineType = DeadlineType.SOFT
    priority: int = 1
    dependencies: List[str] = None

    def __post_init__(self):
        if self.dependencies is None:
            self.dependencies = []

class DeadlineConstraintHandler:
    """截止期约束处理器"""

    def __init__(self, tasks: Dict[str, Task],
                 linear_penalty: float = 1.0,
                 quadratic_penalty: float = 0.1):
        """
        参数:
          tasks: {task_id: Task}
          linear_penalty: 线性惩罚系数
          quadratic_penalty: 二次惩罚系数
        """
        self.tasks = tasks
        self.linear_penalty = linear_penalty
        self.quadratic_penalty = quadratic_penalty

    def validate(self, schedule: Dict[str, datetime]) -> Tuple[bool, List[Dict]]:
        """
        验证调度是否满足截止期约束

        参数:
          schedule: {task_id: completion_time}

        返回:
          (is_valid, violations)
        """
        violations = []

        for task_id, completion_time in schedule.items():
            task = self.tasks.get(task_id)
            if not task:
                continue

            # 检查是否超过截止期
            if completion_time > task.deadline:
                delay = completion_time - task.deadline
                delay_hours = delay.total_seconds() / 3600

                # 计算惩罚
                penalty = self.calculate_penalty(delay, task)

                violations.append({
                    'type': 'deadline_violation',
                    'task': task_id,
                    'deadline': task.deadline,
                    'completion_time': completion_time,
                    'delay': delay,
                    'delay_hours': delay_hours,
                    'deadline_type': task.deadline_type.value,
                    'priority': task.priority,
                    'penalty': penalty
                })

        # 硬截止期违反则方案不可行
        hard_violations = [v for v in violations
                          if v['deadline_type'] == DeadlineType.HARD.value]
        is_valid = len(hard_violations) == 0

        return is_valid, violations

    def calculate_penalty(self, delay: timedelta, task: Task) -> float:
        """
        计算延迟惩罚

        惩罚策略:
          - 硬截止期: 无穷大
          - 软截止期: 线性 + 二次惩罚
          - 优先级: 乘以优先级系数
        """
        if task.deadline_type == DeadlineType.HARD:
            return float('inf')

        delay_hours = delay.total_seconds() / 3600

        # 线性惩罚
        linear_part = self.linear_penalty * delay_hours

        # 二次惩罚（延迟越久越重）
        quadratic_part = self.quadratic_penalty * (delay_hours ** 2)

        total_penalty = linear_part + quadratic_part

        # 优先级加权
        if task.deadline_type == DeadlineType.PRIORITY:
            total_penalty *= task.priority

        return total_penalty

    def get_penalty(self, violations: List[Dict]) -> float:
        """计算总惩罚"""
        return sum(v.get('penalty', 0) for v in violations)

    def repair(self, schedule: Dict[str, datetime],
               violations: List[Dict]) -> Dict[str, datetime]:
        """
        修复截止期违反

        策略:
          1. 硬截止期违反: 提前调度
          2. 软截止期违反: 重新排序（EDD规则）
          3. 优先级调整: 高优先级任务优先
        """
        repaired = schedule.copy()

        # 处理硬截止期违反
        hard_violations = [v for v in violations
                          if v['deadline_type'] == DeadlineType.HARD.value]

        for violation in hard_violations:
            task_id = violation['task']
            task = self.tasks[task_id]
            delay = violation['delay']

            # 提前完工时间
            new_completion = repaired[task_id] - delay - timedelta(minutes=30)
            repaired[task_id] = new_completion

        # 应用EDD (Earliest Due Date)规则重新排序
        if len(violations) > 1:
            repaired = self.apply_edd_rule(repaired)

        return repaired

    def apply_edd_rule(self, schedule: Dict[str, datetime]) -> Dict[str, datetime]:
        """
        应用EDD规则：按截止期排序任务

        EDD规则: 最早截止期的任务最先处理
        理论保证: 最小化最大延迟
        """
        # 按截止期排序任务
        sorted_tasks = sorted(
            self.tasks.items(),
            key=lambda x: x[1].deadline
        )

        # 重新调度
        current_time = min(schedule.values())
        new_schedule = {}

        for task_id, task in sorted_tasks:
            # 考虑依赖关系
            start_time = current_time
            for dep_id in task.dependencies:
                if dep_id in new_schedule:
                    start_time = max(start_time, new_schedule[dep_id])

            completion_time = start_time + task.processing_time
            new_schedule[task_id] = completion_time
            current_time = completion_time

        return new_schedule

    def analyze_tardiness(self, schedule: Dict[str, datetime]) -> Dict:
        """
        分析延迟统计

        返回:
          - num_tardy: 延迟任务数
          - total_tardiness: 总延迟时间
          - max_tardiness: 最大延迟
          - on_time_rate: 准时率
        """
        tardy_tasks = []
        total_tardiness = timedelta(0)
        max_tardiness = timedelta(0)

        for task_id, completion_time in schedule.items():
            task = self.tasks[task_id]

            if completion_time > task.deadline:
                tardiness = completion_time - task.deadline
                tardy_tasks.append({
                    'task_id': task_id,
                    'tardiness': tardiness
                })
                total_tardiness += tardiness
                max_tardiness = max(max_tardiness, tardiness)

        num_tasks = len(schedule)
        num_tardy = len(tardy_tasks)
        on_time_rate = (num_tasks - num_tardy) / num_tasks * 100 if num_tasks > 0 else 0

        return {
            'num_tardy': num_tardy,
            'total_tardiness': total_tardiness,
            'max_tardiness': max_tardiness,
            'on_time_rate': round(on_time_rate, 2),
            'tardy_tasks': tardy_tasks
        }
```

## 📊 应用场景

### 场景1: 订单交付调度

```python
# 定义任务
tasks = {
    'order1': Task(
        id='order1',
        processing_time=timedelta(hours=2),
        deadline=datetime(2025, 1, 1, 10, 0),
        deadline_type=DeadlineType.HARD,
        priority=1
    ),
    'order2': Task(
        id='order2',
        processing_time=timedelta(hours=3),
        deadline=datetime(2025, 1, 1, 14, 0),
        deadline_type=DeadlineType.SOFT,
        priority=2
    ),
    'order3': Task(
        id='order3',
        processing_time=timedelta(hours=1),
        deadline=datetime(2025, 1, 1, 12, 0),
        deadline_type=DeadlineType.PRIORITY,
        priority=3
    )
}

handler = DeadlineConstraintHandler(tasks)

# 验证调度
schedule = {
    'order1': datetime(2025, 1, 1, 11, 0),  # 延迟1小时
    'order2': datetime(2025, 1, 1, 13, 30),  # 准时
    'order3': datetime(2025, 1, 1, 12, 30)   # 延迟30分钟
}

is_valid, violations = handler.validate(schedule)

if not is_valid:
    print(f"硬截止期违反: {violations}")
    repaired = handler.repair(schedule, violations)

# 分析延迟统计
stats = handler.analyze_tardiness(schedule)
print(f"准时率: {stats['on_time_rate']}%")
```
