## Story

**作为一个** BMAD API用户，
**我希望** 在工作流执行过程中能够进行人机交互，通过审批点暂停并恢复工作流执行，
**以便于** 在关键决策点提供人工干预和指导，确保工作流输出符合预期

## Acceptance Criteria

1. P1审批点能在算法推荐后正确暂停工作流
2. P2.5审批点能在约束分析后正确暂停工作流
3. 暂停时保存完整的工作流状态到HumanApproval记录
4. 用户可以通过API提供审批决策（approved/rejected/modified）
5. 工作流能从暂停点恢复执行，基于用户决策继续流程
6. HITL流程有完整的测试覆盖

### HITL审批点设计

**P1审批点（算法推荐后）**:

```python
# 节点触发时机
algorithm_output -> P1_approval_node

# 中断时保存的数据
{
    "algorithm_output": {
        "recommended_algorithms": ["TSP", "VRP"],
        "reasoning": "基于问题特征分析",
        "confidence_scores": [0.85, 0.72]
    },
    "constraint_output": {
        "identified_constraints": ["时间窗口", "车辆容量"],
        "preliminary_analysis": "..."
    },
    "objective_output": {
        "optimization_objectives": ["minimize_distance", "minimize_time"],
        "weights": [0.6, 0.4]
    }
}
```

**P2.5审批点（约束分析后）**:

```python

{
    "constraint_results": {
```

### LangGraph集成要点

**Checkpoint集成**:

- 使用LangGraph的PostgreSQL checkpoint保存器
- 将thread_id映射到WorkflowExecution.thread_id
- 支持工作流状态的序列化和反序列化

**中断点实现**:

```python
from langgraph.checkpoint.postgres import aio as pg
from langgraph.graph import StateGraph
from langgraph.prebuilt import create_react_agent

async def p1_approval_node(state: WorkflowState) -> Dict[str, Any]:
    # 1. 保存当前状态到WorkflowExecution
    await workflow_service.save_checkpoint(state)

    # 2. 创建HumanApproval记录
    approval = HumanApproval(
        workflow_id=state["workflow_id"],
        user_id=state["user_id"],
        approval_point="P1",
        context_data=state["algorithm_output"],
        status="pending"
    )
    await db.save(approval)

    # 3. 返回中断信号
    return {
        "__interrupt__": "Human approval required at P1",
        "approval_id": approval.id,
        "workflow_status": "paused"
    }
```

### 恢复流程设计

**恢复工作流步骤**:

1. 验证HumanApproval存在且属于用户
2. 更新HumanApproval记录（decision, feedback, modified_data）
3. 从checkpoint加载工作流状态
4. 应用用户决策到状态
5. 继续工作流执行

**Modified决策处理**:

```python
async def apply_modifications(state: WorkflowState, modified_data: Dict[str, Any]) -> WorkflowState:
    """应用用户修改到工作流状态"""
    if "algorithm" in modified_data:
        state["selected_algorithm"] = modified_data["algorithm"]
    if "constraints" in modified_data:
        state["user_constraints"] = modified_data["constraints"]
    if "objectives" in modified_data:
        state["optimization_objectives"] = modified_data["objectives"]

    return state
```

**测试覆盖范围**:

### 错误处理

**常见错误场景**:

- 工作流未暂停时尝试恢复
- HumanApproval不存在
- 用户尝试恢复其他人的工作流
- 无效的决策值
- 工作流状态损坏

**错误响应格式**:

```json
{
  "error": {
    "code": "WORKFLOW_NOT_PAUSED",
    "message": "Cannot resume workflow that is not paused",
    "details": {
      "workflow_id": "uuid",
      "current_status": "running"
    }
  }
}
```
