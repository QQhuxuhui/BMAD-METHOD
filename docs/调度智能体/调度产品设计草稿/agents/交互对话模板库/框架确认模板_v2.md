## 新特性

### 1. 状态管理 (State Management)

**功能**:

- 自动保存每个确认项的结果
- 支持会话中断和恢复
- 生成压缩摘要降低上下文消耗
- 阶段完成后自动持久化

**使用方式**:

```python
from tools.interaction.state_manager import StateManager, PhaseType

# 初始化状态管理器
manager = StateManager()

# 创建会话
session = manager.create_session("项目名称", mode="incremental")

# 开始阶段
phase = manager.start_phase(
    session,
    PhaseType.PHASE_1_5_FRAMEWORK_CONFIRMATION,
    "TenElementModel 框架确认"
)

# 记录交互
manager.add_interaction(
    session,
    PhaseType.PHASE_1_5_FRAMEWORK_CONFIRMATION,
    "决策变量确认",
    user_input="1",
    parsed_result={"action": "confirm"}
)

# 完成阶段 (自动生成摘要)
manager.complete_phase(
    session,
    PhaseType.PHASE_1_5_FRAMEWORK_CONFIRMATION,
    confirmed_items={...}
)
```

### 2. 智能推荐 (Recommendation Engine)

**功能**:

- 基于场景特征自动推荐最合适的选项
- 提供可解释的推荐理由
- 支持高/中/低置信度标注
- 为选项添加推荐标记

**使用方式**:

```python
from tools.interaction.recommendation_engine import RecommendationEngine

# 初始化推荐引擎
engine = RecommendationEngine()

# 获取推荐
recommendation = engine.get_recommendation(
    context="scenario_classification",
    features={
        "keywords": ["配送", "车辆"],
        "has_vehicle_capacity": True
    },
    options=[...]
)

# 格式化推荐提示
prompt = engine.format_recommendation_prompt(recommendation, options)

# 为选项添加推荐标记
annotated_options = engine.annotate_options(options, recommendation)
```

### 3. 上下文压缩 (Context Compression)

**效果**:

- 每个阶段完成后，自动生成摘要
- 后续阶段只加载压缩摘要，不加载完整历史
- 上下文消耗降低 **60-70%**

**使用方式**:

```python
# 获取压缩上下文 (仅包含摘要和关键确认项)
compressed = manager.get_compressed_context(session)

# 获取上一阶段摘要
prev_summary = manager.get_previous_phase_summary(
    session,
    PhaseType.PHASE_2_1_DOMAIN_EXPERT
)
```

### 步骤0: 加载或创建会话状态

```python
from tools.interaction.state_manager import StateManager, PhaseType

# 初始化状态管理器
state_manager = StateManager()

# 尝试加载现有会话
session = None
existing_sessions = state_manager.list_sessions()

if existing_sessions:
    # 询问用户是否继续现有会话
    print("检测到未完成的会话:")
    for i, s in enumerate(existing_sessions[:3], 1):
        print(f"{i}. {s['project_name']} - {s['created_at']}")

    choice = input("是否继续现有会话? (输入会话编号或'新建'): ")

    if choice.isdigit() and 0 < int(choice) <= len(existing_sessions):
        session_info = existing_sessions[int(choice) - 1]
        session = state_manager.load_session(session_info['session_id'])
        print(f"已加载会话: {session.session_id}")

# 如果没有加载现有会话，创建新会话
if session is None:
    project_name = input("请输入项目名称: ")
    session = state_manager.create_session(project_name, mode="incremental")
    print(f"已创建新会话: {session.session_id}")

# 开始 Phase 1.5
phase = state_manager.start_phase(
    session,
    PhaseType.PHASE_1_5_FRAMEWORK_CONFIRMATION,
    "TenElementModel 框架确认",
    metadata={"expected_time": "5-8分钟"}
)
```
