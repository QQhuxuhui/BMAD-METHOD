# 17. Monitoring and Observability

## 17.1 监控栈

- **前端**: Console + Performance API
- **后端**: Prometheus + Grafana (Phase 2)
- **错误追踪**: structlog
- **性能监控**: LangSmith (可选)

## 17.2 关键指标

**前端**:

- Core Web Vitals
- JavaScript错误率
- API响应时间

**后端**:

- 请求速率 (RPM)
- 错误率 (%)
- 响应时间 (P50, P95, P99)
- 模型调用延迟
