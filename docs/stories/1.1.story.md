### 开发工作流

**环境搭建流程** [Source: architecture/11-development-workflow.md]

```bash
# 1. 激活nvm环境（宿主机要求）
source ~/.nvm/nvm.sh

# 2. 创建Python环境（使用conda）
conda create -n bmad-langgraph python=3.13
conda activate bmad-langgraph

# 3. 安装依赖
cd backend
pip install -r requirements.txt

# 4. 启动数据库服务
cd ../docker
docker-compose -f docker-compose.dev.yml up -d postgres redis

# 5. 配置环境变量
cp ../.env.example ../.env
# 编辑.env配置数据库和API密钥
```

**开发命令** [Source: architecture/11-development-workflow.md]

```bash
# 启动后端服务
cd backend
uvicorn langgraph_service.main:app --reload --port 8000

# 运行测试
cd backend && pytest tests/
```

### Docker Compose配置

**开发环境配置要求** [Source: architecture/12-deployment-architecture.md]

```yaml
# docker/docker-compose.dev.yml 基本结构
version: '3.8'
services:
  postgres:
    image: postgres:16-alpine
    environment:
      POSTGRES_DB: ${POSTGRES_DB}
      POSTGRES_USER: ${POSTGRES_USER}
      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD}
    volumes:
      - postgres_data:/var/lib/postgresql/data
    ports:
      - '5432:5432'

  redis:
    image: redis:7-alpine
    volumes:
      - redis_data:/data
    ports:
      - '6379:6379'

volumes:
  postgres_data:
  redis_data:
```

### 特别注意事项

**重要约束** [Source: architecture/3-tech-stack.md]

1. Python版本必须是3.11或更高（LangGraph CLI硬性要求）
2. 必须安装langchain-agents包（替代已弃用的prebuilt模块）
3. PostgreSQL用作LangGraph checkpoint持久化后端
4. 所有异步操作必须使用async/await模式

**宿主机环境要求** [Source: CLAUDE.md]

- Conda：Python环境管理（已配置）
- Docker：容器技术（已配置）
- Docker Compose：容器编排（已配置）
- nvm：Node.js版本管理（需要在使用前执行`source ~/.nvm/nvm.sh`）

**依赖包特殊说明**

- LangGraph 1.0.2是稳定版本，提供内置持久化和Human-in-Loop特性
- langchain-agents是新的API，替代了prebuilt模块
- psycopg 3.x支持连接池和异步操作
- cloudpickle是LangGraph checkpoint的必需依赖
