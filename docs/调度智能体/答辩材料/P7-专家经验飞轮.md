## 🎯 页面定位

**全场对业务评委最有穿透力的一页**。任务：让评委认同"这东西不是一次性交付，而是越用越值钱的数字资产"——正面回答"可持续性 / 可推广性"这个创新评审维度。

## 💡 关键设计决策

| 决策                                  | 理由                                                                     |
| ------------------------------------- | ------------------------------------------------------------------------ |
| 圆环飞轮（而非竖向链表）              | "飞轮"这个词本身就是循环概念——圆环图 = 视觉即概念                        |
| 飞轮中心放 "100+ 模板 / 7 专家库"     | 不是空中楼阁——这是**已经在转的飞轮**，中心数字就是硬证据                 |
| 四节点命名：沉淀 → 实战 → 优化 → 复用 | 4 个词每个 2 字，极度精简，节奏感强，口语化易记                          |
| 三句话 "过去 / 现在 / 未来" 对仗      | 答辩最强叙事结构——损失感（过去）+ 解药感（现在）+ 想象力（未来）一次打满 |
| ✘ ✓ 🚀 三符号                         | 视觉上建立 "从问题到解药到想象" 的递进                                   |
| 底部金句 "组织的永久资产"             | "永久资产"是业务评委的母语——把技术创新翻译成组织管理语言                 |

## 🎤 口头讲词（~75 秒）

> "这一页，我特别想跟在座的各位产业同仁分享。
>
> 我们都知道，**企业最值钱的资产之一，是专家经验**。但这件资产有个致命问题——**它长在人脑子里**。专家在，知识在；专家离职，知识清零；新人来了，一切重学。我们做这套智能体，内心最深的动机，就是想破这个局。
>
> 大家看中间这个飞轮——四个环节：
>
> - **① 沉淀**：专家把经验写成模板，进专家库；
> - **② 实战**：真实业务场景调用模板跑方案；
> - **③ 优化**：代码在实战中持续打磨，参数反馈回库；
> - **④ 复用**：新版本沉淀下来，跨场景标准化调用。
>
> 这四步每转一圈，专家库就厚一层。**到今天，我们已经沉淀了 100+ 模板，70-85% 可以跨场景复用**——这意味着新人上手从 3 个月压缩到 2 周。
>
> 一句话——过去专家离职等于经验归零；现在专家经验是**可 Git 管理的数字资产**；未来这个飞轮越转越快。
>
> **智能体不是替代专家，而是让专家的经验，成为整个组织的永久资产**。"

---

## ✏️ 可调整项

- **具体数据**（100+ 模板 / 70-85% 复用率）来自产品文档——如有集团内部真实数据可替换
- **飞轮四环节命名**（沉淀→实战→优化→复用）可根据集团习惯用语调整
- **底部金句**的"永久资产"措辞若与集团文化更匹配的表达（如"组织数字资产"），可替换
