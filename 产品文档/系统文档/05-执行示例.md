**公司**: 某生鲜电商配送公司
**需求**: 优化每日配送路线，降低成本，提高准时率
**规模**: 20辆冷藏车，200个配送点/天
**特殊要求**: 三温区管理（-18℃, 0-4℃, 常温）

═══════════════════════════════════════════════════════════
🔒 约束专家分析报告 - 请确认（李严谨）⭐ (P0触发)
═══════════════════════════════════════════════════════════

基于:
  - TenElementModel.3_constraints (框架)

识别的约束:

1. 车辆容量约束（硬约束）
   类型: capacity
   引用: @专家库/约束库/capacity/车辆容量约束.md

   数学定义:
   ∀ v ∈ Vehicles:
     Σ(weight[c] for c in route[v]) ≤ capacity_weight[v]  (5000kg)
     Σ(volume[c] for c in route[v]) ≤ capacity_volume[v]  (30m³)

   处理策略:
   - 装箱算法预检查（First-Fit Decreasing）
   - 路径构造时累加验证
   - 违反则剪枝该路径

2. 客户时间窗约束（硬约束）
   类型: temporal
   引用: @专家库/约束库/temporal/时间窗约束.md

   数学定义:
   ∀ c ∈ Customers:
     early_time[c] ≤ service_time[c] ≤ late_time[c]

   处理策略:
   - 前向时间传播算法
   - 到达过早则等待，过晚则剪枝
   - 时间窗违反不可修复

3. 温区混载约束（硬约束）
   类型: business_rule
   引用: @专家库/约束库/business-rules/合规性约束.md

   数学定义:
   ∀ v ∈ Vehicles, ∀ c1, c2 ∈ route[v]:
     temperature_zone[c1] == temperature_zone[c2]

   处理策略:
   - 客户预分组（按温区）
   - 每辆车分配唯一温区标签
   - 构造路径时只考虑同温区客户

4. 车辆数量约束（硬约束）
   类型: capacity
   引用: @专家库/约束库/capacity/资源容量约束.md

   数学定义:
   |使用的车辆| ≤ 20

   处理策略:
   - 优先使用少量车辆（降低成本）
   - 如不可行，增加车辆数量
   - 最多20辆为上限

约束复杂度评估:

  预计验证时间: O(n) per solution
