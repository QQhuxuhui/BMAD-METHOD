## 触发场景

**触发时机**: Phase 2.5,在领域、约束、目标、算法四个专家全部完成增量确认后

**前置条件**:

- ✅ Phase 2.1 领域专家增量确认已完成
- ✅ Phase 2.2 约束专家增量确认已完成
- ✅ Phase 2.3 目标专家增量确认已完成
- ✅ Phase 2.4 算法专家增量确认已完成
- ✅ 一致性校验引擎已运行完成

**目的**:

- 向用户呈现跨专家一致性校验结果
- 如有冲突,清晰说明问题、影响和建议
- 引导用户做出明智的调整决策
- 支持自动修复或手动调整
- 确保所有配置协调一致后再进入方案生成

## 对话结构

### 整体流程

```yaml
Phase 2.5_一致性校验交互:
  步骤1: 运行一致性校验引擎
  步骤2: 呈现校验结果
    - 情况A: 无冲突 → 直接进入Phase 3
    - 情况B: 有冲突 → 逐个呈现并处理
  步骤3: 用户选择处理方式
    - 接受冲突继续
    - 调整配置解决冲突
    - 应用自动修复
    - 查看详细分析
  步骤4: 重新校验(如有调整)
  步骤5: 生成校验报告
```

## 步骤3: 用户响应处理

### 响应逻辑

```python
def process_consistency_validation_response(
    user_input: str,
    validation_report: ValidationReport,
    confirmed_data: dict
) -> dict:
    """处理一致性校验的用户响应"""

    if user_input == "1":
        # 接受当前配置,继续
        return {
            "action": "accept_and_continue",
            "message": "用户选择接受当前配置",
            "risks_acknowledged": [c.description for c in validation_report.conflicts]
        }

    elif user_input == "2":
        # 调整某个问题
        return {
            "action": "request_problem_number",
            "prompt": "请输入要调整的问题编号 (1-{N}):"
        }

    elif user_input == "3":
        # 查看详细分析
        return {
            "action": "show_detailed_analysis",
            "content": generate_detailed_conflict_analysis(validation_report.conflicts)
        }

    elif user_input == "4":
        # 应用自动修复
        auto_fixable = [c for c in validation_report.conflicts if c.auto_fix_available]
        if not auto_fixable:
            return {
                "action": "no_auto_fix",
                "message": "当前问题暂不支持自动修复,请手动调整。"
            }
        return {
            "action": "apply_auto_fix",
            "conflicts": auto_fixable,
            "prompt": generate_auto_fix_confirmation_prompt(auto_fixable)
        }

    elif user_input == "5":
        # 举例说明影响
        return {
            "action": "show_impact_examples",
            "content": generate_impact_examples(validation_report.conflicts)
        }

    elif user_input == "6":
        # 查看推荐方案
        return {
            "action": "show_recommended_adjustments",
            "content": generate_recommended_adjustments(validation_report.conflicts)
        }

    elif user_input == "7":
        # 分析接受后果
        return {
            "action": "analyze_acceptance_consequences",
            "content": generate_consequence_analysis(validation_report.conflicts, confirmed_data)
        }

    elif user_input == "8":
        # 重新审查所有配置
        return {
            "action": "restart_expert_confirmations",
            "prompt": "确认要重新开始所有专家的配置吗? (输入 'yes' 确认)"
        }

    elif user_input == "9":
        # 其他问题
        return {
            "action": "open_question",
            "prompt": "请描述您的具体问题或想法:"
        }

    else:
        # 尝试解析为问题编号
        try:
            problem_number = int(user_input)
            if 1 <= problem_number <= len(validation_report.conflicts):
                conflict = validation_report.conflicts[problem_number - 1]
                return {
                    "action": "show_problem_details",
                    "conflict": conflict,
                    "content": generate_problem_detail_view(conflict)
                }
        except ValueError:
            pass

        # 自然语言处理
        return parse_natural_language_response(
            user_input,
            validation_report,
            "consistency_validation"
        )
```

## 工具调用

```python
from tools.validation.consistency_validator import ConsistencyValidator
from tools.interaction.conflict_resolver import ConflictResolver

# 初始化校验器
validator = ConsistencyValidator()
resolver = ConflictResolver()

# 收集确认数据
confirmed_data = {
    "domain": domain_expert_results,
    "constraint": constraint_expert_results,
    "objective": objective_expert_results,
    "algorithm": algorithm_expert_results
}

# 执行校验
validation_report = validator.validate(
    domain_results=confirmed_data["domain"],
    constraint_results=confirmed_data["constraint"],
    objective_results=confirmed_data["objective"],
    algorithm_results=confirmed_data["algorithm"]
)

# 呈现结果
if len(validation_report.conflicts) == 0:
    # 无冲突,直接进入Phase 3
    print(validation_report.to_user_interaction())
else:
    # 有冲突,进入冲突解决流程
    print(validation_report.to_user_interaction())

    # 等待用户响应
    user_response = input()

    # 处理响应
    result = resolver.process_response(
        user_input=user_response,
        validation_report=validation_report,
        confirmed_data=confirmed_data
    )

    # 根据结果执行相应操作
    if result["action"] == "accept_and_continue":
        # 用户接受冲突,进入Phase 3
        pass
    elif result["action"] == "adjust_expert_config":
        # 回到对应专家重新确认
        expert_name = result["expert"]
        adjustment_item = result["item"]
        # 调用对应专家的增量确认流程
    elif result["action"] == "apply_auto_fix":
        # 应用自动修复
        fixed_data = resolver.apply_auto_fix(
            conflicts=result["conflicts"],
            confirmed_data=confirmed_data
        )
        # 重新校验
        validation_report_v2 = validator.validate(**fixed_data)
```
