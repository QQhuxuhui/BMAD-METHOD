## 🎨 样式说明

> 本页由用户原设计保留。**为确保整套答辩视觉统一，强烈建议此页与其他 8 页保持白色系商务正式风格一致**。

**建议对齐的要点**

- **背景**：纯白 `#FFFFFF`
- **主文字**：深墨灰 `#1A202C`
- **强调色**：深蓝 `#1A365D`（用于关键节点 / 专家名称 / 数字）
- **分割线**：浅灰 `#E2E8F0`（1px 细线）
- **字体**：中文思源黑体 / 微软雅黑；英文 Inter / Helvetica Neue
- **emoji 使用**：克制——保留功能性标识（如专家图标 🏢🔒🎯⚙️），删除装饰性表情
- **图示风格**：线框 / 极简 icon（Feather / Tabler 风格），避免卡通化

**与前后页的视觉衔接**

- **承接 P5 架构图**：P5 的 7 位专家名 + 角色颜色体系，在本页应保持一致（不要临时换色或换字体）
- **启后 P7 飞轮**：若流程图有"沉淀 / 实战 / 优化 / 复用"等循环元素，可用和 P7 相同的环形或箭头符号作视觉呼应
- **整体原则**：如原设计已定型难以调整，**答辩时视觉整体感仍比单页追求完美更重要**——其他 8 页都对齐后，评委会自动把 P6 归入"同一套 PPT"

## 🎤 口头讲词提示（~45 秒 · 建议主讲人围绕该页内容补充）

建议在已有内容基础上，围绕以下几个关键点组织讲词：

1. **承接 P5**："刚才讲的是团队结构，这一页讲的是团队怎么协作跑通一个真实任务"

3. **引出 P7**：以一句衔接词结束，比如——"这套流程跑得越多，专家库就越厚——这就是我们的第七页要讲的飞轮效应"
