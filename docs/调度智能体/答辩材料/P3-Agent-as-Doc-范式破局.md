## 💡 关键设计决策

| 决策                                 | 理由                                                                                                                              |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| **"业界首创·已申请专利"** 6 字小标签 | 答辩是"创新案例"——**专利**是最硬的创新证据，必须在王牌页打出                                                                      |

## 🎤 口头讲词（~90 秒）

> "这一页是我们整个项目最想让大家记住的一个词——**Agent as Doc**。
>
> 业界绝大多数 AI Agent 走的是 **Agent as Prompt** 路线：智能体就是一个塞满知识的大 Prompt。问题是——这个 Prompt 一旦到 50K tokens，利用率只有 10-20%，剩下 80% 都是'以防万一'的浪费；而且知识和智能体绑死，更新一次相当于重新训练。
>
> 我们走的是另一条路：**智能体不应该包含知识，智能体应该承载知识**。
>
> 智能体本体只有 500 tokens——就是一个角色定位；所有专业知识，放在外面的文档库里，按需加载。需要算法，拿算法文档；需要约束，拿约束文档。
>
> 结果是三件事同时发生：**Token 省了 75-87%**（底部第一个数）、**知识更新变成改 Markdown**（业务专家都能做，效率提升 100 倍）、**每一条决策都可以追溯到具体文档**（AI 幻觉根本没空间发生）。
>
> 这是一次'智能体'这件事的**根本翻转**。"
