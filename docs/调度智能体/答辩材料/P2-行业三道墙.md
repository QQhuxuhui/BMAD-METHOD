## 🎨 视觉意境描述（投喂 flow 平台 · 敞开想象）

> **整体氛围**
>
> 三道竖立的"墙"压在画面正中央——这不是装饰，而是问题本身的视觉化。整个画面是一种"克制的紧张"：白底依然主导，但三个砖红警示数字与三块灰色"墙体"形成视觉重量，让评委一眼感到——**这件事真的没那么简单**。
>
> **页眉 · 双标题压顶**
>
> 画面顶端居中：主标题「**AI + 专业领域落地 · 三道撞不破的墙**」深墨灰加粗大字——这是"问题宣告"。下方一行副标题「为什么传统方案到调度优化这种场景就失灵？」中灰、字号偏小——这是带评委进入语境的提问。
>
> **画面主体 · 三列等宽对称**
>
> 主体被两条 1px 浅灰竖线均等分割成三列。每一列从顶到底是一段完整的"叙事单元"：
>
> 1. **顶端 8-12px 浅灰粗横线**——这是"墙的横截面"的视觉隐喻。三列三段，构成"三道墙"并立的画面节奏。
> 2. **圆形印章序号**：浅灰底 + 深蓝字的 ① / ② / ③，像评委手中的盖章。
> 3. **一枚线框 icon**（Tabler Icons 风格 · 禁止用 emoji 表情代替）：
>    - 墙①：警示三角 / 感叹号图标
>    - 墙②：钱币 / 沙漏图标
>    - 墙③：大脑 / 人形流失图标
> 4. **痛点关键词**（深墨灰加粗大字）：「**AI 幻觉难控**」「**Token 浪费**」「**专家经验留不住**」——三个词每个都是**口语化、有情绪**的表达。
> 5. **痛点描述**（中灰小字 · 一段话）说明痛点产生的机理。
> 6. **量化证据**（砖红 `#C53030` 加粗大字）：
>    - 墙①：传统 Agent 代码可用率 50-70%
>    - 墙②：50K+ tokens 利用率仅 10-20%
>    - 墙③：新人上手 3 个月 / 专家离职 = 经验清零 / 70% 知识无法复用
>
> 三列之间用 1px 浅灰竖线分隔，**不要厚边框、不要色块底**——保持纯净。
>
> **画面底部 · 金句色带（衔接 P3）**
>
> 画面最下方一条**浅灰底色带**横贯通栏，居中一行**深蓝加粗斜体**的金句：
>
> > 「正是这三道墙，让 AI Agent 在高专业度场景难以真正落地——而这，正是我们要破的局。」
>
> 这条金句是承上启下——上承"三道墙的痛"，下启 P3 的"破局"。它的视觉重量明显高于墙体内的文字，让评委读完三道墙后，视线**自然落到这里**。
>
> **配色协奏**
>
> - 纯白 `#FFFFFF` 主导背景
> - 深墨灰 `#1A202C` 用于主标题与三个痛点关键词
> - 中灰 `#4A5568` 用于副标题与痛点描述
> - 深蓝 `#1A365D` 用于墙序号 ①②③、底部金句
> - **砖红 `#C53030` 仅用于三个量化证据数字**——这是全页**唯一的警示色**，让数字本身成为"问题严重性"的证据
> - 浅灰 `#E2E8F0` / `#F7FAFC` 用于墙体横截面、列分隔竖线、底部金句色带
>
> **严禁出现**
>
> 渐变背景 / 装饰花纹 / 立体阴影 / 背景图 / 卡通的"砖墙城堡"插图 / 任何装饰性 emoji。三道墙的"墙"必须是**抽象几何隐喻**（粗线 + 印章 + 线框 icon），不要画拟物化卡通元素。
>
> **🚨 语言硬性约束**
>
> 画面所有可见文案 **必须使用中文**。**唯一豁免**：专业术语（如 `AI` · `AI Agent` · `Token` · `Prompt` · `Agent as Doc` 等）以及技术度量单位（如 `50K+ tokens`、`10-20%`）保留原写法。**禁止**任何可用中文等价表达的英文（如不要写 "Wall 1 / Wall 2 / Wall 3"，必须用「墙①」「墙②」「墙③」；不要写 "Hallucination / Cost / Knowledge Loss"，必须用「AI 幻觉难控 / Token 浪费 / 专家经验留不住」）。

## 💡 关键设计决策

| 决策                                | 理由                                                                                   |
| ----------------------------------- | -------------------------------------------------------------------------------------- |
| 三墙对称布局（而非竖排 / 流程图）   | 视觉压迫感强，让"问题严重性"一眼可见                                                   |
| 每墙都有"一句话痛点 + 量化证据"双层 | 技术评委看数字，业务评委看痛点描述，各得其所                                           |
| 墙③ 放最后不是最末位                | 专家经验断层是整套答辩中业务评委最共鸣的点；收束时压阵最有力；直接引出 P7 飞轮页的解药 |
| 底部金句 "破的局"                   | 顺势带出下一页 P3 的"王牌破局点"                                                       |

---

## 💡 用词精选说明

- **墙① AI 幻觉难控** → 比"AI 不可靠"更技术、更精准
- **墙② Token 浪费** → 直击成本，业务评委秒懂
- **墙③ 专家经验留不住** → 用"留不住"而不是"难传承"——**口语化、有情绪**，评委更有共鸣

## 🎨 样式说明

**整体风格**：白色系商务正式 · 低密度高留白 · 强理性弱装饰

**配色规范**

| 用途     | 色值      | 用法                     |
| -------- | --------- | ------------------------ |
| 背景     | `#FFFFFF` | 纯白 · 全场统一          |
| 主文字   | `#1A202C` | 深墨灰 · 标题 / 正文     |
| 副文字   | `#4A5568` | 中灰 · 副标题 / 注释     |
| 强调色   | `#1A365D` | 深蓝 · 关键词 / 数字亮点 |
| 分割线   | `#E2E8F0` | 浅灰 · 1px 细线          |
| 警示色   | `#C53030` | 砖红 · 传统方案的负面点  |
| 收益色   | `#2F855A` | 墨绿 · 正面成效          |
| 点缀金色 | `#D69E2E` | 仅用于 🏆 国赛图标       |

**字体规范**

- 中文：思源黑体 / 微软雅黑（兜底）
- 英文 & 数字：Inter / Helvetica Neue（兜底）
- 主标题：大字号 · 加粗 · 深墨灰
- 副标题：次级字号 · 细体 · 中灰
- 数字亮点：超大字号 · 加粗 · 深蓝

**版式规范**

- 每页四角留白 ≥ 5%
- **克制使用 emoji**：保留功能性标识，删除装饰性表情；优先线框 icon（Feather / Tabler Icons 风格）
- 分隔元素：1px 浅灰细线，避免厚重底纹
- 对齐：统一居中或左对齐，避免混用

**文案语言规范**

- **除专业术语外，全文必须使用中文**（含标题、正文、讲词、图示注释、注脚）
- **可保留原文的专业术语**：如 `Agent as Doc` · `Sidecar` · `Token` · `Guardrails` · `Prompt` · `Markdown` · `Phase 0-4` · `Todo` · `QA` · `Git` · `Orchestrator` 等
- **数字与单位**：业务量用中文单位（"500 台"、"100+ 模板"），技术度量保留原单位（"50K tokens"、"15px"）
- **字体 / 产品 / 软件包名**保留原写法（思源黑体、Inter、Tabler Icons、Feather Icons、BMAD）

**本页视觉重点（P2 行业三道墙）**

- **三列等宽**布局，每列顶部用**线框 icon**（不用 emoji 表情）代表"墙"概念
- **墙序号 ①②③**：圆形印章样式 · 浅灰底 · 深蓝字
- **"墙"的视觉隐喻**：每列顶部用浅灰粗线（8-12px）做"墙"的横截面，象征阻隔
- **量化数字**：加粗 · 砖红色（`#C53030`，警示意味）· 字号突出
- **底部金句**：单独一行 · 浅灰底条 + 深蓝加粗字 + 斜体
- **三列分隔**：1px 浅灰竖线

## 🎤 口头讲词（~30 秒）

> "AI 落地调度优化这类专业领域，撞到三道墙——
>
> **墙一 AI 幻觉难控**：长任务链里 AI 会编造算法和业务规则，代码可用率只有 50-70%；
>
> **墙二 Token 浪费严重**：知识全塞进 Prompt，50K tokens 一次加载，利用率只有 10-20%；
>
> **墙三 专家经验留不住**——专家一离职，经验清零。
>
> **这三道墙，就是我们要破的局。**"

## ✏️ 可调整项

- **三道墙的命名用词** 如需更正式可改为："AI 输出不可信 / Token 效率低下 / 专家经验流失"
