## 🎨 视觉意境描述（投喂 flow 平台 · 敞开想象）

> **整体氛围**
>
> 全场最后 30 秒——评委记忆曲线最强的一页。任务是用**一张演进路线图 + 一句强金句**让评委**带着一个清晰的印象离开会场**。
>
> 画面气质是**沉静的展望**：上半部分横向时间轴（演进路线 · 节奏感），下半部分终局对仗金句（**全场字号最大**），底部一行致谢——构成"**演进 → 升华 → 谢幕**"的三段式收束。整页色彩克制到极致，**让金句本身成为唯一的情绪高潮**。
>
> **页眉**
>
> 主标题「**从昆明机场到产业未来 · 调度智能体的演进路线**」深墨灰加粗大字、居中。副标题「**一套可复制、可沉淀、可演进的 AI 范式**」中灰偏小——三个"可"字押韵。
>
> **画面主体 · 横向时间轴三段**（占画面上半部分）
>
> 一条**横线贯穿画面中部**，三个**深蓝实心圆点节点 ●** 等距排列。三个节点之间的连接线分**实虚两段**：
>
> - **昨天 → 今天**：**实线**（已完成段）
> - **今天 → 明天**：**虚线**（未来段）
>
> **视觉即时间**——实虚的过渡本身就讲了"过去已成事实、未来仍可塑造"的故事。
>
> 三个节点上方**颜色递进**地标注（递进的色彩本身就是时间的视觉化）：

> **终局金句**（全场记忆点 · 字号全场最大 ≥ 60pt）

>
> 致谢与金句之间留充足留白——**不抢戏**、**收得住**、**不画蛇添足**。
>
> **配色协奏**
>
> - 纯白 `#FFFFFF` 主导背景（**全页 80% 以上面积**）
> - 中灰 `#4A5568` 用于副标题、"昨天"标签、致谢
> - 深墨灰 `#1A202C` 用于主标题、"今天"标签、三列正文

> - 浅灰 `#E2E8F0` 用于三列分隔竖线、连接虚线
> - **不使用砖红、墨绿、金色** —— P9 是收束页，**情绪要收**，不要再用警示色或暖色干扰
>
> **严禁**
>
> 渐变背景 / 装饰花纹 / 立体阴影 / 卡通插画 / 任何 emoji（包括 🚀 🏆 🎯 等都不要在终局页出现）/ 任何会让金句失去"庄严感"的装饰。**金句必须独占视觉焦点**——它是这场答辩的最后一句话。
>
> **🚨 语言硬性约束**
>
> 画面所有可见文案 **必须使用中文**。**唯一豁免**：专业术语（如 `Agent as Doc` · `AI` · `Token` 等）保留原写法。**禁止**任何可用中文等价表达的英文（如不要写 "Yesterday / Today / Tomorrow / Past / Now / Future / Already Done / On Going / Next"，必须用「昨天 / 今天 / 明天」+「已完成 / 进行中 / 下一步」；不要写 "Phase 1 / Stage 1"，本页这里必须用「破局 / 复制 / 产业标杆」三个意象词；不要写 "Conclusion / Closing / Acknowledgement"，必须用「总结 / 致谢」）。

## 🎨 样式说明

**整体风格**：白色系商务正式 · 低密度高留白 · 强理性弱装饰

**配色规范**

| 用途     | 色值      | 用法                     |
| -------- | --------- | ------------------------ |
| 背景     | `#FFFFFF` | 纯白 · 全场统一          |
| 主文字   | `#1A202C` | 深墨灰 · 标题 / 正文     |
| 副文字   | `#4A5568` | 中灰 · 副标题 / 注释     |
| 强调色   | `#1A365D` | 深蓝 · 关键词 / 数字亮点 |
| 分割线   | `#E2E8F0` | 浅灰 · 1px 细线          |

| 点缀金色 | `#D69E2E` | 仅用于 🏆 国赛图标       |

**字体规范**

- 中文：思源黑体 / 微软雅黑（兜底）
- 英文 & 数字：Inter / Helvetica Neue（兜底）
- 主标题：大字号 · 加粗 · 深墨灰
- 副标题：次级字号 · 细体 · 中灰
- 数字亮点：超大字号 · 加粗 · 深蓝

**版式规范**

- 每页四角留白 ≥ 5%
- **克制使用 emoji**：保留功能性标识，删除装饰性表情；优先线框 icon（Feather / Tabler Icons 风格）
- 分隔元素：1px 浅灰细线，避免厚重底纹
- 对齐：统一居中或左对齐，避免混用

**文案语言规范**

- **除专业术语外，全文必须使用中文**（含标题、正文、讲词、图示注释、注脚）
- **可保留原文的专业术语**：如 `Agent as Doc` · `Sidecar` · `Token` · `Guardrails` · `Prompt` · `Markdown` · `Phase 0-4` · `Todo` · `QA` · `Git` · `Orchestrator` 等
- **数字与单位**：业务量用中文单位（"500 台"、"100+ 模板"），技术度量保留原单位（"50K tokens"、"15px"）
- **字体 / 产品 / 软件包名**保留原写法（思源黑体、Inter、Tabler Icons、Feather Icons、BMAD）

**本页视觉重点（P9 总结 · 终局页）**

- **时间轴（横向三段式）**
  - 三个**深蓝圆点**节点 `●` 等距排列

    - **昨天**：中灰 `#4A5568`（回顾感）
    - **今天**：深墨灰 `#1A202C`（当下感）

  - 重点词加粗深蓝（"Agent as Doc"、"飞轮"、"多场景"等）
- **终局金句（全场记忆点）**
  - **字号全场最大**（≥ 60pt）· 居中 · 双行对仗
  - 深蓝加粗 `#1A365D`
