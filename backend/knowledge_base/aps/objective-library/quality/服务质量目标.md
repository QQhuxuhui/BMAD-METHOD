## 📖 定义

**服务质量** = 准时率 × w1 + 完成率 × w2 + 满意度 × w3

## 🔧 代码实现

```python
class ServiceQualityObjective:
    """服务质量目标函数"""

    def __init__(self, weight: float = 1.0):
        self.name = "service_quality"
        self.optimization_type = "maximize"  # 最大化质量
        self.weight = weight

    def evaluate(self, solution: List[Dict]) -> float:
        """评估服务质量"""
        if not solution:
            return 0.0

        total_tasks = len(solution)
        on_time_tasks = sum(1 for t in solution
                           if t.get('finish_time', 0) <= t.get('deadline', float('inf')))

        on_time_rate = on_time_tasks / total_tasks

        # 简化质量评分 (0-100)
        quality_score = on_time_rate * 100

        return quality_score
```
