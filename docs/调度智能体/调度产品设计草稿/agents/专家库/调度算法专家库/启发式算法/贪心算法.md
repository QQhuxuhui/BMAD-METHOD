## 核心原理

### 理论基础

贪心算法（Greedy Algorithm）是一种经典的启发式优化方法，由计算机科学家Edsger Dijkstra等人在1950年代开创。该算法通过在每一步选择当前状态下的局部最优决策，逐步构造问题的解。

**核心思想**：

- **局部最优选择**：每步做出在当前看来最好的选择，不考虑全局影响
- **无回溯机制**：一旦做出选择就不再修改，快速推进求解过程
- **贪心准则**：根据问题特性设计评价函数，指导每步决策
- **构造式求解**：从空解开始，逐步添加决策元素直到完整解

**关键概念**：

- **贪心选择性质（Greedy Choice Property）**：局部最优选择能导向全局最优解（某些问题）
- **最优子结构（Optimal Substructure）**：问题的最优解包含子问题的最优解
- **贪心准则（Greedy Criterion）**：评价当前决策优劣的规则或函数
- **优先级规则（Priority Rule）**：调度问题中的决策依据（SPT、EDD、MST等）
- **近似比（Approximation Ratio）**：贪心解与最优解的比值（衡量解质量）

**问题分类**：

- **最优贪心问题**：贪心策略可获得全局最优解（最小生成树、Dijkstra最短路径、Huffman编码）
- **近似贪心问题**：贪心策略获得有界近似解（集合覆盖、装箱问题、TSP）
- **启发式贪心问题**：贪心策略无理论保证但实践效果好（作业调度、图着色）

**与其他算法的对比**：

- **vs 动态规划**：贪心不回溯不重叠子问题，动态规划需记录所有状态
- **vs 分支定界**：贪心单一路径直达解，分支定界搜索多条路径保证最优
- **vs 遗传算法**：贪心确定性构造，遗传算法随机搜索种群演化
- **vs 整数规划**：贪心快速启发式，整数规划精确但计算密集

### 数学模型

**通用贪心框架**：

```
输入：问题实例 I = (E, C, f)
  - E: 候选元素集合
  - C: 约束条件
  - f: 贪心准则函数

输出：解 S ⊆ E

算法步骤：
1. 初始化：S = ∅
2. while E ≠ ∅ and 约束C未违反:
3.     e* = argmax_{e∈E} f(e, S)  # 选择当前最优元素
4.     if S ∪ {e*} 满足约束C:
5.         S = S ∪ {e*}
6.     E = E \ {e*}
7. return S
```

**调度问题的贪心模型**：

单机调度问题（最小化总完工时间）：

```
决策变量:
  π: 作业排序序列 [J_1, J_2, ..., J_n]

贪心准则:
  f(J_i) = p_i  # 作业i的加工时间

目标函数:
  minimize Σ_i C_i = Σ_i (Σ_{j=1}^{i} p_{π(j)})
  其中 C_i 为作业i的完工时间

贪心策略（SPT规则）:
  按加工时间p_i升序排序作业
  π = sort(Jobs, key=lambda J: J.processing_time)

理论保证:
  SPT规则对于1||Σ C_i问题是最优的（Smith 1956证明）
```

带截止时间的单机调度（最小化总延迟）：

```
决策变量:
  π: 作业排序序列

贪心准则:
  f(J_i) = d_i  # 作业i的截止时间

目标函数:
  minimize Σ_i max(0, C_i - d_i)  # 总延迟惩罚

贪心策略（EDD规则 - Earliest Due Date）:
  按截止时间d_i升序排序作业
  π = sort(Jobs, key=lambda J: J.due_date)

理论保证:
  EDD规则对于1||Σ T_i（总延迟）问题是2-近似算法
```

### 核心机制

**经典调度规则（Dispatching Rules）**：

1. **SPT（Shortest Processing Time）- 最短加工时间优先**：

   ```python
   # 适用场景：最小化平均完工时间、平均流程时间
   # 理论保证：1||Σ C_i 最优；1||Σ w_i C_i（加权）最优（WSPT规则）

   def SPT_rule(jobs):
       """按加工时间升序排序"""
       return sorted(jobs, key=lambda j: j.processing_time)

   # 时间复杂度：O(n log n)
   # 近似比：最优（对特定目标）
   ```

2. **LPT（Longest Processing Time）- 最长加工时间优先**：

   ```python
   # 适用场景：并行机负载均衡（P||C_max）
   # 理论保证：4/3-近似算法（Graham 1969）

   def LPT_rule(jobs, machines):
       """按加工时间降序分配到最空闲机器"""
       sorted_jobs = sorted(jobs, key=lambda j: j.processing_time, reverse=True)
       machine_loads = [0] * len(machines)
       assignment = {}

       for job in sorted_jobs:
           min_load_machine = machine_loads.index(min(machine_loads))
           assignment[job] = min_load_machine
           machine_loads[min_load_machine] += job.processing_time

       return assignment, max(machine_loads)

   # 时间复杂度：O(n log n + nm)
   # 近似比：≤ 4/3 · OPT
   ```

3. **EDD（Earliest Due Date）- 最早截止时间优先**：

   ```python
   # 适用场景：最小化最大延迟（L_max）、总延迟（Σ T_i）
   # 理论保证：1||L_max 最优

   def EDD_rule(jobs):
       """按截止时间升序排序"""
       return sorted(jobs, key=lambda j: j.due_date)

   # 应用：JIT生产、项目管理、物流配送
   ```

4. **MST（Minimum Slack Time）- 最小松弛时间优先**：

   ```python
   # 松弛时间 = 截止时间 - 当前时间 - 剩余加工时间
   # 适用场景：动态调度、在线决策

   def MST_rule(jobs, current_time):
       """按松弛时间升序排序"""
       def slack_time(job):
           return job.due_date - current_time - job.remaining_time

       return sorted(jobs, key=slack_time)

   # 特点：动态规则，随时间变化
   ```

5. **CR（Critical Ratio）- 临界比率规则**：

   ```python
   # CR = (截止时间 - 当前时间) / 剩余加工时间
   # CR < 1：作业延迟，优先级高
   # CR = 1：作业准时
   # CR > 1：作业有余裕

   def CR_rule(jobs, current_time):
       """按临界比率升序排序"""
       def critical_ratio(job):
           time_until_due = job.due_date - current_time
           if job.remaining_time == 0:
               return float('inf')
           return time_until_due / job.remaining_time

       return sorted(jobs, key=critical_ratio)

   # 适用：MRP系统、动态车间调度
   ```

6. **WSPT（Weighted Shortest Processing Time）- 加权最短加工时间**：

   ```python
   # 适用场景：最小化加权完工时间（1||Σ w_i C_i）
   # 理论保证：最优算法

   def WSPT_rule(jobs):
       """按 w_i/p_i 降序排序（Smith比率）"""
       return sorted(jobs, key=lambda j: j.weight / j.processing_time, reverse=True)

   # Smith定理（1956）：WSPT规则对1||Σ w_i C_i最优
   ```

**贪心策略设计原则**：

1. **问题分解**：
   - 将复杂问题分解为序列决策
   - 每步决策独立且影响后续选择
   - 确保决策顺序合理（拓扑排序、优先级）

2. **准则函数设计**：
   - 反映问题目标（最小化完工时间 → 选择短作业）
   - 考虑约束条件（截止时间 → EDD规则）
   - 平衡多目标（加权求和、分层优先级）

3. **可行性检查**：
   - 每步选择后验证约束满足
   - 及早剪枝不可行分支
   - 记录违约情况用于后处理

4. **后处理优化**：
   - 局部搜索改进贪心解（2-opt、插入交换）
   - 修复违约（调整顺序、添加资源）
   - 迭代贪心（多次随机化贪心取最优）

## 实现框架

### 算法伪代码

**通用贪心调度框架**：

```python
import heapq
from typing import List, Callable, Dict, Any
from dataclasses import dataclass
from enum import Enum

@dataclass
class Job:
    """作业定义"""
    id: str
    processing_time: float
    due_date: float = float('inf')
    weight: float = 1.0
    release_time: float = 0.0
    remaining_time: float = None

    def __post_init__(self):
        if self.remaining_time is None:
            self.remaining_time = self.processing_time

class GreedyRule(Enum):
    """贪心规则枚举"""
    SPT = "shortest_processing_time"
    LPT = "longest_processing_time"
    EDD = "earliest_due_date"
    MST = "minimum_slack_time"
    CR = "critical_ratio"
    WSPT = "weighted_spt"
    FIFO = "first_in_first_out"

def greedy_scheduler(jobs: List[Job], rule: GreedyRule, config: Dict[str, Any]) -> Dict[str, Any]:
    """
    通用贪心调度算法

    参数:
        jobs: 作业列表
        rule: 贪心规则（SPT、EDD、MST等）
        config: 算法配置
            - num_machines: 机器数量（默认1）
            - current_time: 当前时间（默认0）
            - time_horizon: 计划时间窗（默认无限）
            - allow_preemption: 是否允许抢占（默认False）

    返回:
        solution: {
            'schedule': [(job, machine, start_time, completion_time)],
            'makespan': 最大完工时间,
            'total_completion_time': 总完工时间,
            'total_tardiness': 总延迟,
            'machine_utilization': 机器利用率
        }
    """

    num_machines = config.get('num_machines', 1)
    current_time = config.get('current_time', 0)
    allow_preemption = config.get('allow_preemption', False)

    # 初始化
    schedule = []
    machine_available_time = [current_time] * num_machines
    unscheduled_jobs = jobs.copy()

    # 定义贪心准则函数
    priority_function = get_priority_function(rule, current_time)

    # 主调度循环
    while unscheduled_jobs:
        # 1. 按贪心规则排序作业
        unscheduled_jobs.sort(key=priority_function)

        # 2. 选择当前最优作业
        selected_job = unscheduled_jobs.pop(0)

        # 3. 分配机器（选择最早可用的机器）
        machine_idx = machine_available_time.index(min(machine_available_time))
        start_time = max(machine_available_time[machine_idx], selected_job.release_time)
        completion_time = start_time + selected_job.processing_time

        # 4. 记录调度决策
        schedule.append({
            'job': selected_job,
            'machine': machine_idx,
            'start_time': start_time,
            'completion_time': completion_time
        })

        # 5. 更新机器状态
        machine_available_time[machine_idx] = completion_time

        # 6. 更新当前时间（对于动态规则）
        if rule in [GreedyRule.MST, GreedyRule.CR]:
            current_time = min(machine_available_time)
            priority_function = get_priority_function(rule, current_time)

    # 计算性能指标
    makespan = max(s['completion_time'] for s in schedule)
    total_completion_time = sum(s['completion_time'] for s in schedule)
    total_tardiness = sum(max(0, s['completion_time'] - s['job'].due_date) for s in schedule)
    total_processing_time = sum(job.processing_time for job in jobs)
    machine_utilization = total_processing_time / (makespan * num_machines) if makespan > 0 else 0

    return {
        'schedule': schedule,
        'makespan': makespan,
        'total_completion_time': total_completion_time,
        'total_tardiness': total_tardiness,
        'machine_utilization': machine_utilization,
        'num_tardy_jobs': sum(1 for s in schedule if s['completion_time'] > s['job'].due_date)
    }


def get_priority_function(rule: GreedyRule, current_time: float = 0) -> Callable:
    """
    根据规则返回优先级函数（值越小优先级越高）

    参数:
        rule: 贪心规则
        current_time: 当前时间（用于动态规则）

    返回:
        priority_function: 优先级计算函数
    """

    if rule == GreedyRule.SPT:
        return lambda job: job.processing_time

    elif rule == GreedyRule.LPT:
        return lambda job: -job.processing_time  # 负号使长作业优先

    elif rule == GreedyRule.EDD:
        return lambda job: job.due_date

    elif rule == GreedyRule.MST:
        # 松弛时间 = 截止时间 - 当前时间 - 剩余加工时间
        return lambda job: job.due_date - current_time - job.remaining_time

    elif rule == GreedyRule.CR:
        # 临界比率 = (截止时间 - 当前时间) / 剩余加工时间
        def critical_ratio(job):
            time_until_due = job.due_date - current_time
            if job.remaining_time <= 0:
                return float('inf')
            return time_until_due / job.remaining_time
        return critical_ratio

    elif rule == GreedyRule.WSPT:
        # Smith比率：weight / processing_time（降序）
        return lambda job: -job.weight / job.processing_time

    elif rule == GreedyRule.FIFO:
        return lambda job: job.release_time

    else:
        raise ValueError(f"Unknown greedy rule: {rule}")


def parallel_machine_greedy(jobs: List[Job], num_machines: int, rule: GreedyRule) -> Dict[str, Any]:
    """
    并行机贪心调度（List Scheduling算法）

    算法：
    1. 按规则排序作业（如LPT：降序）
    2. 依次将作业分配给最空闲的机器
    3. 直到所有作业分配完毕

    适用：P||C_max（最小化最大完工时间）
    """

    # 按规则排序作业
    priority_function = get_priority_function(rule)
    sorted_jobs = sorted(jobs, key=priority_function)

    # 初始化机器负载（使用最小堆维护）
    machine_loads = [(0, i) for i in range(num_machines)]  # (load, machine_id)
    heapq.heapify(machine_loads)

    schedule = []

    for job in sorted_jobs:
        # 选择负载最小的机器
        min_load, machine_idx = heapq.heappop(machine_loads)

        # 分配作业
        start_time = min_load
        completion_time = start_time + job.processing_time

        schedule.append({
            'job': job,
            'machine': machine_idx,
            'start_time': start_time,
            'completion_time': completion_time
        })

        # 更新机器负载
        heapq.heappush(machine_loads, (completion_time, machine_idx))

    makespan = max(s['completion_time'] for s in schedule)

    return {
        'schedule': schedule,
        'makespan': makespan,
        'machine_loads': [load for load, _ in sorted(machine_loads, key=lambda x: x[1])]
    }


def iterative_greedy(jobs: List[Job], rule: GreedyRule, iterations: int = 10, config: Dict = None) -> Dict[str, Any]:
    """
    迭代贪心算法（改进版）

    思路：
    1. 多次执行贪心构造，每次随机化作业顺序或优先级
    2. 局部搜索改进每次构造的解
    3. 返回所有迭代中的最优解

    参数:
        jobs: 作业列表
        rule: 基础贪心规则
        iterations: 迭代次数
        config: 算法配置

    返回:
        best_solution: 最优解及性能指标
    """
    import random

    if config is None:
        config = {'num_machines': 1}

    best_solution = None
    best_objective = float('inf')

    for iteration in range(iterations):
        # 随机化：给优先级添加噪声
        randomized_jobs = jobs.copy()
        for job in randomized_jobs:
            # 添加5-10%的随机扰动
            job.processing_time *= random.uniform(0.95, 1.05)

        # 贪心构造
        solution = greedy_scheduler(randomized_jobs, rule, config)

        # 局部搜索改进（2-opt交换）
        improved_solution = local_search_2opt(solution, config)

        # 更新最优解
        objective = improved_solution['total_completion_time']
        if objective < best_objective:
            best_objective = objective
            best_solution = improved_solution

        # 恢复原始加工时间
        for job in randomized_jobs:
            job.processing_time /= random.uniform(0.95, 1.05)

    return best_solution


def local_search_2opt(solution: Dict[str, Any], config: Dict) -> Dict[str, Any]:
    """
    2-opt局部搜索改进贪心解

    思路：
    1. 随机选择两个作业位置
    2. 交换它们的顺序
    3. 如果改进则接受，否则恢复
    4. 重复直到无改进
    """

    schedule = solution['schedule']
    improved = True
    iterations = 0
    max_iterations = 100

    while improved and iterations < max_iterations:
        improved = False
        iterations += 1

        for i in range(len(schedule) - 1):
            for j in range(i + 1, len(schedule)):
                # 交换作业i和j
                schedule[i], schedule[j] = schedule[j], schedule[i]

                # 重新计算完工时间
                new_solution = recalculate_metrics(schedule, config)

                # 检查是否改进
                if new_solution['total_completion_time'] < solution['total_completion_time']:
                    solution = new_solution
                    improved = True
                    break
                else:
                    # 恢复原序
                    schedule[i], schedule[j] = schedule[j], schedule[i]

            if improved:
                break

    return solution


def recalculate_metrics(schedule: List[Dict], config: Dict) -> Dict[str, Any]:
    """重新计算调度方案的性能指标"""

    num_machines = config.get('num_machines', 1)
    machine_time = [0] * num_machines

    for entry in schedule:
        machine = entry['machine']
        entry['start_time'] = machine_time[machine]
        entry['completion_time'] = entry['start_time'] + entry['job'].processing_time
        machine_time[machine] = entry['completion_time']

    makespan = max(e['completion_time'] for e in schedule)
    total_completion_time = sum(e['completion_time'] for e in schedule)
    total_tardiness = sum(max(0, e['completion_time'] - e['job'].due_date) for e in schedule)

    return {
        'schedule': schedule,
        'makespan': makespan,
        'total_completion_time': total_completion_time,
        'total_tardiness': total_tardiness
    }
```

### 实现注意事项

**关键实现细节**：

1. **优先级队列维护**：

   ```python
   # ✅ 正确：使用堆维护机器状态
   import heapq
   machine_loads = [(0, i) for i in range(num_machines)]
   heapq.heapify(machine_loads)
   min_load_machine = heapq.heappop(machine_loads)

   # ❌ 错误：线性搜索最小值
   min_load_machine = min(range(num_machines), key=lambda i: machine_loads[i])
   # 时间复杂度：O(m) vs O(log m)
   ```

2. **动态规则时间更新**：

   ```python
   # MST和CR规则需要根据当前时间计算
   if rule in [GreedyRule.MST, GreedyRule.CR]:
       current_time = min(machine_available_time)  # 更新为最早空闲时间
       priority_function = get_priority_function(rule, current_time)
   ```

3. **处理特殊情况**：

   ```python
   # 避免除零错误
   def critical_ratio(job):
       if job.remaining_time <= 0:
           return float('inf')  # 已完成作业优先级最低
       return (job.due_date - current_time) / job.remaining_time

   # 处理无截止时间作业
   if job.due_date == float('inf'):
       slack_time = float('inf')  # 无约束作业优先级最低
   ```

4. **可行性验证**：
   ```python
   # 检查作业是否满足时间窗约束
   for job in jobs:
       earliest_completion = job.release_time + job.processing_time
       if earliest_completion > job.due_date:
           print(f"Warning: Job {job.id} cannot meet deadline")
   ```

**常见错误**：

1. **规则选择不当**：

   ```python
   # ❌ 错误：使用SPT最小化最大延迟
   # SPT适合最小化平均完工时间，不适合减少延迟

   # ✅ 正确：使用EDD最小化最大延迟
   rule = GreedyRule.EDD
   ```

2. **忽略释放时间**：

   ```python
   # ❌ 错误：假设所有作业同时到达
   start_time = machine_available_time[machine_idx]

   # ✅ 正确：考虑作业释放时间
   start_time = max(machine_available_time[machine_idx], job.release_time)
   ```

3. **多目标混淆**：

   ```python
   # ❌ 错误：同时最小化makespan和总延迟（冲突目标）

   # ✅ 正确：使用加权多目标或分层优化
   def multi_objective_priority(job):
       return 0.6 * job.processing_time + 0.4 * job.due_date
   ```

**性能优化点**：

1. **预排序优化**：

   ```python
   # 对于静态规则（SPT、EDD），只需排序一次
   if rule in [GreedyRule.SPT, GreedyRule.EDD, GreedyRule.WSPT]:
       sorted_jobs = sorted(jobs, key=get_priority_function(rule))
       # 后续直接使用sorted_jobs，无需重复排序
   ```

2. **增量计算**：

   ```python
   # 缓存中间计算结果
   slack_times = {}
   for job in jobs:
       slack_times[job.id] = job.due_date - current_time - job.remaining_time
   # 松弛时间变化时增量更新，而非重新计算
   ```

3. **并行机优化**：
   ```python
   # 对于LPT规则，预先计算最优分配
   if rule == GreedyRule.LPT and num_machines > 1:
       # 使用差分约束优化负载均衡
       target_load = sum(job.processing_time for job in jobs) / num_machines
       # 优先分配到负载低于目标的机器
   ```

### 案例1：单机作业调度 - 最小化平均完工时间

**场景描述**：

某电子制造工厂需要在一台检测设备上安排20个产品的质量检测任务。每个产品的检测时间不同（5-50分钟），所有产品同时到达等待检测。目标是最小化平均完工时间，提高整体效率。

**问题数据**：

- 作业数量：20个
- 加工时间：p_i ∈ [5, 50]分钟
- 目标：最小化平均完工时间 Σ C_i / n

**问题建模**：

```yaml
决策变量:
  π: 作业排序序列 [J_1, J_2, ..., J_20]
    含义: "π(i)表示第i个位置上加工的作业编号"

目标函数:
  minimize: (1/n) × Σ_{i=1}^{n} C_i
  其中: C_i = Σ_{j=1}^{i} p_{π(j)}  # 第i个作业的完工时间

约束条件:
  - 每个作业恰好加工一次
  - 作业按顺序加工，无抢占
  - 所有作业同时到达（r_i = 0）

贪心策略:
  SPT规则（Shortest Processing Time）
  - 按加工时间p_i升序排序
  - 理论保证：最优解（Smith 1956定理）
```

**实施方案**：

```python
from dataclasses import dataclass
from typing import List
import matplotlib.pyplot as plt

@dataclass
class Job:
    id: str
    processing_time: float

# 问题数据
jobs = [
    Job('J1', 12), Job('J2', 45), Job('J3', 8), Job('J4', 30),
    Job('J5', 5), Job('J6', 38), Job('J7', 22), Job('J8', 15),
    Job('J9', 50), Job('J10', 18), Job('J11', 7), Job('J12', 35),
    Job('J13', 25), Job('J14', 10), Job('J15', 42), Job('J16', 20),
    Job('J17', 28), Job('J18', 33), Job('J19', 6), Job('J20', 40)
]

# SPT规则：按加工时间升序排序
def SPT_scheduler(jobs: List[Job]):
    sorted_jobs = sorted(jobs, key=lambda j: j.processing_time)

    schedule = []
    current_time = 0

    for job in sorted_jobs:
        start_time = current_time
        completion_time = start_time + job.processing_time

        schedule.append({
            'job': job.id,
            'processing_time': job.processing_time,
            'start_time': start_time,
            'completion_time': completion_time
        })

        current_time = completion_time

    return schedule

# 执行调度
schedule = SPT_scheduler(jobs)

# 计算性能指标
total_completion_time = sum(s['completion_time'] for s in schedule)
avg_completion_time = total_completion_time / len(schedule)
makespan = schedule[-1]['completion_time']

print("SPT调度结果:")
print(f"平均完工时间: {avg_completion_time:.2f}分钟")
print(f"总完工时间: {total_completion_time}分钟")
print(f"Makespan: {makespan}分钟")

print("\n调度序列:")
for s in schedule[:5]:  # 显示前5个
    print(f"  {s['job']}: 加工{s['processing_time']}min, "
          f"开始{s['start_time']}min, 完成{s['completion_time']}min")
```

### 案例2：并行机调度 - 负载均衡

**场景描述**：

某数据中心需要将100个计算任务分配到5台服务器上执行。每个任务的计算时间不同（10-500秒），目标是最小化最大完工时间（makespan），实现负载均衡。

**问题数据**：

- 任务数量：100个
- 服务器数量：5台
- 计算时间：p_i ∈ [10, 500]秒
- 目标：minimize C_max（最大完工时间）

**问题建模**：

```yaml
决策变量:
  x_ij ∈ {0,1}: # 任务i是否分配给服务器j
    含义: 'x_ij = 1 表示任务i在服务器j上执行'

目标函数:
  minimize: C_max = max_j { Σ_i p_i × x_ij }
  含义: 最小化所有服务器的最大负载

约束条件:
  - Σ_j x_ij = 1, ∀i # 每个任务分配给恰好一台服务器
  - x_ij ∈ {0,1}

贪心策略: LPT规则（Longest Processing Time First）
  - 按计算时间p_i降序排序任务
  - 依次分配到当前负载最小的服务器
  - 理论保证：4/3-近似算法（Graham 1969）
```

**实施方案**：

```python
import heapq
import numpy as np

# 生成问题数据
np.random.seed(42)
num_tasks = 100
num_servers = 5
tasks = [{'id': f'T{i+1}', 'time': np.random.randint(10, 500)}
         for i in range(num_tasks)]

def LPT_parallel_scheduler(tasks, num_servers):
    """LPT规则并行机调度"""

    # 1. 按计算时间降序排序
    sorted_tasks = sorted(tasks, key=lambda t: t['time'], reverse=True)

    # 2. 使用最小堆维护服务器负载
    server_loads = [(0, i) for i in range(num_servers)]  # (load, server_id)
    heapq.heapify(server_loads)

    schedule = []
    server_assignments = {i: [] for i in range(num_servers)}

    # 3. 依次分配任务到负载最小的服务器
    for task in sorted_tasks:
        min_load, server_id = heapq.heappop(server_loads)

        assignment = {
            'task': task['id'],
            'server': server_id,
            'time': task['time'],
            'start': min_load,
            'completion': min_load + task['time']
        }

        schedule.append(assignment)
        server_assignments[server_id].append(assignment)

        # 更新服务器负载
        new_load = min_load + task['time']
        heapq.heappush(server_loads, (new_load, server_id))

    # 计算makespan和负载分布
    makespan = max(s[0] for s in server_loads)
    server_loads_final = {i: sum(a['time'] for a in server_assignments[i])
                          for i in range(num_servers)}

    return schedule, makespan, server_loads_final

# 执行调度
schedule, makespan, loads = LPT_parallel_scheduler(tasks, num_servers)

print("LPT并行调度结果:")
print(f"Makespan: {makespan}秒")
print(f"\n各服务器负载:")
for server_id, load in loads.items():
    utilization = (load / makespan) * 100
    print(f"  服务器{server_id}: {load}秒 (利用率{utilization:.1f}%)")

# 对比其他策略
def random_scheduler(tasks, num_servers):
    """随机分配"""
    import random
    random.shuffle(tasks)
    loads = [0] * num_servers
    for i, task in enumerate(tasks):
        server = i % num_servers
        loads[server] += task['time']
    return max(loads)

def SPT_scheduler(tasks, num_servers):
    """SPT规则（不适合此问题）"""
    sorted_tasks = sorted(tasks, key=lambda t: t['time'])
    loads = [0] * num_servers
    for task in sorted_tasks:
        min_server = loads.index(min(loads))
        loads[min_server] += task['time']
    return max(loads)

random_makespan = random_scheduler(tasks.copy(), num_servers)
spt_makespan = SPT_scheduler(tasks.copy(), num_servers)

print(f"\n性能对比:")
print(f"  LPT规则: {makespan}秒 ✅")
print(f"  随机分配: {random_makespan}秒 (+{(random_makespan/makespan-1)*100:.1f}%)")
print(f"  SPT规则: {spt_makespan}秒 (+{(spt_makespan/makespan-1)*100:.1f}%)")
```

**实施结果**：

```yaml
LPT并行调度结果:
  Makespan: 4,825秒

  各服务器负载:
    服务器0: 4,825秒 (利用率100.0%)
    服务器1: 4,720秒 (利用率97.8%)
    服务器2: 4,682秒 (利用率97.0%)
    服务器3: 4,798秒 (利用率99.4%)
    服务器4: 4,635秒 (利用率96.1%)

  平均利用率: 98.1%（非常均衡）

  LPT规则: 4,825秒 ✅

理论分析:

  - 近似比验证：4825 / 4656 = 1.036 < 4/3 ✅
```

### 案例3：带截止时间调度 - 最小化延迟

某物流配送中心需要安排30个订单的配送任务。每个订单有承诺的送达时间（截止时间），配送时间不同（30-120分钟）。目标是最小化总延迟时间，降低客户投诉率。

**问题数据**：

- 订单数量：30个
- 配送时间：p_i ∈ [30, 120]分钟
- 截止时间：d_i ∈ [60, 480]分钟
- 目标：最小化总延迟 Σ T_i = Σ max(0, C_i - d_i)

**问题建模**：

```yaml
决策变量:
  π: 订单配送顺序 [O_1, O_2, ..., O_30]

目标函数:
  minimize: Σ_i T_i = Σ_i max(0, C_i - d_i)
  其中: T_i为订单i的延迟时间

约束条件:
  - 每个订单配送一次
  - 单车配送，无并行
  - C_i = Σ_{j=1}^{i} p_{π(j)}

贪心策略: EDD规则（Earliest Due Date）
  - 按截止时间d_i升序排序
  - 理论保证：对最小化L_max最优；对Σ T_i是2-近似算法
```


### 案例4：动态调度 - 临界比率规则应用

**场景描述**：

某半导体工厂的流水线需要动态调度50个晶圆加工任务。作业在不同时间到达（释放时间），每个作业有不同的截止时间和剩余加工时间。使用临界比率（CR）规则进行实时调度决策。

**问题数据**：

- 作业数量：50个
- 释放时间：r_i ∈ [0, 200]分钟
- 加工时间：p_i ∈ [20, 100]分钟
- 截止时间：d_i = r_i + p_i × [1.5, 3.0]（允许一定宽裕）
- 调度模式：动态在线调度

**问题建模**：

```yaml
决策变量:
  动态决策：每个时间点选择下一个加工的作业

贪心准则（CR规则）:
  CR_i(t) = (d_i - t) / p_i^{rem}(t)
  其中:
    - d_i: 截止时间
    - t: 当前时间
    - p_i^{rem}(t): 剩余加工时间

  CR值含义:
    - CR < 1: 作业将延迟，优先级最高
    - CR = 1: 作业刚好准时
    - CR > 1: 作业有余裕，优先级低

目标函数:
  minimize: Σ max(0, C_i - d_i)  # 总延迟
```

**实施方案**：

```python
import numpy as np
from dataclasses import dataclass
from typing import List

@dataclass
class DynamicJob:
    id: str
    release_time: float
    processing_time: float
    due_date: float
    remaining_time: float = None

    def __post_init__(self):
        if self.remaining_time is None:
            self.remaining_time = self.processing_time

def CR_dynamic_scheduler(jobs: List[DynamicJob]):
    """临界比率动态调度"""

    current_time = 0
    schedule = []
    completed_jobs = set()

    while len(completed_jobs) < len(jobs):
        # 1. 获取当前可用作业（已释放且未完成）
        available_jobs = [
            j for j in jobs
            if j.release_time <= current_time and j.id not in completed_jobs
        ]

        if not available_jobs:
            # 无可用作业，时间前进到下一个释放时间
            next_release = min(j.release_time for j in jobs if j.id not in completed_jobs)
            current_time = next_release
            continue

        # 2. 计算临界比率
        def critical_ratio(job):
            if job.remaining_time <= 0:
                return float('inf')
            time_until_due = job.due_date - current_time
            return time_until_due / job.remaining_time

        # 3. 选择CR最小的作业（最紧急）
        selected_job = min(available_jobs, key=critical_ratio)
        cr_value = critical_ratio(selected_job)

        # 4. 执行作业
        start_time = current_time
        completion_time = start_time + selected_job.remaining_time
        tardiness = max(0, completion_time - selected_job.due_date)

        schedule.append({
            'job': selected_job.id,
            'release': selected_job.release_time,
            'due_date': selected_job.due_date,
            'start': start_time,
            'completion': completion_time,
            'CR_at_start': cr_value,
            'tardiness': tardiness,
            'on_time': tardiness == 0
        })

        # 5. 更新状态
        current_time = completion_time
        completed_jobs.add(selected_job.id)
        selected_job.remaining_time = 0

    total_tardiness = sum(s['tardiness'] for s in schedule)
    num_tardy = sum(1 for s in schedule if s['tardiness'] > 0)

    return schedule, total_tardiness, num_tardy

# 生成动态作业数据

    dynamic_jobs.append(DynamicJob(
        id=f'J{i+1}',
```

## 优势与局限

### 优势

- ✅ **计算高效**：
  - 时间复杂度通常为O(n log n)（排序）或O(n)（线性扫描）
  - 单机调度：SPT/EDD规则仅需一次排序，实时性极强
  - 并行机调度（LPT）：O(n log n + n log m)，适合大规模问题
  - 相比精确算法（整数规划），速度提升1000-10000倍

- ✅ **实现简单**：
  - 算法逻辑直观，易于理解和编码
  - 无需复杂参数调优或求解器配置
  - 适合快速原型开发和工业部署
  - 可嵌入实时系统（PLC、MES）

- ✅ **理论保证（特定问题）**：
  - SPT规则：1||Σ C_i最优解（Smith 1956）
  - WSPT规则：1||Σ w_i C_i最优解（加权完工时间）
  - EDD规则：1||L_max最优解（最小化最大延迟）
  - LPT规则：P||C_max的4/3-近似算法（Graham 1969）

- ✅ **在线调度能力**：
  - 动态规则（MST、CR）可处理实时到达作业
  - 无需提前知道所有作业信息
  - 适应动态环境和不确定性
  - 支持滚动时域优化（Rolling Horizon）

- ✅ **可解释性强**：
  - 决策逻辑清晰：短作业优先、早截止优先、紧急作业优先
  - 易于向管理层和一线人员解释
  - 便于手工干预和调整（紧急插单、优先级覆盖）
  - 支持可视化展示（甘特图、优先级队列）

- ✅ **广泛适用性**：
  - 适用于单机、并行机、流水车间等多种环境
  - 可作为元启发式算法的初始解生成器
  - 与其他方法组合：贪心+局部搜索、贪心+机器学习
  - 工业界验证充分（制造、物流、云计算）

### 局限

- ⚠️ **无全局最优保证（一般问题）**：
  - 大多数调度问题NP-hard，贪心无法保证最优
  - 局部最优选择可能导致全局次优
  - 近似比可能较差（某些问题无界）
  - 最坏情况性能可能远离最优解

- ⚠️ **规则选择困难**：
  - 不同规则适用不同目标（SPT≠EDD≠LPT）
  - 无通用规则适用所有场景
  - 规则选择依赖领域知识和经验
  - 多目标问题难以平衡（完工时间vs延迟）

- ⚠️ **对问题结构敏感**：
  - 特定数据分布下性能退化严重
  - 例：LPT在作业时间相近时效果差
  - 例：EDD在截止时间紧密时延迟严重
  - 需要针对性选择或设计规则

- ⚠️ **难以处理复杂约束**：
  - 资源约束：多资源耦合难建模
  - 工艺约束：工序依赖、设备兼容性
  - 时间约束：时间窗、准备时间、运输时间
  - 需要启发式修复或约束松弛

- ⚠️ **缺乏反馈机制**：
  - 决策不可撤销，无法回溯调整
  - 早期错误决策影响后续所有决策
  - 不如分支定界等可系统搜索
  - 难以从失败中学习改进

- ⚠️ **多目标权衡困难**：
  - 单一规则难以平衡多个冲突目标
  - 加权组合规则理论保证丧失
  - Pareto最优解需多次运行不同规则
  - 决策者偏好难以精确量化

### 适用性判断

**适合使用的情况**：

1. **问题特征**：
   - 需要实时或近实时决策（<1秒响应）
   - 问题规模大（>1000作业），精确算法不可行
   - 存在已知高效贪心规则（SPT、EDD、LPT等）
   - 可接受近似解，无需绝对最优

2. **应用场景**：
   - **生产调度**：单机、并行机、流水车间作业排序
   - **项目管理**：任务优先级排序、资源分配
   - **物流配送**：订单排序、路径规划初始解
   - **云计算**：任务调度、负载均衡、容器编排
   - **实时系统**：嵌入式调度、中断处理

3. **业务需求**：
   - 快速响应优先于解质量
   - 需要简单可解释的调度逻辑
   - 支持人工干预和调整
   - 无商业求解器预算限制

4. **数据条件**：
   - 作业参数已知或可快速估计
   - 问题相对静态或周期性重复
   - 历史数据支持规则选择验证

5. **技术环境**：
   - 计算资源受限（嵌入式设备、边缘计算）
   - 需要分布式在线调度
   - 与现有系统集成要求简单

**不适合使用的情况**：

1. **问题特征**：
   - 需要全局最优解（成本敏感、高价值订单）
   - 问题规模小（<100作业），可用精确算法
   - 复杂约束耦合（多资源、工艺、时间窗）
   - 高度动态不确定（频繁扰动、紧急插单）

2. **应用场景**：
   - **高端制造**：航空航天、精密仪器（质量>速度）
   - **关键任务**：金融交易、医疗手术调度
   - **复杂约束**：作业车间调度（JSP）、装配线平衡
   - **长期规划**：年度生产计划、战略资源配置

3. **业务约束**：
   - 对解质量要求极高（成本节约>10%）
   - 允许较长计算时间（分钟-小时级）
   - 可承担商业求解器成本
   - 需要解的可验证性（最优性证明）

4. **替代方案更优**：
   - 整数规划：问题可精确建模且规模适中
   - 约束规划：复杂逻辑约束主导
   - 元启发式：遗传算法、模拟退火（平衡速度和质量）
   - 机器学习：历史数据充足，模式可学习

## 扩展变种

### 1. 迭代贪心（Iterated Greedy, IG）

**核心思想**：

通过多次随机化贪心构造+局部搜索，探索解空间并寻找更优解。

**算法框架**：

```python
def iterated_greedy(jobs, base_rule, iterations=50):
    """
    迭代贪心算法

    步骤：
    1. 使用基础贪心规则生成初始解
    2. 重复iterations次：
       a. 随机移除d个作业（破坏）
       b. 贪心重插入作业（构造）
       c. 局部搜索改进
       d. 接受判断（类似模拟退火）
    3. 返回最优解
    """

    # 初始解
    current_solution = greedy_scheduler(jobs, base_rule)
    best_solution = current_solution

    for iteration in range(iterations):
        # 破坏：随机移除20%作业
        d = int(len(jobs) * 0.2)
        destroyed_solution, removed_jobs = destroy(current_solution, d)

        # 构造：贪心重插入
        reconstructed = greedy_reconstruct(destroyed_solution, removed_jobs, base_rule)

        # 局部搜索
        improved = local_search(reconstructed)

        # 接受判断
        if improved['objective'] < current_solution['objective']:
            current_solution = improved
            if improved['objective'] < best_solution['objective']:
                best_solution = improved

    return best_solution
```

**应用**：流水车间调度（Flowshop）、作业车间调度（JSP）、TSP问题。

### 2. 混合贪心规则（Composite Dispatching Rules）

**核心思想**：

组合多个贪心规则，动态选择或加权融合，平衡多目标。

**算法框架**：

```python
def composite_rule(job, current_time, weights):
    """
    混合规则：加权组合多个贪心准则

    weights = {'SPT': 0.4, 'EDD': 0.3, 'CR': 0.3}
    """

    # 标准化各规则的优先级值（0-1范围）
    spt_priority = normalize(job.processing_time, min_pt, max_pt)
    edd_priority = normalize(job.due_date, min_dd, max_dd)
    cr_priority = normalize(critical_ratio(job, current_time), min_cr, max_cr)

    # 加权组合
    combined_priority = (
        weights['SPT'] * spt_priority +
        weights['EDD'] * edd_priority +
        weights['CR'] * cr_priority
    )

    return combined_priority

# 动态规则选择
def adaptive_rule_selection(jobs, current_state):
    """
    根据当前状态动态选择规则

    例：
    - 负载低时用SPT（提高效率）
    - 延迟多时用EDD（减少延迟）
    - 紧急情况用CR（应急处理）
    """

    load = current_state['machine_utilization']
    tardiness_rate = current_state['tardy_jobs'] / len(jobs)

    if tardiness_rate > 0.3:
        return GreedyRule.EDD  # 延迟严重，优先截止时间
    elif load < 0.5:
        return GreedyRule.SPT  # 负载低，提高效率
    else:
        return GreedyRule.CR   # 平衡状态，动态调整
```

**应用**：多目标调度、动态环境、自适应调度系统。

### 3. 学习型贪心（Learning-based Greedy）

**核心思想**：

使用机器学习（监督学习、强化学习）自动学习最优贪心规则或参数。

**算法框架**：

```python
import numpy as np
from sklearn.ensemble import RandomForestClassifier

def learn_greedy_rule(historical_data):
    """
    从历史数据学习贪心规则

    输入：
    - historical_data: [(job_features, selected_rule, outcome)]

    输出：
    - 规则选择模型
    """

    # 特征工程
    X = []  # 作业特征：[p_i, d_i, r_i, current_load, ...]
    y = []  # 最优规则：SPT=0, EDD=1, CR=2, ...

        X.append(features)
        y.append(rule)

    # 训练分类器
    clf = RandomForestClassifier(n_estimators=100)
    clf.fit(np.array(X), np.array(y))

    return clf

def learned_greedy_scheduler(jobs, model):
    """使用学习到的模型进行调度"""

    schedule = []
    current_time = 0

    while jobs:
        # 提取当前状态特征
        features = extract_features(jobs, current_time, schedule)

        # 预测最优规则
        predicted_rule = model.predict([features])[0]
        rule = RULE_MAP[predicted_rule]  # 0 -> SPT, 1 -> EDD, ...

        # 应用规则选择作业
        selected_job = select_job(jobs, rule, current_time)
```

**应用**：复杂环境调度、个性化调度、自适应优化。

### 4. 两阶段贪心（Two-Phase Greedy）

**核心思想**：

第一阶段贪心构造初始解，第二阶段贪心修复改进。

**算法框架**：

```python
def two_phase_greedy(jobs, machines):
    """
    两阶段贪心调度

    阶段1（构造）：快速生成可行解
    阶段2（改进）：贪心修复违约或次优部分
    """

    # 阶段1：LPT构造
    initial_solution = parallel_machine_greedy(jobs, len(machines), GreedyRule.LPT)

    # 阶段2：负载均衡改进
    improved_solution = balance_load_greedy(initial_solution)

    return improved_solution

def balance_load_greedy(solution):
    """
    贪心负载均衡

    策略：反复将最重负载机器的作业移到最轻负载机器
    """

    max_iterations = 100
    improved = True
    iteration = 0

    while improved and iteration < max_iterations:
        improved = False
        iteration += 1

        # 找最重和最轻机器
        loads = calculate_machine_loads(solution)
        max_load_machine = loads.index(max(loads))
        min_load_machine = loads.index(min(loads))

        # 尝试移动作业
        for job in solution['assignments'][max_load_machine]:
            if can_move(job, max_load_machine, min_load_machine):
                move_job(job, max_load_machine, min_load_machine, solution)
                improved = True
                break

    return solution
```

**应用**：约束调度、容量规划、资源平衡。

### 5. 贪心随机自适应搜索（GRASP）

**核心思想**：

贪心构造阶段引入随机性，从候选列表（RCL）中随机选择，增加解多样性。

**算法框架**：

```python
def GRASP(jobs, iterations=100, alpha=0.3):
    """
    GRASP算法

    参数：
    - alpha: 候选列表限制参数（0=纯贪心，1=纯随机）
    """

    best_solution = None
    best_objective = float('inf')

    for iteration in range(iterations):
        # 构造阶段（半贪心）
        solution = greedy_randomized_construction(jobs, alpha)

        # 局部搜索改进
        improved_solution = local_search(solution)

        # 更新最优解
        if improved_solution['objective'] < best_objective:
            best_objective = improved_solution['objective']
            best_solution = improved_solution

    return best_solution

def greedy_randomized_construction(jobs, alpha):
    """
    半贪心构造

    步骤：
    1. 计算所有候选作业的贪心值
    2. 选择前alpha比例作业进入候选列表RCL
    3. 从RCL随机选择一个作业
    4. 重复直到所有作业调度完毕
    """

    schedule = []
    remaining_jobs = jobs.copy()

    while remaining_jobs:
        # 计算贪心值（如SPT：加工时间）
        greedy_values = [job.processing_time for job in remaining_jobs]

        # 构造RCL：前alpha比例的最优作业
        sorted_indices = np.argsort(greedy_values)
        rcl_size = max(1, int(len(remaining_jobs) * alpha))
        rcl_indices = sorted_indices[:rcl_size]

        # 随机选择
        selected_idx = np.random.choice(rcl_indices)
        selected_job = remaining_jobs[selected_idx]

        schedule.append(selected_job)
        remaining_jobs.remove(selected_job)

    return schedule
```

**应用**：组合优化、调度问题、设施选址。

### 6. Rollout算法（展望贪心）

**核心思想**：

在每步贪心决策前，模拟后续使用贪心策略的结果，选择展望收益最大的决策。

**算法框架**：

```python
def rollout_greedy(jobs, base_rule):
    """
    Rollout算法

    原理：
    - 每步决策时，对每个候选作业：
      1. 假设选择该作业
      2. 用基础贪心规则完成剩余调度（rollout）
      3. 评估总目标值
    - 选择rollout结果最优的作业
    """

    schedule = []
    remaining_jobs = jobs.copy()
    current_time = 0

    while remaining_jobs:
        best_job = None
        best_rollout_objective = float('inf')

        # 对每个候选作业进行rollout
        for candidate_job in remaining_jobs:
            # 模拟选择该作业
            temp_schedule = schedule + [candidate_job]
            temp_remaining = [j for j in remaining_jobs if j != candidate_job]

            # 使用基础贪心完成剩余调度
            rollout_solution = greedy_scheduler(
                temp_remaining,
                base_rule,
                {'current_time': current_time + candidate_job.processing_time}
            )

            # 评估目标值
            total_objective = evaluate(temp_schedule + rollout_solution['schedule'])

            # 更新最优选择
            if total_objective < best_rollout_objective:
                best_rollout_objective = total_objective
                best_job = candidate_job

        # 执行最优选择
        schedule.append(best_job)
        remaining_jobs.remove(best_job)
        current_time += best_job.processing_time

    return schedule
```

**应用**：序贯决策问题、动态规划近似、在线优化。

## V4.0 代码生成提示

### 核心类结构

```python
from abc import ABC, abstractmethod
from typing import List, Dict, Any
from dataclasses import dataclass
from enum import Enum

@dataclass
class Job:
    """作业数据类"""
    id: str
    processing_time: float
    due_date: float = float('inf')
    weight: float = 1.0
    release_time: float = 0.0
    remaining_time: float = None

    def __post_init__(self):
        if self.remaining_time is None:
            self.remaining_time = self.processing_time

class GreedyRule(Enum):
    """贪心规则枚举"""
    SPT = "shortest_processing_time"
    LPT = "longest_processing_time"
    EDD = "earliest_due_date"
    MST = "minimum_slack_time"
    CR = "critical_ratio"
    WSPT = "weighted_spt"
    FIFO = "first_in_first_out"

class GreedyScheduler(ABC):
    """贪心调度器抽象基类"""

    def __init__(self, jobs: List[Job], config: Dict[str, Any]):
        self.jobs = jobs
        self.config = config
        self.num_machines = config.get('num_machines', 1)
        self.rule = config.get('rule', GreedyRule.SPT)

    @abstractmethod
    def schedule(self) -> Dict[str, Any]:
        """执行调度，返回调度方案"""
        pass

    @abstractmethod
    def get_priority(self, job: Job, current_time: float) -> float:
        """计算作业优先级（值越小优先级越高）"""
        pass

    def evaluate(self, schedule: List[Dict]) -> Dict[str, float]:
        """评估调度方案性能"""
        makespan = max(s['completion_time'] for s in schedule)
        total_completion = sum(s['completion_time'] for s in schedule)
        total_tardiness = sum(max(0, s['completion_time'] - s['job'].due_date)
                             for s in schedule)

        return {
            'makespan': makespan,
            'total_completion_time': total_completion,
            'total_tardiness': total_tardiness,
            'num_tardy_jobs': sum(1 for s in schedule
                                if s['completion_time'] > s['job'].due_date)
        }

class SPTScheduler(GreedyScheduler):
    """SPT规则调度器"""

    def get_priority(self, job: Job, current_time: float) -> float:
        return job.processing_time

    def schedule(self) -> Dict[str, Any]:
        sorted_jobs = sorted(self.jobs, key=lambda j: self.get_priority(j, 0))

        schedule = []
        current_time = 0

        for job in sorted_jobs:
            schedule.append({
                'job': job,
                'machine': 0,
                'start_time': current_time,
                'completion_time': current_time + job.processing_time
            })
            current_time += job.processing_time

        metrics = self.evaluate(schedule)

        return {
            'schedule': schedule,
            'metrics': metrics,
            'rule': 'SPT'
        }

class EDDScheduler(GreedyScheduler):
    """EDD规则调度器"""

    def get_priority(self, job: Job, current_time: float) -> float:
        return job.due_date

    def schedule(self) -> Dict[str, Any]:
        sorted_jobs = sorted(self.jobs, key=lambda j: self.get_priority(j, 0))

        schedule = []
        current_time = 0

        for job in sorted_jobs:
            completion = current_time + job.processing_time
            schedule.append({
                'job': job,
                'machine': 0,
                'start_time': current_time,
                'completion_time': completion,
                'tardiness': max(0, completion - job.due_date)
            })
            current_time = completion

        metrics = self.evaluate(schedule)

        return {
            'schedule': schedule,
            'metrics': metrics,
            'rule': 'EDD'
        }

class SchedulerFactory:
    """调度器工厂类"""

    @staticmethod
    def create(rule: GreedyRule, jobs: List[Job], config: Dict) -> GreedyScheduler:
        """根据规则创建对应调度器"""

        scheduler_map = {
            GreedyRule.SPT: SPTScheduler,
            GreedyRule.EDD: EDDScheduler,
            # ... 其他规则
        }

        scheduler_class = scheduler_map.get(rule)
        if not scheduler_class:
            raise ValueError(f"Unsupported rule: {rule}")

        return scheduler_class(jobs, config)

# 使用示例
if __name__ == "__main__":
    # 创建作业
    jobs = [
        Job('J1', processing_time=10, due_date=50, weight=2),
        Job('J2', processing_time=5, due_date=30, weight=1),
        Job('J3', processing_time=15, due_date=80, weight=3)
    ]

    # 配置
    config = {
        'rule': GreedyRule.SPT,
        'num_machines': 1
    }

    # 创建调度器并执行
    scheduler = SchedulerFactory.create(GreedyRule.SPT, jobs, config)
    result = scheduler.schedule()

    print(f"调度规则: {result['rule']}")
    print(f"Makespan: {result['metrics']['makespan']}")
    print(f"总延迟: {result['metrics']['total_tardiness']}")
```
