├─ 算法分类决策树
├─ exact/ (精确算法：分支定界、动态规划...)

✅ 此时拥有算法全景知识
Step 3: 读取TenElementModel（从Phase 1.5状态）
📄 phase_1_5_state.yaml
├─ 决策变量: 车辆路径 (100客户, 12车辆)
├─ 约束: 时间窗(2h) + 容量(150件) + 温度(2-8℃)
├─ 目标: 成本最小化(0.7) + 满意度(0.3)
└─ 问题规模: 中等，约束复杂度高

🔒 强依赖：必须存在，否则阻断流程
Step 4: 决策树推理 → 选择算法类别
输入特征:
• 问题规模: 中等 (100客户)
• 约束复杂度: 高 (时间窗 + 容量 + 温度)
• 时间敏感度: 高 (2小时硬约束)
• 优化目标: 多目标

决策树输出: meta-heuristic (元启发式算法)
候选算法: 遗传算法 | 禁忌搜索 | 模拟退火
Step 5: 动态加载具体算法模板 (~2.5K tokens)

├─ 算法原理

├─ 编码方案（路径表示）
├─ 遗传算子（交叉、变异）
├─ 参数配置建议
│ ├─ 种群大小: 100 (中等规模)
│ ├─ 交叉率: 0.8
│ ├─ 变异率: 0.05
│ └─ 最大代数: 500
├─ Python代码模板
└─ 引用: @专家库/算法库/meta-heuristic/遗传算法.md

✅ 传统方式: 50000+ tokens，节省84%
