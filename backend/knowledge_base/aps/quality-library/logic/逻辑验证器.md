# 逻辑验证器

## 目标

- 基于最小可运行桩件与测试用例，执行核心函数级逻辑验证与基础覆盖采样。

## 接口

```python
def verify_logic(code: str, model: dict, testcases: list | None) -> dict:
    """返回 {ok: bool, coverage: float, notes: [str]}"""
```

## 说明

- 最小实现阶段：
  - 通过 `exec` 在受限命名空间载入 `code`
  - 约定入口 `solve(model, case)`，不存在则给出说明
  - 对 `testcases` 逐个调用并记录异常/返回
