## 📖 敏捷原则

**核心价值观**:

- 个体和互动 > 流程和工具
- 工作的软件 > 详尽的文档
- 客户合作 > 合同谈判
- 响应变化 > 遵循计划

## 🔧 代码实现

```python
class AgileProjectAdapter:
    """敏捷项目适配器"""

    def calculate_velocity(self, completed_story_points: List[int]) -> float:
        """计算团队速率"""
        # 最近3个Sprint的平均故事点数
        recent_sprints = completed_story_points[-3:]
        velocity = sum(recent_sprints) / len(recent_sprints) if recent_sprints else 0
        return velocity

    def plan_sprint(self, backlog: List[Dict], velocity: float) -> List[Dict]:
        """Sprint规划"""
        sprint_items = []
        total_points = 0

        for item in backlog:
            story_points = item.get('story_points', 0)
            if total_points + story_points <= velocity:
                sprint_items.append(item)
                total_points += story_points
            else:
                break

        return sprint_items
```
