```python
def process_algorithm_selection_response(user_input: str, algorithm: dict) -> dict:

    if user_input == "1":
        # 确认推荐
        algorithm["selected"] = algorithm["recommended"]

        }

    elif user_input == "5":
        # 工作原理
        return {
            "action": "explain_mechanism",
            "content": generate_algorithm_explanation(algorithm)
        }

    elif user_input == "6":
        # 同类场景
        return {
            "action": "show_similar_cases",
            "content": query_similar_scenario_algorithms(algorithm)
        }

    elif user_input == "7":
        # 详细对比
        return {
            "action": "detailed_comparison",
            "content": generate_detailed_algorithm_comparison(algorithm)
        }

    elif user_input == "8":
        # 重新推荐
        return {
            "action": "regenerate",
            "prompt": "请告诉我您的新需求或偏好:"
        }

        # 其他问题
        return {
            "action": "open_question",

        algo_name = parse_algorithm_name(user_input)
```

```markdown
{专家分析参数配置的建议}

示例 (遗传算法):

**核心参数配置建议**:

1. **种群规模 (Population Size)**
   • 建议值: 100
   • 理由: 对于50客户规模,100个体足够保持种群多样性
   • 影响: 过小易早熟收敛,过大增加计算开销

2. **交叉概率 (Crossover Rate)**
   • 建议值: 0.8 (80%)
   • 理由: 标准GA推荐范围 0.6-0.9
   • 影响: 控制遗传信息交换的频率

3. **变异概率 (Mutation Rate)**
   • 建议值: 0.1 (10%)
   • 理由: 保持探索能力,避免过早收敛
   • 影响: 引入新的解空间探索

4. **选择策略 (Selection Method)**
   • 建议值: 锦标赛选择 (Tournament, size=3)
   • 理由: 平衡选择压力和多样性
   • 影响: 决定优秀个体的保留和传播

5. **精英保留 (Elitism)**
   • 建议值: 启用,保留前 5% 个体
   • 理由: 保证最优解不会丢失
   • 影响: 加速收敛,提高稳定性

• 高敏感: 种群规模 (直接影响求解质量)

• 低敏感: 选择策略细节
```

```markdown
算法需要明确的终止条件,常见有以下几种:

**终止条件配置建议**:

1. **最大迭代次数 (Max Generations)**
   • 建议值: 1000 代
   • 理由: 对于中等规模问题,1000代通常足够收敛
   • 预估时间: 约5-8分钟

2. **收敛阈值 (Convergence Threshold)**
   • 建议值: 连续50代最优解提升 < 0.1%
   • 理由: 表示算法已接近最优,继续迭代收益小
   • 优点: 避免无效计算,节省时间

3. **最大运行时间 (Max Time)**
   • 建议值: 600 秒 (10分钟)
   • 理由: 基于领域分析的时效要求
   • 优点: 保证在规定时间内返回结果

**推荐策略**: 采用 **组合终止条件**
• 满足以下任一条件即终止:

- 达到1000代 (质量保证)
- 或 连续50代无明显提升 (效率优化)
- 或 运行时间超过10分钟 (时间上限)

这种组合既保证解质量,又避免不必要的等待。
```

```markdown
   • 建议: 多次运行结果波动 < 5%
```

```python
from tools.interaction.incremental_confirmation import IncrementalConfirmationEngine

engine = IncrementalConfirmationEngine()

# 启动算法专家的增量确认
algorithm_items = generate_algorithm_detail_items(
    framework,
    full_model,
    domain_results,
    constraint_results,
    objective_results
)

for item in algorithm_items:
    # 呈现确认提示
    prompt = engine.generate_confirmation_prompt(
        expert="algorithm-expert",
        item=item,
        context={
            "domain_analysis": domain_results,
            "constraint_analysis": constraint_results,
            "objective_analysis": objective_results,
            "framework": framework
        }
    )

    # 等待用户响应
    user_response = input(prompt)

    # 处理响应
    result = engine.process_response(
        expert="algorithm-expert",
        item=item,
        response=user_response
    )

    # 更新模型
    if result["action"] == "next_question":
        continue
    elif result["action"] == "explain_mechanism":
        print(result["content"])
```
