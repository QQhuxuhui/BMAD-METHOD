## 📖 约束概述

### 定义

**成本约束**（Cost Constraint）规定业务活动的成本上限和成本效益要求，确保在预算范围内实现最优资源配置。

**数学定义**：

```
对于方案 s 和成本函数 C(s)

成本约束:
  C(s) ≤ B  (B为预算上限)

多目标优化:
  min C(s)
  s.t. quality(s) ≥ Q_min
       time(s) ≤ T_max

成本效益:
  ROI = (收益 - 成本) / 成本 × 100%
```

### 成本类型

#### 1. **固定成本** (Fixed Cost)

```
不随业务量变化的成本

例如:
  - 设备折旧
  - 租金
  - 固定工资
  - 软件许可证

CF = constant
```

#### 2. **可变成本** (Variable Cost)

```
随业务量变化的成本

例如:
  - 原材料
  - 计件工资
  - 运输费用
  - 云计算资源

CV(x) = c × x
其中 x 为业务量，c 为单位成本
```

#### 3. **总成本** (Total Cost)

```
固定成本 + 可变成本

TC(x) = CF + CV(x) = CF + c × x

平均成本:
  AC(x) = TC(x) / x = CF/x + c
```

#### 4. **机会成本** (Opportunity Cost)

```
选择某方案放弃的最大收益

例如:
  选择方案A（收益100）
  放弃方案B（收益80）
  机会成本 = 80
```

## 💡 核心理论

### 成本-收益分析 (Cost-Benefit Analysis)

```python
def cost_benefit_analysis(costs, benefits, discount_rate=0.05, years=5):
    """
    成本收益分析

    参数:
      costs: [year1_cost, year2_cost, ...]
      benefits: [year1_benefit, year2_benefit, ...]
      discount_rate: 贴现率
      years: 分析年限

    返回:
      npv: 净现值 (Net Present Value)
      roi: 投资回报率
      payback_period: 回收期
    """
    npv = 0
    cumulative_cash_flow = 0
    payback_period = None

    for year in range(years):
        cost = costs[year] if year < len(costs) else 0
        benefit = benefits[year] if year < len(benefits) else 0

        # 现金流
        cash_flow = benefit - cost

        # 贴现后的现值
        present_value = cash_flow / ((1 + discount_rate) ** (year + 1))
        npv += present_value

        # 计算回收期
        cumulative_cash_flow += cash_flow
        if payback_period is None and cumulative_cash_flow >= 0:
            payback_period = year + 1

    # 投资回报率
    total_investment = sum(costs)
    total_return = sum(benefits)
    roi = ((total_return - total_investment) / total_investment * 100
           if total_investment > 0 else 0)

    return {
        'npv': round(npv, 2),
        'roi': round(roi, 2),
        'payback_period': payback_period or years,
        'total_cost': sum(costs),
        'total_benefit': sum(benefits)
    }
```

### 盈亏平衡分析 (Break-Even Analysis)

```python
def break_even_analysis(fixed_cost, variable_cost_per_unit, price_per_unit):
    """
    盈亏平衡点分析

    BEP = FC / (P - VC)

    参数:
      fixed_cost: 固定成本
      variable_cost_per_unit: 单位可变成本
      price_per_unit: 单价

    返回:
      break_even_quantity: 盈亏平衡点（数量）
      break_even_revenue: 盈亏平衡点（收入）
    """
    if price_per_unit <= variable_cost_per_unit:
        return None, None  # 无法盈利

    break_even_quantity = fixed_cost / (price_per_unit - variable_cost_per_unit)
    break_even_revenue = break_even_quantity * price_per_unit

    return {
        'break_even_quantity': round(break_even_quantity, 2),
        'break_even_revenue': round(break_even_revenue, 2),
        'contribution_margin': price_per_unit - variable_cost_per_unit,
        'contribution_margin_ratio': (price_per_unit - variable_cost_per_unit) / price_per_unit * 100
    }
```

### 总拥有成本 (Total Cost of Ownership, TCO)

```python
def calculate_tco(acquisition_cost, annual_operating_cost,
                 annual_maintenance_cost, lifespan_years,
                 disposal_cost=0, discount_rate=0.05):
    """
    计算总拥有成本

    TCO = 采购成本 + ∑(年运营成本现值) + 处置成本现值

    参数:
      acquisition_cost: 采购成本
      annual_operating_cost: 年运营成本
      annual_maintenance_cost: 年维护成本
      lifespan_years: 使用年限
      disposal_cost: 处置成本
      discount_rate: 贴现率

    返回:
      tco: 总拥有成本
    """
    tco = acquisition_cost

    # 每年运营和维护成本的现值
    for year in range(1, lifespan_years + 1):
        annual_cost = annual_operating_cost + annual_maintenance_cost
        present_value = annual_cost / ((1 + discount_rate) ** year)
        tco += present_value

    # 处置成本现值
    disposal_pv = disposal_cost / ((1 + discount_rate) ** lifespan_years)
    tco += disposal_pv

    return {
        'tco': round(tco, 2),
        'annual_tco': round(tco / lifespan_years, 2),
        'acquisition_cost': acquisition_cost,
        'lifecycle_operating_cost': round(tco - acquisition_cost - disposal_pv, 2)
    }
```

## 🔧 代码实现

```python
from typing import Dict, List, Tuple, Optional
from dataclasses import dataclass, field
from enum import Enum

class CostCategory(Enum):
    """成本类别"""
    FIXED = "fixed"           # 固定成本
    VARIABLE = "variable"     # 可变成本
    CAPITAL = "capital"       # 资本支出
    OPERATING = "operating"   # 运营成本

@dataclass
class CostItem:
    """成本项"""
    id: str
    category: CostCategory
    amount: float
    description: str = ""
    quantity: float = 1.0
    unit_cost: float = 0.0

    def __post_init__(self):
        if self.unit_cost == 0.0 and self.quantity > 0:
            self.unit_cost = self.amount / self.quantity

@dataclass
class Budget:
    """预算"""
    total: float
    by_category: Dict[CostCategory, float] = field(default_factory=dict)

class CostConstraintHandler:
    """成本约束处理器"""

    def __init__(self, budget: Budget):
        """
        参数:
          budget: 预算限制
        """
        self.budget = budget

    def validate(self, cost_items: List[CostItem]) -> Tuple[bool, List[Dict]]:
        """
        验证成本是否在预算内

        参数:
          cost_items: 成本项列表

        返回:
          (within_budget, violations)
        """
        violations = []

        # 计算总成本
        total_cost = sum(item.amount for item in cost_items)

        # 检查总预算
        if total_cost > self.budget.total:
            overrun = total_cost - self.budget.total
            overrun_percent = (overrun / self.budget.total) * 100

            violations.append({
                'type': 'total_budget_overrun',
                'total_cost': round(total_cost, 2),
                'budget': self.budget.total,
                'overrun': round(overrun, 2),
                'overrun_percent': round(overrun_percent, 2),
                'penalty': overrun_percent * 10
            })

        # 检查分类预算
        cost_by_category = {}
        for item in cost_items:
            if item.category not in cost_by_category:
                cost_by_category[item.category] = 0
            cost_by_category[item.category] += item.amount

        for category, cost in cost_by_category.items():
            category_budget = self.budget.by_category.get(category)

            if category_budget and cost > category_budget:
                overrun = cost - category_budget
                overrun_percent = (overrun / category_budget) * 100

                violations.append({
                    'type': 'category_budget_overrun',
                    'category': category.value,
                    'cost': round(cost, 2),
                    'budget': category_budget,
                    'overrun': round(overrun, 2),
                    'overrun_percent': round(overrun_percent, 2),
                    'penalty': overrun_percent * 5
                })

        return len(violations) == 0, violations

    def optimize_allocation(self, cost_items: List[CostItem],
                           priorities: Dict[str, int]) -> List[CostItem]:
        """
        在预算约束下优化成本分配

        参数:
          cost_items: 成本项列表
          priorities: {item_id: priority} 优先级（数值越大越重要）

        返回:
          optimized_items: 优化后的成本项
        """
        # 按优先级排序
        sorted_items = sorted(
            cost_items,
            key=lambda item: priorities.get(item.id, 0),
            reverse=True
        )

        # 贪心分配
        allocated = []
        remaining_budget = self.budget.total

        for item in sorted_items:
            if item.amount <= remaining_budget:
                allocated.append(item)
                remaining_budget -= item.amount

        return allocated

    def calculate_roi(self, investment: float, returns: List[float],
                     years: int = 5, discount_rate: float = 0.05) -> Dict:
        """
        计算投资回报率

        参数:
          investment: 初始投资
          returns: 每年回报 [year1, year2, ...]
          years: 年限
          discount_rate: 贴现率

        返回:
          roi_metrics: ROI相关指标
        """
        npv = -investment  # 初始投资为负现金流
        cumulative_cash_flow = -investment
        payback_period = None

        for year in range(years):
            annual_return = returns[year] if year < len(returns) else 0

            # 现值
            present_value = annual_return / ((1 + discount_rate) ** (year + 1))
            npv += present_value

            # 回收期
            cumulative_cash_flow += annual_return
            if payback_period is None and cumulative_cash_flow >= 0:
                payback_period = year + 1

        total_return = sum(returns[:years])
        simple_roi = ((total_return - investment) / investment * 100
                     if investment > 0 else 0)

        return {
            'npv': round(npv, 2),
            'simple_roi': round(simple_roi, 2),
            'payback_period': payback_period or years,
            'total_investment': investment,
            'total_return': round(total_return, 2),
            'irr_positive': npv > 0
        }

    def calculate_break_even(self, fixed_cost: float,
                            variable_cost_per_unit: float,
                            price_per_unit: float) -> Dict:
        """
        计算盈亏平衡点

        返回:
          break_even_analysis: 盈亏平衡分析结果
        """
        if price_per_unit <= variable_cost_per_unit:
            return {
                'viable': False,
                'reason': '价格低于可变成本，无法盈利'
            }

        contribution_margin = price_per_unit - variable_cost_per_unit
        break_even_quantity = fixed_cost / contribution_margin
        break_even_revenue = break_even_quantity * price_per_unit

        return {
            'viable': True,
            'break_even_quantity': round(break_even_quantity, 2),
            'break_even_revenue': round(break_even_revenue, 2),
            'contribution_margin': round(contribution_margin, 2),
            'contribution_margin_ratio': round(contribution_margin / price_per_unit * 100, 2)
        }

    def calculate_tco(self, acquisition_cost: float,
                     annual_operating_cost: float,
                     lifespan_years: int,
                     disposal_cost: float = 0,
                     discount_rate: float = 0.05) -> Dict:
        """
        计算总拥有成本 (TCO)

        返回:
          tco_analysis: TCO分析结果
        """
        tco = acquisition_cost

        # 运营成本现值
        operating_cost_pv = 0
        for year in range(1, lifespan_years + 1):
            pv = annual_operating_cost / ((1 + discount_rate) ** year)
            operating_cost_pv += pv

        tco += operating_cost_pv

        # 处置成本现值
        disposal_pv = disposal_cost / ((1 + discount_rate) ** lifespan_years)
        tco += disposal_pv

        return {
            'tco': round(tco, 2),
            'annual_tco': round(tco / lifespan_years, 2),
            'acquisition_cost': acquisition_cost,
            'operating_cost_pv': round(operating_cost_pv, 2),
            'disposal_cost_pv': round(disposal_pv, 2)
        }

    def compare_alternatives(self, alternatives: List[Dict]) -> Dict:
        """
        比较多个方案的成本效益

        参数:
          alternatives: [{name, cost, benefit, quality_score}, ...]

        返回:
          comparison: 比较结果
        """
        results = []

        for alt in alternatives:
            name = alt['name']
            cost = alt['cost']
            benefit = alt.get('benefit', 0)
            quality = alt.get('quality_score', 0)

            roi = ((benefit - cost) / cost * 100) if cost > 0 else 0
            cost_effectiveness = benefit / cost if cost > 0 else 0
            quality_per_cost = quality / cost if cost > 0 else 0

            results.append({
                'name': name,
                'cost': cost,
                'benefit': benefit,
                'quality_score': quality,
                'roi': round(roi, 2),
                'cost_effectiveness': round(cost_effectiveness, 4),
                'quality_per_cost': round(quality_per_cost, 4)
            })

        # 按成本效益排序
        results.sort(key=lambda x: x['cost_effectiveness'], reverse=True)

        return {
            'alternatives': results,
            'best_roi': max(results, key=lambda x: x['roi']),
            'best_cost_effectiveness': results[0],
            'lowest_cost': min(results, key=lambda x: x['cost'])
        }

```

## 📊 应用场景

### 场景1: 项目预算管理

```python
# 定义预算
budget = Budget(
    total=100000,
    by_category={
        CostCategory.CAPITAL: 40000,
        CostCategory.OPERATING: 60000
    }
)

handler = CostConstraintHandler(budget)

# 项目成本项
cost_items = [
    CostItem(id='server', category=CostCategory.CAPITAL, amount=30000, description='服务器'),
    CostItem(id='software', category=CostCategory.CAPITAL, amount=15000, description='软件许可'),
    CostItem(id='salary', category=CostCategory.OPERATING, amount=50000, description='人员工资'),
    CostItem(id='cloud', category=CostCategory.OPERATING, amount=12000, description='云服务'),
]

# 验证预算
within_budget, violations = handler.validate(cost_items)

if not within_budget:
    print(f"预算超支 {len(violations)} 项")
    for v in violations:
        print(f"  {v['type']}: 超支 {v['overrun']} ({v['overrun_percent']:.1f}%)")

# 计算总成本
total_cost = sum(item.amount for item in cost_items)
print(f"总成本: {total_cost} / {budget.total}")
```

### 场景2: 投资回报分析

```python
# 软件开发项目ROI
investment = 200000  # 初始投资20万
annual_returns = [50000, 80000, 100000, 120000, 150000]  # 5年收益

roi_analysis = handler.calculate_roi(
    investment=investment,
    returns=annual_returns,
    years=5,
    discount_rate=0.08

print(f"NPV: {roi_analysis['npv']}")

print(f"回收期: {roi_analysis['payback_period']} 年")
```

### 场景3: 盈亏平衡分析

```python
# 产品盈亏平衡点
fixed_cost = 50000  # 固定成本5万
variable_cost_per_unit = 20  # 单位可变成本20元
price_per_unit = 50  # 售价50元

break_even = handler.calculate_break_even(
    fixed_cost=fixed_cost,
    variable_cost_per_unit=variable_cost_per_unit,
    price_per_unit=price_per_unit

if break_even['viable']:
    print(f"盈亏平衡点: {break_even['break_even_quantity']} 件")
    print(f"盈亏平衡收入: {break_even['break_even_revenue']} 元")
    print(f"边际贡献率: {break_even['contribution_margin_ratio']}%")
```

## 🎯 性能优化

### 成本缓存和增量计算

```python
class OptimizedCostHandler(CostConstraintHandler):
    """优化版成本处理器"""

    def __init__(self, budget):
        super().__init__(budget)
        self.cost_cache = {}
        self.total_cost = 0

    def add_cost_item(self, item: CostItem):
        """增量添加成本项"""
        self.cost_cache[item.id] = item
        self.total_cost += item.amount

    def remove_cost_item(self, item_id: str):
        """移除成本项"""
        if item_id in self.cost_cache:
            self.total_cost -= self.cost_cache[item_id].amount
            del self.cost_cache[item_id]

    def get_total_cost(self) -> float:
        """O(1)获取总成本"""
        return self.total_cost
```
