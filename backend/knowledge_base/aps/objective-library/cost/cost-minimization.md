## 💰 目标知识本体

### 成本构成体系

```yaml
直接成本:
  运输成本:
    - 燃料成本: 距离 × 燃料单价 × 油耗率
    - 人工成本: 工作时间 × 司机工资
    - 车辆折旧: 使用时间 × 折旧率
    - 维护成本: 里程 × 维护单价

  生产成本:
    - 原料成本: 用料数量 × 原料单价
    - 加工成本: 加工时间 × 设备成本率
    - 能源成本: 能耗 × 能源单价
    - 人力成本: 工时 × 工人工资

  服务成本:
    - 人员成本: 服务时间 × 人员单价
    - 设备成本: 设备使用费
    - 场地成本: 场地租用费
    - 耗材成本: 耗材使用量 × 单价

间接成本:
  时间成本:
    - 等待成本: 等待时间 × 时间价值
    - 延迟成本: 延迟时间 × 延迟惩罚
    - 库存成本: 库存量 × 持有成本率

  质量成本:
    - 返工成本: 不合格率 × 返工单价
    - 投诉处理成本: 投诉次数 × 处理成本
    - 信誉损失: 质量问题 × 信誉价值

  风险成本:
    - 保险成本: 保险费用
    - 安全成本: 安全措施投入
    - 不确定性成本: 概率 × 损失金额
```

### 成本函数建模

```yaml
线性成本函数:
  总成本 = Σ(c_i × x_i)
  适用: 单一成本驱动因子
  特点: 计算简单，优化容易

分段线性成本:
  c(x) = c1 (0 ≤ x ≤ x1)
         c2 (x1 < x ≤ x2)
         c3 (x > x2)
  适用: 规模经济效应
  特点: 体现成本结构变化

二次成本函数:
  总成本 = a × x² + b × x + c
  适用: 拥堵效应、资源竞争
  特点: 边际成本递增

固定成本 + 变动成本:
  总成本 = 固定成本 + Σ(变动成本率 × 使用量)
  适用: 资源投入决策
  特点: 体现规模经济

概率成本函数:
  期望成本 = Σ(P_i × Cost_i)
  适用: 不确定环境
  特点: 考虑风险因素
```

## 📊 成本分析方法

### 成本-效益分析

```yaml
成本效益比:
  CBR = Total_Benefit / Total_Cost
  CBR > 1: 项目可行
  CBR < 1: 项目不可行

净现值分析:
  NPV = Σ(Cash_Flow_t / (1+r)^t) - Initial_Investment
  NPV > 0: 项目有价值
  NPV < 0: 项目无经济价值

投资回收期:
  Payback_Period = Initial_Investment / Annual_Cash_Flow
  越短越好，通常要求 < 3-5年

内部收益率:
  IRR: 使NPV=0的折现率
  IRR > 资本成本: 项目可接受
  IRR < 资本成本: 项目应拒绝
```

### 敏感性分析

```yaml
单因素敏感性: 固定其他变量，改变单一成本因素
  分析成本变化对总成本的影响
  识别最敏感的成本驱动因子

多因素敏感性: 同时变化多个成本因素
  分析因素交互作用
  构建成本变化的情景分析

蒙特卡洛模拟: 对不确定性因素建立概率分布
  随机抽样进行多次模拟
  得到成本分布和风险评估

盈亏平衡分析: 固定成本 = 变动成本
  计算盈亏平衡点
  分析经营安全边际
```
