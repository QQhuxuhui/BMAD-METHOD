## 核心原理

### 理论基础

差分进化算法（Differential Evolution, DE）由Rainer Storn和Kenneth Price于1995年提出，是一种基于种群的随机搜索算法。算法通过种群内个体间的差分向量产生变异，结合简单的贪婪选择策略，实现对连续优化问题的高效求解。

**算法起源**：

- 1995年Storn和Price在论文"Differential Evolution - A Simple and Efficient Heuristic for Global Optimization over Continuous Spaces"中首次提出
- 最初用于Chebyshev多项式拟合问题
- 后迅速推广到工程优化、神经网络训练、经济预测等领域

**核心思想**：

- **向量差分变异**：利用种群中随机个体的差分向量进行变异，保持搜索方向的多样性
- **贪婪选择**：新个体仅在优于当前个体时才被接受，确保种群质量不退化
- **实数编码**：直接操作实数向量，无需编码解码过程
- **自组织搜索**：通过种群演化自动调整搜索步长和方向

**关键概念**：

- **个体（Individual）**：D维实数向量 X_i = (x_i1, x_i2, ..., x_iD)
- **种群（Population）**：NP个个体的集合，NP通常为5D-10D
- **目标向量（Target Vector）**：当前代的个体 X_i(t)
- **变异向量（Mutant Vector）**：通过差分变异生成的新向量 V_i(t+1)
- **试验向量（Trial Vector）**：交叉后的候选个体 U_i(t+1)
- **缩放因子（Scaling Factor F）**：控制差分向量的缩放程度，通常F ∈ [0, 2]
- **交叉概率（Crossover Rate CR）**：控制参数继承的概率，CR ∈ [0, 1]

**与其他算法对比**：

| 算法           | 编码方式 | 核心操作      | 适用问题      | 参数数量 | 优势             | 劣势             |
| -------------- | -------- | ------------- | ------------- | -------- | ---------------- | ---------------- |
| **差分进化**   | 实数编码 | 差分变异+交叉 | 连续优化      | 3个      | 简单高效、参数少 | 离散问题需改造   |
| **遗传算法**   | 多种编码 | 交叉+变异     | 连续/组合优化 | 4-6个    | 通用性强         | 参数多、收敛慢   |
| **粒子群算法** | 实数编码 | 速度+位置更新 | 连续优化      | 3-4个    | 实现简单         | 易早熟收敛       |
| **模拟退火**   | 多种编码 | 邻域搜索      | 连续/组合优化 | 3-4个    | 理论完备         | 收敛慢、参数敏感 |

**理论优势**：

1. **参数少**：仅需F、CR、NP三个核心参数，易于调优
2. **鲁棒性强**：对参数变化不敏感，默认参数在多数问题上表现良好
3. **全局搜索能力**：差分变异机制提供强大的全局探索能力
4. **无需梯度信息**：黑盒优化，适用于不可微、多模态函数

### 核心机制

**算法工作流程**：

```
阶段1: 初始化
├─ 设置参数：NP（种群大小）, F（缩放因子）, CR（交叉概率）, max_gen（最大代数）
├─ 初始化种群：在搜索空间内随机生成NP个D维个体
└─ 评估初始种群适应度

阶段2: 变异（Mutation）
对每个目标向量 X_i，根据变异策略生成变异向量 V_i
├─ DE/rand/1: V_i = X_r1 + F·(X_r2 - X_r3)
├─ DE/best/1: V_i = X_best + F·(X_r1 - X_r2)
├─ DE/current-to-best/1: V_i = X_i + F·(X_best - X_i) + F·(X_r1 - X_r2)
└─ DE/rand/2: V_i = X_r1 + F·(X_r2 - X_r3) + F·(X_r4 - X_r5)
其中 r1, r2, r3, r4, r5 是互不相同且不等于i的随机索引

阶段3: 交叉（Crossover）
生成试验向量 U_i，混合目标向量和变异向量的参数
├─ 二项交叉（Binomial）：
│  └─ U_ij = V_ij if rand_j < CR or j == j_rand else X_ij
│     j_rand 确保至少继承一个变异参数
├─ 指数交叉（Exponential）：
│  └─ 从随机位置开始，连续继承变异参数直到 rand() >= CR
└─ 二项交叉更常用，指数交叉适合参数相关性强的问题

阶段4: 选择（Selection）
贪婪选择策略，保留更优个体
├─ if f(U_i) ≤ f(X_i):  # 最小化问题
│  └─ X_i(t+1) = U_i
├─ else:
│  └─ X_i(t+1) = X_i(t)
└─ 选择是确定性的，不引入随机性

阶段5: 终止判断
├─ 达到最大代数？
├─ 函数评估次数超限？
├─ 目标函数值达到阈值？
└─ 是 → 输出最优解，否 → 返回阶段2
```

**核心数学公式**：

1. **变异操作**（以DE/rand/1为例）：

   ```
   V_i(t+1) = X_r1(t) + F · (X_r2(t) - X_r3(t))
   ```

   其中：
   - r1, r2, r3 ∈ {1, 2, ..., NP}, 且 r1 ≠ r2 ≠ r3 ≠ i
   - F ∈ [0, 2]，通常取0.5-0.8
   - (X_r2 - X_r3) 是差分向量，提供搜索方向和步长

2. **二项交叉操作**：

   ```
   U_ij(t+1) = { V_ij(t+1),  if rand_j(0,1) ≤ CR or j = j_rand
               { X_ij(t),    otherwise
   ```

   其中：
   - j = 1, 2, ..., D（维度索引）
   - j_rand ∈ {1, 2, ..., D} 随机选择，确保至少一个参数被继承
   - CR ∈ [0, 1]，通常取0.7-0.9

3. **选择操作**：
   ```
   X_i(t+1) = { U_i(t+1),  if f(U_i(t+1)) ≤ f(X_i(t))
              { X_i(t),    otherwise
   ```
   对于最大化问题，不等号方向相反

**五大经典变异策略**：

1. **DE/rand/1** （最常用）：

   ```
   V_i = X_r1 + F·(X_r2 - X_r3)
   ```

   - 基于随机个体，探索能力强
   - 适合多峰函数、未知地形

2. **DE/best/1** （快速收敛）：

   ```
   V_i = X_best + F·(X_r1 - X_r2)
   ```

   - 基于当前最优个体，收敛快
   - 易早熟，适合单峰函数

3. **DE/current-to-best/1** （平衡型）：

   ```
   V_i = X_i + F·(X_best - X_i) + F·(X_r1 - X_r2)
   ```

   - 当前个体向最优个体靠拢，同时保持差分扰动
   - 平衡探索与开发

4. **DE/best/2** （增强版）：

   ```
   V_i = X_best + F·(X_r1 - X_r2) + F·(X_r3 - X_r4)
   ```

   - 两个差分向量增强扰动
   - 避免过快收敛到局部最优

5. **DE/rand/2** （强探索）：
   ```
   V_i = X_r1 + F·(X_r2 - X_r3) + F·(X_r4 - X_r5)
   ```

   - 双差分向量，探索能力极强
   - 适合高维、复杂问题

**边界处理策略**：

当变异或交叉产生越界个体时，需进行边界处理：

1. **边界截断（Clipping）**：

   ```python
   V_ij = min(max(V_ij, lower_j), upper_j)
   ```

   - 简单有效，但可能产生边界聚集

2. **随机重置（Random Reset）**：

   ```python
   if V_ij < lower_j or V_ij > upper_j:
       V_ij = lower_j + rand() * (upper_j - lower_j)
   ```

   - 保持种群多样性

3. **反弹（Bounce-back）**：

   ```python
   if V_ij < lower_j:
       V_ij = lower_j + rand() * (lower_j - V_ij)
   if V_ij > upper_j:
       V_ij = upper_j - rand() * (V_ij - upper_j)
   ```

   - 利用越界信息，避免完全随机

4. **镜像反射（Mirroring）**：
   ```python
   while V_ij < lower_j or V_ij > upper_j:
       if V_ij < lower_j:
           V_ij = 2*lower_j - V_ij
       if V_ij > upper_j:
           V_ij = 2*upper_j - V_ij
   ```

   - 保持搜索方向连续性

## 实现框架

### 算法伪代码

```python
import numpy as np
from typing import List, Tuple, Dict, Callable, Optional
import random


class DifferentialEvolution:
    """
    差分进化算法实现类

    支持多种变异策略、自适应参数调整、约束处理
    适用于连续优化、混合整数优化、参数调优等问题
    """

    def __init__(self,
                 objective_func: Callable,
                 bounds: List[Tuple[float, float]],
                 strategy: str = 'rand/1',
                 NP: int = None,
                 F: float = 0.5,
                 CR: float = 0.7,
                 max_gen: int = 1000,
                 crossover_type: str = 'binomial',
                 constraint_handler: Optional[Callable] = None,
                 seed: int = None):
        """
        初始化差分进化算法

        参数:
            objective_func: 目标函数 f(x) -> float
            bounds: 决策变量边界 [(x1_min, x1_max), (x2_min, x2_max), ...]
            strategy: 变异策略 ('rand/1', 'best/1', 'current-to-best/1', 'rand/2', 'best/2')
            NP: 种群大小（默认为10*D）
            F: 缩放因子（0-2，推荐0.5-0.8）
            CR: 交叉概率（0-1，推荐0.7-0.9）
            max_gen: 最大代数
            crossover_type: 交叉类型 ('binomial', 'exponential')
            constraint_handler: 约束处理函数 g(x) -> x_feasible
            seed: 随机种子
        """
        self.objective_func = objective_func
        self.bounds = np.array(bounds)
        self.D = len(bounds)  # 维度
        self.strategy = strategy
        self.NP = NP if NP else max(20, 10 * self.D)  # 种群大小
        self.F = F
        self.CR = CR
        self.max_gen = max_gen
        self.crossover_type = crossover_type
        self.constraint_handler = constraint_handler

        if seed is not None:
            np.random.seed(seed)
            random.seed(seed)

        # 边界
        self.lower = self.bounds[:, 0]
        self.upper = self.bounds[:, 1]

        # 初始化种群
        self.population = self._initialize_population()
        self.fitness = np.array([self.objective_func(ind) for ind in self.population])

        # 最优解记录
        self.best_idx = np.argmin(self.fitness)
        self.best_solution = self.population[self.best_idx].copy()
        self.best_fitness = self.fitness[self.best_idx]

        # 历史记录
        self.convergence_history = []
        self.diversity_history = []


    def _initialize_population(self) -> np.ndarray:
        """初始化种群 - 在搜索空间内随机生成"""
        population = np.random.rand(self.NP, self.D)
        population = self.lower + population * (self.upper - self.lower)
        return population


    def _mutate(self, i: int) -> np.ndarray:
        """
        变异操作 - 根据策略生成变异向量

        参数:
            i: 当前个体索引

        返回:
            mutant: 变异向量
        """
        # 随机选择互不相同的索引
        candidates = [idx for idx in range(self.NP) if idx != i]

        if self.strategy == 'rand/1':
            # DE/rand/1: V = X_r1 + F*(X_r2 - X_r3)
            r1, r2, r3 = random.sample(candidates, 3)
            mutant = self.population[r1] + self.F * (self.population[r2] - self.population[r3])

        elif self.strategy == 'best/1':
            # DE/best/1: V = X_best + F*(X_r1 - X_r2)
            r1, r2 = random.sample(candidates, 2)
            mutant = self.best_solution + self.F * (self.population[r1] - self.population[r2])

        elif self.strategy == 'current-to-best/1':
            # DE/current-to-best/1: V = X_i + F*(X_best - X_i) + F*(X_r1 - X_r2)
            r1, r2 = random.sample(candidates, 2)
            mutant = (self.population[i] +
                     self.F * (self.best_solution - self.population[i]) +
                     self.F * (self.population[r1] - self.population[r2]))

        elif self.strategy == 'rand/2':
            # DE/rand/2: V = X_r1 + F*(X_r2 - X_r3) + F*(X_r4 - X_r5)
            r1, r2, r3, r4, r5 = random.sample(candidates, 5)
            mutant = (self.population[r1] +
                     self.F * (self.population[r2] - self.population[r3]) +
                     self.F * (self.population[r4] - self.population[r5]))

        elif self.strategy == 'best/2':
            # DE/best/2: V = X_best + F*(X_r1 - X_r2) + F*(X_r3 - X_r4)
            r1, r2, r3, r4 = random.sample(candidates, 4)
            mutant = (self.best_solution +
                     self.F * (self.population[r1] - self.population[r2]) +
                     self.F * (self.population[r3] - self.population[r4]))

        else:
            raise ValueError(f"Unknown strategy: {self.strategy}")

        return mutant


    def _crossover(self, target: np.ndarray, mutant: np.ndarray) -> np.ndarray:
        """
        交叉操作 - 生成试验向量

        参数:
            target: 目标向量 X_i
            mutant: 变异向量 V_i

        返回:
            trial: 试验向量 U_i
        """
        if self.crossover_type == 'binomial':
            # 二项交叉
            trial = target.copy()
            j_rand = random.randint(0, self.D - 1)  # 确保至少一个参数被继承

            for j in range(self.D):
                if random.random() < self.CR or j == j_rand:
                    trial[j] = mutant[j]

        elif self.crossover_type == 'exponential':
            # 指数交叉
            trial = target.copy()
            j = random.randint(0, self.D - 1)  # 起始位置
            L = 0  # 连续继承长度

            while True:
                trial[j] = mutant[j]
                j = (j + 1) % self.D
                L += 1
                if random.random() >= self.CR or L == self.D:
                    break

        else:
            raise ValueError(f"Unknown crossover type: {self.crossover_type}")

        return trial


    def _bound_repair(self, individual: np.ndarray, method: str = 'random') -> np.ndarray:
        """
        边界修复 - 处理越界个体

        参数:
            individual: 待修复个体
            method: 修复方法 ('clip', 'random', 'bounce', 'mirror')

        返回:
            repaired: 修复后的个体
        """
        repaired = individual.copy()

        for j in range(self.D):
            if repaired[j] < self.lower[j] or repaired[j] > self.upper[j]:
                if method == 'clip':
                    # 边界截断
                    repaired[j] = np.clip(repaired[j], self.lower[j], self.upper[j])

                elif method == 'random':
                    # 随机重置
                    repaired[j] = self.lower[j] + random.random() * (self.upper[j] - self.lower[j])

                elif method == 'bounce':
                    # 反弹
                    if repaired[j] < self.lower[j]:
                        repaired[j] = self.lower[j] + random.random() * abs(self.lower[j] - repaired[j])
                    else:
                        repaired[j] = self.upper[j] - random.random() * abs(repaired[j] - self.upper[j])

                elif method == 'mirror':
                    # 镜像反射
                    while repaired[j] < self.lower[j] or repaired[j] > self.upper[j]:
                        if repaired[j] < self.lower[j]:
                            repaired[j] = 2 * self.lower[j] - repaired[j]
                        if repaired[j] > self.upper[j]:
                            repaired[j] = 2 * self.upper[j] - repaired[j]

        return repaired


    def run(self, verbose: bool = True) -> Tuple[np.ndarray, float, Dict]:
        """
        执行差分进化算法

        参数:
            verbose: 是否输出进度信息

        返回:
            best_solution: 最优解
            best_fitness: 最优目标函数值
            info: 算法执行信息字典
        """
        for generation in range(self.max_gen):
            for i in range(self.NP):
                # 变异
                mutant = self._mutate(i)

                # 交叉
                trial = self._crossover(self.population[i], mutant)

                # 边界修复
                trial = self._bound_repair(trial, method='random')

                # 约束处理（如果提供）
                if self.constraint_handler:
                    trial = self.constraint_handler(trial)

                # 评估试验向量
                trial_fitness = self.objective_func(trial)

                # 贪婪选择
                if trial_fitness <= self.fitness[i]:
                    self.population[i] = trial
                    self.fitness[i] = trial_fitness

                    # 更新全局最优
                    if trial_fitness < self.best_fitness:
                        self.best_solution = trial.copy()
                        self.best_fitness = trial_fitness

            # 记录收敛历史
            self.convergence_history.append(self.best_fitness)
            self.diversity_history.append(self._calculate_diversity())

            # 输出进度
            if verbose and generation % 50 == 0:
                print(f"Generation {generation}: Best = {self.best_fitness:.6e}, "
                      f"Diversity = {self.diversity_history[-1]:.4f}")

            # 早停判断（可选）
            if self._check_convergence():
                if verbose:
                    print(f"Converged at generation {generation}")
                break

        # 整理输出信息
        info = {
            'convergence_history': self.convergence_history,
            'diversity_history': self.diversity_history,
            'final_population': self.population,
            'final_fitness': self.fitness,
            'generations': len(self.convergence_history)
        }

        return self.best_solution, self.best_fitness, info


    def _calculate_diversity(self) -> float:
        """计算种群多样性（标准差平均值）"""
        return np.mean(np.std(self.population, axis=0))


    def _check_convergence(self, patience: int = 100, tolerance: float = 1e-6) -> bool:
        """检查是否收敛"""
        if len(self.convergence_history) < patience:
            return False

        recent = self.convergence_history[-patience:]
        improvement = abs(max(recent) - min(recent))

        return improvement < tolerance


# ============= 辅助函数 =============

def create_constraint_handler(constraints: List[Callable]) -> Callable:
    """
    创建约束处理器（罚函数法）

    参数:
        constraints: 约束函数列表 [g1(x), g2(x), ...], gi(x) <= 0 为满足约束

    返回:
        penalized_objective: 带惩罚的目标函数
    """
    def penalized_objective(objective_func: Callable, penalty_factor: float = 1e6):
        def wrapper(x):
            obj_value = objective_func(x)
            penalty = 0
            for constraint in constraints:
                violation = max(0, constraint(x))  # 违反程度
                penalty += violation
            return obj_value + penalty_factor * penalty
        return wrapper

    return penalized_objective
```

### 参数配置指南

| 参数名称             | 推荐范围             | 默认值   | 影响说明                                                 |
| -------------------- | -------------------- | -------- | -------------------------------------------------------- |
| NP（种群大小）       | 5D - 10D             | 10D      | D为维度。过小易早熟，过大增加计算成本                    |
| F（缩放因子）        | 0.4 - 1.0            | 0.5      | 控制差分向量的缩放。较大值增强探索，较小值增强开发       |
| CR（交叉概率）       | 0.1 - 0.9            | 0.7      | 控制参数继承。高CR适合可分离问题，低CR适合相关性强的问题 |

1. **种群大小NP**：
   - 低维问题（D<10）：NP = 30-50
   - 中维问题（10≤D<30）：NP = 5D-10D
   - 高维问题（D≥30）：NP = 100-200
   - 可分离问题可用较小种群，非可分离问题需较大种群

2. **缩放因子F**：
   - 多峰函数：F = 0.7-0.9（增强探索）
   - 单峰函数：F = 0.4-0.6（增强开发）
   - 高维问题：F = 0.5-0.7（平衡）
   - 自适应策略：F = 0.5 + 0.3 \* rand()（每次变异随机化）

3. **交叉概率CR**：
   - 可分离问题：CR = 0.9（高交叉率）
   - 不可分离问题：CR = 0.1-0.3（低交叉率）

   - 未知地形：rand/1（稳健）

### 实现注意事项

1. **关键实现细节**：
   - **索引选择唯一性**：变异时r1, r2, r3必须互不相同且不等于i
   - **至少一个参数继承**：交叉时j_rand确保试验向量与目标向量不完全相同
   - **边界处理一致性**：所有越界个体必须修复，否则影响算法性能
   - **浮点精度**：使用np.float64避免精度损失
   - **随机数质量**：使用高质量随机数生成器（np.random优于Python random）

2. **常见错误**：
   - ❌ 忘记边界修复导致函数评估失败
   - ❌ 变异索引选择不唯一导致差分向量为零
   - ❌ 交叉时未确保至少一个参数继承，导致试验向量等于目标向量
   - ❌ F或CR设置超出合理范围（F>2或CR>1）
   - ❌ 种群过小（NP<4）导致无法选择足够的随机索引
   - ❌ 适应度函数返回NaN或Inf时未处理

3. **性能优化点**：
   - **向量化操作**：使用NumPy向量化替代循环
   - **并行评估**：多进程并行评估种群适应度（`multiprocessing.Pool`）
   - **适应度缓存**：缓存已评估个体避免重复计算
   - **早停机制**：检测收敛停滞自动终止
   - **增量评估**：特定问题可利用增量评估加速（如仅部分参数变化）
   - **代理模型**：计算昂贵问题使用代理模型近似评估

4. **离散变量处理**：

   ```python
   def handle_discrete_variables(x, discrete_indices, discrete_values):
       """处理混合整数优化问题"""
       x_discrete = x.copy()
       for idx in discrete_indices:
           # 取整到最近的离散值
           x_discrete[idx] = min(discrete_values[idx],
                                 key=lambda val: abs(val - x[idx]))
       return x_discrete
   ```

5. **约束处理方法**：
   - **罚函数法**：适应度加上约束违反的惩罚项
   - **可行性规则**：可行解总是优于不可行解，不可行解之间比较违反程度
   - **修复策略**：将不可行解修复为最近的可行解
   - **epsilon约束法**：逐步收紧约束容忍度
