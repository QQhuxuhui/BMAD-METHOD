## 触发场景

当用户提供的需求描述存在以下情况时使用此模板:

1. 缺少关键业务参数 (如任务数量、资源规模)
2. 目标不明确或存在歧义
3. 约束条件未明确说明
4. 领域特征描述不清

## 对话结构

### 步骤1: 呈现分析结果

AI呈现已从需求描述中提取的信息:

- 已识别的领域类型
- 已确定的资源和任务
- 已识别的约束条件
- 初步判断的目标

### 步骤2: 提出不确定项

AI列出需要用户澄清的问题，采用结构化提问:

- **问题类型**: 参数确认、目标澄清、约束明确、场景细化
- **提供选项**: 如适用，提供2-4个常见选项
- **开放式问题**: 需要用户补充详细信息

### 步骤3: 解析用户反馈

- **选项选择**: 用户选择提供的选项 (1, 2, 3...)
- **数值输入**: 用户提供具体数字
- **自然语言**: 用户以自然语言描述
- **确认/修改**: 用户确认当前分析或要求修改

### 步骤4: 更新模型

将用户反馈更新到需求模型:

```python
{
    "domain": "用户确认的领域",
    "resources": {用户补充的资源信息},
    "tasks": {用户补充的任务信息},
    "constraints": {用户澄清的约束},
    "objectives": {用户明确的目标}
}
```

## 模板示例

### 示例1: 缺少关键参数

```yaml
AI: |
  ## 🤝 需求澄清

  **当前理解**:
  - ✅ 领域: 车辆路径规划 (VRP)
  - ✅ 资源: 多辆车辆
  - ✅ 任务: 客户配送

  ### ❓ 需要您澄清的问题

  **问题 1: 车辆数量**
  请问有多少辆车辆可用于配送？
  - 输入具体数字 (如 "30")

  **问题 2: 客户数量**
  请问需要服务多少个客户？
  - 输入具体数字 (如 "200")

  **问题 3: 时间约束**
  是否有配送时间窗要求？
  1. 有严格时间窗 (客户指定的配送时段)
  2. 有期望时间 (希望尽早配送)
  3. 无时间限制

  请提供您的答案 (可以分别回答，或一次性提供)

User: 30辆车，200个客户，有严格时间窗

AI: |
  ✅ 需求已更新:
  - 车辆数量: 30辆
  - 客户数量: 200个
  - 时间约束: 严格时间窗 (VRPTW问题)

  我将基于这些信息生成 TenElementModel 并继续分析。
```

### 示例2: 目标不明确

```yaml
AI: |
  ## 🤝 需求澄清

  **当前理解**:
  - ✅ 领域: 生产调度
  - ✅ 资源: 10台设备
  - ✅ 任务: 100个生产订单

  ### ❓ 需要您澄清的目标

  您提到"优化生产计划"，请明确优化的主要目标:

  1. **最小化生产完成时间** (Makespan)
     - 适用场景: 紧急订单、交期压力大
  2. **最小化生产成本**
     - 适用场景: 成本敏感、利润压力大
  3. **最大化设备利用率**
     - 适用场景: 设备昂贵、闲置成本高
  4. **综合优化** (需要指定权重)
     - 同时考虑多个目标，您可以指定每个目标的重要程度

  请选择一个主要目标，或说明如何综合优化。

User: 综合优化，完成时间最重要(50%)，成本次之(30%)，设备利用率(20%)

AI: |
  ✅ 目标已明确:
  - 多目标优化策略
    - 最小化完成时间: 权重 0.5
    - 最小化生产成本: 权重 0.3
    - 最大化设备利用率: 权重 0.2

  我将基于加权优化方法设计目标函数。
```

### 示例3: 约束条件未明确

```yaml
AI: |
  ## 🤝 需求澄清

  **当前理解**:
  - ✅ 领域: 人员排班
  - ✅ 资源: 50名员工
  - ✅ 任务: 7天x24小时的班次覆盖

  ### ❓ 需要您澄清的约束条件

  **问题 1: 工时限制**
  员工每周工作时长是否有上限？
  - 是，每周不超过 ___小时 (请填写)
  - 否，无限制

  **问题 2: 连续工作**
  员工连续工作天数是否有限制？
  - 是，连续工作不超过 ___天 (请填写)
  - 否，无限制

  **问题 3: 技能要求**
  不同班次是否需要特定技能？
  1. 是，需要技能匹配
  2. 否，所有员工可胜任所有班次

  请提供您的答案。

User: 每周40小时，连续工作不超过5天，需要技能匹配

AI: |
  ✅ 约束已明确:
  - 工时约束: 每周 ≤ 40小时
  - 连续工作: ≤ 5天
  - 技能约束: 需要技能匹配

  我将这些约束纳入模型，确保生成的排班方案满足所有约束。
```

## 使用建议

1. **分步提问**: 不要一次提出过多问题，控制在3-5个以内
2. **提供选项**: 尽可能提供常见选项，降低用户认知负担
3. **自然语言**: 允许用户用自然语言描述，而非强制结构化输入
4. **渐进式**: 先澄清核心参数，再细化边缘情况
