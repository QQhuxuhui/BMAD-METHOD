## 📖 定义

**碳排放** = 能耗 × 碳排放因子

```
CO2排放 (kg) = 能耗 (kWh) × 碳排放因子 (kg CO2/kWh)
```

## 🔧 代码实现

```python
class CarbonEmissionsObjective:
    """碳排放目标函数"""

    def __init__(self,
                 power_ratings: Dict[str, float],
                 carbon_factor: float = 0.5,  # kg CO2/kWh
                 weight: float = 1.0):
        self.name = "carbon_emissions"
        self.optimization_type = "minimize"
        self.weight = weight
        self.power_ratings = power_ratings
        self.carbon_factor = carbon_factor

    def evaluate(self, solution: Dict[str, List[Dict]]) -> float:
        """评估碳排放量 (kg CO2)"""
        total_energy = 0.0

        for resource_id, tasks in solution.items():
            power_kw = self.power_ratings.get(resource_id, 0.0)
            operating_hours = sum(task.get('duration', 0) for task in tasks)
            energy_kwh = power_kw * operating_hours
            total_energy += energy_kwh

        carbon_emissions = total_energy * self.carbon_factor
        return carbon_emissions
```
