   精简率: 67% (667行→450行)

   职责: 语法/逻辑/约束一致性/基准验证与报告聚合

🎯 工作流程 (V4.3完整版)

Phase 0: 任务规划
→ TodoGenerator生成任务清单
→ 用户确认Todo List(执行合同)
→ 初始化TodoTracker

Phase 0.5: 双模式交互选择
→ 呈现模式A/B对比
→ 用户选择交互模式
→ 记录模式并初始化工作流

Phase 1: 需求分析
→ 需求理解
→ TodoTracker追踪执行
→ 偏离检测

Phase 1.5: 十要素建模
模式A: 一次性确认完整TenElementModel
模式B: 仅确认框架(类型/数量/名称)

Phase 2: 专家协调
模式A: 所有专家并行分析(基于完整模型)
模式B: - Phase 2.1: 领域专家增量确认 - Phase 2.2: 约束专家增量确认 - Phase 2.3: 目标专家增量确认 - Phase 2.4: 算法专家增量确认 - Phase 2.5: 跨专家一致性校验

Phase 3: 方案集成
→ 方案融合
→ 一致性检查
→ P2触发(冲突仲裁)

Phase 4: 质量保证
→ 质量门禁验证
→ QE聚合报告(level=pass)
→ Todo完成度检查

🤝 人机交互机制 (5级触发)

P0: Todo List强制要求 (user_confirmation_needed=true)
P1: 置信度过低 (confidence < 0.70)
P2: 专家建议冲突
P3: 能力缺口
P4: 用户主动暂停
