## 💡 关键设计决策

| 决策                                  | 理由                                                                                            |
| ------------------------------------- | ----------------------------------------------------------------------------------------------- |
| 昨天 / 今天 / 明天 三段演进           | 答辩叙事的最强终局结构：有来处（可验证）、有当下（可感知）、有去处（可想象）                    |
| "昨天" 写已获得的硬成果               | 创新案例答辩最后一次打"背书"拳，强化"我们真的做出来了"（专利 + 国赛 + 架构创新）                |
| "今天" 写飞轮正在转动                 | 呼应 P7 飞轮页——让整场答辩的逻辑闭环                                                            |
| "明天" 用三个 "从...到..." 方向性表达 | **不牵扯任何具体项目名**，避免被追问；但方向清晰：单场景→多场景 / 调度→矩阵 / 产品→生态         |
| 终局金句对仗                          | **专家 → 组织 · 架构 → 产业**，两句话双维度升华：业务维度（专家资产化）+ 技术维度（架构标准化） |
| 金句字号全场最大                      | 评委最后看到的文字 = 整场答辩最被记住的文字                                                     |

## 🎨 样式说明

**整体风格**：白色系商务正式 · 低密度高留白 · 强理性弱装饰

**配色规范**

| 用途     | 色值      | 用法                     |
| -------- | --------- | ------------------------ |
| 背景     | `#FFFFFF` | 纯白 · 全场统一          |
| 主文字   | `#1A202C` | 深墨灰 · 标题 / 正文     |
| 副文字   | `#4A5568` | 中灰 · 副标题 / 注释     |
| 强调色   | `#1A365D` | 深蓝 · 关键词 / 数字亮点 |
| 分割线   | `#E2E8F0` | 浅灰 · 1px 细线          |
| 警示色   | `#C53030` | 砖红 · 传统方案的负面点  |
| 收益色   | `#2F855A` | 墨绿 · 正面成效          |
| 点缀金色 | `#D69E2E` | 仅用于 🏆 国赛图标       |

**字体规范**

- 中文：思源黑体 / 微软雅黑（兜底）
- 英文 & 数字：Inter / Helvetica Neue（兜底）
- 主标题：大字号 · 加粗 · 深墨灰
- 副标题：次级字号 · 细体 · 中灰
- 数字亮点：超大字号 · 加粗 · 深蓝

**版式规范**

- 每页四角留白 ≥ 5%
- **克制使用 emoji**：保留功能性标识，删除装饰性表情；优先线框 icon（Feather / Tabler Icons 风格）
- 分隔元素：1px 浅灰细线，避免厚重底纹
- 对齐：统一居中或左对齐，避免混用

**本页视觉重点（P9 总结 · 终局页）**

- **时间轴（横向三段式）**
  - 三个**深蓝圆点**节点 `●` 等距排列
  - 用**浅灰连接线**串联（虚实结合：已完成用实线、未来用虚线）
  - "昨天 / 今天 / 明天" 标签：字号递进 + **颜色递进**
    - **昨天**：中灰 `#4A5568`（回顾感）
    - **今天**：深墨灰 `#1A202C`（当下感）
    - **明天**：深蓝 `#1A365D` + 加粗（前瞻感）
- **三列内容区**
  - 白底 · 列间用 1px 浅灰竖线分隔
  - 重点词加粗深蓝（"Agent as Doc"、"飞轮"、"多场景"等）
- **终局金句（全场记忆点）**
  - **字号全场最大**（≥ 60pt）· 居中 · 双行对仗
  - 深蓝加粗 `#1A365D`
  - 上下用深蓝细线（1px）包夹，形成**"引述"仪式感**
  - 书名号 `「...」` 中文样式
- **致谢**
  - 底部居中 · 中灰 · 小字号（20pt）· 不加粗
  - 与金句之间保留充足留白（≥ 60px）
