## Dev Notes

### 实现要点

**Prompt模板设计原则**:

- 使用markdown格式，便于人类阅读和维护
- 明确定义JSON输出schema
- 提供详细的示例（至少1个）
- 说明输入参数和上下文
- 定义错误处理指导

**节点函数签名**:

```python
async def agent_node(state: WorkflowState) -> Dict[str, Any]:
    """Agent节点函数

    Args:
        state: 当前工作流状态

    Returns:
        Dict包含更新的状态字段
    """
    pass
```

**LLM调用模式**:

```python
from backend.model_adapters.model_factory import ModelFactory
from langchain_core.prompts import ChatPromptTemplate

# 获取LLM
factory = ModelFactory.get_instance()
llm = factory.get_langchain_model()

# 构建Prompt
prompt = ChatPromptTemplate.from_messages([
    ("system", AGENT_PROMPT),
    ("human", "{input_data}")
])

# 调用LLM
chain = prompt | llm
response = await chain.ainvoke(input_data)

# 解析JSON
import json
output = json.loads(response.content)
```

**错误处理策略**:

- JSON解析失败：记录原始输出，重试或返回错误状态
- LLM调用超时：使用tenacity重试3次
- 输出格式不符合：使用Pydantic验证，提供默认值或重试

**状态更新原则**:

- 只返回需要更新的字段
- 不直接修改传入的state对象
- 使用类型提示确保字段正确
