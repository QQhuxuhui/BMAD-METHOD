## 📖 定义

**客户满意度** = f(准时交付, 服务质量, 沟通效率)

## 🔧 代码实现

```python
class CustomerSatisfactionObjective:
    """客户满意度目标函数"""

    def __init__(self, weight: float = 1.0):
        self.name = "customer_satisfaction"
        self.optimization_type = "maximize"
        self.weight = weight

    def evaluate(self, solution: List[Dict]) -> float:
        """评估客户满意度 (0-100)"""
        if not solution:
            return 0.0

        total_score = 0.0

        for task in solution:
            finish = task.get('finish_time', 0)
            deadline = task.get('deadline', float('inf'))

            # 提前完成加分，延迟扣分
            if finish <= deadline:
                early_time = deadline - finish
                score = min(100, 80 + early_time * 2)  # 提前越多，分数越高
            else:
                delay_time = finish - deadline
                score = max(0, 80 - delay_time * 5)    # 延迟越多，分数越低

            total_score += score

        avg_satisfaction = total_score / len(solution)
        return avg_satisfaction
```
