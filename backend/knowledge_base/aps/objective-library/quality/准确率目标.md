## 📖 定义

**准确率** = 正确任务数 / 总任务数

## 🔧 代码实现

```python
class AccuracyObjective:
    """准确率目标函数"""

    def __init__(self, weight: float = 1.0):
        self.name = "accuracy"
        self.optimization_type = "maximize"
        self.weight = weight

    def evaluate(self, solution: List[Dict], correctness_check) -> float:
        """
        评估准确率

        参数:
          correctness_check: 函数，判断任务是否正确完成
        """
        if not solution:
            return 100.0

        correct_count = sum(1 for task in solution if correctness_check(task))
        accuracy = (correct_count / len(solution)) * 100

        return accuracy
```
