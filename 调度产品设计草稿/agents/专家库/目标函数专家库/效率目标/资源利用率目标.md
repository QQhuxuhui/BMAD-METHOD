## 📖 定义

**资源利用率** = 实际使用时间 / 可用时间 × 100%

## 🔧 代码实现

```python
class ResourceUtilizationObjective:
    """资源利用率目标函数"""

    def __init__(self, weight: float = 1.0):
        self.name = "resource_utilization"
        self.optimization_type = "maximize"
        self.weight = weight

    def evaluate(self, solution: Dict[str, List[Dict]], available_time: float) -> float:
        """评估资源利用率"""
        total_utilization = 0.0
        num_resources = len(solution)

        for resource_id, tasks in solution.items():
            usage_time = sum(task.get('duration', 0) for task in tasks)
            utilization = (usage_time / available_time) * 100 if available_time > 0 else 0
            total_utilization += utilization

        avg_utilization = total_utilization / num_resources if num_resources > 0 else 0
        return avg_utilization
```
