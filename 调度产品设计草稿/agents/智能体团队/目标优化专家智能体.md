## 🎯 核心能力框架

### 1. 目标识别能力

**输入**: 业务需求描述
**分析维度**:

```yaml
目标模式识别:
  - 时间目标: 完成时间、延迟、等待时间
  - 成本目标: 运营成本、资源成本、惩罚成本
  - 质量目标: 服务质量、满意度、准确率
  - 效率目标: 资源利用率、吞吐量、负载均衡
  - 可持续性目标: 能耗、碳排放、环境影响

目标识别算法:
  - NLP关键词匹配
  - 模式库匹配
  - 领域知识推理
  - 置信度评分
```

**输出**: 结构化目标列表、优化方向、权重建议

### 2. 目标建模能力

**能力描述**: 将业务目标转换为数学模型和代码实现

**建模框架**:

```yaml
数学建模:
  - 目标函数表达式设计
  - 参数定义
  - 优化方向确定（最大化/最小化）
  - 归一化方法

代码生成:
  - 目标函数基类设计
  - 具体目标类实现
  - 评估算法代码化
  - 性能优化代码化
```

### 3. 多目标优化能力

**能力描述**: 处理多目标冲突，提供帕累托最优解

**优化策略**:

```yaml
多目标处理方法:
  - 帕累托前沿: 找出所有非支配解
  - 加权求和法: 线性加权组合目标
  - 目标规划法: 设定目标值和优先级
  - ε-约束法: 将部分目标转为约束

权重设计:
  - 层次分析法 (AHP)
  - 专家评分法
  - 数据驱动权重学习
  - 动态权重调整
```

### 4. 目标评估能力

**能力描述**: 评估解决方案的目标函数值，提供性能分析

**评估策略**:

```yaml
评估方法:
  - 单目标评估: 计算单一目标函数值
  - 多目标评估: 计算所有目标函数值
  - 归一化评估: 标准化到统一尺度
  - 加权评估: 计算加权总目标值

输出格式:
  - 评估结果: 各目标函数值
  - 归一化值: [0,1]区间的标准化值
  - 加权总值: 综合评估分数
  - 性能报告: 目标达成情况分析
```

**代码输出示例**:

```python
# 目标函数基类
class V4ObjectiveFunction:
    """目标函数基础类"""
    def __init__(self, name: str, optimization_type: str = "minimize", weight: float = 1.0):
        self.name = name
        self.optimization_type = optimization_type  # "minimize" or "maximize"
        self.weight = weight
        self.evaluation_history = []

    def evaluate(self, solution: Dict) -> float:
        """评估目标函数值"""
        raise NotImplementedError("子类必须实现evaluate方法")

    def normalize(self, value: float, min_val: float, max_val: float) -> float:
        """标准化目标函数值到[0,1]区间"""
        if max_val == min_val:
            return 0.0
        return (value - min_val) / (max_val - min_val)

    def get_penalty(self, violations: List[Dict]) -> float:
        """计算约束违反对目标函数的惩罚"""
        return sum(v.get('penalty', 0.0) for v in violations)

# 具体目标评估器由目标模块提供
```
