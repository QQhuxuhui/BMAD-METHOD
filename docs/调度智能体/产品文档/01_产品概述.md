# 一、产品概述

## 1.1 产品定位

**APS (Advanced Planning & Scheduling) 调度智能体团队** 是一个面向调度优化领域的专业 AI Agent 系统，通过 7 个专家智能体的协作，提供从需求分析到代码生成的端到端调度问题求解能力。

**核心价值主张**：将调度优化专家经验知识化、模块化、自动化，让非专家也能快速获得专业级调度解决方案。

## 1.2 产品版本

- **当前版本**：V4.3 (1.0.0-alpha)
- **架构基础**：BMAD-CORE v6-alpha
- **发布时间**：2025-10-20
- **技术状态**：Alpha 测试阶段，核心架构完成，知识库持续填充中

## 1.3 核心特点

### "Agent as Doc" - 智能体即文档

```
传统 AI Agent：智能体 = 大模型 + Prompt
APS 创新模式：智能体 = 角色定位 + 知识文档库 + 动态组合机制

核心思想：
  ✓ 智能体是知识的载体，而非知识的替代者
  ✓ 专业能力来自模板化知识模块的动态加载
  ✓ 工作流程是知识模板的调用与组合机制
```

### Sidecar 模式 - Token 效率优化

```
传统方式：
  agent.md (50K tokens) = 角色 + 全部知识嵌入
  问题：每次激活加载全部，利用率仅10-20%

Sidecar 模式：
  agent.md (500 tokens) = 角色定位
  + <critical-actions>按需加载 templates/*-library/README.md (5K)
  + 根据需求动态加载具体模块 (1-10K)

  结果：Token节省 75-87%，响应速度提升 3-5倍
```

### Theory-to-Code - 从理论到代码

```
输入：业务需求（自然语言）
  ↓
需求理解 → 十要素建模 → 专家协调 → 方案集成
  ↓
输出：可执行代码（92%可用率）+ 完整文档
```
