## 💡 关键设计决策

| 决策                                | 理由                                                                                   |
| ----------------------------------- | -------------------------------------------------------------------------------------- |
| 三墙对称布局（而非竖排 / 流程图）   | 视觉压迫感强，让"问题严重性"一眼可见                                                   |
| 每墙都有"一句话痛点 + 量化证据"双层 | 技术评委看数字，业务评委看痛点描述，各得其所                                           |
| 墙③ 放最后不是最末位                | 专家经验断层是整套答辩中业务评委最共鸣的点；收束时压阵最有力；直接引出 P7 飞轮页的解药 |
| 底部金句 "破的局"                   | 顺势带出下一页 P3 的"王牌破局点"                                                       |

---

## 💡 用词精选说明

- **墙① AI 幻觉难控** → 比"AI 不可靠"更技术、更精准
- **墙② Token 浪费** → 直击成本，业务评委秒懂
- **墙③ 专家经验留不住** → 用"留不住"而不是"难传承"——**口语化、有情绪**，评委更有共鸣

---

## 🎤 口头讲词（~45 秒）

> "在今天的 AI 时代，调度优化这类专业领域落地，撞到三道墙——
>
> **墙一：AI 幻觉难控。** 长任务链中，AI 会编造算法、编造业务规则——传统 Agent 代码可用率只有 50-70%，关键决策没法追溯。
>
> **墙二：Token 浪费严重。** 把知识全塞进 Prompt，一次加载 50K tokens，实际利用率只有 10-20%——成本贵、响应慢。
>
> **墙三：专家经验留不住。** 这是让所有有专业岗位的企业最头疼的问题——专家在，知识在；专家一离职，经验清零；新人上手 3 个月。
>
> **正是这三道墙，让 AI Agent 在高专业度场景难以真正落地——而这，正是我们要破的局。**"

---

## ✏️ 可调整项

- **量化数字**（50-70% / 10-20% / 3 个月）可根据集团内部真实调研数据替换，说服力会更强
- **三道墙的命名用词** 如需更正式可改为："AI 输出不可信 / Token 效率低下 / 专家经验流失"
