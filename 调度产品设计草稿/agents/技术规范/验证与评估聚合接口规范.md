# 验证与评估聚合接口规范

## 目标

- 以统一接口封装语法检查、逻辑验证、约束一致性与性能基准评测，向编排/专家智能体提供标准化的可执行验证能力与统一报告。

## 输入/输出

### 输入（JSON）

```json
{
  "code": "<string: 生成的Python算法代码>",
  "model": { "ten_elements": { "...": "与十要素建模流程一致" } },
  "testcases": [{ "name": "case1", "data": {} }],
  "options": { "benchmark": { "enabled": true, "timeout_s": 5 } }
}
```

### 输出（JSON）

```json
{
  "syntax": { "ok": true, "errors": [] },
  "logic": { "ok": true, "coverage": 0.0, "notes": [] },
  "constraints": {
    "ok": true,
    "implemented": ["time_window", "vehicle_capacity"],
    "missing": [],
    "consistency_score": 1.0
  },
  "benchmark": {
    "ok": true,
    "predicted_runtime_ms": 120,
    "memory_mb": 32,
    "dataset": "synthetic|minimal|custom",
    "notes": []
  },
  "summary": {
    "score": 0.93,
    "level": "pass|concerns|fail",
    "recommendations": ["..."],
    "artifacts": { "raw_log_path": null }
  }
}
```

## 接口形式

- Node/Python 本地库调用（推荐）
- CLI: `python tools/validation/aggregator.py --in input.json --out report.json`

## 与编排/专家协作

- 编排：步骤4“质量保证与风险控制”统一调用本接口；输入采用 TenElementModel。
- 专家：算法/约束/目标专家可在各自自验证阶段局部调用聚合器的子模块。

## 评分规则（建议）

```yaml
score:
  weights: {syntax: 0.2, logic: 0.3, constraints: 0.3, benchmark: 0.2}
  gates:
    - name: 必须门1: syntax.ok
    - name: 必须门2: constraints.ok
  levels:
    pass: score >= 0.85 & all gates pass
    concerns: 0.7 <= score < 0.85
    fail: score < 0.7 or any gate fail
```
