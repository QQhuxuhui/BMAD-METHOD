## 📝 技术决策记录

### 1. 置信度阈值选择

**决策**: 使用 0.70 作为默认阈值

**理由**:

- 参考 Claude Code 的 UltraThink 实践
- 平衡自动化程度和准确性
- 用户可自定义调整

### 2. 偏离检测算法

**决策**: 使用 difflib.SequenceMatcher

**理由**:

- Python 标准库，无额外依赖
- 性能足够 (< 200ms)
- 对中文文本支持良好
- 未来可升级为语义相似度 (sentence-transformers)

### 3. Todo List 结构设计

**决策**: 包含 id, content, activeForm, status, metadata

**理由**:

- 符合 Claude Code TodoWrite 工具规范
- metadata 提供丰富的元信息支持
- 易于序列化和传输

### 4. 交互模板结构

**决策**: YAML 元数据 + Markdown 内容

**理由**:

- 易于解析和管理
- 人类可读性强
- 支持版本控制
- 符合 Agent as Doc 理念

## 🔍 遇到的问题与解决

### 问题1: 中文文本相似度计算不准确

**现象**:

- "十要素建模" vs "通过十要素建模生成TenElementModel"
- 相似度只有 0.345，被误判为严重偏离

**原因**: 字符串长度差异导致相似度下降

**解决**:

- 调整测试用例使用更接近的文本
- 未来可升级为语义相似度算法

### 问题2: ConfirmationTrigger 测试失败

**现象**: 交互历史记录为空

**原因**: confirm 操作直接 return，未记录历史

**解决**: 移除早期 return，统一在函数末尾记录历史
