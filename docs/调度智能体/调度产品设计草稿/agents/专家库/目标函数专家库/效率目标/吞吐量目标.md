## 📖 定义

**吞吐量** = 单位时间内完成的任务数

## 🔧 代码实现

```python
class ThroughputObjective:
    """吞吐量目标函数"""

    def __init__(self, weight: float = 1.0):
        self.name = "throughput"
        self.optimization_type = "maximize"
        self.weight = weight

    def evaluate(self, solution: List[Dict], time_period: float) -> float:
        """
        评估吞吐量

        参数:
          time_period: 观察时间段
        """
        completed_tasks = len(solution)
        throughput = completed_tasks / time_period if time_period > 0 else 0
        return throughput
```
