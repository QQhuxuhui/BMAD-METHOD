## 触发场景

**触发时机**: Phase 2.3,在领域专家和约束专家完成确认之后

**前置条件**:

- ✅ TenElementModel 框架已确认
- ✅ 领域专家已完成场景特征确认
- ✅ 约束专家已完成约束参数确认
- ✅ 目标框架信息已提取 (目标数量、类型、类别)

**目的**:

- 逐条确认每个优化目标的权重和评价标准
- 在具体业务和约束上下文中帮助用户权衡目标
- 确保目标配置符合业务优先级
- 为算法选择和方案评估提供准确的目标函数


**响应处理逻辑**:

```python
def process_weight_response(user_input: str, objective: dict, other_objectives: list) -> dict:
    """处理目标权重确认的用户响应"""

    if user_input == "1":
        # 确认建议
        objective["weight"] = objective["proposed_weight"]
        return {"action": "next_question", "field": "components"}

    elif user_input == "2":
        # 调整为更高权重
        return {
            "action": "adjust_weight",
            "direction": "increase",
            "prompt": "请输入新的权重值 (如 0.7 或 70%):"
        }

    elif user_input == "3":
        # 调整为更低权重
        return {
            "action": "adjust_weight",
            "direction": "decrease",
            "prompt": "请输入新的权重值 (如 0.3 或 30%):"
        }

    elif user_input == "4":
        # 自定义权重
        return {
            "action": "custom_weight",
            "prompt": "请输入权重值 (0.0-1.0 或 0%-100%):"
        }

    elif user_input == "5":
        # 查看影响
        return {
            "action": "show_impact",
            "content": generate_weight_impact_analysis(objective, other_objectives)
        }

    elif user_input == "6":
        # 举例说明
        return {
            "action": "provide_examples",
            "content": generate_weight_examples(objective)
        }

    elif user_input == "7":
        # 查看行业标准
        return {
            "action": "show_industry_standard",
            "content": query_industry_weight_standard(objective)
        }

    elif user_input == "8":
        # 分析权衡
        return {
            "action": "analyze_tradeoff",
            "content": generate_objective_tradeoff_analysis(objective, other_objectives)
        }

    elif user_input == "9":
        # 其他问题
        return {
            "action": "open_question",
            "prompt": "请描述您的具体问题或想法:"
        }

    else:
        # 尝试解析权重值
        weight = parse_weight_value(user_input)
        if weight is not None:
            objective["weight"] = weight
            return {"action": "next_question", "field": "components"}
        else:
            return parse_natural_language_response(user_input, objective, "weight")
```
