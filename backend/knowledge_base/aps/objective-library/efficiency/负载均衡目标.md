## 📖 定义

**负载均衡** = minimize(max_load - min_load)

最小化资源间负载差异

## 🔧 代码实现

```python
import statistics

class LoadBalancingObjective:
    """负载均衡目标函数"""

    def __init__(self, weight: float = 1.0):
        self.name = "load_balancing"
        self.optimization_type = "minimize"
        self.weight = weight

    def evaluate(self, solution: Dict[str, List[Dict]]) -> float:
        """评估负载均衡度（标准差）"""
        loads = []

        for resource_id, tasks in solution.items():
            load = sum(task.get('duration', 0) for task in tasks)
            loads.append(load)

        if not loads:
            return 0.0

        # 使用标准差衡量均衡度（越小越均衡）
        load_std = statistics.stdev(loads) if len(loads) > 1 else 0.0

        return load_std
```
