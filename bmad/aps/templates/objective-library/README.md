## 📋 知识库概述

### 知识库定位

目标优化专家知识库是 BMAD APS 模块中专门针对调度问题目标函数设计和优化的知识集合,涵盖成本、时间、效率、质量、可持续性以及多目标优化六大核心类别。

**核心价值**:

- 提供标准化的目标函数模板和建模范式
- 封装目标优化的理论知识和实践经验
- 支持单目标和多目标优化问题
- 指导智能体进行目标权衡和决策

**使用场景**:

- 调度问题的目标函数设计
- 多目标冲突的权衡和协调
- 目标优化算法的选择
- 解质量的评估和验证

## 🗂️ 知识结构

### 一级分类:目标类型

```yaml
目标分类:
  1. 成本目标 (Cost Objectives):
    - 总成本最小化: 运营成本、资源成本综合
    - 运营成本优化: 人工、能耗、维护成本
    - 资源成本优化: 设备、物料、仓储成本
    - 特点: 可量化、直接影响企业利润

  2. 时间目标 (Time Objectives):
    - 完成时间最小化: Makespan, 总流程时间
    - 延迟最小化: 拖期惩罚、准时交付率
    - 加权延迟优化: 考虑任务优先级
    - 特点: 关键性能指标、客户满意度相关

  3. 效率目标 (Efficiency Objectives):
    - 资源利用率最大化: 设备、人员、仓库利用率
    - 负载均衡: 工作量分配均衡性
    - 吞吐量最大化: 单位时间处理量
    - 特点: 反映系统运行效能

  4. 质量目标 (Quality Objectives):
    - 服务质量优化: SLA达标率、客户满意度
    - 准确率提升: 订单准确性、配送准确性
    - 稳定性保障: 方案鲁棒性、波动控制
    - 特点: 软性指标、长期价值

  5. 可持续性目标 (Sustainability Objectives):
    - 碳排放最小化: 运输碳足迹、生产碳排放
    - 能耗优化: 电力、燃料消耗降低
    - 环境友好: 噪音、污染控制
    - 特点: 社会责任、绿色发展

  6. 多目标优化 (Multi-Objective Optimization):
    - 加权优化: 多目标线性加权
    - 帕累托前沿: 非支配解集合
    - 分层优化: 主次目标逐层优化
    - 特点: 处理目标冲突、提供决策空间
```

### 二级分类:优化方向

```yaml
优化方向:
  - 最小化 (Minimization):
      适用: 成本、时间、延迟、碳排放
      目标: min f(x)

  - 最大化 (Maximization):
      适用: 利用率、吞吐量、满意度
      目标: max f(x)

  - 约束满足 (Constraint Satisfaction):
      适用: SLA、质量标准、合规要求
      目标: f(x) ≤ threshold 或 f(x) ≥ target
```

## 🎯 目标选择矩阵

### 如何选择目标函数?

| 业务关注点     | 推荐目标类型  | 典型目标函数                |
| -------------- | ------------- | --------------------------- |
| 降低运营开支   | 成本目标      | 总成本最小化                |
| 提升交付速度   | 时间目标      | 最大完成时间最小化          |
| 减少客户投诉   | 时间+质量目标 | 延迟最小化 + SLA达标率      |
| 提高设备利用率 | 效率目标      | 资源利用率最大化            |
| 均衡员工工作量 | 效率目标      | 负载均衡目标                |
| 绿色低碳发展   | 可持续性目标  | 碳排放最小化                |
| 成本与服务平衡 | 多目标优化    | 成本 vs 服务质量 帕累托前沿 |

### 目标冲突识别

```yaml
常见目标冲突:
  1. 成本 vs 时效:
    - 冲突: 加快速度通常需要更多资源投入
    - 协调: 设定时效底线,在此基础上最小化成本

  2. 效率 vs 公平:
    - 冲突: 最大化效率可能导致负载不均
    - 协调: 设置负载均衡约束,再优化效率

  3. 质量 vs 成本:
    - 冲突: 高质量标准增加成本
    - 协调: 多目标优化,寻找帕累托最优

  4. 短期成本 vs 长期可持续:
    - 冲突: 绿色设备初期投资高
    - 协调: 全生命周期成本分析
```

## 🔍 使用指南

### 1. 单目标优化流程

```yaml
步骤1: 目标识别
  - 分析业务需求,确定核心优化指标
  - 明确优化方向 (最小化/最大化)
  - 评估目标的可量化性

步骤2: 目标建模
  - 选择对应的目标模块模板
  - 定义目标函数的数学表达式
  - 确定目标函数的系数和权重

步骤3: 算法适配
  - 根据目标函数特性选择算法
  - 配置算法参数以优化该目标
  - 设置收敛条件和终止准则

步骤4: 解评估
  - 计算目标函数值
  - 验证目标改进效果
  - 对比基准方案
```

### 2. 多目标优化策略

```yaml
策略1: 加权求和法
  适用: 目标可转化为同量纲
  方法:
    目标函数: f(x) = w1*f1(x) + w2*f2(x) + ... + wn*fn(x)
    权重设置: Σwi = 1, wi >= 0
    调优: 敏感性分析,调整权重

  示例:
    f(x) = 0.6 * 成本 + 0.4 * 延迟时间
    引用: "@专家库/目标库/multi-objective/加权优化方法.md"

策略2: 约束法 (ε-constraint)
  适用: 有主次目标之分
  方法:
    主目标: min f1(x)
    次要目标作为约束: f2(x) <= ε2, f3(x) <= ε3
    调优: 逐步放松/收紧ε值

  示例:
    主目标: 最小化成本
    约束: 延迟时间 <= 2小时, SLA达标率 >= 95%

策略3: 帕累托优化
  适用: 目标无明显主次,需要多方案比较
  方法:
    寻找帕累托前沿 (非支配解集)
    提供多个可选方案
    由决策者根据偏好选择

  引用: "@专家库/目标库/multi-objective/帕累托前沿.md"

  示例:
    目标1: 最小化配送成本
    目标2: 最小化碳排放
    输出: 成本-碳排放的帕累托前沿曲线
```

### 3. 目标函数设计原则

```yaml
原则1: 业务对齐
  - 目标函数必须反映真实业务需求
  - 避免优化"容易量化"但不重要的指标
  - 与业务部门确认目标权重

原则2: 可计算性
  - 目标函数应能高效计算
  - 避免过于复杂的非线性表达式
  - 考虑算法的适用性

原则3: 数据可得性
  - 目标函数系数需有可靠数据来源
  - 预估参数需经过验证
  - 建立参数更新机制

原则4: 鲁棒性
  - 目标函数对参数扰动不敏感
  - 避免极端参数导致病态问题
  - 考虑不确定性场景

原则5: 可解释性
  - 目标函数构成要清晰
  - 结果可向业务人员解释
  - 支持敏感性分析
```

## 📊 常见目标函数公式

### 成本类目标

```yaml
总成本 (Total Cost):
  公式: TC = FC + VC
  其中:
    FC: 固定成本 (设备、仓库租金)
    VC: 可变成本 (人工、运输、物料)

  详细展开: TC = Σ 固定成本_i + Σ (单位成本_j × 使用量_j)

运输成本 (Transportation Cost):
  公式: TC = Σ_i Σ_j (距离_ij × 单位成本 × 运输量_ij)
  适用: 车辆调度、配送优化

库存成本 (Inventory Cost):
  公式: IC = 持有成本 × 平均库存 + 订货成本 × 订货次数
  适用: 供应链调度
```

### 时间类目标

```yaml
最大完成时间 (Makespan):
  公式: Cmax = max{Ci}
  其中: Ci 为任务i的完成时间
  适用: 生产调度、项目调度

总延迟 (Total Tardiness):
  公式: TT = Σ max{0, Ci - Di}
  其中:
    Ci: 任务i实际完成时间
    Di: 任务i截止期
  适用: 准时交付优化

加权延迟 (Weighted Tardiness):
  公式: WT = Σ wi × max{0, Ci - Di}
  其中: wi 为任务i的权重 (优先级)
  适用: 有优先级差异的调度
```

### 效率类目标

```yaml
资源利用率 (Resource Utilization):
  公式: U = (实际使用时间 / 可用时间) × 100%
  目标: 最大化利用率
  适用: 设备、人员效率优化

负载均衡 (Load Balancing):
  公式: LB = min (max{Li} - min{Li})
  其中: Li 为资源i的负载
  目标: 最小化负载差异
  适用: 人员排班、服务器负载

吞吐量 (Throughput):
  公式: TP = 完成任务数 / 时间周期
  目标: 最大化吞吐量
  适用: 生产线、服务系统
```
