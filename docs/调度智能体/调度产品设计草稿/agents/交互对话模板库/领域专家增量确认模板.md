## 触发场景

**触发时机**: Phase 2.1,在 TenElementModel 框架确认之后的第一个专家阶段

**前置条件**:

- ✅ TenElementModel 框架已确认
- ✅ 用户选择了增量确认模式(模式B)
- ✅ 框架信息已提取(决策变量数量、约束类别等)

**目的**:

- 确认业务场景的核心特征
- 识别关键领域信息(时效性、规模、不确定性等)
- 为后续约束、目标、算法专家提供准确的上下文
- 在具体业务语境中帮助用户澄清需求

def process_scenario_classification_response(user_input: str, scenario: dict) -> dict:
