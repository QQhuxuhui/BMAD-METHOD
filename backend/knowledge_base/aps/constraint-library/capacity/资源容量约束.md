## 📖 约束概述

### 定义

**资源容量约束**（Resource Capacity Constraint）规定资源（人员、设备、能源等）在单位时间内的最大处理能力，确保资源分配不超过容量限制。

**数学定义**：

```
对于资源 r 和时间段 t，定义:
  C_r: 资源 r 的容量（单位/时间）
  L_r(t): 时间段 t 的负载
  w_i: 任务 i 的资源需求

容量约束:
  ∑_{i assigned to r in t} w_i ≤ C_r  ∀r, t

累积约束:
  ∫_0^T L_r(t) dt ≤ C_r × T
```

### 约束类型

#### 1. **离散资源容量** (Discrete Resource)

```
可数资源，整数单位
例如: 人员数量、机器台数

约束:
  ∑ x_i ≤ N  (N为资源数量)
  x_i ∈ {0, 1}  (任务i是否分配)
```

#### 2. **连续资源容量** (Continuous Resource)

```
可分割资源
例如: 电力、内存、带宽

约束:
  ∑ r_i ≤ R_max
  r_i ∈ [0, R_max]
```

#### 3. **可再生资源** (Renewable Resource)

```
周期性恢复的资源
例如: 人工时、机器时

特点:
  - 单位时间内有固定容量
  - 时间结束后容量恢复
  - 不能跨期累积
```

#### 4. **不可再生资源** (Non-Renewable Resource)

```
一次性消耗资源
例如: 原材料、预算

特点:
  - 总量固定
  - 消耗后不恢复
  - 需要全局优化
```

## 💡 核心理论

### 资源受限项目调度 (RCPSP)

**问题定义**：

```
最小化项目完工时间，满足:
  1. 任务优先级约束
  2. 资源容量约束

数学模型:
  min C_max  (最小化完工时间)

  s.t.
    S_j ≥ S_i + p_i  ∀(i,j) ∈ precedence
    ∑_{i active at t} r_ik ≤ R_k  ∀k, t
```

**求解算法**：

```python
def serial_schedule_generation_scheme(tasks, resources, precedence):
    """
    串行调度生成方案 (Serial SGS)

    步骤:
      1. 维护可调度任务集
      2. 按优先级选择任务
      3. 在最早可行时间调度任务
      4. 更新资源可用性
    """
    schedule = {}
    scheduled = set()
    time = 0

    while len(scheduled) < len(tasks):
        # 可调度任务集（前序任务已完成）
        eligible = [
            task for task in tasks
            if task not in scheduled and
            all(pred in scheduled for pred in precedence.get(task, []))
        ]

        if not eligible:
            break

        # 按优先级排序
        eligible.sort(key=lambda t: priority(t))

        # 尝试调度
        for task in eligible:
            # 检查资源可用性
            if resources_available(task, time, resources):
                schedule[task] = time
                scheduled.add(task)
                allocate_resources(task, time, resources)
                break
        else:
            # 无任务可调度，推进时间
            time += 1

    return schedule
```

### 负载均衡

**目标**：最小化资源负载差异，避免瓶颈。

```python
def calculate_load_balance_metrics(resource_loads):
    """
    负载均衡指标

    指标:
      - 最大负载
      - 平均负载
      - 负载标准差
      - 负载均衡度
    """
    max_load = max(resource_loads)
    avg_load = sum(resource_loads) / len(resource_loads)

    variance = sum((load - avg_load) ** 2 for load in resource_loads) / len(resource_loads)
    std_dev = variance ** 0.5

    # 负载均衡度 (0-1, 越接近1越均衡)
    balance_index = 1 - (std_dev / avg_load) if avg_load > 0 else 1

    return {
        'max_load': max_load,
        'avg_load': avg_load,
        'std_dev': std_dev,
        'balance_index': balance_index
    }
```

### 瓶颈识别

**鼓-缓冲-绳理论** (Drum-Buffer-Rope, DBR)：

```
1. Drum（鼓）: 识别系统瓶颈，以瓶颈节奏调度
2. Buffer（缓冲）: 在瓶颈前设置缓冲保护
3. Rope（绳）: 控制投料速度，避免在制品积压

瓶颈判定:
  利用率最高的资源
  或：关键路径上的资源
```

## 🔧 代码实现

```python
from typing import Dict, List, Tuple, Optional, Set
from dataclasses import dataclass, field
from datetime import datetime, timedelta
from enum import Enum
import heapq

class ResourceType(Enum):
    """资源类型"""
    DISCRETE = "discrete"           # 离散资源
    CONTINUOUS = "continuous"       # 连续资源
    RENEWABLE = "renewable"         # 可再生资源
    NON_RENEWABLE = "non_renewable" # 不可再生资源

@dataclass
class Resource:
    """资源定义"""
    id: str
    type: ResourceType
    capacity: float                    # 总容量
    available: float = None           # 当前可用容量
    cost_per_unit: float = 0          # 单位成本

    def __post_init__(self):
        if self.available is None:
            self.available = self.capacity

    @property
    def utilization(self):
        """利用率"""
        if self.capacity == 0:
            return 0
        return (self.capacity - self.available) / self.capacity * 100

@dataclass
class Task:
    """任务定义"""
    id: str
    duration: timedelta
    resource_requirements: Dict[str, float]  # {resource_id: amount}
    predecessors: List[str] = field(default_factory=list)
    priority: int = 0

@dataclass
class ResourceAllocation:
    """资源分配"""
    task_id: str
    resource_id: str
    amount: float
    start_time: datetime
    end_time: datetime

class ResourceCapacityConstraintHandler:
    """资源容量约束处理器"""

    def __init__(self, resources: Dict[str, Resource],
                 tasks: Dict[str, Task]):
        """
        参数:
          resources: {resource_id: Resource}
          tasks: {task_id: Task}
        """
        self.resources = resources
        self.tasks = tasks

    def validate(self, schedule: Dict[str, datetime],
                allocations: List[ResourceAllocation]) -> Tuple[bool, List[Dict]]:
        """
        验证资源分配是否满足容量约束

        参数:
          schedule: {task_id: start_time}
          allocations: 资源分配列表

        返回:
          (is_valid, violations)
        """
        violations = []

        # 按时间段检查资源负载
        time_slots = self._create_time_slots(schedule)

        for slot_start, slot_end in time_slots:
            resource_loads = {r_id: 0 for r_id in self.resources}

            # 计算该时间段的资源负载
            for alloc in allocations:
                # 检查分配是否与时间段重叠
                if self._time_overlap(
                    (alloc.start_time, alloc.end_time),
                    (slot_start, slot_end)
                ):
                    resource_loads[alloc.resource_id] += alloc.amount

            # 检查容量违反
            for resource_id, load in resource_loads.items():
                resource = self.resources.get(resource_id)
                if not resource:
                    continue

                if load > resource.capacity:
                    overflow = load - resource.capacity
                    overflow_percent = (overflow / resource.capacity) * 100

                    violations.append({
                        'type': 'resource_capacity_overflow',
                        'resource': resource_id,
                        'time_slot': (slot_start, slot_end),
                        'capacity': resource.capacity,
                        'load': load,
                        'overflow': overflow,
                        'overflow_percent': round(overflow_percent, 2),
                        'penalty': overflow_percent * 15
                    })

        return len(violations) == 0, violations

    def _create_time_slots(self, schedule: Dict[str, datetime],
                          slot_duration: timedelta = timedelta(hours=1)) -> List[Tuple[datetime, datetime]]:
        """创建时间槽用于容量检查"""
        if not schedule:
            return []

        # 找到最早和最晚时间
        start_times = list(schedule.values())
        end_times = [
            schedule[task_id] + self.tasks[task_id].duration
            for task_id in schedule
        ]

        project_start = min(start_times)
        project_end = max(end_times)

        # 生成时间槽
        slots = []
        current = project_start

        while current < project_end:
            slots.append((current, current + slot_duration))
            current += slot_duration

        return slots

    def _time_overlap(self, interval1: Tuple[datetime, datetime],
                     interval2: Tuple[datetime, datetime]) -> bool:
        """判断两个时间段是否重叠"""
        start1, end1 = interval1
        start2, end2 = interval2
        return start1 < end2 and start2 < end1

    def schedule_rcpsp(self, precedence: Dict[str, List[str]],
                      method: str = "serial_sgs") -> Tuple[Dict[str, datetime], List[ResourceAllocation]]:
        """
        资源受限项目调度 (RCPSP)

        参数:
          precedence: {task_id: [predecessor_ids]}
          method: 调度方法 ("serial_sgs", "parallel_sgs")

        返回:
          (schedule, allocations)
        """
        if method == "serial_sgs":
            return self._serial_sgs(precedence)
        else:
            return self._parallel_sgs(precedence)

    def _serial_sgs(self, precedence: Dict[str, List[str]]) -> Tuple[Dict[str, datetime], List[ResourceAllocation]]:
        """串行调度生成方案"""
        schedule = {}
        allocations = []
        scheduled = set()

        # 复制资源可用性
        resource_available = {
            r_id: resource.capacity
            for r_id, resource in self.resources.items()
        }

        # 时间轴
        current_time = datetime.now()
        time_events = []  # (time, task_id, 'start'/'end')

        # 按优先级排序任务
        task_list = sorted(
            self.tasks.items(),
            key=lambda x: x[1].priority,
            reverse=True
        )

        while len(scheduled) < len(self.tasks):
            # 处理时间事件（释放资源）
            while time_events and time_events[0][0] <= current_time:
                event_time, task_id, event_type = heapq.heappop(time_events)

                if event_type == 'end':
                    # 释放资源
                    task = self.tasks[task_id]
                    for res_id, amount in task.resource_requirements.items():
                        resource_available[res_id] += amount

            # 可调度任务集
            eligible = []

            for task_id, task in task_list:
                if task_id in scheduled:
                    continue

                # 检查前序任务
                preds = precedence.get(task_id, [])
                if not all(p in scheduled for p in preds):
                    continue

                # 检查资源可用性
                resources_ok = all(
                    resource_available[res_id] >= amount
                    for res_id, amount in task.resource_requirements.items()
                )

                if resources_ok:
                    eligible.append((task_id, task))

            if eligible:
                # 调度第一个符合条件的任务
                task_id, task = eligible[0]

                # 最早开始时间
                earliest_start = current_time

                # 考虑前序任务
                preds = precedence.get(task_id, [])
                if preds:
                    pred_ends = [
                        schedule[p] + self.tasks[p].duration
                        for p in preds
                    ]
                    earliest_start = max([current_time] + pred_ends)

                # 调度任务
                schedule[task_id] = earliest_start
                scheduled.add(task_id)

                # 分配资源
                for res_id, amount in task.resource_requirements.items():
                    resource_available[res_id] -= amount

                    allocations.append(ResourceAllocation(
                        task_id=task_id,
                        resource_id=res_id,
                        amount=amount,
                        start_time=earliest_start,
                        end_time=earliest_start + task.duration
                    ))

                # 添加结束事件
                heapq.heappush(
                    time_events,
                    (earliest_start + task.duration, task_id, 'end')
                )
            else:
                # 推进时间到下一个事件
                if time_events:
                    current_time = time_events[0][0]
                else:
                    break

        return schedule, allocations

    def identify_bottleneck(self, schedule: Dict[str, datetime],
                           allocations: List[ResourceAllocation]) -> Dict[str, float]:
        """
        识别瓶颈资源

        返回:
          {resource_id: utilization}
        """
        # 计算每个资源的总使用时间
        resource_usage = {r_id: timedelta(0) for r_id in self.resources}

        for alloc in allocations:
            duration = alloc.end_time - alloc.start_time
            resource_usage[alloc.resource_id] += duration

        # 计算项目总时长
        if not schedule:
            return {}

        project_start = min(schedule.values())
        project_end = max(
            schedule[t_id] + self.tasks[t_id].duration
            for t_id in schedule
        )
        project_duration = project_end - project_start

        # 计算利用率
        utilization = {}
        for res_id, usage in resource_usage.items():
            util = (usage.total_seconds() / project_duration.total_seconds() * 100
                   if project_duration.total_seconds() > 0 else 0)
            utilization[res_id] = round(util, 2)

        return dict(sorted(utilization.items(), key=lambda x: x[1], reverse=True))

    def balance_load(self, schedule: Dict[str, datetime],
                    allocations: List[ResourceAllocation]) -> Dict:
        """
        计算负载均衡指标

        返回:
          balance_metrics
        """
        # 计算每个资源的负载
        resource_loads = {}

        for alloc in allocations:
            duration_hours = (alloc.end_time - alloc.start_time).total_seconds() / 3600
            load = alloc.amount * duration_hours

            if alloc.resource_id not in resource_loads:
                resource_loads[alloc.resource_id] = 0
            resource_loads[alloc.resource_id] += load

        loads = list(resource_loads.values())

        if not loads:
            return {}

        max_load = max(loads)
        avg_load = sum(loads) / len(loads)

        variance = sum((load - avg_load) ** 2 for load in loads) / len(loads)
        std_dev = variance ** 0.5

        balance_index = 1 - (std_dev / avg_load) if avg_load > 0 else 1

        return {
            'max_load': round(max_load, 2),
            'min_load': round(min(loads), 2),
            'avg_load': round(avg_load, 2),
            'std_dev': round(std_dev, 2),
            'balance_index': round(balance_index, 4),
            'resource_loads': {r_id: round(load, 2) for r_id, load in resource_loads.items()}
        }

```

## 📊 应用场景

### 场景1: 生产车间调度

```python
# 定义资源
resources = {
    'machine1': Resource(id='machine1', type=ResourceType.DISCRETE, capacity=1, cost_per_unit=100),
    'machine2': Resource(id='machine2', type=ResourceType.DISCRETE, capacity=1, cost_per_unit=100),
    'worker': Resource(id='worker', type=ResourceType.DISCRETE, capacity=5, cost_per_unit=50),
}

# 定义任务
tasks = {
    'task1': Task(
        id='task1',
        duration=timedelta(hours=2),
        resource_requirements={'machine1': 1, 'worker': 2},
        priority=10
    ),
    'task2': Task(
        id='task2',
        duration=timedelta(hours=3),
        resource_requirements={'machine2': 1, 'worker': 1},
        priority=8
    ),
    'task3': Task(
        id='task3',
        duration=timedelta(hours=1),
        resource_requirements={'machine1': 1, 'worker': 1},
        predecessors=['task1'],
        priority=9
    ),
}

# 前序关系
precedence = {
    'task3': ['task1']
}

handler = ResourceCapacityConstraintHandler(resources, tasks)

# RCPSP调度
schedule, allocations = handler.schedule_rcpsp(precedence)

# 识别瓶颈
bottlenecks = handler.identify_bottleneck(schedule, allocations)
print("资源利用率:", bottlenecks)

# 负载均衡
balance = handler.balance_load(schedule, allocations)
print("负载均衡指标:", balance)
```

### 资源池化

```python
class ResourcePool:
    """资源池管理"""

    def __init__(self, resources: List[Resource]):
        self.resources = resources
        self.pool_capacity = sum(r.capacity for r in resources)

    def allocate(self, amount: float) -> List[Tuple[str, float]]:
        """从资源池分配"""
        allocations = []
        remaining = amount

        for resource in self.resources:
            if remaining <= 0:
                break

            available = resource.available
            allocated = min(available, remaining)

            if allocated > 0:
                allocations.append((resource.id, allocated))
                resource.available -= allocated
                remaining -= allocated

        return allocations
```
