### 适配器基类设计

**BaseModelAdapter接口规范**:

```python
from abc import ABC, abstractmethod
from typing import List, Dict, Any, Optional, AsyncIterator
from pydantic import BaseModel

class ModelResponse(BaseModel):
    content: str
    tokens_used: int
    cost: float
    model: str
    finish_reason: str

class BaseModelAdapter(ABC):
    """所有模型适配器的抽象基类"""

    def __init__(self, config: ModelConfig):
        self.config = config
        self.logger = structlog.get_logger(adapter=self.__class__.__name__)

    @abstractmethod
    async def chat(
        self,
        messages: List[Dict[str, str]],
        **kwargs
    ) -> ModelResponse:
        """发送聊天消息，返回响应"""
        pass

    @abstractmethod
    async def chat_stream(
        self,
        messages: List[Dict[str, str]],
        **kwargs
    ) -> AsyncIterator[str]:
        """流式聊天，yield每个token"""
        pass

    @abstractmethod
    async def health_check(self) -> bool:
        """检查模型服务是否可用"""
        pass

    def calculate_cost(self, tokens: int) -> float:
        """根据token数量计算成本"""
        # 每个适配器可以重写此方法
        pass
```

### 模型工厂和注册表设计

**ModelFactory实现**:

```python
from typing import Dict, Type
import threading

class ModelFactory:
    """模型适配器工厂，支持动态注册和热切换"""

    _registry: Dict[str, Type[BaseModelAdapter]] = {}
    _active_models: Dict[str, BaseModelAdapter] = {}
    _lock = threading.Lock()

    @classmethod
    def register(cls, provider: str, adapter_class: Type[BaseModelAdapter]):
        """注册适配器类"""
        cls._registry[provider] = adapter_class

    @classmethod
    async def create_adapter(cls, config: ModelConfig) -> BaseModelAdapter:
        """根据配置创建适配器实例"""
        adapter_class = cls._registry.get(config.provider)
        if not adapter_class:
            raise ValueError(f"Unknown provider: {config.provider}")
        return adapter_class(config)

    @classmethod
    async def switch_model(cls, new_config: ModelConfig):
        """热切换模型，线程安全"""
        with cls._lock:
            adapter = await cls.create_adapter(new_config)
            # 健康检查
            if not await adapter.health_check():
                raise RuntimeError(f"Model {new_config.name} health check failed")
            # 缓存新模型
            cls._active_models[new_config.name] = adapter
```

### 错误处理和重试机制

**使用tenacity实现重试**:

```python
from tenacity import (
    retry,
    stop_after_attempt,
    wait_exponential,
    retry_if_exception_type
)
import httpx

@retry(
    stop=stop_after_attempt(3),
    wait=wait_exponential(multiplier=1, min=2, max=10),
    retry=retry_if_exception_type((httpx.TimeoutException, httpx.NetworkError))
)
async def call_model_api(url: str, data: dict) -> dict:
    async with httpx.AsyncClient(timeout=30.0) as client:
        response = await client.post(url, json=data)
        response.raise_for_status()
        return response.json()
```

### 特别注意事项

**重要约束**:

1. **向后兼容性**: 必须兼容现有LangGraph工作流，不能破坏Story 1.2已实现的功能
2. **线程安全**: 模型切换必须是线程安全的，避免并发问题
3. **性能**: 适配器调用开销应<50ms，不影响整体工作流性能
4. **错误隔离**: 单个模型失败不应影响其他模型的可用性

### 🔴 高优先级问题

#### 1. 安全：固定Salt存在安全风险

**位置**: backend/app/core/crypto.py:33

```python
salt=b"bmad-method-salt",  # ❌ 固定salt，应该随机生成
```

**问题**: 固定salt降低了加密强度，相同明文会产生相同密文。

**建议修复**:

```python
# 生成随机salt并与密文一起存储
import os
salt = os.urandom(16)
# 存储时: encrypted_data = base64.b64encode(salt + encrypted_bytes)
# 解密时: salt = encrypted_data[:16], ciphertext = encrypted_data[16:]
```

**影响**: 中等安全风险，生产环境必须修复

---

#### 2. 并发：配置加载器缺少线程安全

**位置**: backend/model_adapters/config_loader.py:246-258

```python
_config_loader: Optional[ModelConfigLoader] = None

def get_config_loader() -> ModelConfigLoader:
    global _config_loader
    if _config_loader is None:  # ❌ 无锁保护，存在竞态条件
        _config_loader = ModelConfigLoader()
    return _config_loader
```

**问题**: 在高并发下可能创建多个实例。

**建议修复**:

```python
import threading
_config_loader: Optional[ModelConfigLoader] = None
_loader_lock = threading.Lock()

def get_config_loader() -> ModelConfigLoader:
    global _config_loader
    if _config_loader is None:
        with _loader_lock:
            if _config_loader is None:  # 双重检查锁
                _config_loader = ModelConfigLoader()
    return _config_loader
```
