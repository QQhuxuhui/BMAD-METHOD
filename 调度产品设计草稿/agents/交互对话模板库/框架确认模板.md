## 触发场景

**触发时机**: Phase 1.5，增量确认模式(模式B)下的TenElementModel框架确认

**前置条件**:

- ✅ 用户已选择增量确认模式(模式B)
- ✅ 需求分析已完成
- ✅ TenElementModel框架级信息已提取

**目的**:

- 快速确认问题的整体框架和结构
- 仅确认类型、数量、名称等高层信息
- 不涉及具体参数值的确认（留待各专家增量确认）
- 为后续4个专家的增量确认建立基础

def process_decision_variables_response(user_input: str, variables: dict) -> dict:
    """处理决策变量框架确认的用户响应"""

    if user_input == "1":
        # 确认分析
        variables["confirmed"] = True
        return {"action": "next_question", "field": "constraints"}

    elif user_input == "2":
        # 增加变量
        return {
            "action": "add_variable",
            "prompt": "请描述需要增加的决策变量:"
        }

    elif user_input == "3":
        # 删除变量
        return {
            "action": "remove_variable",
            "prompt": f"请选择要删除的变量编号 (1-{len(variables['list'])}):"
        }

    elif user_input == "4":
        # 修改变量
        return {
            "action": "modify_variable",
            "prompt": "请选择要修改的变量编号:"
        }

    elif user_input == "5":
        # 查看说明
        return {
            "action": "show_explanation",
            "content": generate_variable_type_explanation()
        }

    elif user_input == "6":
        # 举例说明
        return {
            "action": "provide_examples",
            "content": generate_variable_examples(variables)
        }

    elif user_input == "7":
        # 同类问题
        return {
            "action": "show_similar_cases",
            "content": query_similar_problem_variables()
        }

    elif user_input == "8":
        # 重新分析
        return {
            "action": "regenerate",
            "content": regenerate_variable_analysis()
        }

    elif user_input == "9":
        # 其他问题
        return {
            "action": "open_question",
            "prompt": "请描述您的具体问题或想法:"
        }
