## 核心原理

### 理论基础

粒子群算法（Particle Swarm Optimization, PSO）由Kennedy和Eberhart于1995年提出，模拟鸟群觅食行为。

**核心思想**：

- **群体智能**: 每个粒子在搜索空间中飞行，通过个体经验和群体经验调整方向
- **个体学习**: 粒子向自己历史最优位置移动
- **社会学习**: 粒子向群体最优位置移动
- **惯性保持**: 保持之前的运动趋势

**关键概念**：

- **粒子（Particle）**: 搜索空间中的一个候选解
- **位置（Position）**: 粒子当前的解向量
- **速度（Velocity）**: 粒子的移动方向和速率
- **个体最优（pbest）**: 粒子自身历史最优位置
- **全局最优（gbest）**: 整个群体历史最优位置

### 核心机制

**工作流程**：

1. **初始化**: 随机生成粒子位置和速度
2. **评估**: 计算每个粒子的适应度
3. **更新个体最优**: 更新pbest
4. **更新全局最优**: 更新gbest
5. **速度更新**: 根据pbest和gbest调整速度
6. **位置更新**: 根据速度移动粒子
7. **迭代**: 重复2-6直到满足终止条件

**速度和位置更新公式**：

```
v[i] = w * v[i] + c1 * rand() * (pbest[i] - x[i]) + c2 * rand() * (gbest - x[i])
x[i] = x[i] + v[i]

其中:
w: 惯性权重
c1: 个体学习因子
c2: 社会学习因子
rand(): [0,1]随机数
```

## 实现框架

### 算法伪代码

```python
def particle_swarm_optimization(problem, config):
    """
    粒子群算法主函数

    参数:
        problem: 优化问题定义
        config: 算法配置

    返回:
        best_solution: 全局最优解
        convergence_curve: 收敛曲线
    """
    # 1. 初始化粒子群
    particles = initialize_swarm(config.swarm_size, problem.dimension)
    velocities = initialize_velocities(config.swarm_size, problem.dimension)

    # 2. 评估初始适应度
    fitness = evaluate_swarm(particles, problem)

    # 3. 初始化个体最优和全局最优
    pbest = particles.copy()
    pbest_fitness = fitness.copy()
    gbest = particles[argmax(fitness)]
    gbest_fitness = max(fitness)

    convergence_curve = []

    # 4. 主循环
    for iteration in range(config.max_iterations):

        # 5. 更新惯性权重（线性递减）
        w = config.w_max - (config.w_max - config.w_min) * iteration / config.max_iterations

        # 6. 更新每个粒子
        for i in range(config.swarm_size):

            # 7. 更新速度
            velocities[i] = (
                w * velocities[i] +
                config.c1 * random() * (pbest[i] - particles[i]) +
                config.c2 * random() * (gbest - particles[i])
            )

            # 8. 速度限制
            velocities[i] = clip(velocities[i], -config.v_max, config.v_max)

            # 9. 更新位置
            particles[i] = particles[i] + velocities[i]

            # 10. 边界处理
            particles[i] = clip(particles[i], problem.lower_bound, problem.upper_bound)

        # 11. 评估新位置
        fitness = evaluate_swarm(particles, problem)

        # 12. 更新个体最优
        for i in range(config.swarm_size):
            if fitness[i] > pbest_fitness[i]:
                pbest[i] = particles[i].copy()
                pbest_fitness[i] = fitness[i]

        # 13. 更新全局最优
        current_best_idx = argmax(fitness)
        if fitness[current_best_idx] > gbest_fitness:
            gbest = particles[current_best_idx].copy()
            gbest_fitness = fitness[current_best_idx]

        # 14. 记录收敛历史
        convergence_curve.append(gbest_fitness)

        # 15. 检查终止条件
        if termination_condition(convergence_curve, config):
            break

    return gbest, convergence_curve
```

### 参数配置指南

| 参数名称       | 推荐范围 | 默认值   | 影响说明                         |
| -------------- | -------- | -------- | -------------------------------- |
| swarm_size     | 20-100   | 40       | 粒子数量，影响探索能力和计算成本 |
| max_iterations | 100-1000 | 500      | 最大迭代次数                     |
| w_max          | 0.9      | 0.9      | 初始惯性权重，控制全局探索       |
| w_min          | 0.4      | 0.4      | 最终惯性权重，控制局部搜索       |
| c1             | 1.5-2.5  | 2.0      | 个体学习因子                     |
| c2             | 1.5-2.5  | 2.0      | 社会学习因子                     |
| v_max          | 问题相关 | 0.2×范围 | 最大速度限制                     |

**参数调优建议**：

- **惯性权重策略**:
  - 线性递减：`w = w_max - (w_max - w_min) * t / T`
  - 非线性递减：`w = w_min + (w_max - w_min) * exp(-t/T)`

- **学习因子平衡**:
  - c1 > c2: 强调个体经验，探索性强
  - c1 < c2: 强调群体经验，收敛快
  - c1 = c2 = 2.0: 平衡设置（常用）

### 实现注意事项

1. **速度限制**: 必须限制速度以防止粒子飞出搜索空间
2. **边界处理**: 位置超出边界时的处理策略
3. **拓扑结构**: 全连接、环形、星形等不同邻域结构
4. **参数自适应**: 根据收敛状态动态调整参数
