## 推荐效果统计

在每个阶段结束后，可以统计推荐效果：

```python
# 统计用户是否采纳推荐
interactions = phase.user_interactions

recommendation_stats = {
    "total": len(interactions),
    "followed": 0,
    "not_followed": 0
}

for interaction in interactions:
    if interaction['parsed_result'].get('recommendation_followed'):
        recommendation_stats['followed'] += 1
    else:
        recommendation_stats['not_followed'] += 1

print(f"推荐采纳率: {recommendation_stats['followed'] / recommendation_stats['total'] * 100:.1f}%")
```
