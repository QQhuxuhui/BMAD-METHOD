## 🎨 视觉意境描述（投喂 flow 平台 · 敞开想象）

> **整体氛围**
>
> 全场最硬的"**证据墙**"——任务是用 60 秒让评委彻底放心："**这套创新真的成立、真的落地、真的被权威认可**"。
>
> 画面信息密度全场最高，但通过**三段式分层**消化：① 数据墙（看成效）→ ② 专利卡片（看壁垒）→ ③ 案例双栏（看落地）→ 顶部国赛背书（看权威）。每一段独占一带、视觉重量递增——评委的眼睛**层层下沉**，每下一层都收一份新证据。
>
> 整页气质是**铁证如山的克制自信**：白底依然主导，但通过结构化的网格布局让"信息量"本身变成视觉重量——**不靠装饰，靠密度**。
>
> **页眉**
>
> 主标题「**创新验证 · 专利 + 成效 + 落地**」深墨灰加粗大字、居中。副标题「**4 项发明专利已申请 · 集团真实业务落地 · 国家级赛事获奖**」中灰偏小——一句话三段式预告下方三层证据。

## 💡 关键设计决策

| 决策                                    | 理由                                                                                                                              |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 三层信息墙（数字 / 专利 / 案例 + 国赛） | 层次递进：看成效 → 看壁垒 → 看落地 → 看背书——每一层回答一个评委疑问                                                               |
| 6 宫格全部集团真实数据                  | 每个数字都能追溯到集团内部可验证的来源（昆明机场项目 + 调度智能体技术指标 + 组织沉淀），评委追问不怕翻车                          |
| 4 专利用编号 ①②③④                       | 不是 4 个孤立创新，而是**一套组合拳 / 技术壁垒矩阵**——编号制造"成套护城河"的感觉                                                  |
| 每专利配一句话标签                      | 60 秒讲不完 4 个专利——**标签 = 差异化记忆点**                                                                                     |
| 昆明机场打头阵                          | 数据最全、规模最大（500 台、↓27%、↑60%）——作为主案例                                                                              |
| 徐州项目辅阵                            | 地域关联性强（徐州 = 徐工总部），评委觉得"自家地盘也在用"——**情感共鸣 + 信任度**强                                                |
| 国赛获奖独占底部高亮带                  | 国家级二等奖是**比专利更即时、更有冲击力**的权威背书——独占一带不能淹没在案例里                                                    |
| 专利状态写"已提交申请"                  | 与实情一致——写"已授权"被评委问到细节容易翻车；"已提交"同样体现创新保护动作，稳妥                                                  |
| 与 P3 数据墙协同（非重复）              | P3 讲"架构级能力"（Token / 维护效率 / 复用率）；P8 讲"落地规模 + 技术工程 + 组织沉淀"——两页不同维度互补，评委在不同页拿到不同证据 |

## 🎨 样式说明

**整体风格**：白色系商务正式 · 低密度高留白 · 强理性弱装饰

**配色规范**

| 用途     | 色值      | 用法                     |
| -------- | --------- | ------------------------ |
| 背景     | `#FFFFFF` | 纯白 · 全场统一          |
| 主文字   | `#1A202C` | 深墨灰 · 标题 / 正文     |
| 副文字   | `#4A5568` | 中灰 · 副标题 / 注释     |
| 强调色   | `#1A365D` | 深蓝 · 关键词 / 数字亮点 |
| 分割线   | `#E2E8F0` | 浅灰 · 1px 细线          |
| 警示色   | `#C53030` | 砖红 · 传统方案的负面点  |
| 收益色   | `#2F855A` | 墨绿 · 正面成效          |
| 点缀金色 | `#D69E2E` | 仅用于 🏆 国赛图标       |

**字体规范**

- 中文：思源黑体 / 微软雅黑（兜底）
- 英文 & 数字：Inter / Helvetica Neue（兜底）
- 主标题：大字号 · 加粗 · 深墨灰
- 副标题：次级字号 · 细体 · 中灰
- 数字亮点：超大字号 · 加粗 · 深蓝

**版式规范**

- 每页四角留白 ≥ 5%
- **克制使用 emoji**：保留功能性标识，删除装饰性表情；优先线框 icon（Feather / Tabler Icons 风格）
- 分隔元素：1px 浅灰细线，避免厚重底纹
- 对齐：统一居中或左对齐，避免混用

**文案语言规范**

- **除专业术语外，全文必须使用中文**（含标题、正文、讲词、图示注释、注脚）
