## 核心原理

### 理论基础

#### 算法起源与发展

模拟退火算法（Simulated Annealing, SA）由Kirkpatrick、Gelatt和Vecchi于1983年在Science杂志上提出，灵感来源于固体物理中金属退火的过程。

**物理退火过程**：

1. **加热**：将金属加热到高温，原子活动剧烈
2. **缓慢冷却**：温度逐渐降低，原子逐步稳定到低能量状态
3. **结晶**：最终形成规则的晶体结构（能量最低状态）

**映射到优化问题**：

- **温度** → 控制参数T
- **原子状态** → 解
- **能量** → 目标函数值
- **退火过程** → 优化搜索过程

**发展历程**：

- **1983**: Kirkpatrick等提出模拟退火算法
- **1985**: Černý独立提出类似算法
- **1987**: Metropolis准则的理论分析
- **1990s**: 自适应降温策略、并行模拟退火
- **2000s**: 与其他算法的混合策略

#### 核心思想

模拟退火算法的核心思想是**概率性接受劣解以跳出局部最优**：

**关键机制**：

1. **温度控制**
   - 高温阶段：高概率接受劣解，全局探索
   - 低温阶段：低概率接受劣解，局部精细搜索
   - 温度从高到低逐步下降

2. **Metropolis准则**

   ```
   接受概率 P(ΔE, T) = {
       1,                    if ΔE ≤ 0  (更优解)
       exp(-ΔE/T),          if ΔE > 0  (劣解)
   }

   其中：
   ΔE = f(新解) - f(当前解)  (最小化问题)
   T = 当前温度
   ```

3. **平衡探索与利用**
   - 高温 → 探索为主（接受劣解概率高）
   - 低温 → 利用为主（接受劣解概率低）
   - 温度控制平衡策略

**与爬山法的对比**：

| 维度     | 爬山法       | 模拟退火         |
| -------- | ------------ | ---------------- |
| 接受策略 | 只接受改进解 | 概率接受劣解     |
| 局部最优 | 易陷入       | 可跳出           |
| 搜索方式 | 单调上升     | 随机游走+趋势    |
| 理论保证 | 无           | 无穷时间全局最优 |
| 计算时间 | 快           | 较慢             |

#### 数学理论基础

**1. Metropolis准则的推导**

来自统计力学中的Boltzmann分布：

```
P(状态s) = (1/Z) × exp(-E(s) / kT)

其中：
E(s): 状态s的能量
k: Boltzmann常数
T: 温度
Z: 配分函数（归一化常数）
```

接受概率比：

```
P(s2) / P(s1) = exp(-(E(s2) - E(s1)) / kT)
                = exp(-ΔE / kT)
```

**2. 收敛性理论**

**定理（Hajek, 1988）**：
如果降温足够慢（对数降温），模拟退火算法以概率1收敛到全局最优解。

**对数降温条件**：

```
T(k) ≥ d / log(2 + k)

其中：
d: 问题相关常数（与能量障碍深度有关）
k: 迭代次数
```

**实际意义**：

- 理论上保证全局收敛
- 实际中对数降温太慢，通常使用几何降温
- 实践中折衷：合理的降温速度 + 足够的迭代次数

**3. 接受概率分析**

对于最小化问题，当新解更差时（ΔE > 0）：

```
P_accept = exp(-ΔE / T)

示例：
温度T=100, ΔE=10 → P=exp(-10/100)=0.905 (90.5%接受)
温度T=10,  ΔE=10 → P=exp(-10/10)=0.368  (36.8%接受)
温度T=1,   ΔE=10 → P=exp(-10/1)=0.000045 (0.0045%接受)
```

**观察**：

- 温度越高，接受劣解概率越大
- 温度降低，搜索逐渐向局部搜索转变
- ΔE越大（解越差），接受概率越低

#### 关键概念定义

**1. 温度调度（Temperature Schedule）**

温度如何随时间变化的策略。

**几何降温（最常用）**：

```
T(k+1) = α × T(k)

其中：
α ∈ (0, 1): 降温系数
典型值：0.85 - 0.99
```

**对数降温（理论最优）**：

```
T(k) = T0 / log(1 + k)
```

**线性降温**：

```
T(k) = T0 - k × ΔT
```

**指数降温**：

```
T(k) = T0 × α^k
```

**自适应降温**：

```
根据搜索效果动态调整α
```

**2. 内循环长度（Markov Chain Length）**

每个温度下的迭代次数L，确保在该温度下达到平衡。

**常见策略**：

- 固定长度：L = 常数（如100）
- 问题规模相关：L = c × n（c为常数，n为问题规模）
- 自适应：根据接受率调整

**3. 初始温度（Initial Temperature）**

初始温度T0的选择影响算法性能。

**估计方法**：

**方法1：接受率法**

```python
def estimate_T0(target_accept_rate=0.8):
    """
    根据目标接受率估计初始温度

    目标：80%的劣解被接受
    """
    # 随机采样邻域解，统计平均能量差
    delta_E_samples = []
    for _ in range(100):
        s1 = random_solution()
        s2 = neighbor(s1)
        delta_E_samples.append(abs(f(s2) - f(s1)))

    avg_delta_E = mean(delta_E_samples)

    # 求解: exp(-avg_delta_E / T0) = 0.8
    T0 = -avg_delta_E / log(0.8)
    return T0
```

**方法2：经验公式**

```
T0 = 0.1 × (最大目标值 - 最小目标值)
```

**4. 终止条件（Termination Criteria）**

常见终止条件：

| 终止类型 | 条件                  | 说明           |
| -------- | --------------------- | -------------- |
| 温度阈值 | T < T_min             | 温度降到最低值 |
| 迭代次数 | 迭代次数 ≥ max_iter   | 达到最大迭代   |
| 收敛判断 | 连续k次无改进         | 解质量不再提升 |
| 时间限制 | 运行时间 ≥ time_limit | 计算时间约束   |
| 目标达成 | f(best) ≤ target      | 达到满意解     |

```python
# Swap邻域
def swap_neighbor(solution):
    """交换两个元素"""
    s = solution.copy()
    i, j = random.sample(range(len(s)), 2)
    s[i], s[j] = s[j], s[i]
    return s

# Insert邻域
def insert_neighbor(solution):
    """移动一个元素到新位置"""
    s = solution.copy()
    i = random.randint(0, len(s)-1)
    j = random.randint(0, len(s)-1)
    element = s.pop(i)
    s.insert(j, element)
    return s

# 2-opt邻域（TSP专用）
def two_opt_neighbor(tour):
    """反转子路径"""
    n = len(tour)
    i, j = sorted(random.sample(range(n), 2))
    new_tour = tour[:i] + tour[i:j+1][::-1] + tour[j+1:]
    return new_tour
```

```python
def gaussian_neighbor(solution, sigma):
    """高斯扰动"""
    neighbor = solution + np.random.normal(0, sigma, len(solution))

def uniform_neighbor(solution, radius):
    """均匀扰动"""
    neighbor = solution + np.random.uniform(-radius, radius, len(solution))
```

#### 2. 接受准则实现

```python
def acceptance_criterion(current_energy, new_energy, temperature):
    """
    Metropolis接受准则

    参数:
        current_energy: 当前解的能量（目标值）
        new_energy: 新解的能量
        temperature: 当前温度

    返回:
        bool: 是否接受新解
    """
    # 最小化问题
    delta_E = new_energy - current_energy

    # 更优解，直接接受
    if delta_E <= 0:
        return True

    # 劣解，概率接受
    acceptance_prob = math.exp(-delta_E / temperature)
    return random.random() < acceptance_prob
```

**变种接受准则**：

```python
# 阈值接受（Threshold Accepting）
def threshold_acceptance(delta_E, threshold):
    """只要在阈值内就接受"""
    return delta_E <= threshold

# Record-to-Record Travel
def record_to_record(new_energy, best_energy, deviation):
    """在最优解的一定范围内都接受"""
    return new_energy <= best_energy + deviation

# Great Deluge
def great_deluge(new_energy, water_level):
    """只接受优于"水位"的解"""
    return new_energy <= water_level
```

#### 3. 降温策略详解

**策略1：几何降温（最常用）**

```python
def geometric_cooling(T, alpha=0.95):
    """
    几何降温

    优点：简单、有效
    缺点：需要调参alpha
    """
    return alpha * T
```

**策略2：自适应降温**

```python
def adaptive_cooling(T, accept_rate, target_rate=0.4):
    """
    根据接受率自适应调整

    如果接受率太高 → 降温快一点
    如果接受率太低 → 降温慢一点
    """
    if accept_rate > target_rate:
        alpha = 0.95  # 降温快
    else:
        alpha = 0.99  # 降温慢

    return alpha * T
```

**策略3：Lundy-Mees降温**

```python
def lundy_mees_cooling(T, beta=0.01):
    """
    Lundy-Mees降温策略

    T(k+1) = T(k) / (1 + beta * T(k))

    特点：初期降温快，后期降温慢
    """
    return T / (1 + beta * T)
```

**策略4：重加温（Reheating）**

```python
def reheating_strategy(T, iterations_since_improve, threshold=100):
    """
    如果长时间无改进，重新加温

    目的：跳出可能的局部最优区域
    """
    if iterations_since_improve > threshold:
        return T * 2.0  # 温度加倍
    else:
        return T * 0.95  # 正常降温
```

## 实现框架

### 算法1：标准模拟退火

```python
import random
import math
import copy
from typing import Callable, Any, Tuple, List

class SimulatedAnnealing:
    """
    标准模拟退火算法

    算法特点：
    - 单点搜索策略
    - 概率接受劣解
    - 温度控制的平衡机制
    - 理论保证全局收敛（无穷时间）

    适用场景：
    - 组合优化问题
    - 离散优化
    - 连续优化（配合合适邻域）
    - 需要避免局部最优的问题
    """

    def __init__(self, config: dict = None):
        """
        初始化模拟退火算法

        参数:
            config: 算法配置
                - T0: 初始温度
                - T_min: 终止温度
                - alpha: 降温系数（几何降温）
                - L: 每温度迭代次数（内循环长度）
                - cooling_schedule: 降温策略
                - verbose: 是否输出详细信息
        """
        self.config = config or {}
        self.T0 = self.config.get('T0', 100.0)
        self.T_min = self.config.get('T_min', 0.01)
        self.alpha = self.config.get('alpha', 0.95)
        self.L = self.config.get('L', 100)
        self.cooling_schedule = self.config.get('cooling_schedule', 'geometric')
        self.verbose = self.config.get('verbose', False)

        # 记录搜索历史
        self.best_solution = None
        self.best_energy = float('inf')
        self.temperature_history = []
        self.energy_history = []
        self.acceptance_history = []

    def run(self,
            initial_solution: Any,
            energy_function: Callable[[Any], float],
            neighbor_function: Callable[[Any], Any],
            max_iterations: int = None) -> Tuple[Any, float, dict]:
        """
        执行模拟退火算法

        参数:
            initial_solution: 初始解
            energy_function: 能量函数（目标函数）
            neighbor_function: 邻域生成函数
            max_iterations: 最大迭代次数（可选）

        返回:
            (best_solution, best_energy, info)
        """
        # 初始化
        current_solution = copy.deepcopy(initial_solution)
        current_energy = energy_function(current_solution)

        self.best_solution = copy.deepcopy(current_solution)
        self.best_energy = current_energy

        T = self.T0
        iteration = 0
        total_iterations = 0

        if self.verbose:
            print(f"模拟退火算法启动")
            print(f"初始温度: {self.T0:.2f}")
            print(f"初始能量: {current_energy:.4f}")
            print(f"降温策略: {self.cooling_schedule}")
            print("=" * 60)

        # 主循环：温度逐步降低
        while T > self.T_min:
            if max_iterations and total_iterations >= max_iterations:
                break

            iteration += 1
            accepts_at_T = 0
            attempts_at_T = 0

            # 内循环：在当前温度下迭代
            for _ in range(self.L):
                total_iterations += 1
                attempts_at_T += 1

                # 生成邻域解
                neighbor = neighbor_function(current_solution)
                neighbor_energy = energy_function(neighbor)

                # 计算能量差
                delta_E = neighbor_energy - current_energy

                # Metropolis接受准则
                if self._accept(delta_E, T):
                    current_solution = neighbor
                    current_energy = neighbor_energy
                    accepts_at_T += 1

                    # 更新全局最优
                    if current_energy < self.best_energy:
                        self.best_solution = copy.deepcopy(current_solution)
                        self.best_energy = current_energy

                        if self.verbose:
                            print(f"温度 {T:.2f} | 迭代 {total_iterations} | "
                                  f"新最优: {self.best_energy:.4f}")

            # 记录历史
            accept_rate = accepts_at_T / attempts_at_T
            self.temperature_history.append((iteration, T))
            self.energy_history.append((iteration, self.best_energy))
            self.acceptance_history.append((iteration, accept_rate))

            if self.verbose and iteration % 10 == 0:
                print(f"温度 {T:.4f} | 接受率 {accept_rate:.2%} | "
                      f"当前最优 {self.best_energy:.4f}")

            # 降温
            T = self._cool_down(T, accept_rate)

        info = {
            'iterations': total_iterations,
            'temperature_iterations': iteration,
            'final_temperature': T,
            'temperature_history': self.temperature_history,
            'energy_history': self.energy_history,
            'acceptance_history': self.acceptance_history,
            'improvement': energy_function(initial_solution) - self.best_energy
        }

        if self.verbose:
            print("=" * 60)
            print(f"模拟退火完成")
            print(f"总迭代次数: {total_iterations}")
            print(f"最终温度: {T:.4f}")
            print(f"最优能量: {self.best_energy:.4f}")
            print(f"改进量: {info['improvement']:.4f}")

        return self.best_solution, self.best_energy, info

    def _accept(self, delta_E: float, temperature: float) -> bool:
        """
        Metropolis接受准则

        参数:
            delta_E: 能量差
            temperature: 当前温度

        返回:
            是否接受新解
        """
        # 更优解，直接接受
        if delta_E <= 0:
            return True

        # 劣解，概率接受
        acceptance_prob = math.exp(-delta_E / temperature)
        return random.random() < acceptance_prob

    def _cool_down(self, T: float, accept_rate: float = None) -> float:
        """
        降温函数

        参数:
            T: 当前温度
            accept_rate: 当前接受率（用于自适应策略）

        返回:
            新温度
        """
        if self.cooling_schedule == 'geometric':
            return self.alpha * T

        elif self.cooling_schedule == 'logarithmic':
            # 对数降温（理论最优，但很慢）
            k = len(self.temperature_history) + 1
            return self.T0 / math.log(1 + k)

        elif self.cooling_schedule == 'linear':
            # 线性降温
            delta_T = (self.T0 - self.T_min) / 100  # 假设100步
            return max(T - delta_T, self.T_min)

        elif self.cooling_schedule == 'adaptive':
            # 自适应降温
            if accept_rate is not None:
                if accept_rate > 0.5:
                    alpha = 0.90  # 接受率高，降温快
                elif accept_rate > 0.3:
                    alpha = 0.95  # 中等接受率
                else:
                    alpha = 0.98  # 接受率低，降温慢
                return alpha * T
            else:
                return self.alpha * T

        elif self.cooling_schedule == 'lundy-mees':
            # Lundy-Mees降温
            beta = 0.01
            return T / (1 + beta * T)

        else:
            # 默认几何降温
            return self.alpha * T


def estimate_initial_temperature(
    sample_solution_generator: Callable[[], Any],
    neighbor_function: Callable[[Any], Any],
    energy_function: Callable[[Any], float],
    target_accept_rate: float = 0.8,
    num_samples: int = 100
) -> float:
    """
    估计合适的初始温度

    方法：根据目标接受率估计

    参数:
        sample_solution_generator: 随机解生成函数
        neighbor_function: 邻域函数
        energy_function: 能量函数
        target_accept_rate: 目标接受率
        num_samples: 采样数量

    返回:
        估计的初始温度
    """
    delta_E_samples = []

    for _ in range(num_samples):
        s1 = sample_solution_generator()
        s2 = neighbor_function(s1)

        e1 = energy_function(s1)
        e2 = energy_function(s2)

        delta_E = abs(e2 - e1)
        if delta_E > 0:
            delta_E_samples.append(delta_E)

    if not delta_E_samples:
        return 100.0  # 默认值

    avg_delta_E = sum(delta_E_samples) / len(delta_E_samples)

    # 求解: exp(-avg_delta_E / T0) = target_accept_rate
    # T0 = -avg_delta_E / ln(target_accept_rate)
    T0 = -avg_delta_E / math.log(target_accept_rate)

    return T0
```

### 算法2：自适应模拟退火

```python
class AdaptiveSimulatedAnnealing(SimulatedAnnealing):
    """
    自适应模拟退火算法

    增强特性：
    - 自适应降温速率
    - 根据搜索效果调整参数
    - 重加温机制
    """

    def __init__(self, config: dict = None):
        super().__init__(config)
        self.reheating_enabled = self.config.get('reheating', True)
        self.reheating_threshold = self.config.get('reheating_threshold', 100)
        self.iterations_since_improve = 0

    def run(self,
            initial_solution: Any,
            energy_function: Callable[[Any], float],
            neighbor_function: Callable[[Any], Any],
            max_iterations: int = None) -> Tuple[Any, float, dict]:
        """
        执行自适应模拟退火
        """
        current_solution = copy.deepcopy(initial_solution)
        current_energy = energy_function(current_solution)

        self.best_solution = copy.deepcopy(current_solution)
        self.best_energy = current_energy

        T = self.T0
        iteration = 0
        total_iterations = 0

        while T > self.T_min:
            if max_iterations and total_iterations >= max_iterations:
                break

            iteration += 1
            accepts = 0
            attempts = 0
            improved_this_temp = False

            for _ in range(self.L):
                total_iterations += 1
                attempts += 1

                neighbor = neighbor_function(current_solution)
                neighbor_energy = energy_function(neighbor)
                delta_E = neighbor_energy - current_energy

                if self._accept(delta_E, T):
                    current_solution = neighbor
                    current_energy = neighbor_energy
                    accepts += 1

                    if current_energy < self.best_energy:
                        self.best_solution = copy.deepcopy(current_solution)
                        self.best_energy = current_energy
                        self.iterations_since_improve = 0
                        improved_this_temp = True
                    else:
                        self.iterations_since_improve += 1

            accept_rate = accepts / attempts

            # 重加温机制
            if (self.reheating_enabled and
                self.iterations_since_improve > self.reheating_threshold):
                T = T * 2.0  # 温度加倍
                self.iterations_since_improve = 0
                if self.verbose:
                    print(f"重加温: T = {T:.2f}")
            else:
                # 自适应降温
                T = self._adaptive_cooling(T, accept_rate, improved_this_temp)

            self.temperature_history.append((iteration, T))
            self.energy_history.append((iteration, self.best_energy))
            self.acceptance_history.append((iteration, accept_rate))

        info = {
            'iterations': total_iterations,
            'final_temperature': T,
            'temperature_history': self.temperature_history,
            'energy_history': self.energy_history
        }

        return self.best_solution, self.best_energy, info

    def _adaptive_cooling(self, T: float, accept_rate: float, improved: bool) -> float:
        """
        自适应降温策略

        根据接受率和改进情况动态调整降温速度
        """
        if improved:
            # 有改进，降温慢一点
            alpha = 0.97
        elif accept_rate > 0.5:
            # 接受率高，降温快
            alpha = 0.90
        elif accept_rate > 0.3:
            # 中等接受率
            alpha = 0.95
        else:
            # 接受率低，降温慢
            alpha = 0.98

        return alpha * T
```

```python
def tsp_energy(tour, distance_matrix):

    for i in range(len(tour)):
        from_city = tour[i]
        to_city = tour[(i + 1) % len(tour)]
        total_distance += distance_matrix[from_city][to_city]
    return total_distance

def tsp_2opt_neighbor(tour):
```

### 案例2：Flowshop调度优化

**场景描述**：
某电子厂生产线有15个产品需要经过5台机器加工。每台机器按相同顺序处理所有产品。目标是最小化makespan（最大完工时间）。

**问题建模**：

```yaml
决策变量:
  - job_sequence: 作业加工顺序

约束条件:
  - 流水车间约束：所有作业相同加工顺序
  - 机器约束：每台机器同时只处理一个作业

目标函数:
  - minimize: makespan
```

**实施方案**：

```python
# 1. 问题数据
processing_times = np.random.randint(5, 20, size=(15, 5))  # 15作业×5机器

# 2. makespan计算
def calculate_makespan(sequence, proc_times):
    """计算流水车间makespan"""
    n_jobs = len(sequence)
    n_machines = proc_times.shape[1]

    completion = np.zeros((n_jobs, n_machines))

    # 第一个作业
    completion[0, 0] = proc_times[sequence[0], 0]
    for j in range(1, n_machines):
        completion[0, j] = completion[0, j-1] + proc_times[sequence[0], j]

    # 后续作业
    for i in range(1, n_jobs):
        job = sequence[i]
        completion[i, 0] = completion[i-1, 0] + proc_times[job, 0]

        for j in range(1, n_machines):
            completion[i, j] = max(completion[i, j-1], completion[i-1, j]) + proc_times[job, j]

    return completion[n_jobs-1, n_machines-1]

# 3. 邻域：Swap操作
def flowshop_swap_neighbor(sequence):
    """交换两个作业"""
    new_seq = sequence.copy()
    i, j = random.sample(range(len(sequence)), 2)
    new_seq[i], new_seq[j] = new_seq[j], new_seq[i]
    return new_seq

# 4. 初始解：NEH算法
def neh_initial(proc_times):
    """NEH启发式生成初始解"""
    n_jobs = proc_times.shape[0]

    # 按总加工时间降序排序
    total_times = proc_times.sum(axis=1)
    sorted_jobs = np.argsort(-total_times)

    sequence = [sorted_jobs[0], sorted_jobs[1]]

    # 逐个插入
    for k in range(2, n_jobs):
        job = sorted_jobs[k]
        best_pos = 0
        best_makespan = float('inf')

        for pos in range(len(sequence) + 1):
            temp_seq = sequence[:pos] + [job] + sequence[pos:]
            makespan = calculate_makespan(temp_seq, proc_times)
            if makespan < best_makespan:
                best_makespan = makespan
                best_pos = pos

        sequence = sequence[:best_pos] + [job] + sequence[best_pos:]

    return sequence

# 5. 应用模拟退火
def solve_flowshop_with_sa():
    """使用模拟退火求解Flowshop"""

    # 生成初始解
    initial_seq = neh_initial(processing_times)
    initial_makespan = calculate_makespan(initial_seq, processing_times)

    print(f"初始解（NEH）：makespan = {initial_makespan}")

    # 配置自适应模拟退火
    sa = AdaptiveSimulatedAnnealing(config={
        'T0': 50.0,
        'T_min': 0.01,
        'alpha': 0.95,
        'L': 150,
        'reheating': True,
        'reheating_threshold': 200,
        'verbose': False
    })

    # 执行优化
    best_seq, best_makespan, info = sa.run(
        initial_solution=initial_seq,
        energy_function=lambda seq: calculate_makespan(seq, processing_times),
        neighbor_function=flowshop_swap_neighbor,
        max_iterations=20000
    )

    # 结果
    improvement = initial_makespan - best_makespan
    improvement_pct = (improvement / initial_makespan) * 100

    print(f"\n{'='*60}")
    print(f"Flowshop模拟退火优化结果")
    print(f"{'='*60}")
    print(f"问题规模: 15作业 × 5机器")
    print(f"初始makespan（NEH）: {initial_makespan}")
    print(f"最优makespan（SA）: {best_makespan}")
    print(f"改进量: {improvement} ({improvement_pct:.2f}%)")
    print(f"总迭代次数: {info['iterations']}")
    print(f"{'='*60}")

    return best_seq, best_makespan

# 运行
seq, makespan = solve_flowshop_with_sa()
```

```python
# 1. Rastrigin函数
def rastrigin(x):
    """
    Rastrigin函数

    全局最优: x = (0, 0, ..., 0), f(x) = 0
    特点：高度多峰，局部最优点密集
    """
    n = len(x)
    return 10 * n + sum(x**2 - 10 * np.cos(2 * np.pi * x))

# 2. 连续邻域：高斯扰动
def continuous_neighbor(x, sigma=0.5):
    """高斯扰动邻域"""
    neighbor = x + np.random.normal(0, sigma, len(x))

    # 边界处理
    neighbor = np.clip(neighbor, -5.12, 5.12)

    return neighbor

# 3. 自适应sigma的邻域
class AdaptiveNeighborhood:
    """自适应调整扰动强度"""

    def __init__(self, initial_sigma=1.0, min_sigma=0.01):
        self.sigma = initial_sigma
        self.min_sigma = min_sigma
        self.success_count = 0
        self.attempt_count = 0

    def __call__(self, x):
        return continuous_neighbor(x, self.sigma)

    def update(self, accepted):
        """根据接受情况调整sigma"""
        self.attempt_count += 1
        if accepted:
            self.success_count += 1

        if self.attempt_count >= 100:
            success_rate = self.success_count / self.attempt_count

            if success_rate > 0.5:
                self.sigma *= 0.9  # 接受率高，减小扰动
            elif success_rate < 0.2:
                self.sigma *= 1.1  # 接受率低，增大扰动

            self.sigma = max(self.sigma, self.min_sigma)

            # 重置计数
            self.success_count = 0
            self.attempt_count = 0

# 4. 应用模拟退火
def solve_rastrigin_with_sa(n_dim=10):
    """使用模拟退火优化Rastrigin函数"""

    # 随机初始解
```

## 优势与局限

### 优势

- ✅ **理论保证**：在对数降温下，以概率1收敛到全局最优
- ✅ **参数少**：核心参数只有T0、T_min、α、L四个
- ✅ **实现简单**：算法逻辑清晰，易于编程实现
- ✅ **适应性强**：适用于离散、连续、组合等多种优化问题
- ✅ **避免局部最优**：概率接受劣解机制可跳出局部陷阱
- ✅ **灵活性高**：易于与其他算法结合（如混合SA-TS）
- ✅ **可解释性强**：物理类比使算法行为容易理解

### 局限

- ⚠️ **单点搜索慢**：相比群体智能算法（GA、PSO），收敛速度慢
- ⚠️ **参数敏感**：降温速率、初始温度等参数对性能影响大
- ⚠️ **邻域设计关键**：邻域结构设计不当严重影响效果
- ⚠️ **无并行性**：标准SA是串行算法，难以并行化
- ⚠️ **理论与实践差距**：理论要求对数降温，实践中太慢不可行
- ⚠️ **收敛判断困难**：很难判断何时真正收敛
- ⚠️ **大规模问题效率低**：对于超大规模问题，计算时间过长

**✅ 适合使用的情况**：

   - TSP、VRP、调度问题

### 1. 并行模拟退火（Parallel SA）

**核心思想**：
同时运行多个SA实例，定期交换信息。

**实现**：

```python
class ParallelSimulatedAnnealing:
    """并行模拟退火"""

    def __init__(self, num_threads=4, config=None):
        self.num_threads = num_threads
        self.sa_instances = [
            SimulatedAnnealing(config) for _ in range(num_threads)
        ]

    def run(self, initial_solutions, energy_function, neighbor_function):
        """
        并行运行多个SA

        策略：
        - 每个线程独立SA
        - 定期交换最优解
        - 返回全局最优
        """
        import concurrent.futures

        best_overall = None
        best_energy = float('inf')

        with concurrent.futures.ThreadPoolExecutor(max_workers=self.num_threads) as executor:
            futures = []

            for i, sa in enumerate(self.sa_instances):
                future = executor.submit(
                    sa.run,
                    initial_solutions[i],
                    energy_function,
                    neighbor_function
                )
                futures.append(future)

            # 收集结果
            for future in concurrent.futures.as_completed(futures):
                solution, energy, _ = future.result()
                if energy < best_energy:
                    best_overall = solution
                    best_energy = energy

        return best_overall, best_energy
```

**优势**：

- 利用多核CPU加速
- 多个起点增加找到全局最优的概率

```python
    策略：
    - 破坏：随机移除部分解
```

### 4. 量子模拟退火（Quantum SA）

**核心思想**：
引入量子隧穿效应，增强跳出局部最优的能力。

```python
def quantum_tunneling_probability(delta_E, T, gamma):
    """
    量子隧穿概率

    gamma: 量子参数，控制隧穿强度
    """
    classical_prob = math.exp(-delta_E / T)

    # 量子增强：即使能量差大，也有隧穿概率
    quantum_prob = math.exp(-delta_E / (T + gamma * abs(delta_E)))

    return max(classical_prob, quantum_prob)
```

### 5. 多目标模拟退火（Multi-Objective SA）

**核心思想**：
处理多个目标函数的优化。

```python
def multi_objective_sa(initial, objectives):
    """
    多目标模拟退火

    策略：
    - 加权和方法
    - Pareto支配关系
    """
    def weighted_energy(solution):
        """加权多目标函数"""
        values = [obj(solution) for obj in objectives]
        weights = [1/len(objectives)] * len(objectives)
        return sum(w * v for w, v in zip(weights, values))

    # 使用加权能量函数运行SA
    return standard_sa(initial, weighted_energy)
```

```python
模拟退火算法实现
V4.0代码生成模板
"""

from abc import ABC, abstractmethod
from typing import Callable, Any, Tuple, List
import copy
import math
import random

class SimulatedAnnealingBase(ABC):
    """
    模拟退火基类

    定义统一接口
    """

    def __init__(self, config: dict = None):
        """
        初始化

        参数:
            config: 配置字典
                - T0: 初始温度
                - T_min: 终止温度
                - alpha: 降温系数
                - L: 内循环长度
                - cooling_schedule: 降温策略
                - verbose: 详细输出
        """
        self.config = config or {}
        self.T0 = self.config.get('T0', 100.0)
        self.T_min = self.config.get('T_min', 0.01)
        self.alpha = self.config.get('alpha', 0.95)
        self.L = self.config.get('L', 100)
        self.verbose = self.config.get('verbose', False)

        self.best_solution = None
        self.best_energy = float('inf')
        self.temperature_history = []
        self.energy_history = []

    @abstractmethod
    def run(self,
            initial_solution: Any,
            energy_function: Callable[[Any], float],
            neighbor_function: Callable[[Any], Any],
            **kwargs) -> Tuple[Any, float, dict]:
        """
        执行模拟退火（抽象方法）

        参数:
            initial_solution: 初始解
            energy_function: 能量函数
            neighbor_function: 邻域函数

        返回:
            (best_solution, best_energy, info)
        """
        pass

    def _accept(self, delta_E: float, temperature: float) -> bool:
        """Metropolis准则"""
        if delta_E <= 0:
            return True

        if temperature < 1e-10:
            return False

        exponent = -delta_E / temperature
        if exponent < -700:
            return False

        return random.random() < math.exp(exponent)

    def _cool_down(self, T: float) -> float:
        """降温函数"""
        return self.alpha * T
```

```python
# 快速SA原型

def quick_sa(
    initial_solution,
    energy_func,
    neighbor_func,
    T0=100.0,
    alpha=0.95,
    max_iter=10000
):
    """
    快速模拟退火原型

    用于快速测试
    """
    current = initial_solution
    best = current
    current_energy = energy_func(current)
    best_energy = current_energy

    T = T0

    for iteration in range(max_iter):
        if T < 0.01:
            break

        neighbor = neighbor_func(current)
        neighbor_energy = energy_func(neighbor)
        delta_E = neighbor_energy - current_energy

        if delta_E <= 0 or random.random() < math.exp(-delta_E / T):
            current = neighbor
            current_energy = neighbor_energy

            if current_energy < best_energy:
                best = current
                best_energy = current_energy

        if iteration % 100 == 0:
            T *= alpha

    return best, best_energy
```
