# 交互对话模板: 方案确认

**模板ID**: `solution-approval-template`
**版本**: V4.3
**触发级别**: P0 (强制确认)
**用途**: Phase 3 Step 3.4 - 用户确认完整方案，批准进入代码生成阶段

---

## 🎯 确认目标

在代码生成之前，向用户展示完整的调度优化方案，确保用户理解并同意所有关键决策。

## 📋 展示内容

### 1. 方案概览

```markdown

- **方案文档**: `{solution_document_path}`

1. ✅ 问题定义与建模（基于TenElementModel）
```

## 💬 确认对话流程

### 步骤1: 初始展示

```markdown
我已经为您准备好了完整的调度优化方案。在开始代码生成之前，我需要您确认以下内容：

1. **方案文档位置**: `{solution_document_path}`
2. **方案包含**: 6个核心章节（问题定义、领域适配、约束策略、目标策略、算法选择、实现路线图）
3. **一致性验证**: ✓ 通过

请问您希望：

**A.** 直接查看关键决策点并确认
**B.** 先浏览完整的方案文档
**C.** 我有问题需要了解
```

### 步骤2: 展示关键决策（如选择A）

```markdown
好的，让我为您展示5个关键决策点：

[展示上述"关键决策点"部分]

请问您对这些关键决策有什么疑问或修改意见吗？
```

### 步骤3: 收集用户反馈

```markdown
针对您的问题/意见：{user_question}

[AI回答或说明]

请问还有其他需要调整的地方吗？
```

### 步骤4: 最终确认

```markdown
## ✅ 方案确认

感谢您的审查！让我总结一下确认情况：

### 已确认的内容

✓ 算法选择: {algorithm_name}
✓ 约束处理方式: 硬约束-{hard_method}, 软约束-{soft_method}
✓ 多目标优化: {multi_obj_approach}，权重-{weights}
✓ 领域适配: {industry_name}领域特征
✓ 算法参数: {parameters_summary}
✓ 实现路线图: 4阶段开发计划

### 用户反馈

{user_feedback_summary}

### 下一步

确认后，我将：

1. 固化此方案（生成方案快照）
2. 基于此方案生成可执行代码
3. 所有代码都将标注对应的方案依据

**请最终确认**:

□ **我确认批准此方案，可以开始代码生成**
□ 我需要进一步修改（请说明修改意见）
```

确认后，输出以下内容：

```yaml
outputs:
  user_approved_solution:
    type: object
    description: 用户确认后的方案（可能包含修改）
    content: ${integrated_solution}
    approval_status: 'approved'
    approved_at: ${timestamp}

    type: object
    description: 用户反馈意见
```

## 💡 交互技巧

1. **先总后详**: 先展示概览，再深入细节
2. **关注关键**: 重点展示影响代码的关键决策
3. **提供选择**: 让用户选择查看方式（快速/详细）
4. **及时响应**: 对用户问题立即给予清晰回答
5. **可追溯**: 每个决策都标注来源
6. **可修改**: 明确告知修改机制
