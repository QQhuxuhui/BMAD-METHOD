## 📖 约束概述

### 定义

**时序依赖约束**（Precedence Constraint）规定任务之间的先后顺序关系，确保前序任务完成后才能开始后续任务。

**数学定义**：

```
对于任务对 (i, j)，其中 j 依赖于 i
定义:
  S_i: 任务 i 的开始时间
  C_i: 任务 i 的完成时间
  p_i: 任务 i 的处理时间

基本关系: C_i = S_i + p_i
```

### 约束类型

#### 1. **完成-开始** (Finish-to-Start, FS)

最常见的依赖类型，前任务完成后才能开始后任务。

```
FS(i, j, lag): S_j ≥ C_i + lag

例如:
  "墙体砌筑" 完成后才能 "墙面粉刷"
  FS(砌筑, 粉刷, 24h) → 砌筑完成后等待24小时才能粉刷
```

#### 2. **开始-开始** (Start-to-Start, SS)

两个任务必须同时或按一定间隔开始。

```
SS(i, j, lag): S_j ≥ S_i + lag

例如:
  "地基浇筑" 开始2小时后 "钢筋绑扎" 可以开始
  SS(浇筑, 绑扎, 2h)
```

#### 3. **完成-完成** (Finish-to-Finish, FF)

两个任务必须同时或按一定间隔完成。

```
FF(i, j, lag): C_j ≥ C_i + lag

例如:
  "质检" 必须在 "生产" 完成后才能完成
  FF(生产, 质检, 0h)
```

#### 4. **开始-完成** (Start-to-Finish, SF)

较少使用，后任务的完成依赖于前任务的开始。

```
SF(i, j, lag): C_j ≥ S_i + lag

例如:
  "夜班" 完成依赖于 "白班" 开始
  SF(白班, 夜班, 0h)
```

## 💡 核心理论

### 拓扑排序 (Topological Sort)

**用途**：验证依赖图无环，生成合法的任务执行顺序。

**算法**：

```python
def topological_sort(tasks, dependencies):
    """
    Kahn's Algorithm for Topological Sorting

    时间复杂度: O(V + E)
    空间复杂度: O(V)

    参数:
      tasks: 任务列表
      dependencies: {task_j: [task_i1, task_i2, ...]}

    返回:
      sorted_tasks: 拓扑有序的任务列表
      或 None (如果存在环)
    """
    # 计算入度
    in_degree = {task: 0 for task in tasks}
    for task_j, predecessors in dependencies.items():
        in_degree[task_j] = len(predecessors)

    # 初始化队列（入度为0的任务）
    queue = [task for task in tasks if in_degree[task] == 0]
    sorted_tasks = []

    while queue:
        task_i = queue.pop(0)
        sorted_tasks.append(task_i)

        # 更新后继任务的入度
        for task_j in get_successors(task_i):
            in_degree[task_j] -= 1
            if in_degree[task_j] == 0:
                queue.append(task_j)

    # 检测环
    if len(sorted_tasks) != len(tasks):
        return None  # 存在环

    return sorted_tasks
```

### 关键路径法 (Critical Path Method, CPM)

**用途**：识别项目中的关键任务链，优化项目工期。

**核心概念**：

```
ES (Earliest Start): 最早开始时间
EF (Earliest Finish): 最早完成时间
LS (Latest Start): 最晚开始时间
LF (Latest Finish): 最晚完成时间
TF (Total Float): 总浮动时间 = LS - ES = LF - EF

关键路径: TF = 0 的任务链
项目工期: max(EF_i) for all tasks i
```

**计算算法**：

```python
def calculate_critical_path(tasks, dependencies):
    """
    计算关键路径

    步骤:
      1. 正向计算 ES, EF
      2. 反向计算 LS, LF
      3. 计算浮动时间 TF
      4. 识别关键路径 (TF = 0)
    """
    # 正向遍历
    for task in topological_order:
        if not predecessors[task]:
            ES[task] = 0
        else:
            ES[task] = max(EF[pred] + lag(pred, task)
                          for pred in predecessors[task])
        EF[task] = ES[task] + duration[task]

    # 项目工期
    project_duration = max(EF.values())

    # 反向遍历
    for task in reversed(topological_order):
        if not successors[task]:
            LF[task] = project_duration
        else:
            LF[task] = min(LS[succ] - lag(task, succ)
                          for succ in successors[task])
        LS[task] = LF[task] - duration[task]

    # 计算浮动时间
    TF = {task: LS[task] - ES[task] for task in tasks}

    # 关键路径
    critical_tasks = [task for task in tasks if TF[task] == 0]

    return critical_tasks, project_duration, TF
```

## 🔧 代码实现

```python
from typing import Dict, List, Tuple, Set, Optional
from dataclasses import dataclass
from datetime import datetime, timedelta
from enum import Enum
import heapq

class DependencyType(Enum):
    """依赖类型"""
    FINISH_TO_START = "FS"
    START_TO_START = "SS"
    FINISH_TO_FINISH = "FF"
    START_TO_FINISH = "SF"

@dataclass
class Dependency:
    """依赖关系定义"""
    predecessor: str  # 前序任务ID
    successor: str    # 后继任务ID
    type: DependencyType
    lag: timedelta = timedelta(0)  # 延迟时间（可为负数）

@dataclass
class Task:
    """任务定义"""
    id: str
    duration: timedelta
    earliest_start: Optional[datetime] = None
    earliest_finish: Optional[datetime] = None
    latest_start: Optional[datetime] = None
    latest_finish: Optional[datetime] = None
    total_float: Optional[timedelta] = None

class PrecedenceConstraintHandler:
    """时序依赖约束处理器"""

    def __init__(self, tasks: Dict[str, Task],
                 dependencies: List[Dependency]):
        """
        参数:
          tasks: {task_id: Task}
          dependencies: 依赖关系列表
        """
        self.tasks = tasks
        self.dependencies = dependencies
        self._build_graph()

    def _build_graph(self):
        """构建依赖图"""
        self.predecessors = {task_id: [] for task_id in self.tasks}
        self.successors = {task_id: [] for task_id in self.tasks}

        for dep in self.dependencies:
            self.predecessors[dep.successor].append(dep)
            self.successors[dep.predecessor].append(dep)

    def validate(self, schedule: Dict[str, datetime]) -> Tuple[bool, List[Dict]]:
        """
        验证调度是否满足时序依赖约束

        参数:
          schedule: {task_id: start_time}

        返回:
          (is_valid, violations)
        """
        violations = []

        for dep in self.dependencies:
            pred_task = self.tasks[dep.predecessor]
            succ_task = self.tasks[dep.successor]

            pred_start = schedule.get(dep.predecessor)
            succ_start = schedule.get(dep.successor)

            if not pred_start or not succ_start:
                continue

            pred_finish = pred_start + pred_task.duration
            succ_finish = succ_start + succ_task.duration

            # 检查依赖类型
            violation = None

            if dep.type == DependencyType.FINISH_TO_START:
                # S_j >= C_i + lag
                required_start = pred_finish + dep.lag
                if succ_start < required_start:
                    gap = (required_start - succ_start).total_seconds() / 3600
                    violation = {
                        'type': 'FS_violation',
                        'predecessor': dep.predecessor,
                        'successor': dep.successor,
                        'required_start': required_start,
                        'actual_start': succ_start,
                        'gap_hours': gap,
                        'penalty': gap * 10
                    }

            elif dep.type == DependencyType.START_TO_START:
                # S_j >= S_i + lag
                required_start = pred_start + dep.lag
                if succ_start < required_start:
                    gap = (required_start - succ_start).total_seconds() / 3600
                    violation = {
                        'type': 'SS_violation',
                        'predecessor': dep.predecessor,
                        'successor': dep.successor,
                        'gap_hours': gap,
                        'penalty': gap * 10
                    }

            elif dep.type == DependencyType.FINISH_TO_FINISH:
                # C_j >= C_i + lag
                required_finish = pred_finish + dep.lag
                if succ_finish < required_finish:
                    gap = (required_finish - succ_finish).total_seconds() / 3600
                    violation = {
                        'type': 'FF_violation',
                        'predecessor': dep.predecessor,
                        'successor': dep.successor,
                        'gap_hours': gap,
                        'penalty': gap * 10
                    }

            elif dep.type == DependencyType.START_TO_FINISH:
                # C_j >= S_i + lag
                required_finish = pred_start + dep.lag
                if succ_finish < required_finish:
                    gap = (required_finish - succ_finish).total_seconds() / 3600
                    violation = {
                        'type': 'SF_violation',
                        'predecessor': dep.predecessor,
                        'successor': dep.successor,
                        'gap_hours': gap,
                        'penalty': gap * 10
                    }

            if violation:
                violations.append(violation)

        return len(violations) == 0, violations

    def topological_sort(self) -> Optional[List[str]]:
        """
        拓扑排序 - Kahn's Algorithm

        返回:
          sorted_tasks: 拓扑有序的任务列表
          或 None (如果存在环)
        """
        # 计算入度
        in_degree = {task_id: 0 for task_id in self.tasks}
        for dep in self.dependencies:
            in_degree[dep.successor] += 1

        # 初始化队列
        queue = [task_id for task_id, degree in in_degree.items() if degree == 0]
        sorted_tasks = []

        while queue:
            task_id = queue.pop(0)
            sorted_tasks.append(task_id)

            # 更新后继任务的入度
            for dep in self.successors.get(task_id, []):
                in_degree[dep.successor] -= 1
                if in_degree[dep.successor] == 0:
                    queue.append(dep.successor)

        # 检测环
        if len(sorted_tasks) != len(self.tasks):
            return None  # 存在环

        return sorted_tasks

    def calculate_critical_path(self,
                                project_start: datetime) -> Tuple[List[str], datetime, Dict[str, timedelta]]:
        """
        计算关键路径

        参数:
          project_start: 项目开始时间

        返回:
          (critical_tasks, project_end, total_float)
        """
        # 拓扑排序
        topo_order = self.topological_sort()
        if not topo_order:
            raise ValueError("依赖图存在环，无法计算关键路径")

        # 正向计算 ES, EF
        for task_id in topo_order:
            task = self.tasks[task_id]

            if not self.predecessors[task_id]:
                # 起始任务
                task.earliest_start = project_start
            else:
                # 计算所有前序任务约束下的最早开始时间
                earliest_starts = []

                for dep in self.predecessors[task_id]:
                    pred_task = self.tasks[dep.predecessor]

                    if dep.type == DependencyType.FINISH_TO_START:
                        earliest_starts.append(pred_task.earliest_finish + dep.lag)
                    elif dep.type == DependencyType.START_TO_START:
                        earliest_starts.append(pred_task.earliest_start + dep.lag)
                    elif dep.type == DependencyType.FINISH_TO_FINISH:
                        # FF约束下的开始时间
                        earliest_starts.append(pred_task.earliest_finish + dep.lag - task.duration)
                    elif dep.type == DependencyType.START_TO_FINISH:
                        earliest_starts.append(pred_task.earliest_start + dep.lag - task.duration)

                task.earliest_start = max(earliest_starts)

            task.earliest_finish = task.earliest_start + task.duration

        # 项目结束时间
        project_end = max(task.earliest_finish for task in self.tasks.values())

        # 反向计算 LS, LF
        for task_id in reversed(topo_order):
            task = self.tasks[task_id]

            if not self.successors[task_id]:
                # 终止任务
                task.latest_finish = project_end
            else:
                # 计算所有后继任务约束下的最晚完成时间
                latest_finishes = []

                for dep in self.successors[task_id]:
                    succ_task = self.tasks[dep.successor]

                    if dep.type == DependencyType.FINISH_TO_START:
                        latest_finishes.append(succ_task.latest_start - dep.lag)
                    elif dep.type == DependencyType.START_TO_START:
                        latest_finishes.append(succ_task.latest_start - dep.lag + task.duration)
                    elif dep.type == DependencyType.FINISH_TO_FINISH:
                        latest_finishes.append(succ_task.latest_finish - dep.lag)
                    elif dep.type == DependencyType.START_TO_FINISH:
                        latest_finishes.append(succ_task.latest_finish - dep.lag + task.duration)

                task.latest_finish = min(latest_finishes)

            task.latest_start = task.latest_finish - task.duration

        # 计算浮动时间
        total_float = {}
        critical_tasks = []

        for task_id, task in self.tasks.items():
            tf = task.latest_start - task.earliest_start
            task.total_float = tf
            total_float[task_id] = tf

            # 关键任务 (TF = 0)
            if tf == timedelta(0):
                critical_tasks.append(task_id)

        return critical_tasks, project_end, total_float

    def detect_cycles(self) -> List[List[str]]:
        """
        检测依赖环

        返回:
          cycles: 环路列表
        """
        cycles = []
        visited = set()
        rec_stack = set()

        def dfs(task_id, path):
            visited.add(task_id)
            rec_stack.add(task_id)
            path.append(task_id)

            for dep in self.successors.get(task_id, []):
                succ_id = dep.successor

                if succ_id not in visited:
                    dfs(succ_id, path)
                elif succ_id in rec_stack:
                    # 找到环
                    cycle_start = path.index(succ_id)
                    cycle = path[cycle_start:] + [succ_id]
                    cycles.append(cycle)

            path.pop()
            rec_stack.remove(task_id)

        for task_id in self.tasks:
            if task_id not in visited:
                dfs(task_id, [])

        return cycles

    def repair(self, schedule: Dict[str, datetime],
               violations: List[Dict]) -> Dict[str, datetime]:
        """
        修复时序依赖违反

        策略:
          1. 拓扑排序生成合法顺序
          2. 按拓扑顺序重新安排任务
          3. 确保所有依赖关系满足
        """
        topo_order = self.topological_sort()
        if not topo_order:
            raise ValueError("依赖图存在环，无法修复")

        repaired = {}

        for task_id in topo_order:
            task = self.tasks[task_id]

            if not self.predecessors[task_id]:
                # 起始任务，保持原始时间
                repaired[task_id] = schedule.get(task_id, datetime.now())
            else:
                # 根据前序任务计算最早开始时间
                earliest_starts = []

                for dep in self.predecessors[task_id]:
                    pred_start = repaired[dep.predecessor]
                    pred_task = self.tasks[dep.predecessor]
                    pred_finish = pred_start + pred_task.duration

                    if dep.type == DependencyType.FINISH_TO_START:
                        earliest_starts.append(pred_finish + dep.lag)
                    elif dep.type == DependencyType.START_TO_START:
                        earliest_starts.append(pred_start + dep.lag)
                    # ... 其他类型类似

                repaired[task_id] = max(earliest_starts)

        return repaired

```

## 📊 应用场景

### 场景1: 项目管理 - PERT/CPM

```python
# 定义项目任务
tasks = {
    'A': Task(id='A', duration=timedelta(days=3)),  # 需求分析
    'B': Task(id='B', duration=timedelta(days=5)),  # 设计
    'C': Task(id='C', duration=timedelta(days=8)),  # 开发
    'D': Task(id='D', duration=timedelta(days=2)),  # 测试
    'E': Task(id='E', duration=timedelta(days=1)),  # 部署
}

# 定义依赖关系
dependencies = [
    Dependency('A', 'B', DependencyType.FINISH_TO_START),  # 分析完成后才能设计
    Dependency('B', 'C', DependencyType.FINISH_TO_START),  # 设计完成后才能开发
    Dependency('C', 'D', DependencyType.FINISH_TO_START, timedelta(days=1)),  # 开发完成1天后测试
    Dependency('D', 'E', DependencyType.FINISH_TO_START),  # 测试完成后部署
]

handler = PrecedenceConstraintHandler(tasks, dependencies)

# 计算关键路径
project_start = datetime(2025, 1, 1, 9, 0)
critical_tasks, project_end, total_float = handler.calculate_critical_path(project_start)

print(f"关键路径: {' → '.join(critical_tasks)}")
print(f"项目工期: {(project_end - project_start).days} 天")

for task_id, tf in total_float.items():
    print(f"任务 {task_id} 浮动时间: {tf.days} 天")
```

## 🎯 性能优化

### 拓扑排序优化

```python
def parallel_topological_sort(self) -> List[List[str]]:
    """
    并行拓扑排序 - 识别可并行执行的任务层

    返回:
      layers: [[task1, task2], [task3], [task4, task5]]
              每一层的任务可以并行执行
    """
    in_degree = {task_id: 0 for task_id in self.tasks}
    for dep in self.dependencies:
        in_degree[dep.successor] += 1

    layers = []
    current_layer = [task_id for task_id, degree in in_degree.items() if degree == 0]

    while current_layer:
        layers.append(current_layer)
        next_layer = []

        for task_id in current_layer:
            for dep in self.successors.get(task_id, []):
                in_degree[dep.successor] -= 1
                if in_degree[dep.successor] == 0:
                    next_layer.append(dep.successor)

        current_layer = next_layer

    return layers
```

### 关键路径缓存

```python
class OptimizedPrecedenceHandler(PrecedenceConstraintHandler):
    """优化版本 - 缓存关键路径计算结果"""

    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self._critical_path_cache = None

    def calculate_critical_path(self, project_start):
        if self._critical_path_cache is None:
            self._critical_path_cache = super().calculate_critical_path(project_start)
        return self._critical_path_cache

    def invalidate_cache(self):
        """依赖关系变更时清除缓存"""
        self._critical_path_cache = None
```
