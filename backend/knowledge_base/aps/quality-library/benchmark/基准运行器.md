# 基准运行器

## 目标

- 在最小合成数据或用户提供用例上，评估运行时间/内存等基础指标。

## 接口

```python
def run_benchmark(code: str, model: dict, options: dict | None) -> dict:
    """返回 {ok: bool, predicted_runtime_ms: int, memory_mb: int, dataset: str, notes: [str]}"""
```

## 最小实现思路

- 利用 `time.perf_counter()` 与小规模随机用例，调用 `solve` 入口评估耗时。
- 产出可选：采样N次的中位数；内存可暂以估算/占位返回。
