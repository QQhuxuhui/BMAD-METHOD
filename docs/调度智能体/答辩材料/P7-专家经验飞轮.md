# P7 · 专家经验飞轮

## 🎯 页面定位

**全场对业务评委最有穿透力的一页**。任务：让评委认同"这东西不是一次性交付，而是越用越值钱的数字资产"——正面回答"可持续性 / 可推广性"这个创新评审维度。

## 💡 关键设计决策

| 决策                                  | 理由                                                                           |
| ------------------------------------- | ------------------------------------------------------------------------------ |
| 圆环飞轮（而非竖向链表）              | "飞轮"这个词本身就是循环概念——圆环图 = 视觉即概念                              |
| 飞轮中心放 "100+ 模板 / 持续增长"     | 不是空中楼阁——这是**已经在转的飞轮**；用"持续增长"而不是静态库数，强调飞轮动势 |
| 四节点命名：沉淀 → 实战 → 优化 → 复用 | 4 个词每个 2 字，极度精简，节奏感强，口语化易记                                |
| 三句话 "过去 / 现在 / 未来" 对仗      | 答辩最强叙事结构——损失感（过去）+ 解药感（现在）+ 想象力（未来）一次打满       |
| ✘ ✓ 🚀 三符号                         | 视觉上建立 "从问题到解药到想象" 的递进                                         |
| 底部金句 "组织的永久资产"             | "永久资产"是业务评委的母语——把技术创新翻译成组织管理语言                       |

## 🎨 样式说明

**整体风格**：白色系商务正式 · 低密度高留白 · 强理性弱装饰

**配色规范**

| 用途     | 色值      | 用法                     |
| -------- | --------- | ------------------------ |
| 背景     | `#FFFFFF` | 纯白 · 全场统一          |
| 主文字   | `#1A202C` | 深墨灰 · 标题 / 正文     |
| 副文字   | `#4A5568` | 中灰 · 副标题 / 注释     |
| 强调色   | `#1A365D` | 深蓝 · 关键词 / 数字亮点 |
| 分割线   | `#E2E8F0` | 浅灰 · 1px 细线          |
| 警示色   | `#C53030` | 砖红 · 传统方案的负面点  |
| 收益色   | `#2F855A` | 墨绿 · 正面成效          |
| 点缀金色 | `#D69E2E` | 仅用于 🏆 国赛图标       |

**字体规范**

- 中文：思源黑体 / 微软雅黑（兜底）
- 英文 & 数字：Inter / Helvetica Neue（兜底）
- 主标题：大字号 · 加粗 · 深墨灰
- 副标题：次级字号 · 细体 · 中灰
- 数字亮点：超大字号 · 加粗 · 深蓝

**版式规范**

- 每页四角留白 ≥ 5%
- **克制使用 emoji**：保留功能性标识，删除装饰性表情；优先线框 icon（Feather / Tabler Icons 风格）
- 分隔元素：1px 浅灰细线，避免厚重底纹
- 对齐：统一居中或左对齐，避免混用

**本页视觉重点（P7 飞轮）**

- **中心圆环**：4 节点**等距分布** · 顺时针箭头流转 · 整体圆形构图（飞轮 = 视觉即概念）
- **中心核**：深蓝实心圆 `#1A365D` + 白字 "100+ 模板 / 持续增长 / 飞轮中心"
- **4 节点圆章**：白底 + 浅蓝边框 + 深蓝编号 ①②③④（圆章样式）· 节点名加粗
- **箭头流转**：浅蓝细实线（1.5px）· 单向箭头 · 表达"转动"感
- **底部三句（过去 / 现在 / 未来）**：
  - **过去**：`✘` 砖红 + 中灰字 "专家离职 = 经验归零"
  - **现在**：`✓` 墨绿 + 深墨灰字 "可 Git 管理的数字资产"
  - **未来**：`→` 深蓝加粗 + 深蓝加粗字 "100+ 模板已沉淀 · 70-85% 可跨场景复用"
- **金句收尾**：大字号（32pt+）· 居中 · 深蓝加粗 · "组织的永久资产"
- **整体构图**：中心飞轮居上，三句话居下，金句压底——三层结构

## 🎤 口头讲词（~60 秒）

> "这一页最想跟业务同仁分享——**专家经验**这件资产的致命问题：**它长在人脑子里，专家一离职就清零**。
>
> 我们用这个飞轮破局：**① 沉淀**（专家经验写入模板）→ **② 实战**（真实业务调用）→ **③ 优化**（持续打磨）→ **④ 复用**（跨场景标准化）——四步一圈，专家库越来越厚。
>
> **到今天已沉淀 100+ 模板，70-85% 可跨场景复用**，新人上手从 3 个月压缩到 2 周。
>
> 一句话——过去专家离职等于经验归零；现在专家经验是**可 Git 管理的数字资产**；未来飞轮越转越快。
>
> **智能体不是替代专家，而是让专家的经验成为组织的永久资产**。"

## ✏️ 可调整项

- **具体数据**（100+ 模板 / 70-85% 复用率）来自产品文档——如有集团内部真实数据可替换
- **飞轮四环节命名**（沉淀→实战→优化→复用）可根据集团习惯用语调整
- **底部金句**的"永久资产"措辞若与集团文化更匹配的表达（如"组织数字资产"），可替换
