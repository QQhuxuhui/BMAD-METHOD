## 核心原理

### 理论基础

禁忌搜索（Tabu Search, TS）由Fred Glover在1986年提出，是一种模拟人类记忆机制的智能优化算法。核心思想是利用禁忌表（Tabu List）记录近期访问过的解或移动，避免搜索过程中的循环，并通过特赦准则（Aspiration Criteria）允许突破禁忌以接受更优解。

**核心思想**：

- **记忆机制**: 使用禁忌表记录近期搜索历史，防止重复访问
- **强制多样性**: 通过禁忌约束迫使搜索探索新区域
- **智能特赦**: 即使在禁忌表中，若发现更优解也可接受
- **局部强化**: 在解空间中进行深度局部搜索

**关键概念**：

- **当前解（Current Solution）**: 搜索过程中的当前位置
- **邻域（Neighborhood）**: 通过移动操作从当前解可达的解集合
- **移动（Move）**: 从一个解转换到另一个解的操作
- **禁忌表（Tabu List）**: 存储近期禁忌移动或解的列表
- **特赦准则（Aspiration Criteria）**: 允许接受禁忌移动的条件
- **禁忌任期（Tabu Tenure）**: 移动或解在禁忌表中保持的迭代次数

### 核心机制

**工作流程**：

1. **初始化**: 生成初始解，设置空禁忌表
2. **邻域生成**: 生成当前解的所有邻域解
3. **候选评估**: 评估邻域中的候选解，考虑禁忌状态
4. **移动选择**: 选择最优非禁忌移动（或满足特赦准则）
5. **禁忌表更新**: 将当前移动加入禁忌表，移除过期记录
6. **多样化**: 检测停滞，触发重启或多样化策略
7. **迭代**: 重复2-6步直到满足终止条件

**三大核心机制**：

1. **禁忌策略**：
   - **基于移动的禁忌**: 禁止特定移动操作（如：交换(i,j)）
   - **基于属性的禁忌**: 禁止产生特定属性的解（如：某个位置的赋值）
   - **基于解的禁忌**: 直接禁止重复访问某些解

2. **特赦准则**：
   - **目标值特赦**: 若移动产生的解优于历史最优，则取消禁忌
   - **频率特赦**: 对长期未访问的移动取消禁忌
   - **多样性特赦**: 为增加多样性而接受某些禁忌移动

3. **多样化与强化**：
   - **强化（Intensification）**: 在有希望的区域深入搜索
   - **多样化（Diversification）**: 探索新的未访问区域
     - 频率记忆：记录移动或属性的使用频率
     - 长期记忆：使用长期未访问的移动
     - 重启机制：从新的随机解重新开始

## 实现框架

### 算法伪代码

```python
def tabu_search(problem, config):
    """
    禁忌搜索主函数

    参数:
        problem: 调度问题定义（目标函数、约束条件、邻域操作）
        config: 算法配置（迭代次数、禁忌表长度、多样化策略）

    返回:
        best_solution: 最优解
        search_history: 搜索历史（收敛曲线、多样化事件）
    """
    # 1. 初始化
    current_solution = generate_initial_solution(problem)
    best_solution = current_solution
    best_fitness = evaluate(best_solution, problem)

    tabu_list = []  # 禁忌表
    tabu_tenure = config.tabu_tenure  # 禁忌任期
    frequency_memory = {}  # 频率记忆
    search_history = []

    no_improve_count = 0  # 无改进计数器

    # 2. 主循环
    for iteration in range(config.max_iterations):

        # 3. 生成候选解邻域
        neighborhood = generate_neighborhood(current_solution, problem)

        # 4. 评估候选解
        candidates = []
        for move, candidate in neighborhood:
            fitness = evaluate(candidate, problem)
            is_tabu = check_tabu(move, tabu_list)

            # 特赦准则：若优于历史最优，取消禁忌
            aspiration = (fitness > best_fitness)

            candidates.append({
                'move': move,
                'solution': candidate,
                'fitness': fitness,
                'is_tabu': is_tabu,
                'aspiration': aspiration
            })

        # 5. 选择最优候选
        # 优先选择非禁忌且最优的，或满足特赦准则的
        candidates.sort(key=lambda x: x['fitness'], reverse=True)

        selected = None
        for cand in candidates:
            if not cand['is_tabu'] or cand['aspiration']:
                selected = cand
                break

        if selected is None:
            # 所有移动都被禁忌且无特赦，选择最优禁忌移动
            selected = candidates[0]

        # 6. 更新当前解
        current_solution = selected['solution']
        current_fitness = selected['fitness']

        # 7. 更新最优解
        if current_fitness > best_fitness:
            best_solution = current_solution
            best_fitness = current_fitness
            no_improve_count = 0
        else:
            no_improve_count += 1

        # 8. 更新禁忌表
        tabu_list.append({
            'move': selected['move'],
            'iteration': iteration,
            'expiry': iteration + tabu_tenure
        })

        # 移除过期的禁忌记录
        tabu_list = [t for t in tabu_list if t['expiry'] > iteration]

        # 9. 更新频率记忆
        move_key = str(selected['move'])
        frequency_memory[move_key] = frequency_memory.get(move_key, 0) + 1

        # 10. 记录搜索历史
        search_history.append({
            'iteration': iteration,
            'current_fitness': current_fitness,
            'best_fitness': best_fitness,
            'tabu_list_size': len(tabu_list)
        })

        # 11. 多样化检测
        if no_improve_count >= config.diversification_threshold:
            # 触发多样化策略
            current_solution = diversify(
                current_solution,
                frequency_memory,
                problem
            )
            no_improve_count = 0
            search_history[-1]['diversification'] = True

        # 12. 强化检测（在有希望的区域深入搜索）
        if should_intensify(search_history, config):
            current_solution = intensify(
                best_solution,
                problem,
                config
            )
            search_history[-1]['intensification'] = True

        # 13. 检查终止条件
        if termination_condition(search_history, config):
            break

    return best_solution, search_history


def check_tabu(move, tabu_list):
    """检查移动是否在禁忌表中"""
    for tabu in tabu_list:
        if moves_equal(move, tabu['move']):
            return True
    return False


def diversify(solution, frequency_memory, problem):
    """多样化策略：倾向使用频率低的移动"""
    # 生成邻域
    neighborhood = generate_neighborhood(solution, problem)

    # 选择频率最低的移动
    best_move = None
    min_frequency = float('inf')

    for move, neighbor in neighborhood:
        freq = frequency_memory.get(str(move), 0)
        if freq < min_frequency:
            min_frequency = freq
            best_move = (move, neighbor)

    return best_move[1] if best_move else solution


def intensify(best_solution, problem, config):
    """强化策略：在最优解附近深入搜索"""
    # 临时进行局部搜索
    current = best_solution
    for _ in range(config.intensification_depth):
        neighborhood = generate_neighborhood(current, problem)
        best_neighbor = max(neighborhood,
                          key=lambda x: evaluate(x[1], problem))
        current = best_neighbor[1]
    return current
```

### 参数配置指南

| 参数名称                  | 推荐范围   | 默认值 | 影响说明                             |
| ------------------------- | ---------- | ------ | ------------------------------------ |
| max_iterations            | 100-10000  | 1000   | 迭代次数，根据问题规模和时间预算调整 |
| tabu_tenure               | 5-20       | 7      | 禁忌任期，过短易循环，过长限制搜索   |
| neighborhood_size         | 20-100     | 50     | 邻域大小，影响搜索质量和速度         |
| diversification_threshold | 20-100     | 50     | 无改进迭代数，触发多样化             |
| intensification_depth     | 10-50      | 20     | 强化搜索深度                         |
| aspiration_enabled        | True/False | True   | 是否启用特赦准则                     |

**参数调优建议**：

- **禁忌任期（Tabu Tenure）**:
  - 小规模问题(<100变量): 5-7
  - 中规模问题(100-500变量): 7-12
  - 大规模问题(>500变量): 12-20
  - **自适应策略**: `tenure = 5 + random(0, 3)` - 每次更新随机变化

- **邻域大小vs计算时间**:
  - 全邻域：质量最优，但耗时（适合小规模）
  - 候选列表：折中方案，只评估部分邻域（常用）
  - 首改策略：找到改进立即接受（快速but质量较低）

- **多样化vs强化平衡**:
  - 搜索初期：少多样化，多强化（快速收敛）
  - 搜索中期：平衡多样化和强化
  - 搜索后期：多多样化，少强化（跳出局部最优）

### 实现注意事项

1. **邻域操作设计**:
   - **交换（Swap）**: 交换两个元素位置
   - **插入（Insert）**: 移动元素到新位置
   - **反转（Reverse）**: 反转子序列
   - **2-opt/3-opt**: 路径问题专用

2. **性能优化点**:
   - **增量评估**: 只计算移动导致的目标值变化
   - **候选列表**: 预先筛选有希望的邻域解
   - **哈希表**: 快速检查禁忌状态（O(1)时间）
   - **并行评估**: 并行评估邻域解

3. **常见错误**:
   - 禁忌任期过短导致频繁循环
   - 邻域操作设计不当，无法到达最优解
   - 忽略特赦准则，错过更优解
   - 缺少多样化机制，陷入局部最优

**场景描述**：
15个工件，每个工件8道工序，共40台机器，目标最小化最大完工时间(Makespan)。

**问题建模**：

```yaml
决策变量: 工序调度序列
约束条件:
  - 工序顺序约束: 每个工件的工序按固定顺序执行
  - 机器容量约束: 每台机器同一时刻只能处理一个工序
目标函数: minimize max(完工时间)
```

**实施方案**：

```python
# 邻域操作: 交换两个工序位置（保持工序顺序约束）
def generate_neighborhood(solution, problem):
    neighborhood = []
    for i in range(len(solution)):
        for j in range(i+1, len(solution)):
            # 检查交换是否保持约束
            if can_swap(solution, i, j, problem):
                neighbor = solution.copy()
                neighbor[i], neighbor[j] = neighbor[j], neighbor[i]
                neighborhood.append(('swap', (i,j)), neighbor)
    return neighborhood

# 禁忌策略: 基于移动的禁忌（禁止交换相同的工序对）
# 禁忌任期: 7（适中值）

# 参数设置
config = {

    'neighborhood_size': 100,  # 候选列表策略

    'aspiration_enabled': True
}

# 多样化策略: 随机重启 + 频率记忆
def diversify(solution, frequency_memory, problem):
```

### 案例2：车辆路径规划（VRP）

**场景描述**：
80个客户配送问题，15辆车，考虑容量约束和距离优化。

**问题建模**：

```yaml
决策变量: 车辆路径分配和访问顺序
约束条件:
  - 容量约束: 每条路径的需求总量 ≤ 车辆容量
  - 访问约束: 每个客户恰好被访问一次
目标函数: minimize Σ(路径总距离)
```

**实施方案**：

```python
# 邻域操作: 组合多种移动
def generate_neighborhood(solution, problem):
    neighborhood = []

    # 1. 2-opt: 路径内优化
    neighborhood.extend(two_opt_moves(solution))

    # 2. Relocate: 客户重定位到不同路径
    neighborhood.extend(relocate_moves(solution))

    # 3. Exchange: 交换两个客户
    neighborhood.extend(exchange_moves(solution))

    # 4. Cross: 交换两条路径的子序列
    neighborhood.extend(cross_moves(solution))

    return neighborhood

# 禁忌策略: 基于属性的禁忌（禁止客户c在路径r中的位置p）
# 禁忌任期: 自适应 5 + random(0, 5)

config = {
    'max_iterations': 5000,
    'tabu_tenure': (5, 10),  # 动态范围
    'neighborhood_size': 200,
    'diversification_threshold': 150,
    'intensification_depth': 30
}

# 特赦准则: 目标值特赦 + 多样性特赦
def aspiration_criteria(move, current_best, diversity_score):
    # 若产生新的历史最优，特赦
    if move.fitness > current_best:
        return True
    # 若多样性得分高，特赦
    if diversity_score > threshold:
```

- **收敛特性**: 3次多样化事件，2次强化事件

## 优势与局限

### 优势

- ✅ **强大的局部搜索能力**: 通过深度邻域搜索快速找到高质量解
- ✅ **有效避免循环**: 禁忌表机制防止搜索重复访问相同区域
- ✅ **灵活的记忆机制**: 短期、中期、长期记忆相结合
- ✅ **智能特赦准则**: 允许接受禁忌但优质的解
- ✅ **参数少易调**: 主要参数只有禁忌任期和迭代次数
- ✅ **实现相对简单**: 比遗传算法等种群算法更易实现

### 局限

- ⚠️ **依赖初始解质量**: 初始解较差时收敛速度慢
  - **应对**: 使用构造式启发式生成高质量初始解

- ⚠️ **邻域设计关键**: 邻域操作不当无法到达最优
  - **应对**: 设计多种互补的邻域操作组合使用

- ⚠️ **停滞风险**: 可能长时间停滞在局部最优区域
  - **应对**: 引入多样化策略和重启机制

- ⚠️ **参数敏感**: 禁忌任期对性能影响显著
  - **应对**: 使用自适应禁忌任期策略

### 适用性判断

**适合使用的情况**：

- 问题规模中大型（>100变量），精确算法不可行
- 解空间离散，邻域操作明确定义
- 需要高质量解but不强求全局最优
- 已有好的初始解或构造启发式

**不适合使用的情况**：

- 问题规模极小（<50变量），精确算法可行
- 解空间连续且光滑，梯度方法更优
- 邻域操作难以定义（如某些黑箱优化）
- 需要多样化解集合（禁忌搜索只返回单个解）

### 变种1：响应阈值禁忌搜索（Reactive Tabu Search）

```python
def reactive_tabu_search(problem, config):
    """响应式禁忌搜索：自适应禁忌任期"""

    tabu_tenure = config.initial_tenure
    repetition_count = 0

    for iteration in range(config.max_iterations):
        # ... 标准禁忌搜索流程 ...

        # 检测重复访问
        if solution_visited_before(current_solution, history):
            repetition_count += 1
            # 增加禁忌任期以增强多样性
            tabu_tenure = min(tabu_tenure + 1, config.max_tenure)
        else:
            repetition_count = 0
            # 减少禁忌任期以增强强化
            if repetition_count == 0:
                tabu_tenure = max(tabu_tenure - 1, config.min_tenure)
```

**适用场景**：无需手工调参的自动优化
**性能提升**：相比固定任期，解质量提升3-5%

```python
def candidate_list_tabu_search(problem, config):

    # 预先构建候选列表（启发式选择）

    best_move = None

           and fitness > best_fitness:

            best_fitness = fitness

    # 定期更新候选列表
    if iteration % config.update_frequency == 0:
        candidate_list = rebuild_candidate_list(...)
```

**适用场景**：大规模问题，全邻域评估耗时

```python
def path_relinking_tabu_search(problem, config):
    """路径重链接：连接精英解"""

    elite_solutions = []  # 存储历史优质解

    # 标准禁忌搜索
    current = tabu_search_phase(problem, config)
    elite_solutions.append(current)

    # 定期执行路径重链接
    if len(elite_solutions) >= 2:
        # 选择两个不同的精英解
        source = elite_solutions[-1]
        target = select_diverse_elite(elite_solutions)

        # 生成从source到target的路径
        path = []
        current = source
        while current != target:
            # 找到最接近target的移动
            move = get_move_toward_target(current, target)
            current = apply_move(current, move)
            path.append(current)

            # 评估路径上的解
            if evaluate(current) > best_ever:
                best_solution = current
```

**适用场景**：需要高质量解的复杂问题
**性能提升**：相比单独TS，解质量提升8-12%

```python
    """

            config: 算法配置对象

        self.config = config
        self.current_solution = None
        self.best_solution = None
        self.tabu_list = []
        self.frequency_memory = {}
        self.search_history = []

        pass

    def generate_neighborhood(self, solution: Solution) -> List[Tuple[Move, Solution]]:
        """
        生成邻域

        Args:
            solution: 当前解

        Returns:
            neighborhood: [(move, neighbor_solution), ...]
        """
        pass

    def evaluate(self, solution: Solution) -> float:
        """评估解的目标函数值"""
        pass

    def check_tabu(self, move: Move) -> bool:
        """检查移动是否在禁忌表中"""
        for tabu in self.tabu_list:
            if self._moves_equal(move, tabu['move']):
                return True
        return False

    def aspiration_criteria(self, fitness: float) -> bool:
        """特赦准则：若优于历史最优则特赦"""
        return fitness > self.best_fitness

    def update_tabu_list(self, move: Move, iteration: int):
        """更新禁忌表"""
        self.tabu_list.append({
            'move': move,
            'iteration': iteration,
            'expiry': iteration + self.config.tabu_tenure
        })
        # 移除过期记录
        self.tabu_list = [t for t in self.tabu_list
                         if t['expiry'] > iteration]

    def update_frequency_memory(self, move: Move):
        """更新频率记忆"""
        key = str(move)
        self.frequency_memory[key] = self.frequency_memory.get(key, 0) + 1

    def diversify(self):
        """多样化策略"""
        # 使用频率记忆指导多样化
        low_freq_moves = self._get_low_frequency_moves()
        return self._apply_moves(self.current_solution, low_freq_moves)

    def intensify(self):
        """强化策略"""
        # 在最优解附近深入搜索
        current = self.best_solution
        for _ in range(self.config.intensification_depth):
            neighborhood = self.generate_neighborhood(current)
            best_neighbor = max(neighborhood, key=lambda x: self.evaluate(x[1]))
            current = best_neighbor[1]
        return current

    def run(self) -> Tuple[Solution, Dict]:
        """
        执行禁忌搜索主循环

        Returns:
            best_solution: 最优解
            search_info: 搜索过程信息
        """
        # 初始化
        self.current_solution = self.generate_initial_solution()
        self.best_solution = self.current_solution
        self.best_fitness = self.evaluate(self.best_solution)

        no_improve_count = 0

        # 主循环
        for iteration in range(self.config.max_iterations):
            # 生成邻域
            neighborhood = self.generate_neighborhood(self.current_solution)

            # 评估候选
            candidates = []
            for move, neighbor in neighborhood:
                fitness = self.evaluate(neighbor)
                is_tabu = self.check_tabu(move)
                aspiration = self.aspiration_criteria(fitness)

                candidates.append({
                    'move': move,
                    'solution': neighbor,
                    'fitness': fitness,
                    'is_tabu': is_tabu,
                    'aspiration': aspiration
                })

            # 选择最优候选
            candidates.sort(key=lambda x: x['fitness'], reverse=True)
            selected = None
            for cand in candidates:
                if not cand['is_tabu'] or cand['aspiration']:
                    selected = cand
                    break

            if selected is None:
                selected = candidates[0]

            # 更新当前解
            self.current_solution = selected['solution']
            current_fitness = selected['fitness']

            # 更新最优解
            if current_fitness > self.best_fitness:
                self.best_solution = self.current_solution
                self.best_fitness = current_fitness
                no_improve_count = 0
            else:
                no_improve_count += 1

            # 更新禁忌表和频率记忆
            self.update_tabu_list(selected['move'], iteration)
            self.update_frequency_memory(selected['move'])

            # 记录历史
            self._record_history(iteration, current_fitness)

            # 多样化
            if no_improve_count >= self.config.diversification_threshold:
                self.current_solution = self.diversify()
                no_improve_count = 0

            # 检查终止
            if self._check_termination():
                break

        return self.best_solution, self._get_search_info()
```
