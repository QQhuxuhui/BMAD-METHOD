## 📋 知识库概述

### 知识库定位

领域应用专家知识库是 BMAD APS 模块中专门针对各类调度领域的知识集合,涵盖车辆调度、生产调度、服务调度、项目调度和供应链调度五大核心领域。

**核心价值**:

- 提供领域特定的建模模式和最佳实践
- 封装领域专家的经验知识和决策规则
- 支持跨领域知识复用和迁移
- 指导智能体进行领域适配和方案定制

**使用场景**:

- 新问题的领域识别和分类
- 领域特定约束和目标的提取
- 领域适配器的选择和配置
- 最佳实践的应用和定制

## 🗂️ 知识结构

### 一级分类:领域类型

```yaml
领域分类:
  1. 车辆调度 (Vehicle Scheduling):
    - 路径规划: VRP, CVRP, VRPTW
    - 配送优化: 生鲜配送, 快递配送, B2B配送
    - 最佳实践: 冷链物流标准流程

  2. 生产调度 (Production Scheduling):
    - 车间调度: JSP, Flow Shop, Job Shop
    - 产能规划: MRP, APS, 产线平衡
    - 最佳实践: JIT生产, 精益制造

  3. 服务调度 (Service Scheduling):
    - 人员排班: 护士排班, 客服排班, 维修工排班
    - 服务质量: SLA管理, 响应时间优化
    - 最佳实践: 技能匹配, 公平性保障

  4. 项目调度 (Project Scheduling):
    - 项目规划: PERT, CPM, 关键路径
    - 资源分配: RCPSP, 多项目协调
    - 最佳实践: 敏捷开发, Scrum冲刺规划

  5. 供应链调度 (Supply Chain Scheduling):
    - 库存管理: VMI, JIT库存, 安全库存
    - 供需协调: 生产-库存-配送协同
    - 最佳实践: 牛鞭效应控制, 协同预测
```

### 二级分类:知识类型

```yaml
知识模块类型:
  - 领域适配器 (Domain Adapter):
      功能: 将通用调度问题映射到领域特定问题
      内容: 参数映射、约束转换、目标定制

  - 最佳实践 (Best Practice):
      功能: 领域专家经验的结构化知识
      内容: 标准流程、常见陷阱、优化技巧

  - 领域案例 (Domain Case):
      功能: 真实场景的完整解决方案
      内容: 问题描述、建模过程、实施效果
```

## 🎯 领域识别矩阵

### 如何选择领域?

| 问题特征                 | 推荐领域   | 核心关注点                 |
| ------------------------ | ---------- | -------------------------- |
| 涉及车辆、路线、配送     | 车辆调度   | 路径优化、时间窗、容量限制 |
| 涉及机器、工件、产线     | 生产调度   | 加工顺序、设备利用率       |
| 涉及人员、班次、技能匹配 | 服务调度   | 公平性、技能覆盖、SLA      |
| 涉及任务、依赖、里程碑   | 项目调度   | 关键路径、资源冲突         |
| 涉及仓库、库存、供应商   | 供应链调度 | 库存成本、响应时间         |

### 领域特征决策树

```
问题是否涉及物理位置移动?
├─ 是 → 涉及车辆/运输工具?
│   ├─ 是 → 车辆调度领域 (VRP系列问题)
│   └─ 否 → 服务调度领域 (现场服务)
│
└─ 否 → 涉及生产设备/机器?
    ├─ 是 → 生产调度领域 (JSP系列问题)
    └─ 否 → 涉及任务依赖关系?
        ├─ 是 → 项目调度领域 (RCPSP系列问题)
        └─ 否 → 涉及库存/供应链?
            ├─ 是 → 供应链调度领域
            └─ 否 → 通用调度问题 (需进一步分析)
```

## 🔍 使用指南

### 1. 领域识别流程

```yaml
步骤1: 问题描述分析
  - 提取关键实体 (车辆、机器、人员、任务...)
  - 识别核心约束 (容量、时间窗、依赖关系...)
  - 明确优化目标 (成本、时间、质量...)

步骤2: 领域分类匹配
  - 使用领域识别矩阵进行初步判断
  - 通过决策树确认领域类型
  - 识别是否涉及跨领域问题

步骤3: 适配器选择
  - 查找对应领域的适配器模块
  - 检查适配器的适用条件
  - 确认参数映射规则

步骤4: 最佳实践应用
  - 查阅领域最佳实践文档
  - 借鉴成功案例经验
  - 规避常见陷阱
```

### 2. 领域适配器使用模式

```yaml
# 标准调用格式
领域适配:
  问题类型: '生鲜配送调度'
  领域识别: '车辆调度 (Vehicle Scheduling)'

  加载适配器:
    - 引用: '@专家库/领域库/vehicle/VRP领域适配器.md'
    - 引用: '@专家库/领域库/vehicle/冷链物流最佳实践.md'

  参数映射:
    通用参数 → 领域参数:
      - 任务 → 配送订单
      - 资源 → 冷链车辆
      - 位置 → 客户地址
      - 时间窗 → 收货时间窗
      - 容量 → 载重 + 温控仓容

  约束定制:
    领域特定约束:
      - 温度控制约束 (2-8℃)
      - 时效性约束 (2小时内送达)
      - 车辆兼容性约束

  目标函数:
    - 主目标: 最小化配送成本
    - 次要目标: 最小化温度波动
    - 约束目标: 保证时效达标率 > 95%
```

### 3. 跨领域问题处理

对于涉及多个领域的复杂问题:

```yaml
场景示例: "生产-配送一体化调度"

涉及领域:
  - 生产调度: 产线排程、批量计划
  - 供应链调度: 库存管理、需求预测
  - 车辆调度: 成品配送路径优化

处理策略:
  方法1: 分层优化
    - 第一层: 生产调度 (确定生产计划)
    - 第二层: 库存调度 (平衡库存水平)
    - 第三层: 车辆调度 (配送路径规划)

  方法2: 协同优化
    - 使用多目标优化框架
    - 建立领域间耦合约束
    - 迭代收敛到综合最优解

  方法3: 主导领域策略
    - 识别关键瓶颈领域 (如生产产能)
    - 以主导领域为核心优化
    - 其他领域适配主导领域方案
```
