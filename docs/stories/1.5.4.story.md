## Dev Notes

### 测试策略

**测试金字塔**:

```
      /\
     /E2E\        <- 少量端到端测试（复杂场景）
    /------\
   /集成测试\     <- 中量集成测试（组件协作）
  /----------\
 /  单元测试  \   <- 大量单元测试（节点逻辑）
/--------------\
```

**覆盖率目标**:

- 单元测试：>90%
- 集成测试：>70%
- 端到端测试：关键路径100%

### 性能目标

| 指标           | 目标               | 测量方法                 |
| -------------- | ------------------ | ------------------------ |
| 单agent响应    | P95 < 10s          | Prometheus histogram     |
| 完整工作流     | P95 < 60min        | Workflow duration metric |
| 并发支持       | 10个同时           | 负载测试                 |
| Checkpoint开销 | < 100ms            | 性能基准测试             |
| 内存使用       | < 2GB per workflow | 内存分析                 |

### Langfuse最佳实践

- **Session ID**: 使用thread_id作为session ID
- **User ID**: 记录真实用户ID
- **Tags**: 添加phase、agent_name等标签
- **元数据**: 记录problem_description、domain
- **成本追踪**: 记录token使用和成本估算
