## 📖 约束概述

### 定义

**互斥约束**（Mutual Exclusion Constraint）规定某些任务、资源、状态不能同时存在或执行，确保冲突项不会并发。

**数学定义**：

```
对于任务集合 T，定义互斥关系 M ⊆ T × T

互斥约束:
  对于 (i, j) ∈ M，任务 i 和 j 不能同时执行

时间互斥:
  [start_i, end_i) ∩ [start_j, end_j) = ∅

资源互斥:
  同一时刻，资源只能被一个任务占用
```

### 约束类型

#### 1. **时间互斥** (Temporal Mutual Exclusion)

```
任务在时间上不能重叠

条件:
  end_i ≤ start_j  OR  end_j ≤ start_i

例如:
  机器A不能同时处理两个任务
  会议室不能同时安排两个会议
```

#### 2. **资源互斥** (Resource Mutual Exclusion)

```
资源独占访问

例如:
  临界资源（数据库连接、文件锁）
  单线程资源（打印机、设备）
```

#### 3. **逻辑互斥** (Logical Mutual Exclusion)

```
业务规则约束

例如:
  - 同一订单不能同时分配给多个司机
  - 同一时段不能接受冲突的订单
  - 产品A和产品B不能同时生产（共用设备）
```

#### 4. **选择互斥** (Choice Mutual Exclusion)

```
"或"关系 - 多选一

例如:
  - 任务A或任务B必须执行，但不能同时执行
  - 路径1或路径2选择其一
```

## 💡 核心理论

### 图着色问题 (Graph Coloring)

**问题定义**：

```
给定冲突图 G = (V, E)
- V: 任务集合
- E: 冲突边集合 {(i, j) | i和j互斥}

目标: 为每个任务分配时间槽（颜色），使得相邻任务不同槽

最小化颜色数 = 最小化时间槽数
```

**贪心着色算法**：

```python
def greedy_coloring(conflict_graph):
    """
    贪心图着色算法

    复杂度: O(V + E)
    近似比: 无保证，实际效果通常良好

    步骤:
      1. 按度数降序排序节点
      2. 依次为每个节点分配最小可用颜色
    """
    colors = {}
    vertices = sorted(conflict_graph.keys(),
                     key=lambda v: len(conflict_graph[v]),
                     reverse=True)

    for vertex in vertices:
        # 找到邻居已使用的颜色
        neighbor_colors = set(
            colors.get(neighbor)
            for neighbor in conflict_graph[vertex]
            if neighbor in colors
        )

        # 分配最小可用颜色
        color = 0
        while color in neighbor_colors:
            color += 1

        colors[vertex] = color

    return colors
```

### 信号量机制 (Semaphore)

```python
import threading

class ResourceSemaphore:
    """
    信号量实现资源互斥访问

    用于并发环境下的资源分配
    """

    def __init__(self, capacity: int):
        """
        参数:
          capacity: 资源容量
        """
        self.semaphore = threading.Semaphore(capacity)
        self.current_users = []

    def acquire(self, task_id: str, timeout: float = None) -> bool:
        """
        获取资源

        返回:
          True: 获取成功
          False: 获取失败（超时）
        """
        acquired = self.semaphore.acquire(timeout=timeout)

        if acquired:
            self.current_users.append(task_id)

        return acquired

    def release(self, task_id: str):
        """释放资源"""
        if task_id in self.current_users:
            self.current_users.remove(task_id)
            self.semaphore.release()
```

## 🔧 代码实现

```python
from typing import Dict, List, Tuple, Set, Optional
from dataclasses import dataclass
from datetime import datetime, timedelta

@dataclass
class Task:
    """任务定义"""
    id: str
    start_time: datetime
    end_time: datetime
    resources: Set[str] = None  # 需要的资源

    def __post_init__(self):
        if self.resources is None:
            self.resources = set()

    def overlaps(self, other: 'Task') -> bool:
        """判断与另一个任务是否时间重叠"""
        return (self.start_time < other.end_time and
                other.start_time < self.end_time)

@dataclass
class ConflictRule:
    """冲突规则"""
    task1: str
    task2: str
    reason: str = ""

class MutualExclusionConstraintHandler:
    """互斥约束处理器"""

    def __init__(self, conflict_rules: List[ConflictRule] = None):
        """
        参数:
          conflict_rules: 冲突规则列表
        """
        self.conflict_rules = conflict_rules or []
        self.conflict_graph = self._build_conflict_graph()

    def _build_conflict_graph(self) -> Dict[str, Set[str]]:
        """构建冲突图"""
        graph = {}

        for rule in self.conflict_rules:
            if rule.task1 not in graph:
                graph[rule.task1] = set()
            if rule.task2 not in graph:
                graph[rule.task2] = set()

            graph[rule.task1].add(rule.task2)
            graph[rule.task2].add(rule.task1)

        return graph

    def validate(self, tasks: List[Task]) -> Tuple[bool, List[Dict]]:
        """
        验证调度是否满足互斥约束

        检查:
          1. 时间冲突
          2. 资源冲突
          3. 逻辑冲突

        返回:
          (is_valid, violations)
        """
        violations = []

        # 检查时间和资源冲突
        for i, task1 in enumerate(tasks):
            for j, task2 in enumerate(tasks[i + 1:], start=i + 1):
                # 时间重叠检查
                if task1.overlaps(task2):
                    # 资源冲突
                    shared_resources = task1.resources & task2.resources

                    if shared_resources:
                        violations.append({
                            'type': 'resource_conflict',
                            'task1': task1.id,
                            'task2': task2.id,
                            'conflicting_resources': list(shared_resources),
                            'time_overlap': self._calculate_overlap(task1, task2),
                            'penalty': len(shared_resources) * 50
                        })

        # 检查逻辑冲突
        for rule in self.conflict_rules:
            task1 = next((t for t in tasks if t.id == rule.task1), None)
            task2 = next((t for t in tasks if t.id == rule.task2), None)

            if task1 and task2 and task1.overlaps(task2):
                violations.append({
                    'type': 'logical_conflict',
                    'task1': task1.id,
                    'task2': task2.id,
                    'reason': rule.reason,
                    'time_overlap': self._calculate_overlap(task1, task2),
                    'penalty': 100
                })

        return len(violations) == 0, violations

    def _calculate_overlap(self, task1: Task, task2: Task) -> timedelta:
        """计算两个任务的时间重叠长度"""
        overlap_start = max(task1.start_time, task2.start_time)
        overlap_end = min(task1.end_time, task2.end_time)

        if overlap_start < overlap_end:
            return overlap_end - overlap_start
        return timedelta(0)

    def greedy_coloring(self, tasks: List[Task]) -> Dict[str, int]:
        """
        贪心图着色 - 为任务分配时间槽

        返回:
          {task_id: time_slot}
        """
        # 构建冲突图（包括时间冲突）
        full_conflict_graph = {}

        for task in tasks:
            full_conflict_graph[task.id] = set()

        # 添加规则定义的冲突
        for task_id, conflicts in self.conflict_graph.items():
            if task_id in full_conflict_graph:
                full_conflict_graph[task_id].update(conflicts)

        # 添加时间重叠冲突
        for i, task1 in enumerate(tasks):
            for j, task2 in enumerate(tasks[i + 1:], start=i + 1):
                if task1.overlaps(task2):
                    full_conflict_graph[task1.id].add(task2.id)
                    full_conflict_graph[task2.id].add(task1.id)

        # 贪心着色
        colors = {}
        vertices = sorted(full_conflict_graph.keys(),
                         key=lambda v: len(full_conflict_graph[v]),
                         reverse=True)

        for vertex in vertices:
            # 邻居已使用的颜色
            neighbor_colors = set(
                colors.get(neighbor)
                for neighbor in full_conflict_graph[vertex]
                if neighbor in colors
            )

            # 分配最小可用颜色
            color = 0
            while color in neighbor_colors:
                color += 1

            colors[vertex] = color

        return colors

    def repair(self, tasks: List[Task],
              violations: List[Dict]) -> List[Task]:
        """
        修复互斥冲突

        策略:
          1. 识别冲突任务对
          2. 调整任务时间，消除重叠
        """
        repaired = tasks[:]

        for violation in violations:
            if violation['type'] in ['resource_conflict', 'logical_conflict']:
                task1_id = violation['task1']
                task2_id = violation['task2']

                task1 = next(t for t in repaired if t.id == task1_id)
                task2 = next(t for t in repaired if t.id == task2_id)

                # 将task2移到task1之后
                task2.start_time = task1.end_time
                task2.end_time = task2.start_time + (task2.end_time - task2.start_time)

        return repaired

    def find_minimal_time_slots(self, tasks: List[Task]) -> int:
        """
        找到最小时间槽数（图着色数）

        返回:
          chromatic_number: 最小颜色数
        """
        coloring = self.greedy_coloring(tasks)
        return max(coloring.values()) + 1 if coloring else 0

    def assign_to_time_slots(self, tasks: List[Task]) -> Dict[int, List[str]]:
        """
        将任务分配到时间槽

        返回:
          {slot_index: [task_ids]}
        """
        coloring = self.greedy_coloring(tasks)

        slots = {}
        for task_id, slot in coloring.items():
            if slot not in slots:
                slots[slot] = []
            slots[slot].append(task_id)

        return slots

```

## 📊 应用场景

### 场景1: 会议室调度

```python
# 定义会议任务
tasks = [
    Task(id='meeting1', start_time=datetime(2025, 1, 6, 9, 0), end_time=datetime(2025, 1, 6, 10, 0),
         resources={'room_A'}),
    Task(id='meeting2', start_time=datetime(2025, 1, 6, 9, 30), end_time=datetime(2025, 1, 6, 11, 0),
         resources={'room_A'}),  # 冲突：与meeting1争用room_A
    Task(id='meeting3', start_time=datetime(2025, 1, 6, 10, 30), end_time=datetime(2025, 1, 6, 12, 0),
         resources={'room_B'}),
]

handler = MutualExclusionConstraintHandler()

# 验证冲突
is_valid, violations = handler.validate(tasks)

if not is_valid:
    print(f"发现 {len(violations)} 个冲突")
    for v in violations:
        print(f"  {v['type']}: {v['task1']} vs {v['task2']}")
        print(f"    冲突资源: {v.get('conflicting_resources', [])}")

    # 修复冲突
    repaired = handler.repair(tasks, violations)
```

### 场景2: 生产线任务调度

```python
# 定义冲突规则
conflict_rules = [
    ConflictRule('product_A', 'product_B', reason='共用设备1'),
    ConflictRule('product_C', 'product_D', reason='共用原料'),
]

handler = MutualExclusionConstraintHandler(conflict_rules)

# 任务列表
tasks = [
    Task('product_A', datetime(2025, 1, 6, 8, 0), datetime(2025, 1, 6, 10, 0)),
    Task('product_B', datetime(2025, 1, 6, 9, 0), datetime(2025, 1, 6, 11, 0)),  # 与A冲突
    Task('product_C', datetime(2025, 1, 6, 10, 0), datetime(2025, 1, 6, 12, 0)),
    Task('product_D', datetime(2025, 1, 6, 11, 0), datetime(2025, 1, 6, 13, 0)),  # 与C冲突
]

# 验证
is_valid, violations = handler.validate(tasks)

# 图着色分配时间槽
time_slots = handler.assign_to_time_slots(tasks)
print(f"最少需要 {len(time_slots)} 个时间槽")

for slot, task_ids in time_slots.items():
    print(f"时间槽 {slot}: {', '.join(task_ids)}")
```

## 🎯 性能优化

### 冲突矩阵预计算

```python
class OptimizedMutexHandler(MutualExclusionConstraintHandler):
    """优化版本 - 使用冲突矩阵"""

    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self._conflict_matrix_cache = {}

    def _build_conflict_matrix(self, tasks: List[Task]) -> Dict[Tuple[str, str], bool]:
        """预计算冲突矩阵"""
        matrix = {}

        for i, task1 in enumerate(tasks):
            for j, task2 in enumerate(tasks[i + 1:], start=i + 1):
                key = (task1.id, task2.id)

                conflicts = (
                    task1.overlaps(task2) and
                    bool(task1.resources & task2.resources)
                )

                matrix[key] = conflicts

        return matrix
```
