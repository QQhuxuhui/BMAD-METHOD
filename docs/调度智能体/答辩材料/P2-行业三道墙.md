## 💡 关键设计决策

| 决策                                | 理由                                                                                   |
| ----------------------------------- | -------------------------------------------------------------------------------------- |
| 三墙对称布局（而非竖排 / 流程图）   | 视觉压迫感强，让"问题严重性"一眼可见                                                   |
| 每墙都有"一句话痛点 + 量化证据"双层 | 技术评委看数字，业务评委看痛点描述，各得其所                                           |
| 墙③ 放最后不是最末位                | 专家经验断层是整套答辩中业务评委最共鸣的点；收束时压阵最有力；直接引出 P7 飞轮页的解药 |
| 底部金句 "破的局"                   | 顺势带出下一页 P3 的"王牌破局点"                                                       |

---

## 💡 用词精选说明

- **墙① AI 幻觉难控** → 比"AI 不可靠"更技术、更精准
- **墙② Token 浪费** → 直击成本，业务评委秒懂
- **墙③ 专家经验留不住** → 用"留不住"而不是"难传承"——**口语化、有情绪**，评委更有共鸣

## 🎨 样式说明

**整体风格**：白色系商务正式 · 低密度高留白 · 强理性弱装饰

**配色规范**

| 用途     | 色值      | 用法                     |
| -------- | --------- | ------------------------ |
| 背景     | `#FFFFFF` | 纯白 · 全场统一          |
| 主文字   | `#1A202C` | 深墨灰 · 标题 / 正文     |
| 副文字   | `#4A5568` | 中灰 · 副标题 / 注释     |
| 强调色   | `#1A365D` | 深蓝 · 关键词 / 数字亮点 |
| 分割线   | `#E2E8F0` | 浅灰 · 1px 细线          |
| 警示色   | `#C53030` | 砖红 · 传统方案的负面点  |
| 收益色   | `#2F855A` | 墨绿 · 正面成效          |
| 点缀金色 | `#D69E2E` | 仅用于 🏆 国赛图标       |

**字体规范**

- 中文：思源黑体 / 微软雅黑（兜底）
- 英文 & 数字：Inter / Helvetica Neue（兜底）
- 主标题：大字号 · 加粗 · 深墨灰
- 副标题：次级字号 · 细体 · 中灰
- 数字亮点：超大字号 · 加粗 · 深蓝

**版式规范**

- 每页四角留白 ≥ 5%
- **克制使用 emoji**：保留功能性标识，删除装饰性表情；优先线框 icon（Feather / Tabler Icons 风格）
- 分隔元素：1px 浅灰细线，避免厚重底纹
- 对齐：统一居中或左对齐，避免混用

**本页视觉重点（P2 行业三道墙）**

- **三列等宽**布局，每列顶部用**线框 icon**（不用 emoji 表情）代表"墙"概念
- **墙序号 ①②③**：圆形印章样式 · 浅灰底 · 深蓝字
- **"墙"的视觉隐喻**：每列顶部用浅灰粗线（8-12px）做"墙"的横截面，象征阻隔
- **量化数字**：加粗 · 砖红色（`#C53030`，警示意味）· 字号突出
- **底部金句**：单独一行 · 浅灰底条 + 深蓝加粗字 + 斜体
- **三列分隔**：1px 浅灰竖线

## 🎤 口头讲词（~30 秒）

> "AI 落地调度优化这类专业领域，撞到三道墙——
>
> **墙一 AI 幻觉难控**：长任务链里 AI 会编造算法和业务规则，代码可用率只有 50-70%；
>
> **墙二 Token 浪费严重**：知识全塞进 Prompt，50K tokens 一次加载，利用率只有 10-20%；
>
> **墙三 专家经验留不住**——专家一离职，经验清零。
>
> **这三道墙，就是我们要破的局。**"

---

## ✏️ 可调整项

- **量化数字**（50-70% / 10-20% / 3 个月）可根据集团内部真实调研数据替换，说服力会更强
- **三道墙的命名用词** 如需更正式可改为："AI 输出不可信 / Token 效率低下 / 专家经验流失"
