## 2.2 架构设计理念

### 模块化架构

```
┌─────────────────────────────────────────────────────┐
│  用户需求（自然语言）                                │
└─────────────────┬───────────────────────────────────┘
                  ↓
┌─────────────────────────────────────────────────────┐
│  系统编排协调智能体 (Orchestrator)                   │
│  • Phase 0-4 流程编排                               │
│  • Todo List 追踪                                   │
│  • Human-in-the-Loop 触发                           │
└────┬────────────┬────────────┬────────────┬─────────┘
     ↓            ↓            ↓            ↓
┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐
│ 领域专家│ │ 约束专家│ │ 目标专家│ │ 算法专家│
│ 赵领域  │ │ 李严谨  │ │ 王目标  │ │ 张效率  │
└────┬────┘ └────┬────┘ └────┬────┘ └────┬────┘
     ↓            ↓            ↓            ↓
┌─────────────────────────────────────────────────────┐
│  知识库（Sidecar 模式）                              │
│  ├─ domain-library/    (领域知识库)                 │
│  ├─ constraint-library/ (约束知识库)                │
│  ├─ objective-library/  (目标知识库)                │
│  └─ algorithm-library/  (算法知识库)                │
└────┬────────────────────────────────────────────────┘
     ↓
┌─────────────────────────────────────────────────────┐
│  方案集成 + 质量保证                                 │
│  • 跨专家一致性校验                                  │
│  • Theory-to-Code 代码生成                          │
│  • 6 层质量门禁                                     │
└────┬────────────────────────────────────────────────┘
     ↓
┌─────────────────────────────────────────────────────┐
│  交付物                                              │
│  • TenElementModel (YAML)                           │
│  • 调度解决方案 (YAML)                              │
│  • 可执行代码 (Python)                              │
│  • 质量报告 (JSON)                                  │
└─────────────────────────────────────────────────────┘
```

## 2.3 技术栈

```yaml
核心框架: BMAD-METHOD v6 (自研智能体编排框架)
智能体定义: YAML配置 + Markdown文档
工作流引擎: workflow.yaml (支持条件/并行/串行/人机交互)
知识库格式: Markdown + YAML + Python模板
状态管理: 文件系统持久化 (YAML/JSON)
质量保证: 多层级验证 + 基准测试
语言支持: 中文为主，支持多语言配置
LLM模型: Claude Sonnet 4.5 (Anthropic)
```
