## 📖 目标概述

### 定义

**最大完成时间**（Makespan）是所有任务完成所需的总时间跨度，即从开始执行第一个任务到最后一个任务完成的时间间隔。

**数学定义**：

```
对于调度方案 S，任务集 J = {j_1, j_2, ..., j_n}

makespan(S) = max{C_j | j ∈ J}

其中:
  C_j = 任务 j 的完成时间

目标:
  minimize makespan(S)
```

### 目标类型

#### 1. **单机最大完成时间** (Single Machine Makespan)

```
问题: 1 || C_max

定义: 所有任务在单台机器上顺序执行的完成时间
计算: C_max = ∑ p_j (所有任务处理时间之和)
特点: 任务顺序不影响makespan
```

#### 2. **并行机最大完成时间** (Parallel Machine Makespan)

```
问题: P || C_max

定义: 任务在多台并行机器上执行的完成时间
计算: C_max = max{C_i | i ∈ M} (最晚完成的机器时间)
特点: 负载均衡影响makespan
优化目标: LPT (Longest Processing Time)算法
```

#### 3. **流水车间最大完成时间** (Flow Shop Makespan)

```
问题: F_m || C_max

定义: 任务按相同顺序经过m台机器的完成时间
计算: 考虑机器间等待时间
特点: Johnson算法 (m=2时最优)
```

#### 4. **作业车间最大完成时间** (Job Shop Makespan)

```
问题: J_m || C_max

定义: 每个任务有不同的机器加工路线
复杂度: NP-hard
求解方法: 遗传算法、禁忌搜索
```

## 💡 核心理论

### Makespan下界估计

```python
def calculate_makespan_lower_bound(jobs, machines):
    """
    计算makespan理论下界

    下界估计方法:
    1. LB1 = max{p_j} (最长任务时间)
    2. LB2 = ∑p_j / m (平均负载)
    3. LB = max{LB1, LB2}
    """
    if not jobs:
        return 0

    # LB1: 最长任务时间
    max_processing_time = max(job.get('duration', 0) for job in jobs)

    # LB2: 平均负载
    total_processing_time = sum(job.get('duration', 0) for job in jobs)
    num_machines = len(machines)
    average_load = total_processing_time / num_machines if num_machines > 0 else float('inf')

    # 理论下界
    lower_bound = max(max_processing_time, average_load)

    return lower_bound
```

### LPT算法 (Longest Processing Time)

```python
import heapq

def lpt_schedule(jobs, num_machines):
    """
    LPT算法: 最长处理时间优先

    近似比: 4/3 - 1/(3m) ≤ LPT/OPT ≤ 4/3

    步骤:
    1. 按处理时间降序排列任务
    2. 将每个任务分配给当前负载最小的机器
    """
    # 按处理时间降序排序
    sorted_jobs = sorted(jobs, key=lambda j: j.get('duration', 0), reverse=True)

    # 机器负载堆（最小堆）: (完成时间, 机器ID, 任务列表)
    machines = [(0, i, []) for i in range(num_machines)]
    heapq.heapify(machines)

    # 分配任务
    for job in sorted_jobs:
        # 取出当前负载最小的机器
        finish_time, machine_id, task_list = heapq.heappop(machines)

        # 分配任务
        job_duration = job.get('duration', 0)
        job_start = finish_time
        job_finish = job_start + job_duration

        task_list.append({
            'job_id': job.get('id'),
            'start_time': job_start,
            'finish_time': job_finish,
            'duration': job_duration
        })

        # 更新机器负载并放回堆
        heapq.heappush(machines, (job_finish, machine_id, task_list))

    # 计算makespan
    makespan = max(machine[0] for machine in machines)

    # 组织调度结果
    schedule = {f"machine_{machine[1]}": machine[2] for machine in machines}

    return makespan, schedule
```

## 🔧 代码实现

```python
from typing import Dict, List, Tuple
from dataclasses import dataclass
import heapq

@dataclass
class Job:
    """任务定义"""
    id: str
    duration: float
    release_time: float = 0  # 释放时间
    deadline: float = float('inf')  # 截止期

@dataclass
class Machine:
    """机器定义"""
    id: str
    availability: float = 0  # 可用时间

class MakespanObjective:
    """最大完成时间目标函数"""

    def __init__(self, weight: float = 1.0):
        self.name = "makespan"
        self.optimization_type = "minimize"
        self.weight = weight
        self.evaluation_history = []

    def evaluate(self, solution: Dict[str, List[Dict]]) -> float:
        """
        评估调度方案的makespan

        参数:
          solution: {machine_id: [tasks]} 调度方案

        返回:
          makespan值
        """
        if not solution:
            return 0.0

        makespan = 0.0

        for machine_id, tasks in solution.items():
            if not tasks:
                continue

            # 计算该机器的完成时间
            machine_completion = 0.0

            for task in tasks:
                if isinstance(task, dict):
                    # 任务完成时间 = 开始时间 + 持续时间
                    finish_time = task.get('finish_time')
                    if finish_time is not None:
                        machine_completion = max(machine_completion, finish_time)
                    else:
                        # 如果没有finish_time，计算它
                        start = task.get('start_time', machine_completion)
                        duration = task.get('duration', 0)
                        machine_completion = max(machine_completion, start + duration)

            makespan = max(makespan, machine_completion)

        # 记录评估历史
        self.evaluation_history.append({
            'value': makespan,
            'solution_hash': hash(str(sorted(solution.items())))
        })

        return makespan

    def calculate_lower_bound(self, jobs: List[Job], num_machines: int) -> float:
        """计算makespan理论下界"""
        if not jobs:
            return 0.0

        # LB1: 最长任务时间
        max_duration = max(job.duration for job in jobs)

        # LB2: 平均负载
        total_duration = sum(job.duration for job in jobs)
        avg_load = total_duration / num_machines if num_machines > 0 else float('inf')

        return max(max_duration, avg_load)

    def lpt_schedule(self, jobs: List[Job], machines: List[Machine]) -> Tuple[float, Dict]:
        """
        LPT算法调度

        返回:
          (makespan, schedule)
        """
        num_machines = len(machines)

        # 按处理时间降序排序
        sorted_jobs = sorted(jobs, key=lambda j: j.duration, reverse=True)

        # 初始化机器负载
        machine_heap = [(machine.availability, machine.id, [])
                        for machine in machines]
        heapq.heapify(machine_heap)

        # 分配任务
        for job in sorted_jobs:
            # 取出最早可用的机器
            avail_time, machine_id, task_list = heapq.heappop(machine_heap)

            # 考虑任务释放时间
            start_time = max(avail_time, job.release_time)
            finish_time = start_time + job.duration

            task_list.append({
                'job_id': job.id,
                'start_time': start_time,
                'finish_time': finish_time,
                'duration': job.duration
            })

            # 更新机器可用时间
            heapq.heappush(machine_heap, (finish_time, machine_id, task_list))

        # 构建调度方案
        schedule = {machine_id: tasks for _, machine_id, tasks in machine_heap}

        # 计算makespan
        makespan = self.evaluate(schedule)

        return makespan, schedule

    def calculate_gap(self, actual_makespan: float, lower_bound: float) -> float:
        """
        计算与下界的差距

        gap = (actual - lower_bound) / lower_bound * 100%
        """
        if lower_bound == 0:
            return 0.0

        gap = (actual_makespan - lower_bound) / lower_bound * 100
        return gap

```

## 📊 应用场景

### 场景1: 生产排程

```python
# 生产任务
jobs = [
    Job(id='J1', duration=5),
    Job(id='J2', duration=8),
    Job(id='J3', duration=3),
    Job(id='J4', duration=6),
    Job(id='J5', duration=4),
    Job(id='J6', duration=7)
]

# 3台并行机器
machines = [
    Machine(id='M1'),
    Machine(id='M2'),
    Machine(id='M3')
]

# 使用LPT算法调度
objective = MakespanObjective()
makespan, schedule = objective.lpt_schedule(jobs, machines)

print(f"Makespan: {makespan}")
print(f"Schedule: {schedule}")

# 计算性能
lower_bound = objective.calculate_lower_bound(jobs, len(machines))
gap = objective.calculate_gap(makespan, lower_bound)
print(f"Lower Bound: {lower_bound}")
print(f"Gap: {gap:.2f}%")
```

## 🎯 性能优化

### 并行化调度

```python
from concurrent.futures import ProcessPoolExecutor

class ParallelMakespanOptimizer:
    """并行makespan优化器"""

    def __init__(self, jobs, machines):
        self.jobs = jobs
        self.machines = machines
        self.objective = MakespanObjective()

    def try_schedule(self, job_permutation):
        """尝试一个任务排列"""
        # 重新排列任务
        reordered_jobs = [self.jobs[i] for i in job_permutation]

        # 调度
        makespan, schedule = self.objective.lpt_schedule(reordered_jobs, self.machines)

        return makespan, schedule, job_permutation

    def optimize_parallel(self, num_trials=1000, num_workers=4):
        """并行尝试多种排列"""
        import random

        # 生成多种排列
        permutations = [random.sample(range(len(self.jobs)), len(self.jobs))
                       for _ in range(num_trials)]

        # 并行评估
        with ProcessPoolExecutor(max_workers=num_workers) as executor:
            results = list(executor.map(self.try_schedule, permutations))

        # 找到最优解
        best_makespan, best_schedule, best_perm = min(results, key=lambda x: x[0])

        return best_makespan, best_schedule
```

- **MULTIFIT**: Bin packing启发式

### 复杂度分析

- **P||C_max**: NP-hard（一般情况）
- **LPT复杂度**: O(n log n + n log m)
- **最优解**: 动态规划 O(n·∑p_j)
