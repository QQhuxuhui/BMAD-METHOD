## 核心原理

### 理论基础

#### 算法起源与发展

改进式启发式（Improvement Heuristic）起源于1960年代，Lin在其开创性论文中提出了2-opt和3-opt算法用于解决旅行商问题（TSP）。这标志着局部搜索方法在组合优化中的正式应用。

**发展历程**：

- **1960s**: Lin提出2-opt/3-opt，开创局部搜索方法
- **1970s**: 邻域搜索理论框架建立，Lin-Kernighan算法提出
- **1980s**: 变邻域下降（VND）、多起点局部搜索发展
- **1990s**: 迭代局部搜索（ILS）、引导局部搜索（GLS）等高级变种
- **2000s**: 与元启发式算法的深度融合，成为混合算法的核心组件

#### 核心思想

改进式启发式的核心思想是**局部迭代优化**：

1. **邻域概念**：对于当前解，定义一个邻域N(s)，包含通过简单操作可达的解集合
2. **局部搜索**：在邻域中寻找更优的解，如果找到则移动到新解
3. **迭代改进**：重复搜索过程，直到无法找到更优邻域解（局部最优）或达到终止条件

**关键特征**：

- **局部性**：每次只考虑当前解的邻域，不进行全局搜索
- **贪心性**：接受改进解，拒绝劣化解（基础版本）
- **迭代性**：通过多次邻域搜索逐步逼近高质量解
- **确定性**：对于相同初始解和邻域结构，结果通常是确定的（基础版本）

#### 数学形式化

**问题定义**：

- 搜索空间：S（所有可行解的集合）
- 目标函数：f: S → ℝ（评估解的质量）
- 邻域函数：N: S → 2^S（映射解到其邻域）

**局部最优性**：
解s\*称为局部最优解，当且仅当：

```
∀s' ∈ N(s*): f(s') ≥ f(s*)  (最小化问题)
```

**基础改进式启发式算法框架**：

```
输入: 初始解 s₀, 邻域函数 N, 目标函数 f
输出: 局部最优解 s*

1. s ← s₀
2. repeat
3.   s' ← argmin{f(x) | x ∈ N(s)}  # 在邻域中找最优解
4.   if f(s') < f(s) then
5.     s ← s'  # 接受改进
6.   else
7.     break  # 达到局部最优
8. until 终止条件满足
9. return s
```

#### 关键概念定义

**1. 邻域结构（Neighborhood Structure）**

邻域结构定义了从当前解可以到达的解集合。常见邻域结构：

| 邻域类型   | 定义                 | 适用问题     | 邻域大小 |
| ---------- | -------------------- | ------------ | -------- |
| Swap       | 交换两个元素         | 排列问题     | O(n²)    |
| Insert     | 移动一个元素到新位置 | 排列问题     | O(n²)    |
| Reverse    | 反转子序列           | TSP等        | O(n²)    |
| 2-opt      | 删除2条边，重新连接  | TSP          | O(n²)    |
| 3-opt      | 删除3条边，重新连接  | TSP          | O(n³)    |
| k-exchange | 交换k个元素          | 一般组合优化 | O(n^k)   |

**2. 搜索轨迹（Search Trajectory）**

搜索轨迹是算法访问的解序列：

```
s₀ → s₁ → s₂ → ... → s*
```

其中每个 sᵢ₊₁ ∈ N(sᵢ) 且 f(sᵢ₊₁) ≤ f(sᵢ)

**3. 局部最优陷阱（Local Optimum Trap）**

局部最优解不一定是全局最优解。解决策略：

- 多起点搜索（从不同初始解开始）
- 扰动机制（如ILS）
- 接受劣化解（如模拟退火）
- 变邻域策略（如VND）

**4. 终止条件（Termination Criteria）**

常见终止条件：

- 达到局部最优（无改进解）
- 达到最大迭代次数
- 达到时间限制
- 目标值达到阈值

#### 与其他算法的对比

| 维度           | 改进式启发式         | 构造式启发式 | 元启发式算法 |
| -------------- | -------------------- | ------------ | ------------ |
| **起点**       | 需要初始解           | 从空解开始   | 需要初始解   |
| **搜索方式**   | 局部邻域搜索         | 逐步构建     | 全局引导搜索 |
| **解空间探索** | 局部探索             | 构建路径探索 | 全局探索     |
| **计算复杂度** | 中等                 | 低           | 高           |
| **解质量**     | 较好                 | 中等         | 最好         |
| **实现难度**   | 简单                 | 简单         | 中等-复杂    |
| **典型应用**   | 解精炼、混合算法组件 | 快速初始解   | 复杂优化问题 |

**协同使用模式**：

```
构造式启发式 → 初始解 → 改进式启发式 → 精炼解
                              ↓
                        元启发式算法 ← 局部搜索组件
```

### 核心机制

#### 1. 邻域生成机制

**Swap邻域（交换邻域）**：

```python
def generate_swap_neighborhood(solution):
    """
    生成Swap邻域：交换解中任意两个元素

    时间复杂度: O(n²)
    空间复杂度: O(n²) 或 O(1) (生成器模式)
    """
    n = len(solution)
    neighborhood = []

    for i in range(n):
        for j in range(i + 1, n):
            # 创建邻域解：交换位置i和j的元素
            neighbor = solution.copy()
            neighbor[i], neighbor[j] = neighbor[j], neighbor[i]
            neighborhood.append(neighbor)

    return neighborhood
```

**Insert邻域（插入邻域）**：

```python
def generate_insert_neighborhood(solution):
    """
    生成Insert邻域：移动一个元素到新位置

    时间复杂度: O(n²)
    邻域大小: n(n-1)
    """
    n = len(solution)
    neighborhood = []

    for i in range(n):
        for j in range(n):
            if i != j:
                # 移除位置i的元素，插入到位置j
                neighbor = solution.copy()
                element = neighbor.pop(i)
                neighbor.insert(j, element)
                neighborhood.append(neighbor)

    return neighborhood
```

**2-opt邻域（TSP专用）**：

```python
def generate_2opt_neighborhood(tour):
    """
    生成2-opt邻域：删除两条边，反转中间子路径

    原理: 对于TSP路径 [a, i, i+1, ..., j, j+1, b]
          删除边(a,i)和(j,j+1)，反转i到j的子路径

    时间复杂度: O(n²)
    """
    n = len(tour)
    neighborhood = []

    for i in range(n - 1):
        for j in range(i + 2, n):
            # 执行2-opt操作
            neighbor = tour[:i+1] + tour[i+1:j+1][::-1] + tour[j+1:]
            neighborhood.append(neighbor)

    return neighborhood
```

#### 2. 邻域搜索策略

**Best Improvement（最优改进）**：

```python
def best_improvement(current_solution, objective_function, neighborhood_generator):
    """
    最优改进策略：搜索完整邻域，选择最优邻域解

    优点：每次移动质量高
    缺点：计算量大，需遍历完整邻域
    """
    current_obj = objective_function(current_solution)
    best_neighbor = None
    best_obj = current_obj

    # 遍历所有邻域解
    for neighbor in neighborhood_generator(current_solution):
        neighbor_obj = objective_function(neighbor)
        if neighbor_obj < best_obj:
            best_obj = neighbor_obj
            best_neighbor = neighbor

    return best_neighbor, best_obj
```

**First Improvement（首次改进）**：

```python
def first_improvement(current_solution, objective_function, neighborhood_generator):
    """
    首次改进策略：找到第一个改进解就接受

    优点：计算速度快，响应迅速
    缺点：改进质量可能不是最优
    """
    current_obj = objective_function(current_solution)

    # 遍历邻域，找到第一个改进就返回
    for neighbor in neighborhood_generator(current_solution):
        neighbor_obj = objective_function(neighbor)
        if neighbor_obj < current_obj:
            return neighbor, neighbor_obj

    return None, current_obj
```

**策略对比**：
| 策略 | 每次迭代时间 | 迭代次数 | 总时间 | 解质量 |
|-----|-------------|---------|--------|--------|
| Best Improvement | 高（遍历完整邻域） | 少 | 中等 | 较好 |
| First Improvement | 低（早停） | 多 | 中等 | 中等 |

#### 3. 增量评估机制

**问题**：完整重新计算目标函数代价高昂

**解决**：增量评估（Delta Evaluation）

- 只计算邻域操作引起的变化量
- 避免完整重新计算

**示例：Flowshop调度的Swap增量评估**：

```python
def evaluate_swap_delta(solution, i, j, completion_times):
    """
    增量评估Swap操作对makespan的影响

    完整评估: O(n×m) - 重新计算所有作业的完工时间
    增量评估: O(k×m) - 只计算受影响的k个作业
    """
    # 只有位置i到j之间的作业受影响
    affected_jobs = range(min(i,j), max(i,j)+1)

    # 计算这些作业的完工时间变化
    delta = 0
    for job_idx in affected_jobs:
        old_completion = completion_times[job_idx]
        new_completion = recalculate_job_completion(solution, job_idx)
        delta += new_completion - old_completion

    return delta
```

**目的**：减少邻域大小，提高搜索效率

**技术1：候选列表（Candidate List）**

```python
def generate_candidate_neighborhood(solution, candidate_size=20):
    """
    只生成部分有希望的邻域解

    策略：基于启发式选择候选邻域操作
    """
    # 例如：只考虑关键路径上的作业交换
    critical_jobs = identify_critical_path_jobs(solution)

    neighborhood = []
    for i in critical_jobs:
        for j in critical_jobs:
            if i < j:
                neighbor = swap(solution, i, j)
                neighborhood.append(neighbor)

    return neighborhood[:candidate_size]
```

**技术2：Don't Look Bits**

```python
class DontLookBits:
    """
    标记近期无改进的元素，暂时跳过

    原理：如果元素i参与的邻域操作都无改进，
         暂时不考虑涉及i的操作，直到i被其他操作改变
    """
    def __init__(self, n):
        self.bits = [False] * n  # False表示需要查看

    def should_skip(self, i):
        return self.bits[i]

    def mark_no_improvement(self, i):
        self.bits[i] = True  # 标记为暂时跳过

    def reset(self, i):
        self.bits[i] = False  # 元素改变，重新激活
```

## 实现框架

### 算法1：Hill Climbing（爬山法）

Hill Climbing是最基础的改进式启发式算法，严格接受改进解，直到局部最优。

```python
import copy
from typing import Callable, Any, Tuple, List

class HillClimbing:
    """
    爬山法（Hill Climbing）

    算法特点：
    - 最简单的局部搜索算法
    - 严格只接受改进解
    - 确定性算法，同一初始解得到同一结果
    - 快速收敛到局部最优

    适用场景：
    - 快速解精炼
    - 作为更复杂算法的基础组件
    - 解空间相对平滑的问题
    """

    def __init__(self, config: dict = None):
        """
        初始化爬山法

        参数:
            config: 算法配置
                - max_iterations: 最大迭代次数
                - improvement_strategy: 'best' 或 'first'
                - verbose: 是否输出详细信息
        """
        self.config = config or {}
        self.max_iterations = self.config.get('max_iterations', 1000)
        self.improvement_strategy = self.config.get('improvement_strategy', 'best')
        self.verbose = self.config.get('verbose', False)

        # 记录搜索历史
        self.iteration_history = []
        self.best_solution = None
        self.best_objective = float('inf')

    def run(self,
            initial_solution: Any,
            objective_function: Callable[[Any], float],
            neighborhood_generator: Callable[[Any], List[Any]]) -> Tuple[Any, float, dict]:
        """
        执行爬山法

        参数:
            initial_solution: 初始解
            objective_function: 目标函数 f(solution) -> objective_value
            neighborhood_generator: 邻域生成函数 g(solution) -> [neighbors]

        返回:
            (best_solution, best_objective, info)
            info包含：iterations, trajectory, convergence_iteration
        """
        current_solution = copy.deepcopy(initial_solution)
        current_objective = objective_function(current_solution)

        self.best_solution = copy.deepcopy(current_solution)
        self.best_objective = current_objective
        self.iteration_history = [(0, current_objective)]

        iteration = 0
        no_improvement_count = 0

        if self.verbose:
            print(f"Initial solution objective: {current_objective:.4f}")

        while iteration < self.max_iterations:
            iteration += 1

            # 生成邻域并寻找改进解
            if self.improvement_strategy == 'best':
                neighbor, neighbor_obj = self._best_improvement(
                    current_solution, objective_function, neighborhood_generator
                )
            else:  # first improvement
                neighbor, neighbor_obj = self._first_improvement(
                    current_solution, objective_function, neighborhood_generator
                )

            # 如果找到改进解
            if neighbor is not None and neighbor_obj < current_objective:
                improvement = current_objective - neighbor_obj
                current_solution = neighbor
                current_objective = neighbor_obj

                # 更新最优解
                if current_objective < self.best_objective:
                    self.best_solution = copy.deepcopy(current_solution)
                    self.best_objective = current_objective

                no_improvement_count = 0

                if self.verbose:
                    print(f"Iteration {iteration}: Objective = {current_objective:.4f}, "
                          f"Improvement = {improvement:.4f}")
            else:
                # 无改进，达到局部最优
                no_improvement_count += 1
                if self.verbose:
                    print(f"Iteration {iteration}: No improvement found, "
                          f"local optimum reached")
                break

            self.iteration_history.append((iteration, current_objective))

        info = {
            'iterations': iteration,
            'trajectory': self.iteration_history,
            'convergence_iteration': iteration - no_improvement_count,
            'final_objective': self.best_objective,
            'improvement_from_initial': initial_solution_obj - self.best_objective
        }

        if self.verbose:
            print(f"\nHill Climbing completed:")
            print(f"  Total iterations: {iteration}")
            print(f"  Best objective: {self.best_objective:.4f}")
            print(f"  Improvement: {info['improvement_from_initial']:.4f}")

        return self.best_solution, self.best_objective, info

    def _best_improvement(self, current_solution, objective_function, neighborhood_generator):
        """最优改进策略"""
        current_obj = objective_function(current_solution)
        best_neighbor = None
        best_obj = current_obj

        for neighbor in neighborhood_generator(current_solution):
            neighbor_obj = objective_function(neighbor)
            if neighbor_obj < best_obj:
                best_obj = neighbor_obj
                best_neighbor = neighbor

        return best_neighbor, best_obj

    def _first_improvement(self, current_solution, objective_function, neighborhood_generator):
        """首次改进策略"""
        current_obj = objective_function(current_solution)

        for neighbor in neighborhood_generator(current_solution):
            neighbor_obj = objective_function(neighbor)
            if neighbor_obj < current_obj:
                return neighbor, neighbor_obj

        return None, current_obj


# 保存初始解目标值用于计算改进
initial_solution_obj = None

def set_initial_objective(obj):
    global initial_solution_obj
    initial_solution_obj = obj
```

### 算法2：Variable Neighborhood Descent (VND)

VND通过系统化地使用多个邻域结构来提高搜索质量。

```python
class VariableNeighborhoodDescent:
    """
    变邻域下降法（Variable Neighborhood Descent, VND）

    核心思想：
    - 使用多个不同的邻域结构
    - 在一个邻域达到局部最优后，切换到下一个邻域
    - 如果在新邻域找到改进，回到第一个邻域重新开始

    优势：
    - 一个邻域的局部最优可能在另一个邻域有改进空间
    - 系统化探索不同类型的邻域
    - 通常能跳出简单局部搜索的陷阱

    适用场景：
    - 多种自然邻域操作的问题（如排列问题：swap, insert, reverse）
    - 需要较高解质量的场景
    - 作为元启发式算法的局部搜索组件
    """

    def __init__(self, config: dict = None):
        """
        初始化VND

        参数:
            config: 算法配置
                - max_iterations: 最大迭代次数
                - improvement_strategy: 每个邻域内的改进策略
                - neighborhood_order: 邻域使用顺序策略
        """
        self.config = config or {}
        self.max_iterations = self.config.get('max_iterations', 10000)
        self.improvement_strategy = self.config.get('improvement_strategy', 'best')
        self.verbose = self.config.get('verbose', False)

        self.iteration_history = []
        self.neighborhood_usage = []  # 记录每次使用的邻域

    def run(self,
            initial_solution: Any,
            objective_function: Callable[[Any], float],
            neighborhood_generators: List[Callable[[Any], List[Any]]]) -> Tuple[Any, float, dict]:
        """
        执行VND

        参数:
            initial_solution: 初始解
            objective_function: 目标函数
            neighborhood_generators: 邻域生成函数列表
                例如：[swap_neighborhood, insert_neighborhood, reverse_neighborhood]

        返回:
            (best_solution, best_objective, info)
        """
        current_solution = copy.deepcopy(initial_solution)
        current_objective = objective_function(current_solution)

        best_solution = copy.deepcopy(current_solution)
        best_objective = current_objective

        k = 0  # 当前邻域索引
        num_neighborhoods = len(neighborhood_generators)
        iteration = 0

        if self.verbose:
            print(f"VND started with {num_neighborhoods} neighborhood structures")
            print(f"Initial objective: {current_objective:.4f}")

        while k < num_neighborhoods and iteration < self.max_iterations:
            iteration += 1

            # 在当前邻域k中搜索
            if self.improvement_strategy == 'best':
                neighbor, neighbor_obj = self._best_improvement(
                    current_solution, objective_function, neighborhood_generators[k]
                )
            else:
                neighbor, neighbor_obj = self._first_improvement(
                    current_solution, objective_function, neighborhood_generators[k]
                )

            # 如果在当前邻域找到改进
            if neighbor is not None and neighbor_obj < current_objective:
                improvement = current_objective - neighbor_obj
                current_solution = neighbor
                current_objective = neighbor_obj

                if current_objective < best_objective:
                    best_solution = copy.deepcopy(current_solution)
                    best_objective = current_objective

                k = 0  # 回到第一个邻域

                self.neighborhood_usage.append(k)
                self.iteration_history.append((iteration, current_objective, k))

                if self.verbose:
                    print(f"Iteration {iteration}: Neighborhood {k}, "
                          f"Objective = {current_objective:.4f}, "
                          f"Improvement = {improvement:.4f}")
            else:
                # 当前邻域无改进，切换到下一个邻域
                k += 1
                if self.verbose and k < num_neighborhoods:
                    print(f"Iteration {iteration}: Switching to neighborhood {k}")

        info = {
            'iterations': iteration,
            'trajectory': self.iteration_history,
            'neighborhood_usage': self.neighborhood_usage,
            'neighborhoods_explored': num_neighborhoods,
            'final_objective': best_objective
        }

        if self.verbose:
            print(f"\nVND completed:")
            print(f"  Total iterations: {iteration}")
            print(f"  Best objective: {best_objective:.4f}")
            print(f"  Neighborhoods used: {len(set(self.neighborhood_usage))}/{num_neighborhoods}")

        return best_solution, best_objective, info

    def _best_improvement(self, current_solution, objective_function, neighborhood_generator):
        """最优改进"""
        current_obj = objective_function(current_solution)
        best_neighbor = None
        best_obj = current_obj

        for neighbor in neighborhood_generator(current_solution):
            neighbor_obj = objective_function(neighbor)
            if neighbor_obj < best_obj:
                best_obj = neighbor_obj
                best_neighbor = neighbor

        return best_neighbor, best_obj

    def _first_improvement(self, current_solution, objective_function, neighborhood_generator):
        """首次改进"""
        current_obj = objective_function(current_solution)

        for neighbor in neighborhood_generator(current_solution):
            neighbor_obj = objective_function(neighbor)
            if neighbor_obj < current_obj:
                return neighbor, neighbor_obj

        return None, current_obj
```

### 算法3：2-opt for TSP

2-opt是TSP问题最经典的改进式启发式算法。

```python
class TwoOpt:
    """
    2-opt算法：TSP专用局部搜索

    原理：
    - 删除路径中的两条边
    - 反转中间的子路径，重新连接
    - 消除路径交叉，减少总距离

    示例：
    原路径: A → B → C → D → E → A
    删除边: (B,C) 和 (D,E)
    反转C-D: A → B → D → C → E → A

    时间复杂度：
    - 单次迭代: O(n²) 邻域大小
    - 总复杂度: O(k × n²) k为迭代次数

    适用：
    - 旅行商问题（TSP）
    - 车辆路径问题（VRP）
    - 任何环形路径优化问题
    """

    def __init__(self, distance_matrix: List[List[float]], config: dict = None):
        """
        初始化2-opt算法

        参数:
            distance_matrix: 距离矩阵 [n x n]
            config: 算法配置
        """
        self.distance_matrix = distance_matrix
        self.n = len(distance_matrix)
        self.config = config or {}
        self.max_iterations = self.config.get('max_iterations', 1000)
        self.verbose = self.config.get('verbose', False)

    def calculate_tour_length(self, tour: List[int]) -> float:
        """计算路径总长度"""
        length = 0
        for i in range(len(tour)):
            from_city = tour[i]
            to_city = tour[(i + 1) % len(tour)]
            length += self.distance_matrix[from_city][to_city]
        return length

    def two_opt_swap(self, tour: List[int], i: int, k: int) -> List[int]:
        """
        执行2-opt交换

        参数:
            tour: 当前路径
            i, k: 删除边的位置

        返回:
            新路径
        """
        # 取路径的前半部分，反转中间部分，连接后半部分
        new_tour = tour[:i] + tour[i:k+1][::-1] + tour[k+1:]
        return new_tour

    def run(self, initial_tour: List[int]) -> Tuple[List[int], float, dict]:
        """
        执行2-opt优化

        参数:
            initial_tour: 初始路径（城市索引序列）

        返回:
            (best_tour, best_length, info)
        """
        best_tour = initial_tour.copy()
        best_length = self.calculate_tour_length(best_tour)

        iteration = 0
        improvement = True
        iteration_history = [(0, best_length)]

        if self.verbose:
            print(f"Initial tour length: {best_length:.4f}")

        while improvement and iteration < self.max_iterations:
            improvement = False
            iteration += 1

            # 尝试所有可能的2-opt交换
            for i in range(self.n - 1):
                for k in range(i + 1, self.n):
                    # 执行2-opt交换
                    new_tour = self.two_opt_swap(best_tour, i, k)
                    new_length = self.calculate_tour_length(new_tour)

                    # 如果找到改进
                    if new_length < best_length:
                        best_tour = new_tour
                        improvement_value = best_length - new_length
                        best_length = new_length
                        improvement = True

                        iteration_history.append((iteration, best_length))

                        if self.verbose:
                            print(f"Iteration {iteration}: "
                                  f"Found improvement at ({i},{k}), "
                                  f"New length = {best_length:.4f}, "
                                  f"Improvement = {improvement_value:.4f}")

                        break  # First improvement策略

                if improvement:
                    break

        info = {
            'iterations': iteration,
            'trajectory': iteration_history,
            'final_length': best_length,
            'improvement': iteration_history[0][1] - best_length
        }

        if self.verbose:
            print(f"\n2-opt completed:")
            print(f"  Total iterations: {iteration}")
            print(f"  Best tour length: {best_length:.4f}")
            print(f"  Total improvement: {info['improvement']:.4f}")

        return best_tour, best_length, info
```

### 算法4：Swap Neighborhood for Scheduling

针对调度问题的Swap邻域搜索实现。

```python
class SwapNeighborhoodSearch:
    """
    Swap邻域搜索：调度问题专用

    原理：
    - 交换序列中任意两个作业的位置
    - 重新计算调度目标（如makespan, 总完工时间等）
    - 接受改进的交换

    适用问题：
    - 流水车间调度（Flowshop Scheduling）
    - 单机调度（Single Machine Scheduling）
    - 作业车间调度（Job Shop Scheduling）的部分子问题

    邻域大小：C(n,2) = n(n-1)/2
    """

    def __init__(self, problem_data: dict, config: dict = None):
        """
        初始化Swap邻域搜索

        参数:
            problem_data: 问题数据
                - processing_times: 加工时间矩阵 [n_jobs x n_machines]
                - objective_type: 'makespan', 'total_completion', 'total_tardiness'
                - due_dates: 交货期（可选，用于tardiness目标）
            config: 算法配置
        """
        self.problem_data = problem_data
        self.processing_times = problem_data['processing_times']
        self.n_jobs = len(self.processing_times)
        self.n_machines = len(self.processing_times[0]) if self.processing_times else 0
        self.objective_type = problem_data.get('objective_type', 'makespan')
        self.due_dates = problem_data.get('due_dates', None)

        self.config = config or {}
        self.max_iterations = self.config.get('max_iterations', 1000)
        self.improvement_strategy = self.config.get('improvement_strategy', 'best')
        self.verbose = self.config.get('verbose', False)

    def calculate_makespan(self, job_sequence: List[int]) -> float:
        """
        计算流水车间调度的makespan

        参数:
            job_sequence: 作业序列（作业索引列表）

        返回:
            makespan值
        """
        n = len(job_sequence)
        m = self.n_machines

        # completion[i][j]: 第i个作业在第j台机器上的完工时间
        completion = [[0] * m for _ in range(n)]

        # 第一个作业
        completion[0][0] = self.processing_times[job_sequence[0]][0]
        for j in range(1, m):
            completion[0][j] = completion[0][j-1] + self.processing_times[job_sequence[0]][j]

        # 后续作业
        for i in range(1, n):
            job = job_sequence[i]

            # 第一台机器
            completion[i][0] = completion[i-1][0] + self.processing_times[job][0]

            # 后续机器
            for j in range(1, m):
                completion[i][j] = max(completion[i][j-1], completion[i-1][j]) + \
                                   self.processing_times[job][j]

        return completion[n-1][m-1]

    def calculate_objective(self, job_sequence: List[int]) -> float:
        """根据目标类型计算目标值"""
        if self.objective_type == 'makespan':
            return self.calculate_makespan(job_sequence)
        elif self.objective_type == 'total_completion':
            return self._calculate_total_completion(job_sequence)
        elif self.objective_type == 'total_tardiness':
            return self._calculate_total_tardiness(job_sequence)
        else:
            raise ValueError(f"Unknown objective type: {self.objective_type}")

    def _calculate_total_completion(self, job_sequence: List[int]) -> float:
        """计算总完工时间"""
        # 简化版本：假设单机调度
        total = 0
        current_time = 0
        for job in job_sequence:
            current_time += sum(self.processing_times[job])
            total += current_time
        return total

    def _calculate_total_tardiness(self, job_sequence: List[int]) -> float:
        """计算总拖期"""
        if self.due_dates is None:
            raise ValueError("Due dates required for tardiness objective")

        total_tardiness = 0
        current_time = 0
        for job in job_sequence:
            current_time += sum(self.processing_times[job])
            tardiness = max(0, current_time - self.due_dates[job])
            total_tardiness += tardiness
        return total_tardiness

    def generate_swap_neighborhood(self, job_sequence: List[int]) -> List[List[int]]:
        """生成Swap邻域"""
        neighborhood = []
        n = len(job_sequence)

        for i in range(n):
            for j in range(i + 1, n):
                neighbor = job_sequence.copy()
                neighbor[i], neighbor[j] = neighbor[j], neighbor[i]
                neighborhood.append(neighbor)

        return neighborhood

    def run(self, initial_sequence: List[int]) -> Tuple[List[int], float, dict]:
        """
        执行Swap邻域搜索

        参数:
            initial_sequence: 初始作业序列

        返回:
            (best_sequence, best_objective, info)
        """
        current_sequence = initial_sequence.copy()
        current_objective = self.calculate_objective(current_sequence)

        best_sequence = current_sequence.copy()
        best_objective = current_objective

        iteration = 0
        iteration_history = [(0, current_objective)]

        if self.verbose:
            print(f"Initial {self.objective_type}: {current_objective:.4f}")

        while iteration < self.max_iterations:
            iteration += 1
            improved = False

            # 生成邻域
            neighborhood = self.generate_swap_neighborhood(current_sequence)

            if self.improvement_strategy == 'best':
                # Best improvement
                best_neighbor = None
                best_neighbor_obj = current_objective

                for neighbor in neighborhood:
                    neighbor_obj = self.calculate_objective(neighbor)
                    if neighbor_obj < best_neighbor_obj:
                        best_neighbor_obj = neighbor_obj
                        best_neighbor = neighbor
                        improved = True

                if improved:
                    current_sequence = best_neighbor
                    current_objective = best_neighbor_obj

            else:  # first improvement
                for neighbor in neighborhood:
                    neighbor_obj = self.calculate_objective(neighbor)
                    if neighbor_obj < current_objective:
                        current_sequence = neighbor
                        current_objective = neighbor_obj
                        improved = True
                        break

            if improved:
                if current_objective < best_objective:
                    best_sequence = current_sequence.copy()
                    best_objective = current_objective

                iteration_history.append((iteration, current_objective))

                if self.verbose:
                    print(f"Iteration {iteration}: {self.objective_type} = {current_objective:.4f}")
            else:
                # 达到局部最优
                if self.verbose:
                    print(f"Iteration {iteration}: Local optimum reached")
                break

        info = {
            'iterations': iteration,
            'trajectory': iteration_history,
            'final_objective': best_objective,
            'improvement': iteration_history[0][1] - best_objective
        }

        if self.verbose:
            print(f"\nSwap neighborhood search completed:")
            print(f"  Iterations: {iteration}")
            print(f"  Best {self.objective_type}: {best_objective:.4f}")
            print(f"  Improvement: {info['improvement']:.4f}")

        return best_sequence, best_objective, info
```

### 参数配置指南

| 参数名称                 | 推荐范围                 | 默认值 | 影响说明                                           |
| ------------------------ | ------------------------ | ------ | -------------------------------------------------- |
| **max_iterations**       | 100-10000                | 1000   | 最大迭代次数；过小可能未充分搜索，过大浪费计算时间 |
| **improvement_strategy** | first/best               | best   | first更快但质量略低，best质量高但计算量大          |
| **neighborhood_type**    | swap/insert/reverse/2opt | swap   | 邻域类型影响搜索方向，需根据问题选择               |
| **neighborhood_size**    | 10-n²                    | 全邻域 | 候选列表大小，减少可提速但可能错过最优解           |
| **aspiration_criterion** | true/false               | false  | 是否使用aspiration准则，允许特殊情况接受劣化解     |
| **diversification_rate** | 0.0-0.3                  | 0.0    | 多样化比例，>0时随机接受部分邻域解                 |
| **vnd_neighborhoods**    | 2-5个                    | 3      | VND使用的邻域数量，太多计算量大，太少效果差        |
| **delta_evaluation**     | true/false               | true   | 是否使用增量评估，建议开启以提速                   |

**参数调优建议**：

1. **小规模问题（n < 50）**：
   - improvement_strategy = 'best'
   - max_iterations = 500
   - 使用完整邻域

2. **中等规模问题（50 ≤ n < 200）**：
   - improvement_strategy = 'best' 或 'first'
   - max_iterations = 1000
   - 考虑候选列表

3. **大规模问题（n ≥ 200）**：
   - improvement_strategy = 'first'
   - max_iterations = 2000
   - 必须使用候选列表和增量评估

### 实现注意事项

**1. 深拷贝 vs 浅拷贝**

```python

def evaluate_neighbor_delta(current_solution, move, current_obj):
```

### 案例1：TSP的2-opt改进

**场景描述**：
某物流公司需要规划配送路线，访问50个客户点后返回仓库。目标是最小化总行驶距离。

**问题建模**：

```yaml
决策变量:
  - tour: 城市访问顺序 [0, 1, 2, ..., 49, 0]
  - 0表示仓库，1-49表示客户点

约束条件:
  - 每个城市恰好访问一次
  - 路径形成闭环

目标函数:
  - minimize: Σ distance(tour[i], tour[i+1])
```

**实施方案**：

```python
import numpy as np
import random

# 1. 生成测试数据：50个随机分布的城市
def generate_tsp_instance(n_cities=50, seed=42):
    """生成TSP测试实例"""
    np.random.seed(seed)

    # 随机生成城市坐标
    coordinates = np.random.rand(n_cities, 2) * 100

    # 计算距离矩阵
    distance_matrix = np.zeros((n_cities, n_cities))
    for i in range(n_cities):
        for j in range(n_cities):
            distance_matrix[i][j] = np.linalg.norm(
                coordinates[i] - coordinates[j]
            )

    return distance_matrix, coordinates

# 2. 生成初始解：最近邻启发式
def nearest_neighbor_tsp(distance_matrix, start_city=0):
    """最近邻算法生成初始TSP路径"""
    n = len(distance_matrix)
    unvisited = set(range(n))
    tour = [start_city]
    unvisited.remove(start_city)

    current = start_city
    while unvisited:
        # 找最近的未访问城市
        nearest = min(unvisited, key=lambda city: distance_matrix[current][city])
        tour.append(nearest)
        unvisited.remove(nearest)
        current = nearest

    return tour

# 3. 应用2-opt改进

    print("Generating initial solution with Nearest Neighbor...")
    initial_tour = nearest_neighbor_tsp(distance_matrix)

    two_opt = TwoOpt(
        distance_matrix=distance_matrix,
        config={
            'max_iterations': 1000,
            'verbose': True
        }
    )

    # 执行2-opt优化
    print("\nApplying 2-opt improvement...")
    improved_tour, improved_length, info = two_opt.run(initial_tour)

    # 结果分析
    initial_length = two_opt.calculate_tour_length(initial_tour)
    improvement_percentage = (initial_length - improved_length) / initial_length * 100

    print(f"\n{'='*60}")
    print(f"TSP 2-opt Optimization Results")
    print(f"{'='*60}")
    print(f"Number of cities: 50")
    print(f"Initial tour length (Nearest Neighbor): {initial_length:.2f}")
    print(f"Improved tour length (2-opt): {improved_length:.2f}")
    print(f"Improvement: {improvement_percentage:.2f}%")
    print(f"Iterations: {info['iterations']}")
    print(f"{'='*60}")

    return improved_tour, improved_length, info

# 运行示例
if __name__ == "__main__":
    tour, length, info = apply_2opt_to_tsp()
```

### 案例2：Flowshop调度的VND改进

**场景描述**：
电子制造厂的SMT生产线，10个产品需要经过5道工序（印刷、贴片、回流焊、检测、包装）。每道工序只有一台设备，产品必须按相同顺序流经所有工序。目标是最小化makespan（最大完工时间）。

**问题建模**：

```yaml
决策变量:
  - job_sequence: 作业加工顺序 [J1, J2, ..., J10]

约束条件:
  - 流水车间约束：所有作业相同工序顺序
  - 机器约束：每台机器同时只能加工一个作业
  - 作业约束：每个作业同时只在一台机器上

目标函数:
  - minimize: makespan = max{完工时间}
```

**实施方案**：

```python
import numpy as np

# 1. 问题数据：10个作业 × 5台机器的加工时间
processing_times = [
    [5, 3, 6, 7, 4],   # Job 0
    [4, 5, 5, 6, 5],   # Job 1
    [6, 4, 7, 8, 5],   # Job 2
    [3, 6, 4, 5, 6],   # Job 3
    [5, 4, 6, 7, 4],   # Job 4
    [4, 5, 5, 6, 5],   # Job 5
    [6, 3, 7, 8, 6],   # Job 6
    [3, 5, 4, 5, 5],   # Job 7
    [5, 4, 6, 7, 4],   # Job 8
    [4, 6, 5, 6, 5],   # Job 9
]

# 2. 定义多个邻域结构
def swap_neighborhood(sequence):
    """Swap邻域：交换任意两个作业"""
    n = len(sequence)
    for i in range(n):
        for j in range(i + 1, n):
            neighbor = sequence.copy()
            neighbor[i], neighbor[j] = neighbor[j], neighbor[i]
            yield neighbor

def insert_neighborhood(sequence):
    """Insert邻域：移动一个作业到新位置"""
    n = len(sequence)
    for i in range(n):
        for j in range(n):
            if i != j:
                neighbor = sequence.copy()
                job = neighbor.pop(i)
                neighbor.insert(j, job)
                yield neighbor

def reverse_neighborhood(sequence):
    """Reverse邻域：反转子序列"""
    n = len(sequence)
    for i in range(n):
        for j in range(i + 2, n + 1):  # 至少反转2个元素
            neighbor = sequence.copy()
            neighbor[i:j] = neighbor[i:j][::-1]
            yield neighbor

# 3. 生成初始解：NEH算法
def neh_algorithm(processing_times):
    """NEH算法生成Flowshop初始解"""
    n_jobs = len(processing_times)

    # 按总加工时间降序排序
    total_times = [sum(processing_times[j]) for j in range(n_jobs)]
    sorted_jobs = sorted(range(n_jobs), key=lambda j: total_times[j], reverse=True)

    # 取前两个作业
    sequence = sorted_jobs[:2]

    # 逐个插入剩余作业
    for k in range(2, n_jobs):
        job = sorted_jobs[k]
        best_pos = 0
        best_makespan = float('inf')

        # 尝试所有插入位置
        for pos in range(len(sequence) + 1):
            temp_seq = sequence[:pos] + [job] + sequence[pos:]
            makespan = calculate_makespan(temp_seq, processing_times)
            if makespan < best_makespan:
                best_makespan = makespan
                best_pos = pos

        sequence = sequence[:best_pos] + [job] + sequence[best_pos:]

    return sequence

def calculate_makespan(sequence, processing_times):
    """计算makespan"""
    n = len(sequence)
    m = len(processing_times[0])

    completion = [[0] * m for _ in range(n)]

    # 第一个作业
    completion[0][0] = processing_times[sequence[0]][0]
    for j in range(1, m):
        completion[0][j] = completion[0][j-1] + processing_times[sequence[0]][j]

    # 后续作业
    for i in range(1, n):
        job = sequence[i]
        completion[i][0] = completion[i-1][0] + processing_times[job][0]
        for j in range(1, m):
            completion[i][j] = max(completion[i][j-1], completion[i-1][j]) + processing_times[job][j]

    return completion[n-1][m-1]
```

### 案例3：Job Shop关键路径改进

**场景描述**：
机械加工车间有3台机器，需要加工5个零件。每个零件有不同的工艺路线和加工时间。目标是最小化makespan。

**问题建模**：

```yaml
决策变量:
  - operation_sequence: 每台机器上的操作序列

约束条件:
  - 工艺路线约束：每个作业按指定工艺路线加工
  - 机器约束：机器不能同时加工多个操作
  - 作业约束：作业不能同时在多台机器上

目标函数:
  - minimize: makespan
```

**实施方案**：

```python
# Job Shop数据结构
# jobs[i] = [(machine, processing_time), ...]
jobs = [
    # Job 0: M0(3) → M1(2) → M2(2)
    [(0, 3), (1, 2), (2, 2)],
    # Job 1: M0(2) → M2(1) → M1(4)
    [(0, 2), (2, 1), (1, 4)],
    # Job 2: M1(4) → M2(3)
    [(1, 4), (2, 3)],
    # Job 3: M0(4) → M1(3)
    [(0, 4), (1, 3)],
    # Job 4: M2(2) → M0(3) → M1(1)
    [(2, 2), (0, 3), (1, 1)],
]

def calculate_jobshop_makespan(solution, jobs):
    """
    计算Job Shop调度的makespan

    参数:
        solution: {machine_id: [operation_indices]}
        jobs: 作业工艺路线定义
    """
    # operation_completion[(job, op_idx)] = 完工时间
    operation_completion = {}
    machine_available = {m: 0 for m in range(3)}  # 3台机器

    # 按机器序列处理操作
    for machine, op_sequence in solution.items():
        for op_idx in op_sequence:
            job_id, op_position = op_idx
            machine_id, proc_time = jobs[job_id][op_position]

            # 计算开始时间
            # 考虑：机器可用时间、前序操作完工时间
            machine_ready = machine_available[machine]

            if op_position == 0:
                # 第一道工序
                start_time = machine_ready
            else:
                # 等待前序工序完工
                prev_op_completion = operation_completion[(job_id, op_position - 1)]
                start_time = max(machine_ready, prev_op_completion)

            completion_time = start_time + proc_time
            operation_completion[(job_id, op_position)] = completion_time
            machine_available[machine] = completion_time

    # Makespan = 最后完成的操作
    return max(operation_completion.values())

def identify_critical_path(solution, jobs):
    """识别关键路径上的操作"""
    # 简化版：返回makespan路径上的操作
    # 实际实现需要回溯完工时间等于makespan的路径
    makespan = calculate_jobshop_makespan(solution, jobs)

    critical_operations = []
    # 找到完工时间等于makespan的作业
    for job_id in range(len(jobs)):
        last_op = len(jobs[job_id]) - 1
        # 检查是否在关键路径上
        critical_operations.append((job_id, last_op))

    return critical_operations

def critical_path_neighborhood(solution, jobs):
    """
    关键路径邻域：只交换关键路径上的操作

    策略：
    - 识别关键路径
    - 只考虑关键路径上操作的位置调整
    - 大幅减少邻域大小，提高效率
    """
    critical_ops = identify_critical_path(solution, jobs)

    # 生成关键路径操作的交换邻域
    for i, op1 in enumerate(critical_ops):
        for op2 in critical_ops[i+1:]:
            job1, pos1 = op1
            job2, pos2 = op2

            # 只交换同一台机器上的操作
            machine1 = jobs[job1][pos1][0]
            machine2 = jobs[job2][pos2][0]

            if machine1 == machine2:
                # 创建邻域解：交换机器序列中的位置
                neighbor = copy.deepcopy(solution)
                machine_seq = neighbor[machine1]

                idx1 = machine_seq.index((job1, pos1))
                idx2 = machine_seq.index((job2, pos2))
                machine_seq[idx1], machine_seq[idx2] = machine_seq[idx2], machine_seq[idx1]

                yield neighbor
```

## 优势与局限

### 优势

- ✅ **灵活的起点**：可以从任意初始解开始，不限于构造式方法
- ✅ **实现简单**：算法逻辑清晰，编程难度低
- ✅ **计算高效**：相比元启发式，单次迭代计算量小
- ✅ **组合性强**：易于与其他算法组合（如GA的局部搜索、ILS的改进阶段）
- ✅ **并行化容易**：多起点搜索天然支持并行
- ✅ **可解释性好**：搜索轨迹和改进过程容易理解
- ✅ **适合大规模**：对于大规模问题，局部搜索仍可快速执行

### 局限

- ⚠️ **局部最优陷阱**：基础版本容易陷入局部最优，难以跳出
- ⚠️ **依赖初始解**：解质量受初始解影响大，差的初始解可能导致差的局部最优
- ⚠️ **邻域设计关键**：不合适的邻域结构严重影响性能
- ⚠️ **缺乏全局视野**：只关注当前解邻域,可能错过远处的优质区域
- ⚠️ **参数敏感**：邻域大小、改进策略等参数需要调优
- ⚠️ **无质量保证**：无法保证解的质量上界或与最优解的距离

### 适用性判断

**✅ 适合使用的情况**：

1. **已有较好初始解**：
   - 构造式启发式已生成不错的解
   - 需要进一步精炼提升质量

2. **需要快速改进**：
   - 时间约束严格
   - 需要实时响应
   - 在线优化场景

3. **作为混合算法组件**：
   - 遗传算法的局部搜索
   - 模拟退火的邻域搜索
   - 蚁群算法的信息素更新后改进

4. **问题有明确邻域结构**：
   - 排列问题（Swap, Insert, Reverse）
   - TSP类问题（2-opt, 3-opt）
   - 调度问题（邻域操作容易定义）

5. **大规模问题的快速优化**：
   - 完整优化方法太慢
   - 需要"足够好"的解即可

**❌ 不适合使用的情况**：

1. **需要全局最优保证**：
   - 关键任务，必须最优
   - 小规模问题，精确算法可行

2. **初始解质量很差**：
   - 随机生成的初始解
   - 没有好的构造式方法

3. **邻域结构难以定义**：
   - 连续优化问题（不如梯度方法）
   - 高度约束问题（邻域大多不可行）

4. **解空间高度不连续**：
   - 微小改变导致目标值剧变
   - 大量局部最优均匀分布

## 扩展变种

### 1. 随机化改进（Randomized Improvement）

**核心思想**：
在邻域中随机选择解，而非总是选择最优或首次改进解。

**算法调整**：

```python
def randomized_improvement(current_solution, objective_function, neighborhood_generator, acceptance_prob=0.3):
    """
    随机化改进策略

    以概率p接受随机改进解，以概率(1-p)使用最优改进
    """
    current_obj = objective_function(current_solution)

    # 生成邻域
    neighborhood = list(neighborhood_generator(current_solution))

    if random.random() < acceptance_prob:
        # 随机选择改进解
        improving_neighbors = [
            (n, objective_function(n))
            for n in neighborhood
            if objective_function(n) < current_obj
        ]
        if improving_neighbors:
            return random.choice(improving_neighbors)
    else:
        # 最优改进
        best_neighbor = min(
            neighborhood,
            key=lambda n: objective_function(n)
        )
        best_obj = objective_function(best_neighbor)
        if best_obj < current_obj:
            return best_neighbor, best_obj

    return None, current_obj
```

**优势**：

- 增加搜索多样性
- 可能避免过早收敛
- 探索更多解空间区域

**适用**：

- 与确定性方法配合使用
- 解空间有多个相似质量的区域

### 2. First vs Best Improvement策略对比

**First Improvement（首次改进）**：

```python
def first_improvement_search(solution, objective_func, neighborhood_gen):
    """找到第一个改进就接受"""
    current_obj = objective_func(solution)

    for neighbor in neighborhood_gen(solution):
        neighbor_obj = objective_func(neighbor)
        if neighbor_obj < current_obj:
            return neighbor, neighbor_obj  # 立即返回

    return None, current_obj
```

**Best Improvement（最优改进）**：

```python
def best_improvement_search(solution, objective_func, neighborhood_gen):
    """搜索完整邻域找最优"""
    current_obj = objective_func(solution)
    best_neighbor = None
    best_obj = current_obj

    for neighbor in neighborhood_gen(solution):
        neighbor_obj = objective_func(neighbor)
        if neighbor_obj < best_obj:
            best_obj = neighbor_obj
            best_neighbor = neighbor

    return best_neighbor, best_obj
```

**性能对比**：
| 维度 | First Improvement | Best Improvement |
|-----|------------------|------------------|
| 单次迭代时间 | 快（平均搜索一半邻域） | 慢（搜索完整邻域） |
| 迭代次数 | 多 | 少 |
| 解质量 | 中等 | 较好 |
| 适用场景 | 大规模邻域 | 小规模邻域 |

### 3. 变邻域下降（VND）扩展

**动态邻域顺序**：

```python
class AdaptiveVND(VariableNeighborhoodDescent):
    """
    自适应VND：根据邻域效果动态调整顺序
    """

    def __init__(self, config=None):
        super().__init__(config)
        self.neighborhood_scores = []  # 记录每个邻域的效果

    def run(self, initial_solution, objective_function, neighborhood_generators):
        # 初始化邻域得分
        self.neighborhood_scores = [0] * len(neighborhood_generators)

        current_solution = initial_solution
        current_obj = objective_function(current_solution)

        # 动态调整邻域顺序
        neighborhood_order = list(range(len(neighborhood_generators)))

        iteration = 0
        k = 0

        while k < len(neighborhood_order) and iteration < self.max_iterations:
            iteration += 1

            # 按当前顺序选择邻域
            neighborhood_idx = neighborhood_order[k]
            neighbor, neighbor_obj = self._best_improvement(
                current_solution,
                objective_function,
                neighborhood_generators[neighborhood_idx]
            )

            if neighbor is not None and neighbor_obj < current_obj:
                improvement = current_obj - neighbor_obj
                current_solution = neighbor
                current_obj = neighbor_obj

                # 更新邻域得分
                self.neighborhood_scores[neighborhood_idx] += improvement

                # 重新排序：效果好的邻域优先
                neighborhood_order.sort(
                    key=lambda idx: self.neighborhood_scores[idx],
                    reverse=True
                )

                k = 0  # 回到第一个邻域
            else:
                k += 1

        return current_solution, current_obj, {'iterations': iteration}
```

**优势**：

- 自动识别有效邻域
- 减少无效邻域搜索时间
- 适应不同问题实例

### 4. 多起点局部搜索（Multi-Start Local Search）

**核心思想**：
从多个不同初始解开始局部搜索，取最优结果。

**实现**：

```python
def multi_start_local_search(
    num_starts,
    initial_solution_generator,
    local_search_algorithm,
    objective_function,
    **ls_params
):
    """
    多起点局部搜索

    参数:
        num_starts: 起点数量
        initial_solution_generator: 初始解生成函数
        local_search_algorithm: 局部搜索算法
        objective_function: 目标函数
        **ls_params: 局部搜索参数
    """
    best_solution = None
    best_objective = float('inf')
    all_results = []

    for start_idx in range(num_starts):
        print(f"Multi-start iteration {start_idx + 1}/{num_starts}")

        # 生成初始解
        initial_solution = initial_solution_generator()

        # 执行局部搜索
        solution, objective, info = local_search_algorithm(
            initial_solution,
            objective_function,
            **ls_params
        )

        all_results.append((solution, objective, info))

        # 更新全局最优
        if objective < best_objective:
            best_solution = solution
            best_objective = objective
            print(f"  New best found: {best_objective:.4f}")

    # 统计分析
    objectives = [obj for _, obj, _ in all_results]
    avg_obj = sum(objectives) / len(objectives)
    std_obj = (sum((obj - avg_obj)**2 for obj in objectives) / len(objectives)) ** 0.5

    print(f"\nMulti-start results:")
    print(f"  Best: {best_objective:.4f}")
    print(f"  Average: {avg_obj:.4f}")
    print(f"  Std dev: {std_obj:.4f}")

    return best_solution, best_objective, {
        'all_results': all_results,
        'best_objective': best_objective,
        'average_objective': avg_obj,
        'std_objective': std_obj
    }
```

**优势**：

- 降低对初始解的依赖
- 探索多个解空间区域
- 易于并行实现

**适用**：

- 初始解生成快速
- 局部搜索收敛快
- 有并行计算资源

### 5. 迭代局部搜索（Iterated Local Search, ILS）

**核心思想**：
局部搜索 → 扰动 → 再次局部搜索 → 接受准则

**实现**：

```python
class IteratedLocalSearch:
    """
    迭代局部搜索（ILS）

    算法流程：
    1. 生成初始解s0
    2. s* ← LocalSearch(s0)
    3. repeat:
       a) s' ← Perturbation(s*, strength)
       b) s'' ← LocalSearch(s')
       c) s* ← AcceptanceCriterion(s*, s'', history)
    4. until 终止条件
    """

    def __init__(self, config=None):
        self.config = config or {}
        self.max_iterations = self.config.get('max_iterations', 100)
        self.perturbation_strength = self.config.get('perturbation_strength', 3)
        self.acceptance_criterion = self.config.get('acceptance_criterion', 'better')

    def perturbation(self, solution, strength):
        """
        扰动函数：对解进行适度破坏

        strength: 扰动强度（执行多少次随机操作）
        """
        perturbed = copy.deepcopy(solution)

        for _ in range(strength):
            # 随机swap操作
            n = len(perturbed)
            i, j = random.sample(range(n), 2)
            perturbed[i], perturbed[j] = perturbed[j], perturbed[i]

        return perturbed

    def acceptance_criterion(self, current_best, new_solution, current_obj, new_obj):
        """
        接受准则

        - 'better': 只接受更优解
        - 'random_walk': 总是接受
        - 'simulated_annealing': 以概率接受劣化解
        """
        if self.acceptance_criterion == 'better':
            return new_solution if new_obj < current_obj else current_best

        elif self.acceptance_criterion == 'random_walk':
            return new_solution

        elif self.acceptance_criterion == 'simulated_annealing':
            if new_obj < current_obj:
                return new_solution
            else:
                # 以概率接受劣化解
                delta = new_obj - current_obj
                temperature = self.config.get('temperature', 100)
                prob = math.exp(-delta / temperature)
                return new_solution if random.random() < prob else current_best

    def run(self,
            initial_solution,
            objective_function,
            local_search_algorithm,
            **ls_params):
        """
        执行ILS

        参数:
            initial_solution: 初始解
            objective_function: 目标函数
            local_search_algorithm: 局部搜索算法
            **ls_params: 局部搜索参数
        """
        # 初始局部搜索
        current_best, current_obj, _ = local_search_algorithm(
            initial_solution,
            objective_function,
            **ls_params
        )

        global_best = copy.deepcopy(current_best)
        global_obj = current_obj

        history = [(0, global_obj)]

        for iteration in range(self.max_iterations):
            # 扰动
            perturbed = self.perturbation(current_best, self.perturbation_strength)

            # 局部搜索
            improved, improved_obj, _ = local_search_algorithm(
                perturbed,
                objective_function,
                **ls_params
            )

            # 接受准则
            current_best = self.acceptance_criterion(
                current_best, improved, current_obj, improved_obj
            )
            current_obj = objective_function(current_best)

            # 更新全局最优
            if current_obj < global_obj:
                global_best = copy.deepcopy(current_best)
                global_obj = current_obj
                print(f"ILS Iteration {iteration+1}: New best = {global_obj:.4f}")

            history.append((iteration+1, global_obj))

        return global_best, global_obj, {'history': history}
```

**优势**：

- 有效跳出局部最优
- 比完全随机重启更高效
- 保持搜索的连续性

**扰动强度选择**：

- 太小：难以跳出当前邻域
- 太大：退化为多起点搜索
- 推荐：3-5次基本邻域操作

### 6. 引导局部搜索（Guided Local Search, GLS）

**核心思想**：
使用惩罚函数动态修改目标函数，引导搜索离开频繁访问的区域。

**实现**：

```python
class GuidedLocalSearch:
    """
    引导局部搜索（GLS）

    原理：
    - 维护特征惩罚值
    - 修改目标函数：f'(s) = f(s) + λ * Σ penalty[feature]
    - 局部最优时，惩罚当前解的特征
    """

    def __init__(self, config=None):
        self.config = config or {}
        self.lambda_param = self.config.get('lambda', 0.1)
        self.max_iterations = self.config.get('max_iterations', 1000)

        self.feature_penalties = {}  # 特征 → 惩罚值

    def extract_features(self, solution):
        """
        提取解的特征

        示例：对于TSP，特征可以是边
        对于调度，特征可以是(job_i, job_j)的相对顺序
        """
        features = set()
        n = len(solution)

        # 示例：相邻元素对作为特征
        for i in range(n - 1):
            edge = tuple(sorted([solution[i], solution[i+1]]))
            features.add(edge)

        return features

    def augmented_objective(self, solution, base_objective):
        """
        增广目标函数

        f'(s) = f(s) + λ * Σ penalty[feature(s)]
        """
        base_obj = base_objective(solution)

        features = self.extract_features(solution)
        penalty_sum = sum(
            self.feature_penalties.get(feature, 0)
            for feature in features
        )

        return base_obj + self.lambda_param * penalty_sum

    def penalize_features(self, solution, base_objective):
        """
        惩罚当前解的特征

        策略：惩罚utility最高的特征
        utility[feature] = cost[feature] / (1 + penalty[feature])
        """
        features = self.extract_features(solution)

        # 计算每个特征的utility
        feature_utilities = {}
        for feature in features:
            # 简化：假设每个特征贡献相同
            cost = base_objective(solution) / len(features)
            current_penalty = self.feature_penalties.get(feature, 0)
            utility = cost / (1 + current_penalty)
            feature_utilities[feature] = utility

        # 惩罚utility最高的特征
        max_utility_feature = max(feature_utilities, key=feature_utilities.get)
        self.feature_penalties[max_utility_feature] = \
            self.feature_penalties.get(max_utility_feature, 0) + 1

    def run(self,
            initial_solution,
            base_objective,
            local_search_algorithm,
            **ls_params):
        """执行GLS"""

        current_solution = initial_solution
        best_solution = copy.deepcopy(initial_solution)
        best_objective = base_objective(initial_solution)

        for iteration in range(self.max_iterations):
            # 使用增广目标函数进行局部搜索
            augmented_obj = lambda s: self.augmented_objective(s, base_objective)

            current_solution, _, _ = local_search_algorithm(
                current_solution,
                augmented_obj,
                **ls_params
            )

            # 评估真实目标
            current_real_obj = base_objective(current_solution)

            if current_real_obj < best_objective:
                best_solution = copy.deepcopy(current_solution)
                best_objective = current_real_obj
                print(f"GLS Iteration {iteration+1}: New best = {best_objective:.4f}")

            # 达到局部最优，惩罚特征
            self.penalize_features(current_solution, base_objective)

        return best_solution, best_objective, {}
```

**优势**：

- 系统化避免重复搜索
- 保持解的结构连续性
- 适合有明确特征的问题

**适用**：

- TSP、VRP等边/路径问题
- 调度问题（作业对顺序特征）

```python
V4.0代码生成模板

from abc import ABC, abstractmethod
from typing import Callable, Any, List, Tuple
import copy
import random

class ImprovementHeuristicBase(ABC):
    """
    改进式启发式基类

    所有改进式启发式算法的抽象基类，定义统一接口
    """

    def __init__(self, config: dict = None):
        """
        初始化改进式启发式

        参数:
            config: 配置字典
                - max_iterations: 最大迭代次数
                - improvement_strategy: 'best' 或 'first'
                - verbose: 是否输出详细信息
                - random_seed: 随机种子
        """
        self.config = config or {}
        self.max_iterations = self.config.get('max_iterations', 1000)
        self.improvement_strategy = self.config.get('improvement_strategy', 'best')
        self.verbose = self.config.get('verbose', False)

        if 'random_seed' in self.config:
            random.seed(self.config['random_seed'])

        # 搜索历史
        self.best_solution = None
        self.best_objective = float('inf')
        self.iteration_history = []

    @abstractmethod
    def run(self,
            initial_solution: Any,
            objective_function: Callable[[Any], float],
            **kwargs) -> Tuple[Any, float, dict]:
        """
        执行改进式启发式（抽象方法）

        参数:
            initial_solution: 初始解
            objective_function: 目标函数
            **kwargs: 算法特定参数

        返回:
            (best_solution, best_objective, info)
        """
        pass

    def _evaluate_solution(self, solution: Any, objective_function: Callable) -> float:
        """评估解的目标值"""
        return objective_function(solution)

    def _is_improvement(self, new_obj: float, current_obj: float) -> bool:
        """判断是否为改进"""
        return new_obj < current_obj

    def _update_best(self, solution: Any, objective: float):
        """更新最优解"""
        if objective < self.best_objective:
            self.best_solution = copy.deepcopy(solution)
            self.best_objective = objective

    def get_search_history(self) -> List[Tuple[int, float]]:
        """获取搜索历史"""
        return self.iteration_history


# 示例：具体算法实现
class SimpleHillClimbing(ImprovementHeuristicBase):
    """简化的爬山法实现"""

    def run(self,
            initial_solution: Any,
            objective_function: Callable[[Any], float],
            neighborhood_generator: Callable[[Any], List[Any]]) -> Tuple[Any, float, dict]:

        current_solution = copy.deepcopy(initial_solution)
        current_objective = self._evaluate_solution(current_solution, objective_function)

        self.best_solution = copy.deepcopy(current_solution)
        self.best_objective = current_objective
        self.iteration_history = [(0, current_objective)]

        for iteration in range(1, self.max_iterations + 1):
            # 生成邻域
            neighborhood = neighborhood_generator(current_solution)

            # 寻找改进
            improved = False
            for neighbor in neighborhood:
                neighbor_obj = self._evaluate_solution(neighbor, objective_function)

                if self._is_improvement(neighbor_obj, current_objective):
                    current_solution = neighbor
                    current_objective = neighbor_obj
                    self._update_best(current_solution, current_objective)
                    improved = True

                    if self.improvement_strategy == 'first':
                        break  # First improvement

            self.iteration_history.append((iteration, self.best_objective))

            if not improved:
                break  # 局部最优

        info = {
            'iterations': iteration,
            'final_objective': self.best_objective,
            'trajectory': self.iteration_history
        }

        return self.best_solution, self.best_objective, info
```

```python
# 快速生成改进式启发式原型的辅助函数

def quick_local_search(
    initial_solution,
    objective_func,
    neighbor_generator,
    max_iter=100,
    strategy='best'
):
    """
    快速局部搜索原型

    用于快速测试和原型开发
    """
    current = initial_solution
    current_obj = objective_func(current)
    best, best_obj = current, current_obj

    for _ in range(max_iter):
        neighbors = list(neighbor_generator(current))

        if strategy == 'best':
            # Best improvement
            best_neighbor = min(neighbors, key=objective_func, default=None)
            if best_neighbor and objective_func(best_neighbor) < current_obj:
                current = best_neighbor
                current_obj = objective_func(current)
        else:
            # First improvement
            for neighbor in neighbors:
                if objective_func(neighbor) < current_obj:
                    current = neighbor
                    current_obj = objective_func(current)
                    break

        if current_obj < best_obj:
            best, best_obj = current, current_obj
        else:
            break

    return best, best_obj

    objective_func=lambda s: calculate_makespan(s, processing_times),
    neighbor_generator=lambda s: swap_neighborhood(s),

    strategy='best'
```
