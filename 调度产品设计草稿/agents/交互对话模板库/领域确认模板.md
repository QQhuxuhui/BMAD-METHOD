## 触发场景

当领域识别存在以下情况时使用此模板:

1. 置信度低于阈值 (< 0.70)
2. 多个领域都可能匹配
3. 领域特征不典型或混合
4. 需要用户确认细分领域

## 对话结构

### 步骤1: 呈现分析结果

AI呈现领域识别结果:

- 识别到的主要领域
- 识别置信度
- 识别依据 (关键特征)
- 可能的备选领域

### 步骤2: 提出不确定项

AI请用户确认或选择领域:

- 呈现2-3个最可能的领域
- 说明每个领域的典型特征
- 询问用户的业务场景是否符合

### 步骤3: 解析用户反馈

- **选项选择**: 用户选择匹配的领域
- **特征描述**: 用户补充领域特征
- **多领域**: 用户说明是混合领域

### 步骤4: 更新模型

更新TenElementModel的domain_knowledge:

```python
{
    "domain_type": "用户确认的领域类型",
    "industry": "行业分类",
    "characteristics": ["领域特征1", "领域特征2"],
    "confidence": 0.95  # 用户确认后置信度提升
}
```

## 模板示例

### 示例1: 低置信度需确认

```yaml
AI: |
  ## 🤝 领域场景确认

  **领域识别结果**:
  - 识别到的领域: **车辆路径规划 (VRP)**
  - 置信度: 0.65 (中等)

  **识别依据**:
  - ✅ 涉及多辆车辆
  - ✅ 涉及多个配送点
  - ✅ 涉及路径优化

  ### ❓ 请确认您的业务场景

  您的问题是否符合以下场景之一?

  **选项 1: 标准车辆路径问题 (VRP)**
  - 多辆车从配送中心出发
  - 服务多个客户后返回配送中心
  - 每个客户只需访问一次

  **选项 2: 带时间窗的车辆路径问题 (VRPTW)**
  - 除了标准VRP特征外
  - 每个客户有指定的服务时间窗
  - 必须在时间窗内到达客户

  **选项 3: 多配送中心车辆路径问题 (MDVRP)**
  - 有多个配送中心
  - 车辆从不同配送中心出发
  - 可能需要协调多个中心的配送

  请选择最匹配的选项，或描述您的具体场景。

User: 2，有时间窗要求

AI: |
  ✅ 领域已确认:
  - 领域类型: VRPTW (带时间窗的车辆路径问题)
  - 置信度: 0.95 (用户确认)

  我将调用 VRPTW 领域适配器和相关约束模板。
```

### 示例2: 多领域可能性

```yaml
AI: |
  ## 🤝 领域场景确认

  **领域识别结果**:
  - 识别到 **2个可能的领域** (置信度接近)

  ### ❓ 请选择最匹配的领域

  **选项 1: 项目调度 (Project Scheduling)** - 置信度 0.68
  - 典型特征:
    - 多个任务有先后依赖关系
    - 资源可以同时执行多个任务
    - 关注项目总完成时间
  - 适用: 软件开发、工程项目、活动策划

  **选项 2: 生产调度 (Production Scheduling)** - 置信度 0.64
  - 典型特征:
    - 任务需要在机器/设备上加工
    - 每台设备同时只能加工一个任务
    - 关注生产效率和成本
  - 适用: 制造业、加工业、装配线

  您的问题更接近哪个领域？

User: 项目调度，我们是软件开发团队

AI: |
  ✅ 领域已确认:
  - 领域类型: 项目调度 (Project Scheduling)
  - 行业: 软件开发
  - 置信度: 0.95 (用户确认)

  我将调用项目调度领域适配器，考虑任务依赖和团队协作特性。
```

### 示例3: 混合领域

```yaml
AI: |
  ## 🤝 领域场景确认

  **领域识别结果**:
  - 识别到的主要领域: **供应链调度**
  - 置信度: 0.72

  **但同时检测到以下混合特征**:
  - 包含运输路径规划 (VRP 特征)
  - 包含库存管理 (库存优化特征)
  - 包含订单分配 (调度特征)

  ### ❓ 请确认您的实际场景

  您的问题是否涉及多个子问题的综合优化?

  1. **是** - 这是一个综合供应链优化问题
     - 我会使用多领域协同方法
     - 分别建模不同子问题并协调

  2. **否** - 主要关注某一个子问题
     - 请说明最核心的问题是什么

User: 是的，需要综合优化

AI: |
  ✅ 领域已确认:
  - 领域类型: 综合供应链调度 (Integrated Supply Chain Scheduling)
  - 子领域: 运输路径、库存管理、订单分配
  - 置信度: 0.95 (用户确认)

  我将采用多领域协同建模方法，确保子问题间的协调优化。
```

## 使用建议

1. **简化描述**: 用业务语言描述领域特征，避免技术术语
2. **对比呈现**: 将相似领域并列对比，突出差异
3. **典型场景**: 提供每个领域的典型应用场景帮助用户判断
4. **混合领域**: 允许用户说明是多领域混合问题
